## 摘要
循环 Transformer 在多个循环深度上复用共享块，使得自回归解码代价高昂，因为每个生成的 token 都需要许多顺序的循环前向传递。自推测解码器通过在早期深度进行草稿并在完整深度进行验证来降低这一开销，但通常将草稿计算绑定到来自同一循环深度的前缀表示。我们发现，查询和键比值更早接近其最终深度表示，并且受控的前缀通道干预表明，成熟的值能显著改善浅层草稿预测。受这种不对称性启发，我们提出了深度异步自推测（DAS），它将草稿计算的深度与其所读取的已验证前缀表示的深度解耦。其 Mature-V 原语使浅层查询无需额外的循环计算即可检索全深度前缀值。我们进一步开发了 DAS-Wave，它将深度异步前缀读取与携带式并行精化、渐进式块增长以及独立的完整深度验证器相结合。在四个循环模型检查点以及数学和代码工作负载上，DAS-Wave 在同一推理栈中相较于配对的完整深度自回归解码实现了 4.00–6.96 倍的平均吞吐量加速。这些结果将前缀信息深度确定为循环自推测的一个有效设计轴。

## Abstract
Looped Transformers reuse a shared block across recurrent depths, making autoregressive decoding expensive because every generated token requires many sequential recurrent passes. Self-speculative decoders reduce this cost by drafting at an early depth and verifying at full depth, but typically bind draft computation to prefix representations from the same recurrent depth. We find that queries and keys approach their final-depth representations earlier than values, and controlled prefix-channel interventions show that mature values substantially improve shallow draft predictions. Motivated by this asymmetry, we introduce Depth-Asynchronous Self-Speculation (DAS), which decouples the depth of draft computation from the depth of verified-prefix representations it reads. Its Mature-V primitive lets shallow queries retrieve full-depth prefix values without additional recurrent computation. We further develop DAS-Wave, which combines depth-asynchronous prefix reads with carried parallel refinement, progressive block growth, and an independent full-depth verifier. Across four recurrent-model checkpoints and mathematics and code workloads, DAS-Wave achieves 4.00--6.96$\times$ mean throughput speedup over paired full-depth autoregressive decoding in the same inference stack. These results identify prefix-information depth as an effective design axis for recurrent self-speculation.

## 1. 核心问题与整体含义

- **背景**：循环 Transformer（Looped / Recurrent-depth Transformer）通过反复应用共享块来增加有效深度，从而在不显著增加参数量的情况下提升推理时计算。但自回归解码时，每生成一个 token 都需要执行多次串行递归，导致解码延迟很高。
- **现有自推测解码的局限**：自推测解码通常用早期深度的草稿模型提出候选 token，再用全深度目标模型并行验证。但已有方法往往将草稿计算深度与其读取的前缀表示深度绑定，即浅层草稿读取的也是浅层或同深度前缀 K/V。
- **核心观察**：作者发现循环 Transformer 中注意力表示的成熟速度存在通道不对称：Query 和 Key 比 Value 更早接近最终深度表示。受控前缀通道替换实验表明，给浅层草稿提供“成熟”的 Value 可显著提升其与全深度目标的 token 一致性。
- **整体含义**：论文提出将“草稿计算深度”与“已验证前缀表示深度”解耦，把“前缀信息深度”作为循环自推测解码的一个新设计轴。这样既能保持草稿计算便宜，又能利用目标验证已物化的全深度前缀信息。

## 2. 方法论

### 2.1 核心思想

- 提出 **Depth-Asynchronous Self-Speculation（DAS，深度异步自推测）**：解耦草稿的递归计算深度与草稿所读取的已验证前缀 K/V 的递归深度。
- 关键洞察：浅层 Query 已能形成有用的注意力路由信号，但浅层 Value 内容不够成熟；因此让浅层 Query 读取全深度前缀 Value，可以在不增加草稿递归深度的前提下提升草稿质量。
- 提出 **Mature-V** 原语：训练-free，仅让浅层草稿查询读取已验证前缀的全深度 Value，不改变目标验证流程。

### 2.2 关键技术细节

- 对核心层 ℓ，设已验证前缀为 C，当前草稿侧活跃位置为 U。DAS 显式指定前缀 Key 读取深度 κ 和 Value 读取深度 ν。
- 注意力权重：
  - 将当前 Query 与前缀 Key、草稿侧 Key 拼接后计算 softmax，并加入因果掩码 M。
- 注意力输出：
  - 输出由前缀 Value 项和草稿侧 Value 项组成；只有已验证前缀的读取深度由 DAS 改变，草稿侧 K/V 始终来自当前草稿计算。
- 读深度策略构成 2×2 设计空间：
  - Aligned：κ=r，ν=r，即深度对齐读取。
  - Mature-V / Deep V：κ=r，ν=R，前缀 K 保持浅层，前缀 V 用全深度。
  - Deep K：κ=R，ν=r。
  - Deep K/V：κ=R，ν=R。
- 跨深度读取只作用于已验证前缀 token，因此其全深度表示已由目标验证物化，不需要额外递归计算。

### 2.3 DAS-Wave 解码器

- **DAS-Wave** 在 DAS 基础上结合携带式并行精化、渐进块增长和独立全深度验证器。
- 草稿侧固定使用 **Deep K/V 策略**，即已验证前缀 K/V 均读取全深度。
- 并行精化流程：
  - 以最后提交 token 为固定锚点。
  - 第 j 轮活跃宽度增长：\(W_j = \min(\gamma, W_{\text{init}} + j)\)，其中 γ 为验证器容量，\(W_{\text{init}}\) 为初始活跃宽度。
  - 活跃位置并行进行 k 次递归草稿更新，并通过移位读出更新下一个候选位置。
  - 候选 token 猜测与潜在状态分离：潜在状态跨轮携带，即使候选 token 被修正，中间计算仍保留。
  - 仅新激活位置使用检查点标准初始化。
- 独立全深度验证：
  - 目标模型对 \([x_t, y_1, \dots, y_{w-1}]\) 执行全部 R 次递归，产生移位后的下一 token 条件分布。
  - 贪心解码下按序接受与目标 argmax 一致的草稿 token；首个不匹配处输出目标预测，并丢弃剩余草稿后缀。
  - 验证器不使用携带的草稿状态，只保留被接受、已物化输入对应的全深度 K/V 作为下一轮成熟前缀缓存。
- **目标保持性**：由于只改变提案构造和前缀读取，不改变目标计算与验证规则，在精确算术下，贪心目标保持性与标准推测解码论证一致。
