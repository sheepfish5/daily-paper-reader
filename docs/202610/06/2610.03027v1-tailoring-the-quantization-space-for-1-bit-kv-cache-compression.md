## 摘要
键值（KV）缓存已成为长上下文 LLM 推理中的主要内存瓶颈，给内存容量和带宽带来巨大压力。为缓解这一瓶颈，向量量化（VQ）已成为一种有前景的激进 KV 缓存压缩方法。然而，现有 VQ 方法在 1 比特情形下性能显著下降。在如此极端的压缩下，每个码本必须用有限的一组质心来表示更大的一组通道，这使得有效利用其容量愈发困难。为解决这一问题，我们提出 TaSQ，它通过结合查询引导的通道加权、跨头归一化以及协方差感知的通道分组来定制 VQ 目标空间，以更好地反映缓存激活的误差敏感性和统计结构。由于这些变换与 RoPE 兼容，且可以轻松合并到投影权重和码本中，TaSQ 保留了传统的 VQ 查找结构，并带来可忽略的推理服务开销。在通用、长思维链推理和长上下文检索基准上，TaSQ 持续优于现有的低比特 KV 缓存 VQ 基线，同时保持推理稳定性。在单块 RTX 6000 Ada GPU 上，其 SGLang 实现相比 BF16 基线支持高达 14 倍的批大小，并实现 1.87 倍的峰值吞吐量提升。

## Abstract
The key-value (KV) cache becomes a major memory bottleneck in long-context LLM inference, placing substantial pressure on memory capacity and bandwidth. To mitigate this bottleneck, vector quantization (VQ) has emerged as a promising approach for aggressive KV cache compression. However, existing VQ methods degrade substantially in the 1-bit regime. At such extreme compression, each codebook must represent a larger group of channels with a limited set of centroids, making effective use of its capacity increasingly challenging. To address this, we introduce $\textbf{TaSQ}$, which tailors the VQ target space by combining query-guided channel weighting, cross-head normalization, and covariance-aware channel grouping to better reflect the error sensitivity and statistical structure of cached activations. Since these transforms are RoPE-compatible and can be easily merged into projection weights and codebooks, TaSQ preserves the conventional VQ lookup structure and adds negligible serving overhead. Across general, long-chain-of-thought reasoning, and long-context retrieval benchmarks, TaSQ consistently outperforms existing low-bit KV cache VQ baselines while preserving reasoning stability. On a single RTX 6000 Ada GPU, its SGLang implementation supports up to $14\times$ larger batch sizes and achieves $1.87\times$ higher peak throughput compared to the BF16 baseline.

# 论文总结：Tailoring the Quantization Space for 1-Bit KV Cache Compression（TaSQ）

## 一、核心问题与研究动机

- **背景**：长上下文 LLM 推理中，KV cache 随序列长度线性增长，且每个解码步都需重复读取，成为内存容量与带宽的核心瓶颈。
- **现有方案**：KV cache 压缩主要有 token 淘汰、缓存合并与量化三条路线，其中量化（尤其向量量化 VQ）因能联合编码多个通道、捕捉多维结构，在超低比特场景最具吸引力。
- **核心痛点**：现有 VQ 方法在 **1 比特/通道** 的极端压缩下性能显著退化。原因在于每个码本必须用有限质心表示更大的通道组，容量利用效率急剧下降。
- **两条关键洞察**（本文立论基础）：
  1. 不同 key 通道的重建误差对注意力 logits（QK^⊤）的影响**不均衡**——误差会被对应 query 激活放大；
  2. VQ 只有在**相互依赖的通道被分到同一码本组**时，才能利用通道间依赖结构。
- **整体含义**：作者主张不应在原生 key 空间直接做 VQ，而应"定制"一个能反映误差敏感性与统计结构的量化目标空间，从而在 1-bit 下同时保住精度、推理稳定性与服务水平。

## 二、方法论

### 核心思想
通过三种可离线合并的线性变换（通道加权、归一化、通道置换分组）重塑 key 的 VQ 目标空间，使欧氏距离下的 VQ 重建误差更贴近对注意力输出的真实影响，同时保留标准 VQ 查表结构与零运行时开销。

### 关键技术细节

- **1. 查询引导的通道加权（Query-Guided Channel Weighting）**
  - 定义 key 量化误差 δ，推导 QK^⊤ 平方误差为二次型 δ^⊤ A δ，其中 A = R_p^⊤ q̄ q̄^⊤ R_p 依赖 query 与位置。
  - 对校准集上所有因果有效 query–key 对取期望，并用其**对角近似**得通道权重 W_h = diag(Ã_h)。
  - 变换 k^w = W_h^{1/2} k，使加权空间中的欧氏 VQ 误差直接等价于 QK^⊤ 误差的代理指标。
  - 选择对角近似而非稠密矩阵，是为避免每步对缓存 key 做 d×d 乘法（实测在 16k 上下文时稠密恢复开销达注意力耗时的 103%）。

- **2. 跨头共享尺度归一化（Cross-Head Shared-Scale Normalization）**
  - 借鉴 NSNQuant 的 token-wise 归一化抑制离群 token，但将原方法的**逐头 scale** 改为**全部 KV 头共享一个 RMS scale** s_p。
  - 元数据成本从 b_s/d 降至 b_s/(Hd)，节省的比特可回投给码本索引（扩大 K）。

- **3. 协方差感知的通道分组（Covariance-Aware Grouping）**
  - 在校准集估计加权归一化后 key 的协方差 Σ^wn_h。
  - 定义组代价 c_h(G) = det(Σ^wn_h[G,G] + εI)^{1/|G|}，依据高斯模型下 VQ 率失真理论 D_G ∝ K^{−2/|G|} det(Σ)^{1/|G|}。
  - 求解等大小、**保持 RoPE 配对完整**的分组划分问题，采用**层次最小权完美匹配**近似求解（每轮精确配对当前组，重复至组内达 g 通道）。
  - 得到置换矩阵 P_h，把每组通道排成连续块：k^wnp = P_h W_h^{1/2} k / s_p。

- **4. 定制空间中的码本拟合与运行时重构**
  - 对每个 (layer, KV head, channel group) 拟合 K 质心码本，并采用 **Fisher 加权 k-means**（按通道组汇总对角经验 Fisher 权重 ω），让对损失更敏感的校准 token 获得更高权重。
  - 运行时把加权与置换**吸收进 key 投影矩阵**（W̃_K,h = P_h W_h^{1/2} W_K,h），把逆变换吸收进解码码本；query 投影同样置换（W̃_Q,h = P_h W_Q,h），RoPE 旋转矩阵变为 R̃_p = P_h R_p P_h^⊤，仍保持标准块对角结构，只需重排 RoPE 频率。
  - 注意力核内融合码字查表、scale 恢复、逐对 RoPE 与点积，**无需运行时通道重排、稠密变换或额外 kernel**。

- **5. Value 路径**：保持标准连续分组 VQ。因实验显示 value 的通道敏感度更均匀（CV 0.176 vs key 0.841）、通道间相关性更弱（0.067 vs 0.136），定制收益有限。

## 六、主要结论与发现

- **精度**：TaSQ 在通用、长 CoT 推理、长上下文检索三类任务上**一致优于** CQ / NovaKV / NSNQuant，最接近 BF16。推理任务提升尤为明显（如 Qwen3-4B-Thinking 平均 60.55 vs 基线最高 46.67）；检索任务随上下文增长退化最小（Llama-3.1-8B 在 64k 仍达 93.17，而 NovaKV 仅 1.83）。
- **NovaKV 的反常现象**：通用任务尚可，但长上下文急剧崩溃；作者通过位置泛化分析指出其 post-RoPE 拟合对超出校准范围的位置分布漂移敏感。
- **消融结论**：三个组件均有贡献，其中**去掉协方差感知分组导致 PPL 增幅最大**（8.46 → 10.17），说明分组贡献最大。
- **加权近似的选择**：对角加权在校准集上误差略高，但在 GSM8K 上误差约为稠密加权的 1/4，且无运行时开销。
- **效率**：KV cache 池从 235,257 扩展到 2,935,184 tokens（**12.48×**），最大批大小从 6 提升到 84（约 **14×**），峰值吞吐从 220.8 提升到 412.6 tok/s（**1.87×**）。Prefill 阶段 VQ 编码使 TTFT 增加 10–14%，但在长生成中可摊薄。
- **推理稳定性**：TaSQ 的生成长度与 32k 截断命中率接近 BF16，避免了低比特方法常见的重复/不收敛生成。

## 七、优点

- **洞察驱动、动机清晰**：从"误差敏感性不均"和"VQ 只能利用同组通道依赖"两条第一性观察出发，方法设计有明确理论依据（率失真理论、Fisher 加权）。
- **工程友好性突出**：仅用通道缩放 + 置换（无稠密旋转），且全部可离线合并进投影权重与码本，保持标准 VQ 查表结构，运行时零额外开销——这是相对 NovaKV 稠密变换路线的关键优势。
- **RoPE 兼容性处理优雅**：分组约束保持 RoPE 配对完整，使置换后的旋转矩阵仍是标准块对角，只需重排频率。
- **元数据成本意识强**：跨头共享 scale 把归一化开销降低 H 倍，并把节省比特回投给码本容量，体现比特预算的精细权衡。
- **实验维度完整**：不止报精度，还给出服务吞吐、TTFT、生成长度分布、位置泛化、对角近似的误差–开销权衡，兼顾算法与系统两侧。
- **诚实报告局限**：明确说明 value 路径未做定制、校准集有限、NovaKV 配置为自行匹配。

## 八、不足与局限

- **Value 路径未优化**：作者仅保留连续分组 VQ，虽然 value 侧变换消融只有 0.42% 的 PPL 改善，但作者也承认这可能是设计未充分探索，留作未来工作。
