## 摘要
推测解码通过使用轻量级草稿模型提出多个 token，并由目标模型并行验证，从而加速自回归生成。然而，标准接受规则侧重于精确分布校正，当草稿模型赋予过高概率时，会拒绝那些在目标模型下仍然高度合理的 token。这种保守验证限制了每次验证前向传播后保留下来的草稿 token 数量。我们提出 Nucleus 推测解码（NSD），一种将目标模型合理性纳入推测解码的松弛验证方法。如果草稿 token 满足标准接受规则，或属于目标模型的 nucleus，NSD 就接受该 token。我们从理论上刻画了该方法引入的分布偏差，并表明单步误差恰好由草稿模型在目标 nucleus 内的超额概率决定。我们进一步推导了序列级保真度上界，量化局部偏差如何在自回归解码中累积。在多个目标模型和提议机制上的实验表明，NSD 在保持有竞争力的任务性能的同时，持续提升推测解码效率。我们的方法相比自回归解码实现了最高 5.16 倍的吞吐量加速，相比标准推测解码实现了最高 3.15 倍的吞吐量加速。这些提升伴随着更长的接受长度，使更多输出 token 能够分摊每次目标验证前向传播的成本。分析表明，合理性感知验证为松弛验证和推测解码效率提供了一种有效方法。我们的代码可在 https://github.com/EIT-NLP/Nucleus-Speculative-Decoding 获取。

## Abstract
Speculative decoding accelerates autoregressive generation by using a lightweight draft model to propose multiple tokens that are verified by a target model in parallel. However, the standard acceptance rule focuses on exact distribution correction and rejects tokens that remain highly plausible under the target model when the draft model assigns excess probability. This conservative verification limits the number of draft tokens retained after each verification forward pass. We introduce Nucleus Speculative Decoding (NSD), a relaxed verification method that incorporates target-model plausibility into speculative decoding. NSD accepts a draft token if it satisfies the standard acceptance rule or belongs to the target model's nucleus. We theoretically characterize the distributional deviation introduced by our method and show that the single-step error is exactly determined by the draft model's excess probability within the target nucleus. We further derive sequence-level fidelity bounds that quantify how local deviations accumulate over autoregressive decoding. Experiments across multiple target models and proposal mechanisms demonstrate that NSD consistently improves speculative decoding efficiency while maintaining competitive task performance. Our method achieves throughput speedups of up to $5.16\times$ over autoregressive decoding and up to $3.15\times$ over standard speculative decoding. These improvements coincide with longer accepted lengths, allowing more output tokens to share the cost of each target verification pass. Analysis shows that plausibility-aware verification provides an effective approach for relaxed verification and speculative decoding efficiency. Our code is available at https://github.com/EIT-NLP/Nucleus-Speculative-Decoding.

# 论文总结：Nucleus Speculative Decoding（NSD）

## 1. 核心问题与整体含义

- **背景**：大语言模型（LLM）的自回归解码（AR）本质串行、开销高。推测解码（Speculative Decoding, SD）用轻量草稿模型一次提议多个 token，再由目标模型并行验证，以加速生成。
- **核心痛点**：标准 SD 的接受规则为 $\min\{1, p(x)/q(x)\}$，关注的是“精确分布校正”，而非 token 在目标分布下的合理性。当草稿模型赋予某 token 过高概率（$q(x)>p(x)$）时，即便该 token 在目标模型下排名很高，也会被拒绝。
- **实证观察**：
  - 目标验证占端到端墙钟时间的 57.1%–78.1%，是主要瓶颈。
  - 被拒 token 中 81.5% 仍位于目标模型 top-10；在 Top-P=0.95 时，52.6% 的被拒 token 仍属于目标 nucleus。
- **整体含义**：这种保守验证限制了每次验证后保留的 token 数。论文提出一种“合理性感知”的松弛验证方法，在可控分布偏差下换取更高接受长度与吞吐。

## 2. 方法论：Nucleus Speculative Decoding

- **核心思想**：在标准随机接受规则之外，增加一条基于目标模型 nucleus 的接受条件——若草稿 token 属于目标分布的高概率 nucleus，则接受；不修改提议机制、残差校正和 bonus 采样。
- **关键定义**：
  - 目标 nucleus：$S_i(\theta)=\{v_{i,(1)},\dots,v_{i,(k_i(\theta))}\}$，其中 $k_i(\theta)=\min\{k:\sum_{j=1}^{k}p_i(v_{i,(j)})\ge\theta\}$。
  - NSD 接受指示：$b_i=\mathbf{1}\{u_i\le a_i^{SD}(x_i)\ \lor\ x_i\in S_i(\theta)\}$，即“标准接受 或 落入目标 nucleus”。
  - 不对 $p_i$、$q_i$ 在 nucleus 内重新归一化。
- **算法流程（单次验证循环）**：
  1. 草稿模型生成 $x_{1:K}$，保留实际条件提议分布 $q_{1:K}$；
  2. 目标模型一次前向计算 $p_1,\dots,p_{K+1}$；
  3. 逐位置构造 $S_i(\theta)$，采样 $u_i$，计算 $a_i^{SD}$；
  4. 若 $u_i\le a_i^{SD}$ 或 $x_i\in S_i(\theta)$，接受并继续；否则从残差分布 $\rho_i(v)\propto[p_i(v)-q_i(v)]^+$ 重采样并返回；
  5. 若全部接受，则从 $p_{K+1}$ 采样 bonus token。
- **理论刻画**：
  - 定义拒绝概率 $R=D_{TV}(q,p)=\sum_v[q(v)-p(v)]^+$，以及草稿在目标 nucleus 内的超额概率 $E_S=\sum_{v\in S}[q(v)-p(v)]^+$。
  - 单步输出分布偏差满足：$D_{TV}(\tilde p,p)=E_S=\bar a_{NSD}-\bar a_{SD}\le R$。即“额外接受的质量恰好等于单步分布偏差”。
  - 当且仅当 $E_S=0$（即 $S$ 内处处 $q\le p$）时，NSD 单步精确等价于目标分布；$S=\emptyset$ 退化为标准 SD。
  - 序列级保真度：若每步 $D_{TV}(K_t,p_t)\le\epsilon_t$，则 $D_{TV}(P^{(T)}_{NSD},P^{(T)}_p)\le 1-\prod_{t=1}^T(1-\epsilon_t)$；均匀界下耦合一致概率 $\ge(1-\epsilon)^T\ge 1-T\epsilon$。

## 6. 主要结论与发现

- **吞吐提升**：NSD 在所有对比中取得最高加速比，相对 AR 最高 **5.16×**，相对标准 SD 最高 **3.15×**；30 组配对比较平均提升约 **323.0%（对 AR）** 和 **84.98%（对 SD）**。
- **接受长度增加**：各模型 $\tau$ 均上升，例如 Nemotron-3B/8B/14B 整体 $\tau$ 从 SD 的 6.29/4.98/4.67 提升到 9.54/11.82/11.54；Qwen3 系列从约 5.4 提升到约 6.6。
- **任务性能**：30 组比较中 15 胜、1 平、14 负，平均准确率高 **0.40 个百分点**；差异范围 −1.58 至 +4.14 个百分点。Qwen3-4B 出现准确率下降但加速提升的权衡。
- **效率来源**：验证调用次数每输出 token 从 0.1600 降到 0.0835（减少 47.81%），验证时间从 5.26 ms 降到 2.72 ms（减少 48.3%）；单次目标调用耗时几乎不变，说明收益来自“每次验证摊薄到更多 token”。
- **机制分析**：额外接受的 token 中 86.65% 位于 nucleus 核心，72.9% 在目标 top-2，94.1% 在 top-5，98.5% 在 top-10，说明松弛主要保留高合理性的 token。
- **消融结论**：增大 $K$ 通常提升吞吐与 $\tau$，但存在边际递减；$\theta$ 的影响依模型与任务而异，不单调，需联合调参。

## 7. 优点

- **方法简洁、训练无关**：仅增加一条基于目标概率的接受条件，不改变残差校正与 bonus 采样，可直接与多种草稿机制（DSpark、DFlash、EAGLE-3、MTP、自推测）组合。
- **理论清晰**：给出单步偏差的精确恒等式 $D_{TV}(\tilde p,p)=E_S$，并进一步推导序列级耦合上界，明确刻画“额外接受”与“分布偏差”的等价关系。
- **实证分析深入**：不仅报告加速比，还从熵、rank、nucleus 位置、验证调用次数等角度解释收益来源。
- **实验覆盖较广**：跨 Nemotron/Qwen 家族、多规模、多基准、多提议机制，并包含消融与附加机制验证。

## 8. 不足与局限

- **模型规模受限**：受硬件与 checkpoint 可用性限制，实验集中在较小模型（最大 14B），未验证更大模型上的可扩展性。
- **质量-效率权衡**：任务性能并非一致提升，部分设置（如 Qwen3-4B）准确率下降；$\theta$ 需按模型与任务调节，缺少自适应选择策略。
- **理论假设较强**：序列级保真度界依赖条件核假设，需包含提议选择、恢复、bonus 采样与解码器状态；论文也承认诊断平均值不能直接提供均匀误差界，并非所有实现都能保证该界成立。
- **加速比表述需注意**：摘要中“最高 3.15× over SD”与正文平均提升 84.98% 的表述口径不同，读者需区分“最高值”与“平均值”。
- **实验噪声与公平性**：AIME 样本量小；部分附加机制运行条件未完全受控（如 DFlash 某 seed 异常缓慢）；不同基线的实现细节差异可能影响对比公平性。
- **应用限制**：NSD 放弃严格精确分布保证，对分布保真度要求极高的场景需谨慎；nucleus 阈值 $\theta$ 的敏感性带来额外调参成本。
