## 摘要
网格编码量化能够以超低比特宽度对大语言模型（LLM）权重进行高维压缩，而无需传统向量量化所需的指数级大规模码本。然而，实际部署面临两个挑战：以足够的并行吞吐量重建压缩权重，以避免反量化成为推理瓶颈；以及在不进行昂贵的非相干变换的情况下保持量化精度。我们通过两项互补技术来应对这些挑战。首先，我们提出一种超低复杂度的网格反量化器，它采用结构化且硬件高效的状态到值映射，同时为网格搜索保留多样的重建选择。其次，我们用曲率感知目标重新表述离散网格路径优化，该目标直接在原始坐标空间中反映模型敏感性。这些技术共同实现了高质量的极低比特网格量化，其运行时重建成本低廉且高度并行，并且不依赖基于 Hadamard 的非相干处理。

## Abstract
Trellis-coded quantization enables high-dimensional compression of large language model (LLM) weights at ultra-low bit widths without the exponentially large codebooks required by conventional vector quantization. Practical deployment, however, presents two challenges: reconstructing compressed weights at sufficient parallel throughput to avoid making dequantization an inference bottleneck, and maintaining quantization accuracy without costly incoherence transformations. We address these challenges with two complementary techniques. First, we introduce an ultra-low-complexity trellis dequantizer that uses a structured, hardware-efficient state-to-value mapping while preserving diverse reconstruction choices for trellis search. Second, we reformulate discrete trellis path optimization with a curvature-aware objective that reflects model sensitivity directly in the original coordinate space. Together, these techniques enable high-quality ultra-low-bit trellis quantization with inexpensive, highly parallel runtime reconstruction and without relying on Hadamard-based incoherence processing.

# XOR-Trellis 论文中文总结

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：LLM 推理受存储与内存带宽约束，权重仅后训练量化（PTQ）尤为关键。超低位宽下精度难以保持。
- **Trellis 编码量化（TCQ）的优势**：通过有限状态路径耦合量化决策，只存低位分支即可实现远超传统 VQ 的等效维度，避免码本指数膨胀。QTIP 已将 TCQ 用于 LLM 超低位宽量化。
- **两大部署瓶颈**：
  - **反量化吞吐瓶颈**：压缩权重在推理时需实时还原。若每权重重建算术过重（如 QTIP 的 3INST 约需等价 12 次 32 位加减、掩码/XOR 逻辑及 FP16 加法，约 3–5k 门规模），会成为带宽收益的抵消项，无法跟上 GPU/NPU/向量 CPU 的并行权重消费速率。
  - **非相干变换依赖**：主流超低位宽方法（QTIP、QuaRot、SpinQuant）依赖随机 Hadamard 变换（RHT）或学习旋转来展平离群值与敏感方向，但不可吸收的旋转会引入运行时开销。
- **关键洞察**：RHT 之所以有帮助，部分原因是它掩盖了**二阶 PTQ 的模型感知目标**与**离散 trellis 路径搜索的各向同性欧氏失真**之间的目标错配。因此，与其变换表示，不如让搜索目标本身反映曲率。
- **整体含义**：提出硬件–算法协同设计的 XOR-Trellis，同时实现（1）超低复杂度、可高度并行的反量化器；（2）无需 Hadamard 的曲率感知 trellis 路径优化。

## 2. 方法论

### 2.1 XOR-Trellis FP4 反量化器

- **设计目标**：状态到数值映射既要足够丰富以保持 trellis 搜索精度，又要足够简单以支持高吞吐并行重建。避免大状态查找表，也避免昂贵计算码。
- **Trellis 结构**：K=2 bitshift trellis，16 位状态 = 14 位历史 h + 2 位当前分支 b；历史作为滑动记忆耦合相邻决策。
- **局部重建调色板**：对固定历史 h，四个分支定义四个可选重建值。设计围绕条件调色板几何，而非仅匹配全局输出直方图。
- **四个 FP4 调色板**：
  - P0 = [−6, −1.5, 0, 2]
  - P1 = [−4, −1, 0.5, 3]
  - P2 = [−3, −0.5, 1, 4]
  - P3 = [−2, 0, 1.5, 6]
  - 每个调色板四值互异、跨正负与近零区，最小间距 1.5；每个 14 位历史都暴露四个分离良好的选择。
- **理论支撑**：在固定 16 个 FP4 载荷、四个不相交四元调色板、均匀调色板使用与标量平方误差下，上述“秩交错模四”调色板对任意标量目标 x 达到单步最近距离的**逐点最优**；同时达到最大可能的调色板内最小间距 1.5。随机分配四个有序层全部出现的概率仅 4!/4⁴ = 9.375%，说明结构化分层可保留全局分布并强制局部覆盖。
- **XOR 映射**：四个掩码奇偶函数从历史产生 p0,p1,q0,q1：
  - p = p0|(p1≪1)，b′ = b ⊕ (q0|(q1≪1))，ŵ = P_p[b′]
  - 掩码为 {0x1089, 0x2112, 0x0A24, 0x2441}
  - 第一对决定激活哪个调色板，第二对置换分支身份到调色板条目的映射。
- **秩理论**：由于映射在 F₂ 上线性，可用二元秩条件精确检测退化。若 rank₂(A)=2 则调色板均匀；相邻调色板对全部 16 种等概率出现当且仅当 rank₂(E₂)=4；更长的 w 步窗口要求 rank₂(E_w)=2w。秩亏暴露确定性奇偶约束。这些是**拒绝准则**而非最优性定理，最终掩码选择仍需在真实 trellis 记忆与编码时域下用留出全路径失真评估。
- **硬件实现**：预查找逻辑约 14 个 XOR2 门，加两次 XOR 做分支置换，再索引固定 4×4 FP4 调色板查找。无乘法器、旋转或通用算术。512 权重/周期实现用 N3P 标准单元综合仅占 1,917 μm²，可宽并行复制以匹配高吞吐权重消费。
- **状态利用与路径混合**：穷举 2¹⁶ 状态显示翻转任一位都改变数值；相邻转移的带符号与绝对值线性相关均为 0.000000。全局重建分布均值 0、标准差 2.9262、均值绝对值 2.25，P(|q|≥4)=25%，P(|q|=6)=12.5%。

### 2.2 曲率感知 Trellis 路径优化（无 RHT）

- **目标错配**：二阶 PTQ 最小化模型感知二次代理 L_Q(e) ∝ eᵀHe，而传统 Viterbi 最小化各向同性欧氏距离 Σ(z_i − ẑ_i(π))²。欧氏等误差在模型影响上可能差异巨大。
- **LDL 分解**：H = LDLᵀ，eᵀHe = (Lᵀe)ᵀD(Lᵀe) = rᵀDr = Σ D_ii r_i²。L 捕获坐标间交互，D 描述交互后剩余误差方向的相对代价。
- **曲率感知 Viterbi 目标**：
  - π_D = arg min_π Σ D_ii (z_i − ẑ_i(π))²
  - 等价于每个残差先乘以 √D_ii 再累积平方失真。
  - 直观例子：|e_i|=|e_j|=0.1 但 D_ii = 8D_jj 时，曲率感知目标给前者 8 倍代价，鼓励 trellis 保护更敏感方向。
  - 仅对现有分支失真做标量加权；状态空间、分支结构、存活路径数、压缩表示与渐近 Viterbi 复杂度均不变。
- **RHT 作为条件化 vs 曲率感知作为替代**：
  - RHT：改变表示使各向同性路径度量更合适。
  - 本文：保留表示，使路径度量反映其曲率。
  - 若 D = αI，两者最小化子完全相同。欧氏代理质量由对角各向异性 κ_D = D_max/D_min 控制，近似在各向同性附近最紧，随 D 的分散度增大而变弱。
  - 路径级近似界：L_D(π_E) ≤ κ_D L_D(π_D)。
  - 实验采用混合策略：无 RHT 时用 D 加权，有 RHT 时用无权欧氏（因为 RHT 已条件化问题）。
- **能量排序**：按特征块聚合曲率 E_b = tr(H_Bb,Bb) = Σ_{i∈Bb} H_ii 降序处理特征块，让最敏感方向先进入 LDLQ 递归，后续块可通过 L 的三角反馈补偿先引入的误差。排序与 D 加权互补，完全离线，不需额外比特或修改运行时解码器。
- **离线与在线分离**：D 仅用于离线 Viterbi 分支打分，不存入部署比特流，运行时解码器不变。
