## 摘要
大型语言模型的服务成本日益高昂。在大规模服务系统中，自回归解码常常受限于将模型权重从加速器高带宽内存传输到片上 SRAM。专家混合（MoE）模型通过每个 token 仅激活一小部分专家来减少计算，但这种稀疏性并不能直接转化为批处理解码的效率。不同请求会选择不同专家；因此，许多并发请求的合并活跃集可能覆盖专家池的相当大一部分，并需要传输显著更多的专家权重。大多数专家削减技术对每个 token 独立做出保留决策，因此无法解决这种批级扩展问题。最近，批感知方法尝试协调并发请求间的专家使用，并复用已为批次获取的专家。然而，其选择标准主要基于路由器排名或校准期间收集的专家统计信息。因此，这些标准与丢弃某个专家所导致的输出误差没有直接关联，也无法刻画推理时专家贡献如何随 token 变化。我们改为根据移除专家会在多大程度上改变 MoE 层输出来对专家排序。为了在服务期间应用这一准则，我们在校准期间训练一个轻量级线性预测器，用于估计每个输入 token 的专家移除代价，并开发用于代价预测和专家选择的自定义 GPU 内核。在三种 MoE 架构上，BASE 无需重新训练即可改善质量-效率权衡。在 Qwen3-30B-A3B 上，在严格专家预算下，在吞吐量相当的情况下，它相比最强基线将平均准确率提高 29.5 个百分点。在更高的专家预算下，它比密集推理快 60%，同时准确率差距保持在 0.4 个百分点以内。

## Abstract
Large language models are increasingly expensive to serve. In large-scale serving systems, autoregressive decoding is often bottlenecked by transferring model weights from accelerator high-bandwidth memory into on-chip SRAM. Mixture-of-experts (MoE) models reduce computation by activating only a small subset of experts per token, but this sparsity does not translate directly to batched decoding. Different requests select different experts; therefore, the combined active set across many concurrent requests can span a substantial fraction of the expert pool and require significantly more expert weights to be transferred. Most expert-reduction techniques make retention decisions independently for each token and therefore do not address this batch-level expansion. More recently, batch-aware methods have attempted to coordinate expert use across concurrent requests and reuse experts already fetched for the batch. Yet their selection criteria are based primarily on router rankings or expert statistics collected during calibration. Consequently, these criteria are not directly tied to the output error caused by dropping an expert, nor do they capture how an expert's contribution changes across tokens at inference time. We instead rank experts according to how much their removal would change the MoE-layer output. To apply this criterion during serving, we train a lightweight linear predictor during calibration that estimates the expert removal cost for each incoming token, and develop custom GPU kernels for cost prediction and expert selection. Across three MoE architectures, BASE improves the quality-efficiency tradeoff without retraining. On Qwen3-30B-A3B, it improves average accuracy by 29.5 points over the strongest baseline at comparable throughput under a tight expert budget. At a higher expert budget, it is 60% faster than dense inference while remaining within 0.4 accuracy points.

# BASE：利用预测移除误差进行批感知专家选择以实现高效 MoE 解码

## 1. 核心问题与研究动机

- **背景**：大模型自回归解码在服务系统中受内存带宽约束，主要开销来自把模型权重（含专家权重）从 HBM 搬到片上 SRAM；MoE 虽然每 token 只激活少量专家，但**稀疏性是 token 级定义的，而服务成本是 batch 级产生的**。
- **核心矛盾**：一个解码步内，batch 中每个请求各选各的专家，其并集 $A_\ell$ 可能覆盖专家池的很大比例。层延迟近似为 $T_\ell \approx \tau_{fetch}|A_\ell| + \tau_{comp}\sum_t |R'_t|$，在内存受限区第一项主导，因此**延迟由 batch 级活跃集大小决定，而非单 token 的稀疏度**。
- **已有方法的缺陷**：
  - 逐 token 削减（剪枝/合并、自适应执行）不解决 batch 级膨胀。
  - 批感知方法 SERE、OEA 以各 token 路由并集构造活跃集，单个 token 就能把专家拉进集合；Lynx 用路由置信度与批内流行度，但不估计移除专家的输出变化。
  - 最接近的 ExFold 使用**校准期测得的固定专家输出范数** + 固定 batch 预算，无法刻画专家贡献在推理时随 token 的变化。
- **核心研究问题**：*在固定 batch 专家预算 $|A_\ell| \le M$ 下，应抓取哪些专家才能最小化 MoE 层输出的变化？*

## 2. 方法论

### 2.1 问题形式化

- MoE 层输出 $y_t = \sum_{u \in R_t} w_{t,u} E_u(z_t)$，权重贡献记为 $a_{t,u} \triangleq w_{t,u}E_u(z_t)$，被省略专家集合 $U_t = R_t \setminus A_\ell$。
- 精确 batch 输出误差：
  $$E(A_\ell) = \sum_t \left\|\sum_{u \in U_t} a_{t,u}\right\|_2^2 = \underbrace{\sum_t\sum_{u\in U_t}\|a_{t,u}\|_2^2}_{\text{个体损伤}} + \underbrace{2\sum_t\sum_{u<v}\langle a_{t,u},a_{t,v}\rangle}_{\text{交叉项}}$$
- 单专家移除代价（跨 batch 聚合）：$D_u \triangleq \sum_{t: u\in R_t} w_{t,u}^2 \|E_u(z_t)\|_2^2$。

### 2.2 关键分析：交叉项可安全丢弃

- **共路由专家输出近乎正交**：加权平均 |cos| 仅 0.045 / 0.040 / 0.043（三个模型）。
- **交叉项偏差小且可预测**：定义精确/加性误差比 $\rho_t$，推导出恒等式 $\rho_t - 1 = \bar c_t\,(|U_t|_{\text{eff}} - 1)$，每模型只需一个拟合常数（0.021 / 0.026 / 0.032），拟合曲线与实测均值误差 < 0.65%。
- **对选择结果影响可忽略**：在 $M=12$ 下比较加性选择与考虑交叉项的贪心选择，精确误差比在 95 分位仅为 **1.018 / 1.025 / 1.032**，即丢弃交叉项只带来 ≤3.2% 的额外误差。
- **替代（substitution）不可行**：用活跃专家 $v$ 替代 $u$ 优于直接丢弃的条件约为 $c_{t,uv} > 1/2$，远高于实测相似度，因此 SERE 式的"相似专家替换"假设不成立。

### 2.3 移除代价预测器

- 无法在抓取前得到 $\|E_u(z_t)\|_2^2$，故用**轻量线性预测器**：
  $$\hat s_u(z) = a_u^\top \bar z + b_u,\quad \bar z = z/\|z\|_2,\quad \hat e_u(z) = \exp(\hat s_u(z)),\quad \hat D_u = \sum_{t:u\in R_t} w_{t,u}^2 \hat e_u(z_t)$$
- 目标为 $s_u(z) = \log(\|E_u(z)\|_2^2 + \epsilon)$；按专家独立用**岭回归闭式解**拟合（centered Gram + 交叉矩，25 个 $\lambda$ 通过边际似然逐专家选择），并对指数化带来的偏差做专家级修正，折叠进部署截距。
- 每个预测器只依赖自身 layer–expert 的充分统计量，可跨层/专家并行校准。
