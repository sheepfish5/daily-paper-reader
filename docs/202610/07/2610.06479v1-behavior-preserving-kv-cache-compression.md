## 摘要
KV 缓存是大语言模型长上下文推理和长文本生成中的主要瓶颈。现有的免训练淘汰策略大多依赖代理重要性信号（例如注意力质量）来决定保留哪些历史 token。我们认为，缓存压缩应当转而保持完整缓存模型的预测行为，即保留那些一旦移除就会显著改变模型输出分布的条目。我们提出行为保持型 KV 缓存压缩（Behavior-Preserving KV Cache Compression），一种免训练框架，通过估计移除候选条目所诱导的压缩缓存 logits，并评估其与完整缓存下一 token 分布之间的 KL 散度，来为候选淘汰项打分。该方法利用淘汰前的前向统计量，避免为每个候选条目分别运行掩码前向传播。在多种架构以及预填充时和生成时压缩下，我们的方法在相同的保留 KV 预算下，相比轻量级基于注意力的启发式方法，在下游任务质量上取得显著提升，并且在激进压缩下提升最大。它通过额外的压缩时计算实现这些提升，同时在我们评估的设置中仍保持相对于完整缓存推理的端到端加速。

## Abstract
KV caches are a major bottleneck in long-context inference and long-form generation with large language models. Existing training-free eviction policies largely rely on proxy importance signals, such as attention mass, to decide which past tokens to retain. We argue that cache compression should instead preserve the predictive behavior of the full-cache model, retaining entries whose removal would substantially change the model's output distribution. We propose Behavior-Preserving KV Cache Compression, a training-free framework that scores candidate evictions by estimating the compressed-cache logits induced by their removal and evaluating the resulting KL to the full-cache next-token distribution. Using pre-eviction forward statistics, the method avoids running separate masked forward passes for each candidate. Across diverse architectures and both prefill-time and generation-time compression, our method delivers substantial gains in downstream task quality over lightweight attention-based heuristics at matched retained-KV budgets, with the largest gains under aggressive compression. It achieves these gains with additional compression-time computation while retaining an end-to-end speedup over full-cache inference in our evaluated settings.

# Behavior-Preserving KV Cache Compression 论文总结

## 1. 核心问题与研究动机

- **背景**：LLM 自回归解码依赖 KV 缓存避免重复计算，但缓存随序列长度线性增长，成为长上下文推理与长文本生成的主要内存与注意力计算瓶颈。
- **现有做法**：免训练（training-free）缓存压缩通过推理时统计量决定淘汰哪些 KV 条目，主流方法依赖**代理重要性信号**：
  - 注意力质量 / 重击者（H2O、SnapKV、PyramidKV）；
  - 未来注意力估计（Expected Attention）；
  - 上下文重构效用（KVzip）；
  - 注意力输出误差（CAOTE）；
  - 重要性–冗余权衡（R-KV）。
- **核心论点**：代理目标与"淘汰对预测的实际影响"并不一致——注意力会高估冗余条目，重构效用偏向恢复上下文而非保持下一 token 分布。
- **本文主张**：缓存压缩的目标应是**保持全缓存模型的预测行为**，即保留那些一旦移除就会显著改变模型输出分布的条目；并以此重构免训练压缩问题。

## 2. 方法论

### 2.1 行为保持目标

- 以未来续写分布的自回归 KL 为理想目标，利用链式法则可知：**下一 token 的 KL 是长程行为差异的第一项**，也是压缩时唯一可观测的部分（其余项依赖未来 token 与未来查询状态）。
- 定义压缩时可用查询位置集合 $\mathcal{T}$ 上的目标：
  $$J(d)=\frac{1}{|\mathcal{T}|}\sum_{t\in\mathcal{T}} D_{\mathrm{KL}}\big(p_t \,\|\, q_t^{(d)}\big),\quad q_t^{(d)}=\mathrm{softmax}(z_t+\Delta z_{t,d})$$
  其中 $d$ 为层–token 保留掩码（层内跨 KV 头共享）。
- 直接求 $\Delta z_{t,d}$ 需对每个候选掩码做前向，代价不可接受，因此改为**用淘汰前向统计量估计**。

### 2.2 从 KV 淘汰到层扰动

- 采用**删除反事实**：固定淘汰前的 query/key/value，删除被掩码条目并对保留条目重新归一化注意力。
- 单头扰动为"重归一化后的保留贡献 − 全缓存贡献"，等价形式为
  $$\Delta o_{\ell r t}(d_\ell)=\frac{\sum_j \bar d_{\ell j} a_{\ell r t j}\big(o_{\ell r t}-\tilde v_{\ell r j}\big)}{1-A_{\ell r t}(d_\ell)}$$
  其中 $\bar d$ 为淘汰指示、$A$ 为被移除注意力质量。
- 对头求和得到该层注意力块注入残差流的扰动 $\Delta u_{\ell t}(d_\ell)=\sum_r \Delta o_{\ell r t}(d_\ell)$。

### 2.3 从层扰动到 logits

- 对最终归一化与 LM head 做一阶展开：$\Delta z_{t,d}\approx W J_t \Delta x^L_{t,d}$，$J_t=\nabla N_f(x^L_t)$。
- 用**直接残差路径近似**估计最终状态扰动：$\widehat{\Delta x^L_{t,d}}=\sum_{\ell=1}^{L}\Delta u_{\ell t}(d_\ell)$，即只保留注意力块直接写入残差流的分量，后续层响应作为近似误差。
- 得到估计 logits $\hat z_{t,d}=z_t+\widehat{\Delta z_{t,d}}$，代入 KL 得到实用评分
  $$\hat J(d)=\frac{1}{|\mathcal{T}|}\sum_{t}D_{\mathrm{KL}}\big(p_t\,\|\,\hat q_t^{(d)}\big)$$

### 2.4 预算约束下的掩码选择（两阶段贪心）

- 目标是选定 $B$ 个淘汰条目，但淘汰代价**非可加**（重归一化与分布变化相互耦合），全局搜索不可行。
- **第一阶段（候选池）**：用单条目（singleton）淘汰的 KL 评分，取最低的 $\lceil \alpha B\rceil$ 个组成候选池。
- **第二阶段（精炼）**：从空集开始，每轮评估候选加入当前多条目掩码后的**边际 KL 代价**，加入代价最小的 $\min(b_{\text{ref}}, B-|M|)$ 个，并更新缓存统计，直到选满 $B$ 个。
- **工程细节**：
  - 只对 $\mathcal{T}$ 位置重算注意力行（存储 $H\times|\mathcal{T}|\times S$），而非完整注意力图；投影值按候选 chunk 即时计算并释放。
  - RMSNorm 的 Jacobian-向量积有闭式解；无最终归一化的模型取 $J_t=I$。
  - KL 在**全缓存分布的 top-$K$ 支撑**上计算（log-sum-exp 数值稳定），$K$ 为全词表时退化为原始式。
  - 数值稳定性：若某位置/层/头的保留注意力质量低于阈值 $\epsilon$ 则拒绝该候选；GQA/MQA 下按 query 头计算、掩码层内共享。
  - 超参（各 regime 固定，不按 benchmark 调）：prefill $m=4,K=128,\alpha=2,b=512$；generation $m=4,K=256,\alpha=2,b=256$，触发间隔 $I_{\text{comp}}=512$，近期保护窗 4。

## 6. 主要结论与发现

- 以**输出分布扰动**而非代理重要性来评分淘汰，能在匹配保留预算下持续优于注意力启发式；**压缩越激进，优势越明显**（ρ=0.75/0.90 时差距最大）。
- 图 1 显示行为保持分数与未来位置 KL 的 Spearman 相关最高（LongBench 0.90、MATH500 0.86、AIME25 0.89），而 SnapKV/EA 仅 0.22–0.45。
- 图 2 显示在**多条目淘汰**下，掩码级估计 logits KL 与真实掩码缓存 KL 的排序相关性最强（0.77，对比 singleton 0.67、CAOTE 0.53、SnapKV 0.45），验证残差路径近似可用。
- 生成时压缩：12× 压缩、生成长度 2048→8192 时，SnapKV 在 MATH500 上相对全缓存下降 16.8→25.4 分（DeepSeek-R1-Distill-Qwen-7B）与 19.0→27.7 分（Qwen2.5-Math-7B），而本文方法下降仅 3.8–5.8 分；R-KV 在部分设置下为最强基线，本文方法与之接近或更优，且未使用推理专用的冗余启发式。
- 效率：跨预算比较下，本文方法可比 SnapKV **少保留 2.5–3× 的 KV 条目**同时取得更高分数；端到端延迟比 SnapKV 增加 0.24–0.75 秒，但仍快于全缓存推理。
- 消融：最终归一化传播显著影响残差扰动到 logits 的映射；打分窗口 $m=4$ 已足够；top-$K$ 增大收益有限；掩码级精炼（pool-refine）明显优于 singleton，恢复全候选精炼 80–86% 的增益而快约 3.6×。

## 7. 优点

- **目标设定清晰且有理论依据**：用自回归 KL 链式法则论证"下一 token KL 是长程行为差异的可观测首项"，把压缩目标从代理信号转为输出分布保持。
- **无需候选级掩码前向**：借助删除反事实 + 残差路径 + 一阶 logits 传播，把评分完全建立在淘汰前统计量上，工程上可落地。
- **非可加性的处理**：识别出淘汰代价不可加，采用"候选池 + 掩码级边际代价精炼"的两阶段贪心，兼顾效果与效率。
- **验证链条完整**：既有与真实掩码缓存 KL 的排序相关性验证，也有与代理分数的对比，还有效率与超参敏感性分析。
- **公平的实验协议**：统一预算记账（保护条目计入预算）、保留基线原生粒度、同一压缩时机与解码设置。

## 8. 不足与局限

- **行为保持的范围有限（作者自述）**：仅保证相对于**压缩时可用查询位置**的下一 token 分布；对任意未见未来续写无保证，后续查询可能放大或抑制淘汰扰动。压缩时如何预判未来查询仍是开放问题。
- **近似误差**：残差路径近似忽略后续注意力、MLP 与归一化层的响应，仅在 LLaMA3.1-8B + LongBench 上经验验证，跨架构（如不同归一化、MoE）的稳健性未充分检验。
- **额外压缩时开销**：虽然端到端仍快于全缓存，但压缩时计算显著高于轻量启发式（如 LLaMA3.1-8B、ρ=0.90 时为 1.97 s/例 vs SnapKV 0.29 s/例），对低延迟或高频在线剪枝场景可能不友好。
- **算力与规模覆盖有限**：仅单张 A100 80GB；最大模型 12B；未报告多卡、长批处理或大规模部署下的表现。
- **对比范围**：未与学习型压缩、量化类方法在同一协议下比较；基线集中于免训练启发式。
- **部分结果非单调 / 波动**：如 AIME25 在 12× 压缩下本文方法（20.0）略低于 R-KV（21.1），且 AIME25 绝对分数低、仅三次随机运行取均值，统计噪声风险较高；LongBench 轻度压缩（ρ=0.10–0.25）时与最强基线的差距较小（约 0.1–0.5 分）。
- **超参依赖**：虽然作者强调各 regime 固定超参、未按 benchmark 调优，但 $\alpha$、$b_{\text{ref}}$、$K$、$m$、$\epsilon$ 等仍需按压缩场景设定，迁移到新场景时可能需要重新选择。
