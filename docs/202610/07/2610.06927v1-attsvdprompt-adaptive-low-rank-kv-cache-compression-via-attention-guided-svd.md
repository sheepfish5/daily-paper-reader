## 摘要
自回归 Transformer 的键值（KV）缓存随上下文长度线性增长，并在长上下文中主导内存占用。大多数免训练补救方法会驱逐低重要性 token，这是沿序列轴不可逆的选择。我们则保留每个 token，并沿“特征”轴以更低成本存储。因此，我们提出 AttSVD，一种新的“可解释”低秩压缩方法，其基由每个提示自身的注意力几何推导而来：一种在线的、针对每个提示的截断 SVD，只保留注意力实际读取的方向，并按保留秩的比例削减每个头的常驻 KV 内存。我们提出两种解码时缓存策略，累积式和流式，分别用于短生成和长生成场景。此外，我们提出两种改进，使压缩具有自适应性。一种逐矩阵能量规则独立地确定 logit 空间和注意力质量的大小。一种注意力感知的基仅在注意力实际读取的空间中进行截断，从而同时保留注意力 logits 和注意力输出。同样的因子还以零额外成本提供逐头的可解释性洞察，揭示有效秩以及注意力所消耗的几何结构。在多个模型上，在智能体基准和完整 LongBench 套件上，AttSVD 与稠密缓存保持相当，同时最多仅使用 50% 的 KV 缓存内存。

## Abstract
The key-value (KV) cache of autoregressive transformers grows linearly with context length and dominates memory at long context. Most training-free remedies evict low-importance tokens, an irreversible choice along the sequence axis. We instead keep every token and store it more cheaply along the "feature" axis. We therefore propose AttSVD, a new "interpretable" low-rank compression whose basis is derived from each prompt's own attention geometry: an online, per-prompt truncated SVD that keeps only the directions attention actually reads, cutting persistent per-head KV memory in proportion to the retained rank. We propose two decode-time caching strategies, accumulating and streaming, for short and long generation regimes. Furthermore, we propose two refinements that make compression adaptive. A per-matrix energy rule sizes the logit space and the attention mass independently. An attention-aware basis truncates only in the spaces attention actually reads, preserving both the attention logits and the attention output. The same factors also provide free, per-head interpretability insights into the effective rank and the geometry attention consumes. Across multiple models, on both an agentic benchmark and the full LongBench suite AttSVD stays on par with the dense cache while using up to 50% of the KV-cache memory.

## 1. 核心问题与整体含义

- **研究背景**：自回归 Transformer 的 KV 缓存随上下文长度线性增长，在长上下文推理中成为显存主导瓶颈。
- **现有免训练方法的两条路线**：
  - **Token 驱逐/保留预算**：如 H2O、SnapKV、KeyDiff、KVzip，沿序列轴丢弃低重要性 token，属于不可逆决策，误删 token 无法再被注意。
  - **低秩重建**：如 VECTOR、Palu，保留所有位置但近似存储，沿特征轴压缩。
- **AttSVD 的定位**：
  - 不驱逐任何 token，而是在**特征轴**上对每个 prompt、每层、每个 KV 头在线做低秩压缩。
  - 基来自当前 prompt 自身的注意力几何，而不是离线权重、校准语料或训练。
  - 目标是在长上下文、短/长生成场景下，以约 50% KV 缓存内存达到与 dense cache 相当的质量，并提供零额外成本的可解释性。

## 2. 方法论

### 2.1 核心思想

- 保留全部 token，将 K/V 存为低秩因子 \(A B\)，解码时按需瞬时重建。
- 对每个 prompt 单独计算截断 SVD，基在生成过程中冻结；无校准、无训练、无 running basis 维护。
- 与普通 raw-KV SVD 不同：AttSVD 在**注意力真正读取的空间**中截断：
  - Key 用 query 几何 \(C_Q=Q^\top Q\) 加权，以保留注意力 logits \(QK^\top\)。
  - Value 用每 token 注意力质量 \(a_i=\sum_q P_{qi}\) 加权，以保留输出 \(PV\)。

### 2.2 关键技术细节

- **标准截断 SVD 与 Eckart-Young 最优性**：
  - 对矩阵 \(Z\) 做 rank-\(r\) 截断：\(Z_r=U_{:,1:r}\Sigma_{1:r}V^\top_{:,1:r}\)，存储 \(A=U_{:,1:r}\Sigma_{1:r}\)、\(B=V^\top_{:,1:r}\)。
  - 该截断在 Frobenius 范数下是 rank-\(r\) 最优近似。
- **注意力感知 Key 截断**：
  - 目标是最小化 logits 扰动：\(\|Q(K-X)^\top\|_F\)。
  - 等价于 \(\|(K-X)C_Q^{1/2}\|_F\)，其中 \(C_Q=Q^\top Q\)。
  - 令 \(\tilde K=K C_Q^{1/2}\)，对其做标准截断 SVD，再把右因子乘回 \(C_Q^{-1/2}\)，得到 \(K_r^\star=A_{\tilde K}B_{\tilde K}\)。
  - 仅改变基，不改变缓存布局和解码重建形式。
- **注意力感知 Value 截断**：
  - 精确目标 \(\|P(V-V_r)\|_F\) 需要 \(S\times S\) 的 \(P^\top P\)，代价过高。
  - 使用对角近似：每 key 的注意力质量 \(a_i=\sum_q P_{qi}\)，最小化 \(\sum_i a_i\|V_i-X_i\|_2^2\)。
  - 等价于对 \(\tilde V=\mathrm{diag}(\sqrt a)V\) 做截断 SVD，再将左因子乘回 \(\mathrm{diag}(1/\sqrt a)\)。
  - 对角近似的理由：避免 \(O(S^2)\)/\(O(S^3)\) 成本、兼容 FlashAttention 不显式形成 \(P\)、数值条件更好、注意力质量本身已捕捉主要行重要性。
- **Q 与 a 的获取**：
  - Prefill 时通过轻量 forward hook 捕获 post-RoPE queries，并用一次 attention-shaped pass 读取 value mass。
  - 支持 GQA 扩展，并加入数值保护。
- **Prefill 阶段**：
  - 将 prompt 分成 bulk 和最近 \(w\) 个 token 的 exact tail。
  - 对 bulk 做 attention-aware SVD，只把因子存入 side cache；exact tail 精确保留。
  - Prefill 前向本身使用原始精确 K/V，因此 prefill 输出与 dense cache 一致，不引入重建损失。
- **两种 Decode 缓存策略**：
  - **Accumulating**：prefill 因子固定，新生成 token 全部精确追加，适合长 prompt、短生成场景。
  - **Streaming**：维护最近 \(w\) 个 token 的滑动精确窗口；窗口溢出 \( \ell \) 个 token 后，将最旧的 \( \ell \) 个仍精确的 token 压缩为冻结低秩块，再移出窗口。缓存大小有界，适合长 prompt、长生成/think 模式。
  - Streaming 中旧 token 从精确值压缩，且每块只压缩一次，避免误差跨生成累积。
- **定秩策略**：
  - **统一压缩比/秩**：给定压缩比 \(c\)，令 \(r=\mathrm{round}((1-c)d)\)，K/V 同秩，适合明确内存预算。
  - **逐矩阵能量规则**：对矩阵 \(M\) 的奇异值，保留最小秩 \(r_M(\tau)\)，使其能量占比达到 \(\tau\)，默认 0.99。
  - 每 batch/head 得到秩后，可用 max/mean/percentile 聚合，默认 max；也可显式设置 \(r_{\tilde K}, r_{\tilde V}\)。
  - 论文观察到 \(r_{\tilde K}\ll r_{\tilde V}\)：key 更易压缩，value 需要更高秩。
- **内存成本**：
  - 持久因子成本约 \((r_{\tilde K}+r_{\tilde V})(S+d)\)，相对 dense 的 \(2Sd\)。
  - 长上下文极限下压缩比趋近 \((r_{\tilde K}+r_{\tilde V})/(2d)\)；若共享秩 \(r\)，则约 \(r/d\)。
  - 最近窗口增加 \(O(wd)\) 的精确尾部，但 \(w\ll S\) 时可忽略。
- **可解释性**：
  - 有效秩 \(r_{\tilde K}, r_{\tilde V}\) 反映 score 和 output 的内在维度与压缩能力。
  - \(C_Q\) 的谱反映每个 head 的 query 子空间聚焦程度。
  - 注意力质量 \(a_i\) 提供 token saliency 画像。
  - 这些是几何解释，不是语义概念解释。

### 2.3 算法流程文字版

- **Prefill 算法**：
  - 输入 K、V、post-RoPE Q、窗口 \(w\)、是否 streaming、chunk 大小 \(\ell\)。
  - 拆分 bulk 和 exact tail。
  - 对 bulk 调用 AttentionSVD：若 Q 可用，则 Key 用 \(C_Q\) 加权、Value 用 mass 加权；若不可用则退化为普通截断 SVD。
  - 存储因子；若 streaming，初始化 decode block 列表。
  - Prefill 前向返回原始精确 K/V。
- **Decode 算法**：
  - 每个生成 token 先精确
