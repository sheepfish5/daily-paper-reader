## 摘要
长链式思维推理在自回归解码期间显著增加KV缓存内存，因为每个生成的token都会引入新的键和值状态，并使缓存随解码长度线性增长。现有KV缓存压缩方法通常通过token驱逐来控制这种增长，但不可逆的删除可能会移除后续推理可能需要重新访问的历史状态。基于SVD的低秩压缩提供了一种替代方案，通过更紧凑的表示保留所有位置。然而，将其从固定的提示缓存扩展到在线解码并非易事。通过研究，我们发现，如果为新token更新基，而旧token保留其在旧基中的坐标，则存储的历史会发生显著漂移。基于这一观察，我们提出iS-KV，一种面向长时程推理的在线低秩KV缓存压缩方法。iS-KV保留最近窗口的精确表示，同时将较旧状态增量折叠为有界秩表示。随着低秩基的演化，它同步历史坐标与更新后的基，以保持表示一致性。在DeepSeek-R1-Distill-Llama-8B上，iS-KV在4.06倍持久KV压缩下达到82.6%的准确率，接近原模型的83.6%。在Qwen3-8B上，它在5.64倍压缩下达到89.2%的准确率。在匹配内存预算下，iS-KV始终优于token驱逐基线。

## Abstract
Long chain-of-thought reasoning substantially increases KV-cache memory during autoregressive decoding, as every generated token introduces new key and value states and causes the cache to grow linearly with decoding length. Existing KV-cache compression methods typically control this growth through token eviction, but irreversible deletion can remove historical states that later reasoning may need to revisit. SVD-based low-rank compression provides an alternative by retaining all positions with a more compact representation. However, extending it from a fixed prompt cache to online decoding is non-trivial. Through our investigation, we find that if the basis is updated for new tokens while old tokens keep their coordinates in the old basis, the stored history drifts substantially. Based on this observation, we propose iS-KV, an online low-rank KV-cache compression method for long-horizon reasoning. iS-KV keeps a recent window exact while incrementally folding older states into bounded-rank representations. As the low-rank basis evolves, it synchronizes historical coordinates with the updated basis to maintain representation consistency. On DeepSeek-R1-Distill-Llama-8B, iS-KV achieves 82.6% accuracy at 4.06-fold persistent-KV compression, close to the original model's 83.6%. On Qwen3-8B, it achieves 89.2% accuracy at 5.64-fold compression. Under matched memory budgets, iS-KV consistently outperforms token-eviction baselines.

- **现有方法的痛点**：主流 KV 压缩依赖 token 驱逐（如 H2O、StreamingLLM、SnapKV、R-KV），但驱逐是**不可逆删除**。论文指出，当前看起来低注意力的旧 token，可能在数千 token 后重新变得重要；一旦删除便无法恢复。
- **关键观察**：
  - 在解码 step 1024 标记 75% 最低近期注意力 token，不删除，仅观察后续：在 AIME 上约 30% 会在后续 8K token 内重新获得强注意力，到 30K 时约 60%。
  - 匹配内存下，R-KV 在 DeepSeek-R1-Distill-Llama-8B 上损失 5.4–11.0 个点，在 Qwen3-8B 上损失 23.0–33.6 个点。
  - K/V 状态具有低秩结构，尤其 pre-RoPE key 衰减更快，value 衰减较慢、更难压缩。
  - 在线低秩压缩的核心困难：新 token 到来时低秩基会演化；若只更新基而保留旧坐标，历史表示会显著漂移。论文测得仅更新基时 key/value drift 为 1.55/1.40，而联合更新旧坐标后降至 0.023/0.051。
- **整体含义**：iS-KV 提出一种**保留所有 token 位置、但将旧状态压缩为有界秩表示**的在线 KV cache 压缩方案，用“表示精度换 token 可用性”，避免不可逆驱逐。

## 2. 方法论

- **核心思想**：近期窗口保持精确，旧状态增量折叠进低秩历史；低秩基更新时，同步更新所有历史 token 的坐标，保持表示一致性。
- **预填充阶段**：
  - 对每层 K/V，将 prompt 位置划分为精确集与压缩集。
  - key 使用 **pre-RoPE 表示**进行低秩压缩；对 post-RoPE key 按 chunk 打分，选择低相似度 outlier chunk、局部后缀作为保护位置，保护位置保留完整 pre-RoPE key。
  - value 保护位置由 key 保护位置扩张得到，并保留最近窗口。
  - 剩余行做截断 SVD：`(U_X, Σ_X, B_X) = SVD_rX(X[C_X])`，缓存 `U_X, Σ_X, B_X`，每行 token 的系数为 `U_X Σ_X`。
- **在线解码阶段**：
  - 新 K/V 行先进入精确 recent window；离开窗口且不受保护的旧行进入 FIFO 队列。
  - 每累计一个 block（如 64 行）触发一次更新。
  - value 路径有一次特殊 refit：当 pending value 行数达到 `r_V` 时，将其追加到重构后的 prompt value 历史并重新做 rank-`r_V` 截断 SVD。
- **块增量 SVD 更新**：
  - 设当前历史 `A = U Σ B^T`，新块为 `F`，目标是近似 `M = [A; F]`，并保持秩不超过 `r`。
  - 计算残差 `E = F - (F B) B^T`，构造残差基 `P`。
  - 在增广基 `[B P]` 下，问题化为小核心矩阵 `Z = [[Σ, 0], [F B, F P]]` 的 SVD。
  - 对 `Z` 做截断 SVD：`(G, Σ+, H) = SVD_r(Z)`，再更新：
    - `U+ = [[U, 0], [0, I_b]] G`
    - `B+ = [B P] H`
  - 该核心矩阵尺寸为 `(k+b) × (k+p)`，与历史长度 `n` 无关。
  - 周期性重正交化，保持 `U Σ B^T` 乘积不变。
- **重建与注意力**：
  - 按原始 token 顺序重建 cache：压缩位置用 `U_X Σ_X B_X^T` 重建，精确位置直接使用原始行。
  - 对 key 在原始位置应用 RoPE，再与 query 做 attention。
- **存储与复杂度**：
  - 持久存储约 `O(nr)`，每个旧 K/V token 存 `2r` 个系数而非 `2d` 个标量，另加共享基与奇异值。
  - 更新历史坐标成本约 `O(n r (r+b))`；重建、重正交化也依赖历史长度 `n`。
  - 因此 iS-KV 是“减缓增长”，并非使 KV cache 恒定大小。
