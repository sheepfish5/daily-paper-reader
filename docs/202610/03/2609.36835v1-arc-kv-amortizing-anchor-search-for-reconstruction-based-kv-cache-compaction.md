## 摘要
长上下文大语言模型推理受到随序列长度线性增长的 KV 缓存的瓶颈制约。对于长且可复用的上下文前缀，这一负担尤为严重，因为其缓存必须服务于许多下游查询。诸如 Attention Matching 等基于重建的方法能够以紧凑的 KV 缓存取得很强的下游任务性能。然而，迭代式锚点搜索主导了基于 OMP 的 Attention Matching 的压缩成本。这促使我们提出选择性摊销原则：学习跨上下文可复用的锚点选择策略，同时保留上下文特定的重建。在这项工作中，我们提出 ARC-KV，一种遵循该原则的新型基于重建的 KV 缓存压缩方法。为此，我们首先训练一个值感知索引器，以在单次评分过程中选择真实键锚点。然后，ARC-KV 应用凸包约束的键合并，并针对完整缓存拟合注意力质量偏置和紧凑值。在推理时，ARC-KV 使用冻结的索引器为每个上下文构建一次紧凑缓存，并将其复用于所有后续查询。大量实验表明，在 Llama-3.1-8B-Instruct 上，ARC-KV 在 QuALITY、RULER 和 LongBench 的大多数设置中优于已报道的压缩方法。特别地，在 QuALITY 上保持 10% KV 时，相较于 Attention Matching，ARC-KV 将准确率从 0.6409 提升至 0.6474，同时将压缩时间缩短 25.73 倍，从 959.8 秒降至 37.3 秒。

## Abstract
Long-context large language model inference is bottlenecked by KV caches that grow linearly with sequence length. This burden is especially severe for long, reusable context prefixes, whose cache must serve many downstream queries. Reconstruction-based methods such as Attention Matching achieve strong downstream task performance with compact KV caches. However, iterative anchor search dominates the compaction cost of OMP-based Attention Matching. This motivates our selective amortization principle of learning a reusable anchor-selection policy across contexts while retaining context-specific reconstruction. In this work, we propose ARC-KV, a novel reconstruction-based KV cache compaction method that follows this principle. To this end, we first train a value-aware indexer to select real-key anchors in a single scoring pass. ARC-KV then applies convex-hull-constrained key merging and fits an attention-mass bias and compact values against the full cache. At inference time, ARC-KV builds the compact cache once per context using the frozen indexer and reuses it for all subsequent queries. Extensive experiments demonstrate that ARC-KV outperforms reported compaction methods in most settings across QuALITY, RULER, and LongBench on Llama-3.1-8B-Instruct. In particular, at 10% KV retention on QuALITY, ARC-KV improves accuracy from 0.6409 to 0.6474 over Attention Matching while reducing compaction time by a factor of 25.73, from 959.8 s to 37.3 s.

# ARC-KV 论文中文总结

## 1. 核心问题与整体含义（研究动机与背景）

- **背景瓶颈**：长上下文大模型推理受限于随序列长度线性增长的 KV 缓存。以 LLaMA-65B 为例，128K token 序列在 FP16 下仅 KV 缓存就需 320GB，严重拖累吞吐与延迟。
- **特别场景**：对于**长且可复用的上下文前缀**（如系统日志、代码库、长文档），缓存需服务大量下游查询，压缩收益尤为显著。
- **现有方法三类**：
  - 规则式 token 驱逐（StreamingLLM、H2O、SnapKV）：永久丢弃 token，信息不可逆丢失。
  - 学习式驱逐（KVP、LKV）：训练轻量选择器，但仍为硬子集。
  - **缓存重建**（Cartridges、Attention Matching、Still）：将 KV 重建为紧凑形式，保留更丰富信息。
- **关键痛点**：Attention Matching（AM）虽性能强，但其 **OMP 迭代锚点搜索**主导压缩成本——在 64K 上下文、20% 保留率下，OMP-fast 单独耗时 15.36 小时，而其他阶段最多 1.17 分钟。
- **核心洞见（选择性摊销原则）**：锚点**发现**可学习跨上下文复用的先验；而**重建**必须针对当前上下文拟合。因此应将选择策略摊销到跨上下文，同时保留上下文特定的重建。

## 2. 方法论

### 2.1 核心思想
将 AM 中"锚点发现 + 缓存重建"的耦合优化解耦：训练一个**可复用的值感知索引器**（每模型一次，冻结），推理时每个上下文只做一次评分选锚，再执行上下文特定的键合并与闭式拟合。

### 2.2 四阶段流程（推理）
1. **参考查询池构建**：采用 repeat-prefill，让模型复述上下文，保留每个位置的 pre-query-projection 激活 $x_i$ 与 post-RoPE 查询 $q_i$，形成 $D_{ref}$。所有被压缩的 KV 仍来自原始 prefill。
2. **锚点选择**：索引器对每个缓存位置打分，经 softmax 归一化后按 **RMS 池化**聚合跨查询分数，取 top-$t$ 作为真实键锚点 $S$。RMS 池化比 mean/max 更能保留"仅对部分查询重要"的位置。
3. **凸包约束键合并**：用归一化注意力响应画像（而非原始键空间距离）将每个非锚键硬分配给最相似的锚点，形成分组 $G_r$；用查询平均未归一化注意力质量作为权重，将锚点向组内加权质心移动：
   $$c_{k,r} = (1-\lambda_m)k_{s_r} + \lambda_m \mu_r$$
   由于 $s_r \in G_r$，紧凑键必落于该组真实键的凸包内，避免外推。
4. **闭式拟合**：固定合并后的 $C_k$，用投影最小二乘求非负权重 $w^\star$，令 $\beta^\star = \log w^\star$ 拟合注意力质量；再用岭回归拟合紧凑值 $C_v^\star$。两步均不引入学习参数。

### 2.3 紧凑注意力算子
$$\hat{O}(Q; C_k, \beta, C_v) = \text{softmax}(QC_k^\top + \mathbf{1}_n\beta^\top)C_v$$
目标不仅是局部输出保真，还要保持与未压缩块共同参与注意力时的**注意力质量** $Z_K(q) \approx Z_C(q;\beta)$。

### 2.4 值感知索引器架构
- 扩展 DeepSeek Sparse Attention 索引器：每 KV 头 $H_I$ 个低维索引头（宽度 $d_I$）+ 1 个辅助值注意力头（宽度 $d_A$）。
- 辅助头形成值缓存的查询条件摘要 $c_i$；查询嵌入同时被值上下文增强，键嵌入同时被共位值增强，使注意力模式相似但值不同的键得到不同分数。
- 投影 $L_c, L_v$ 初始化为 0，因此可精确加载纯 query-key 检查点后学习值相关修正。

### 2.5 训练策略（无 OMP 标签，自监督）
- **参考查询三元划分**：每上下文从 $D_{ref}$ 采样互不相交的 $D_{score}$、$D_{fit}$、$D_{holdout}$。
- **硬分支**：用 top-$t$ 选锚，$C_k^h=K_S$，由 $Q_{fit}$ 拟合 $\beta^h, C_v^h$，在 $Q_{holdout}$ 上计算相对 MSE $\mathcal{L}_{out}^h$（无梯度）。
- **软代理分支**：因 top-$t$ 不可微，在候选集 $C=\text{TopK}(s, 2t)$ 上用 sigmoid 门 $g_j$ 松弛，温度从 1.0 退火到 0.1，可微岭回归求 $C_v^s$，得到 $\mathcal{L}_{out}^s$。
- **STE 组合**：$\mathcal{L}_{out}^{STE} = \text{sg}(\mathcal{L}_{out}^h) + \mathcal{L}_{out}^s - \text{sg}(\mathcal{L}_{out}^s)$，前向值为硬损失，梯度来自软代理。
- **KL 预热**：先用 $\mathcal{L}_{KL}$ 对齐索引器分布与全注意力分布，再联合训练 $\mathcal{L} = \lambda_{out}\mathcal{L}_{out}^{STE} + \lambda_{KL}\mathcal{L}_{KL}$，最终取 $(\lambda_{out}, \lambda_{KL})=(2,1)$。

## 6. 主要结论与发现

- **性能**：在 Llama-3.1-8B 上，15 个基准-保留率设置中 **13 个排名第一**（QuALITY 全 5 个、RULER 4/5、LongBench 4/5）。

  - RULER 在 ρ=0.01–0.10 上高 **3.34–25.94 点**（ρ=0.05 时 0.7394 vs. AM 的 0.4800）。
  - LongBench 在 ρ=0.02–0.20 上高 **1.76–5.51 点**。
  - ρ=0.05–0.20 时 QuALITY 达到 0.6437–0.6567，**超过全上下文参考 0.6387**。
  - RULER 在 ρ=0.20 时保留全上下文 **98.6%** 性能。
- **效率**：QuALITY 10% 保留率下，压缩时间从 **959.8 s 降至 37.3 s（25.73×）**，同时准确率从 0.6409 升至 0.6474。5% 保留率下加速 8.47×，1% 下加速 1.30×。

- **解码注意力**：ρ=0.20 时每层比 FlashAttention-2 快 **3.19–4.43×**，KV 存储减少约 5×。
- **交叉模型**：4 个设置中 3 个排名第一；Qwen3-8B 的 RULER 上以 0.3815 落后 KVzip（0.4040）。
- **关键发现**：锚点选择与 OMP 选择的集合重叠度低（平均 Jaccard 0.144–0.201），说明索引器学到了不同的支撑集；但论文明确不据此主张质量优势。

## 7. 优点

- **问题定位精准**：通过 profiling 明确 OMP 锚点搜索是压缩成本瓶颈，据此提出选择性摊销，动机清晰。
- **设计原则简洁有力**：区分"可摊销的选择策略"与"上下文特定的重建"，为后续工作提供通用框架。
- **方法组合巧妙**：
  - 值感知索引器仅需每键一个标量分数，训练轻量（0.57–2.13% 参数），且可精确加载 query-key 检查点。
  - 凸包约束保证紧凑键几何合理性，避免外推。
  - RMS 池化保留稀有查询重要位置。
  - 闭式拟合无额外学习参数。
- **训练无需 OMP 标签**：以全注意力行为自监督，训练/拟合/留出查询三分划分，评估严格。
- **效率收益显著且实测充分**：给出压缩时间分解、解码注意力加速、各阶段占比。
- **诚实的负结果报告**：明确列出两个未排名第一的设置，并说明 LongBench 使用 AM-HA 的替代原因。

## 8. 不足与局限

- **应用范围受限**：当前仅针对**静态可复用上下文前缀的一次性压缩**，不支持生成状态的再压缩（generated-state recompression）。
- **剩余瓶颈未解决**：
