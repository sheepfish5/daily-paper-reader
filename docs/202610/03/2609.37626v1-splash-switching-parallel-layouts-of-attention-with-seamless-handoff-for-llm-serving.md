## 摘要
没有任何一种注意力并行方式能在所有负载下都很好地服务大语言模型。低并发适合张量并行，大量独立请求适合数据并行注意力，长提示词适合上下文并行。推理、智能体和强化学习 rollout 类工作负载使固定选择难以为继：一个以大量短请求开始的批次最终会变成少数几个很长的请求，因此最优布局会在同一批请求运行期间发生变化。然而服务引擎在启动时就固定一种布局，因为改变布局意味着要排空请求并重启工作进程。我们提出 SPLASH，一种可在请求运行期间切换注意力并行布局的服务系统。它基于一个观察：现代注意力机制（KV 头很少甚至没有）将请求的 KV 缓存所在位置与注意力权重的切分方式解耦。这带来两个结果。首先，不同布局之间的差异仅在于权重和缓存归谁所有，而其中大部分状态已经位于下一个布局所需的位置；SPLASH 复用这些状态，在持续推理的后台迁移其余部分，并在批次边界处完成交接，使切换几乎零开销：其中位开销低于其所处步骤的 0.51%。其次，这种解耦揭示出一种现有引擎所缺少的布局：解耦归属并行（Decoupled Ownership Parallelism, DOP），它像张量并行那样切分注意力权重，同时像数据并行注意力那样将每个请求的缓存保留在单一所有者上。DOP 对二者均不做复制，相比数据并行注意力提供 27-60% 更多的 KV 容量，并在 KV 内存限制准入时给调度器提供了选择。一个感知切换的调度器会随负载变化跟踪四种布局中的最优者。在 B200 GPU 上服务 GLM-5.3 时，SPLASH 相比固定布局部署将端到端服务吞吐提升 1.3-1.73 倍，并且在 H200 上运行 DeepSeek-V3.2 以及 DCU 上运行 GLM-5.3-Flash 时也出现了相同的布局区间。

## Abstract
No single way of parallelizing attention serves large language models well under all loads. Low concurrency favors tensor parallelism, many independent requests favor data-parallel attention, and long prompts favor context parallelism. Reasoning, agentic, and RL-rollout workloads make a fixed choice untenable: a batch that begins as many short requests ends as a few very long ones, so the best layout changes while the same requests run. Serving engines nevertheless fix one layout at launch, because changing it has meant draining requests and restarting workers. We present SPLASH, a serving system that switches the parallel layout of attention while requests are running. It builds on one observation: modern attention, with few or no KV heads, decouples where a request's KV cache lives from how attention weights are sharded. This has two consequences. First, layouts differ only in who owns the weights and the cache, and most of that state already sits where the next layout needs it; SPLASH reuses it, moves the rest in the background of ongoing inference, and hands off at a batch boundary, making a switch nearly free: its median overhead is under 0.51% of the step it runs in. Second, the decoupling exposes a layout that existing engines lack: Decoupled Ownership Parallelism (DOP) shards attention weights as tensor parallelism does while keeping each request's cache on a single owner as data-parallel attention does. DOP replicates neither, offers 27-60% more KV capacity than data-parallel attention, and gives the scheduler a choice when KV memory limits admission. A transition-aware scheduler follows the best of the four layouts as load changes. On B200 GPUs serving GLM-5.3, SPLASH improves end-to-end serving throughput by 1.3-1.73x over fixed-layout deployments, and the same layout regimes appear with DeepSeek-V3.2 on H200 and GLM-5.3-Flash on DCU.

## 1. 核心问题与整体含义（研究动机与背景）

- **核心问题**：LLM 服务中注意力（attention）的并行布局在启动时被固定，但真实工作负载的最优布局会随负载变化而改变，导致固定布局无法在所有场景下保持高效。
- **三种经典布局各有胜场**：
  - **张量并行（TP）**：适合并发低、请求少的场景；
  - **数据并行注意力（DP-attention）**：适合大量独立请求；
  - **上下文并行（CP）**：适合长提示词 / 长上下文。
- **动态负载使固定选择不可持续**：
  - 推理、智能体（agentic）、强化学习 rollout 等工作负载中，一个批次往往**从大量短请求开始、以少数超长请求结束**，同一批请求运行期间最优布局就会改变。
  - 例如 RL rollout：每步同时启动数千个生成，多数很快结束，少数长推理链拖住整组，直到它们结束。
- **切换布局的现实障碍**：
  - 权重是只读的，可重新分片或接收一次；但**存活的 KV 历史持续增长**，改变缓存归属必须保留全部历史、追加顺序以及各 rank 达成一致的集合通信序列。
  - 现有引擎因此采取「排空请求 + 重启 worker」，而这恰恰在最需要切换（长请求）时耗时最长。
- **整体含义**：SPLASH 首次让注意力并行布局成为**运行期可实时切换的选择**，覆盖所有值得运行的布局之间的切换，并把准备开销隐藏在持续推理之后，使布局能跟随负载变化。

## 2. 方法论

### 2.1 核心思想：注意力布局的「所有权模型」

- **关键观察**：现代注意力（MQA/GQA/MLA）将 KV 头数量降至极少甚至取消（MLA 只保留一个头共享的 latent 历史），从而**把「注意力权重如何分片」与「请求 KV 缓存归谁所有」解耦为两个独立决策**。
- 一个布局 = 对这两个决策的一种设定：
  - 投影权重：分片（sharded）还是复制（replicated）；
  - KV 历史：按请求归单一所有者，还是按位置/头切分。
- 四种布局及其每 rank 内存（$W_A$ 为 TP/DOP 分片的投影大小，$k$ 为每 token 的 KV 字节，$B$ 为均衡请求数，$s$ 为上下文长度）：
  - $M_{TP}(s) = W_A/T + Bks$（每 rank 复制完整历史）
  - $M_{DOP}(s) = W_A/T + Bks/T$（权重分片 + 缓存单属主，**零冗余**）
  - $M_{DP}(s) = M_{CP}(s) = W_A + Bks/T$（复制完整投影）

### 2.2 新布局：解耦归属并行（DOP）

- **定义**：像 TP 一样分片注意力权重（Q-B、KV-B、O 投影），同时像 DP-attention 一样让每个请求的历史保留在单一所有者上。
- **计算流程**：
  - 分片投影使每个 rank 先拿到全部 $N$ 个 query 行但只对应 $H/T$ 个头（形状 $[N, H/T, d_q]$）；
  - 注意力需要所有者 rank 上的 $N_r$ 行 × 全部 $H$ 个头（形状 $[N_r, H, d_q]$）；
  - DOP 用**一次可变大小 all-to-all**在注意力前转换，注意力后再做反向 all-to-all，将头切片还原为分片值并接输出投影。
- **通信代价**（每层两次交换的总字节）：
  $$V_{DOP} = (1 - 1/T) N H (d_q + d_z) b$$
  其中 $d_q = d_c + d_r$，$d_z = d_c$（吸收式 MLA）。**该量与上下文长度无关**，只随本步 query 行数变化。
- **容量收益**：相比 DP-attention，每 rank 多出 $W_A(1-1/T)$ 字节给 KV。GLM-5.3 FP8、T=8 时，分片 78 层的 Q-B/KV-B/O 投影为 KV **释放 12.69 GiB/rank**。
- **DOP-P 变体**：在所有者上缓存部分完整投影，用部分返还内存换取更少交换。

### 2.3 切换机制：12 个有向切换，3 种原语

- 设 $K^a_r$、$P^a_{r,k}$ 为布局 $a$ 下 rank $r$ 持有的 KV 块与第 $k$ 层投影块，切换到 $b$ 只需补足差集：
  - $V^K_r(a \to b) = K^b_r \setminus K^a_r$
  - $V^W_{r,k}(a \to b) = P^b_{r,k} \setminus P^a_{r,k}$
- **三种原语**即可覆盖全部 $A^4_2 = 12$ 个有向切换：
  - **discard**：目标是子集时原地保留所需块、释放其余，零网络开销；
  - **all-gather**：从其他 rank 收集散布块（如 TP/DOP 进入复制投影时权重 all-gather）；
  - **all-to-all**：状态在「请求归属」与「位置分片」之间移动时使用（如 CP 与请求归属布局之间）。
- **切换成本只取决于目标缺失的状态**，与模型大小或缓存总量无关：DP-attention → DOP 无需跨网络；TP → DOP 保留每份 MLA 历史的一个所有者副本并退役其余。

### 2.4 单步内无缝交接（四步流程）

1. **Reuse（复用）**：在步边界计算差集清单，为每层权重和 KV 分配一种原语；要求精度、量化 scale、位置约定一致。
2. **Overlapped transfer（重叠传输）**：第 1 层缺失状态先传；随后第 $i$ 层集合通信在独立流上运行，与第 $i-1$ 层计算重叠。GLM-5.3 FP8、T=8 时每 rank 在途权重仅 145.73 MiB（全 78 层为 11.3 GiB）。
3. **Handoff（交接）**：第 $i$ 层状态到达后即按目标布局运行；所有 rank 同步切换，保证每层集合通信匹配；请求历史保留、worker 不中断；indexer、位置、循环状态随层 KV 一起迁移。
4. **Retire（退役）**：传输完成后释放旧页与投影副本。内存约束为：
   $$\max\{M_r(a), M_r(b)\} + \Delta^{layer}_r + R_r \le H_r$$

### 2.5 感知切换的调度器

- 调度器 $\pi(x;\theta)$：$\theta$ 为硬件常数（组大小 $T$、显存 $H_r$、算力、权重读、KV 读、互连带宽、固定集合通信延迟，部署时一次性微基准标定）；$x$ 为当前批次（运行请求数 $B$、各请求活跃上下文 $s_i$、本步 query 行数 $q_i$）。
- **可行性约束**：
  - 稳态：$M_{0,r} + W_r(\ell) + K_r(\ell,x) + A_r(\ell,x) + R_r \le H_r$
  - 切换瞬间：满足上式及 $\max\{M_r(a), M_r(b)\} + \Delta^{layer}_r + R_r \le H_r$
- **暴露的切换开销**（仅第 1 层传输及无法被前一层计算掩盖的后续传输）：
  $$bt_{exposed} = bt_{xfer,1} + \sum_{i=2}^{L} [bt_{xfer,i} - bt_{comp,i-1}]^+$$
- **决策**：$\ell^\star = \arg\min_{\ell \in F(x;\theta)} t_\ell(x;\theta)$，只有当新布局领先当前布局超过设定 margin 时才切换，避免在交叉点附近抖动。

    - 未与已有的动态并行/弹性重分片系统（如面向 MoE 的弹性 EP、通用弹性并行框架）做横向对比，切换开销的比较对象主要是 blocking 与 target-ready 两个内部基线；
    - 切换开销的暴露时间建模依赖微基准标定的 $\theta$，论文未报告标定误差对调度决策稳定性的敏感性分析（margin 取值的鲁棒性仅作定性说明）；
    - 12 个有向切换虽全部覆盖，但部分方向（如涉及 CP 的切换）的测量样本量小于固定布局扫描，统计置信度相对较低。

## 6. 主要结果与结论

- **DOP 作为新布局的价值**：在权重分片的同时保持 KV 单属主，使其在内存上同时优于 TP（不复制历史）与 DP-attention（不复制投影），在通信上仅付出与 query 行数成正比、**与上下文长度无关**的 all-to-all。长上下文场景下，这一"零冗余 + 常数交换"组合是 DOP 被纳入布局集合的关键理由。
- **切换开销可被隐藏**：借助四步交接与逐层重叠，第 1 层之后的传输大多被前一层计算掩盖。论文报告 SPLASH 的实际暴露开销显著低于 blocking 式"排空 + 重启"，并**接近 target-ready 这一需要预知未来布局的下界基线**，而 SPLASH 并不需要先知信息。
- **切换成本与状态总量解耦**：由于只传输差集 $K^b_r \setminus K^a_r$ 与 $P^b_{r,k} \setminus P^a_{r,k}$，成本由"目标缺失的状态"决定，而非模型大小或累积缓存总量，这使得长上下文、大模型下的切换仍然可行——正是这一点打破了"越需要切换时越难切换"的困局。
- **布局随负载变化带来吞吐收益**：在三种硬件平台上，SPLASH 在扫描空间中均优于任一单一固定布局；收益主要来自负载形态发生转变的区段（如批次由大量短请求逐步收敛为少数长请求），此时固定布局不可避免地处于次优。
- **跨平台一致性**：B200（GLM-5.3）、H200（DeepSeek-V3.2）、DCU（GLM-5.3-Flash）三套差异明显的软硬件组合上，DOP 的内存优势、切换原语的适用性以及调度器的决策趋势均保持一致，说明结论不依赖于特定加速器或特定注意力变体（MLA / KDA 混合）。
- **总体结论**：注意力并行布局不应是启动时的一次性静态选择，而可以作为**运行期的一等决策变量**；通过所有权模型统一描述布局、用三种原语覆盖全部有向切换、用逐层重叠隐藏传输，可以在不中断服务、不丢失 KV 历史的前提下实时跟随负载变化。

## 7. 局限性与讨论

- **精度与量化一致性假设**：复用原语要求源与目标布局在精度、量化 scale、位置约定上一致。若未来引入异构精度分片或不同 KV 量化方案跨布局，差集复用的前提需要重新论证。
- **调度器的可观测性依赖**：$\pi$ 的输入 $x$ 需要当前批次的活跃上下文与 query 行数，在连续批处理（continuous batching）与抢占式调度下如何保持估计准确、如何与调度队列交互，论文着墨有限。
- **抖动与切换频率**：margin 机制抑制了交叉点附近的震荡，但未给出切换频率上限的显式保证；高频切换虽单次开销低，累积暴露时间仍需实证。
- **适用范围**：方法依赖"权重可重新分片 / 复制"与"KV 可迁移"两个前提，对于权重被深度融合或 KV 结构不可拆分的模型，需重新推导差集与映射规则。

## 8. 学术与实践意义

- **概念层面**：把"注意力并行布局"从部署期超参提升为运行期可优化对象，并提出以"权重分片方式 × KV 归属方式"两个正交维度刻画布局的统一框架，DOP 正是该二维空间中此前未被系统利用的格点。
- **系统层面**：给出了布局切换的最小原语集（discard / all-gather / all-to-all）与可证明的差集传输公式，使切换开销与状态规模解耦，为后续弹性并行系统提供了可复用的设计范式。
- **工程层面**：在 SGLang 上落地并开源，表明该机制可与现有连续批处理、稀疏注意力后端（FlashMLA）及 PD 分离部署共存，具备较强的可迁移性。
