## 摘要
现有的 LLM 服务系统对 KV 缓存内存进行虚拟化和优化，但在整个执行过程中将模型权重内存视为固定不变。近期关于多精度模型表示的工作挑战了这一设计，它允许单个已存储模型同时支持全精度和较低精度执行，从而使有效权重占用随运行时变化。这为突发型工作负载创造了机会，因为 KV 缓存需求的临时峰值往往决定吞吐量和 SLO 合规性。我们提出 DPS，一种双精度 LLM 服务系统，将权重内存变为弹性资源：在正常负载下，DPS 服务全精度模型；在 KV 压力下，它切换到嵌套的较低精度变体，并将未使用的权重内存重新用于 KV 缓存块。DPS 构建于半统一内存（SUM）之上，SUM 将权重区域划分为一个持久化的较低精度子区域和一个共享区域，该共享区域在残差权重张量和 KV 缓存块之间交替，同时保持与分页 KV 缓存管理的兼容性。我们在 vLLM 之上实现 DPS，并在稠密和 MoE 模型以及多种生产工作负载轨迹上对其进行评估。结果表明，与 Static FP16 相比，DPS 将持续吞吐量提高 2.1--3.3 倍，并将有效 pass@1 最多提高 41 个百分点，同时保持 FP16 级精度。

## Abstract
Existing LLM serving systems virtualize and optimize KV-cache memory, but treat model-weight memory as fixed throughout execution. Recent work on multi-precision model representations challenges this design by allowing a single stored model to support both full-accuracy and lower-precision execution, making the effective weight footprint runtime-dependent. This creates an opportunity under bursty workloads, where temporary spikes in KV-cache demand often determine throughput and SLO compliance. We present DPS, a dual-precision LLM serving system that turns weight memory into an elastic resource: under normal load, DPS serves the full-accuracy model; under KV pressure, it switches to a nested, lower-precision variant and repurposes unused weight memory for KV cache blocks. DPS is built on Semi-Unified Memory (SUM), which partitions the weight region into a persistent lower-precision sub-region and a shared region that alternates between residual weight tensors and KV-cache blocks, preserving compatibility with paged KV-cache management. We implement DPS on top of vLLM and evaluate it across both dense and MoE models and various production workload traces. Our results show that \sysname improves sustained throughput by $2.1$--$3.3\times$ and effective pass@1 by up to $+41$\,pp over Static FP16, while preserving FP16-class accuracy.

## 1. 核心问题与整体含义

- **研究背景**：现有 LLM 服务系统（如 vLLM、SGLang）重点优化 KV-cache 的虚拟化与分页管理，但通常把模型权重内存视为部署后固定不变。权重占用往往很大，例如 30B 模型在 H100-80G 上可占 71.2% GPU 显存，而 KV cache 仅约 15.5%。
- **核心矛盾**：真实 LLM 负载具有强突发性，请求到达率、输入/输出长度波动大，KV cache 压力短时激增，导致排队、抢占、TTFT/TPOT 飙升和 SLO 违约。静态权重内存使系统无法在突发时扩展 KV cache。
- **机会**：多精度/嵌套模型表示允许同一存储模型同时支持全精度和低精度执行。FP8 模型可由 FP16 直接派生，残差权重可视为“可牺牲”内存；在 KV 压力高时释放残差权重内存给 KV cache，压力低时恢复全精度。
- **整体含义**：DPS 将权重内存从固定资源变为弹性资源，在保持 FP16 级精度的同时，用运行时精度切换换取 KV cache 容量，缓解突发负载下的吞吐与 SLO 问题。

## 2. 方法论

### 2.1 核心思想

- 提出 **Semi-Unified Memory（SUM，半统一内存）**：将权重区分为：
  - **持久区**：常驻低精度 FP8 权重，系统始终可执行 FP8 模型。
  - **共享区**：可在“残差权重张量”和“KV cache 块”之间动态切换。
  - **CPU pinned 残差备份**：保存被 KV 覆盖后的残差权重，用于恢复 FP16。
  - **SUM Manager**：管理物理单元与虚拟张量的绑定、分配/释放、模式切换和后台恢复。
- DPS 支持两种模式：
  - **full mode**：持久 FP8 + 共享区残差权重，在 kernel 内重建 FP16，精度接近原始 FP16。
  - **fast mode**：仅使用持久 FP8，共享区可全部给 KV cache，提升吞吐并降低显存压力。
- 切换不对称：
  - **FP16 → FP8**：几乎零成本，只需标记残差映射为 stale，无需搬数据。
  - **FP8 → FP16**：需要将残差权重从 CPU 通过 H2D 拷回 GPU，但通过后台 worker 与 decode 重叠。
