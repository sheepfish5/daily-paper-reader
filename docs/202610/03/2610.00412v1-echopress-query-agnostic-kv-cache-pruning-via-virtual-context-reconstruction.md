## 摘要
KV 缓存剪枝通过逐出较不重要的键值对来降低长上下文推理的内存占用。KVzip 通过上下文重建来估计重要性：提示模型逐块重复上下文。这实现了很强的压缩质量，但代价是额外的前向传播。学习式近似降低了这一成本，但需要针对特定模型进行训练。我们分析了 KVzip 如何识别重要的缓存信息，并展示了如何利用预填充期间已计算的信息来近似其重建分数。这些发现促成了 EchoPress，这是一种无需训练的方法，它使用标准预填充中的查询和键来近似重建注意力。对于每个请求，它仅重建第一个块，以校准剩余上下文的重要性分数。在 LongBench 和 RULER 上，使用 Qwen3-8B 和 Llama-3.1-8B-Instruct 进行的实验表明，在 50% 到 90% 的逐出率下，EchoPress 在任务准确率上与 KVzip 相当，同时将压缩开销降低 1.7-19.6 倍，并将总预填充时间最多降低 2.9 倍。代码可在 https://github.com/ljwljwljwljw/kvpress/tree/echo-press 获取。

## Abstract
KV cache pruning reduces long-context inference memory usage by evicting less important key-value pairs. KVzip estimates importance through context reconstruction: prompting a model to repeat the context chunk by chunk. This achieves strong compression quality at the cost of additional forward passes. Learned approximations reduce this cost but require model-specific training. We analyze how KVzip identifies important cached information and show how to approximate its reconstruction scores using information already computed during prefill. These findings motivate EchoPress, a training-free method that approximates reconstruction attention using queries and keys from standard prefill. For each request, it reconstructs only the first chunk to calibrate importance scores for the remaining context. Experiments on LongBench and RULER with Qwen3-8B and Llama-3.1-8B-Instruct show that EchoPress matches KVzip in task accuracy across eviction ratios from 50% to 90%, while reducing compression overhead by a factor of 1.7-19.6 and total prefill time by a factor of up to 2.9. Code is available at https://github.com/ljwljwljwljw/kvpress/tree/echo-press.

## 2. 方法论

### 2.1 核心思想

- **虚拟上下文重建**：不真正执行 KVzip 的逐块重复前向，而是复用 prefill 中已有的 query/key，通过 RoPE 位置偏移和因果虚拟复制，模拟“重复上下文”时的注意力评分。
- **第一 chunk 精确重建 + 后续虚拟评分**：第一个 chunk 的 prefill 状态与重建状态差异最大，因此只对它做一次精确重建；用其精确分数校准后续 chunk 的虚拟分数。
- **每请求自校准**：不依赖外部校准数据、任务标签、优化或存储的模型特定参数。

### 2.2 关键技术细节

- **KVzip 重建评分回顾**：
  - 对每个 chunk，KVzip 用完整原始 cache 作为前缀，输入重复提示和原 chunk，做 teacher-forced 前向。
  - 评分 softmax 只包含初始 sink keys、目标缓存 chunk、重复 chunk 的因果前缀；其他上下文 key 影响隐藏状态但不进入评分 softmax。
  - 每个缓存位置的重要性分数为该 KV 对在重复过程中收到的最大注意力概率，最后用全局阈值跨层、KV head、位置逐出最低分 KV 对。
- **EchoPress 虚拟评分**：
  - 保留 prefill 的因果表示，将 token 位置旋转到重复时对应位置：偏移量为 \(\Delta_t = n + P_t - a_t\)。
  - 对 prefill query/key 施加同一旋转 \(R_\Delta\)，得到虚拟 query/key。
  - 利用旋转共享性：\( (R_\Delta q)\cdot k_i = (R_\Delta q)\cdot k_i\)，且 \( (R_\Delta q)\cdot (R_\Delta k_i)=q\cdot k_i\)，因此缓存 chunk 与虚拟副本可共享 key 张量。
  - 虚拟评分同时考虑：
    1. 目标缓存 chunk 中所有 key 对移位 query 的可见性；
    2. 因果虚拟副本分支，仅允许 \(v \le j\) 的副本 key 可见；
    3. sink keys。
  - 每个缓存 key 的虚拟分数是其跨 query 位置和同 KV head 下 query head 的最大注意力概率。
- **第一 chunk 校准**：
  - 虚拟分数保留 head 内排序，但尺度跨层、跨 KV head 失真。
  - EchoPress 对第一 chunk 做一次精确重建，得到精确分数 \(s\)；同时保留第一 chunk 的虚拟分数 \(\hat{s}\)。
  - 对每层、每 KV head，构造经验分位映射 \(M(\hat{s}_{(k)}) = s_{(k)}\)，并在端点间做分段线性插值、端点外裁剪。
  - 后续 chunk 的虚拟分数通过该映射被拉到精确分数尺度，再参与全局逐出。
- **复杂度**：
  - KVzip 额外注意力成本约为 \(O(LHdn^2)\)。
  - EchoPress 额外注意力成本约为 \(O(LHdnC)\)，固定 chunk 大小 \(C\) 时从二次降为线性，约减少 \(n/C\)。
  - 标准 prefill 本身仍为二次。
- **实现**：使用融合 Triton kernel 高效计算虚拟评分；每层评分后释放 query，只保留标量重要性分数。
