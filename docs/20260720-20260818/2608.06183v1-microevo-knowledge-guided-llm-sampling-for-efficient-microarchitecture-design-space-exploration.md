## 摘要
微架构设计空间探索面临搜索空间庞大和PPA评估成本高昂的问题，导致用于设计决策的仿真预算十分有限。现有方法不考虑微架构依赖关系进行盲目搜索，且无法有效从迭代搜索中学习，导致评估资源浪费和帕累托收敛性能不佳。本文提出MicroEvo，一种知识引导框架，将现成的大语言模型与蒙特卡洛树搜索相结合，用于多目标微架构优化。MicroEvo结合了LLM驱动的进化算子、平衡帕累托贡献与多样性的帕累托感知树策略、提取并复用优化见解的主动知识积累机制，以及在线调整搜索行为的状态感知指令。实验表明，与NSGA-II相比，MicroEvo将帕累托前沿质量提升了高达36.2%，搜索效率提高了10.6倍，并展现出对复杂工业级核心的强可扩展性。代码仓库位于：https://github.com/GEAR-SEU/MicroEvo-ICCAD-26。

## Abstract
Microarchitecture design space exploration suffers from expansive search spaces and expensive PPA evaluation, leaving only a small simulation budget for design decision-making. Existing methods perform blind search without considering microarchitectural dependencies and fail to learn from the iterative search effectively, leading to wasted evaluations and weak Pareto convergence. In this paper, we propose MicroEvo, a knowledge-guided framework that couples off-the-shelf LLMs with Monte Carlo Tree Search (MCTS) for multi-objective microarchitecture optimization. MicroEvo combines LLM-driven evolutionary operators, a Pareto-aware tree policy that balances Pareto contribution and diversity, an active knowledge accumulation mechanism that extracts and reuses optimization insights, and state-aware directives that adapt the search behavior online. Experiments show that MicroEvo improves Pareto-front quality by up to 36.2% over NSGA-II and achieves 10.6x higher search efficiency, and also demonstrates strong scalability to a complex industrial-scale core. The code repository is available at: https://github.com/GEAR-SEU/MicroEvo-ICCAD-26.

- **核心问题**：如何在极少的评估次数内，高效逼近帕累托最优前沿，同时避免盲目搜索和评估资源浪费。
- **现有方法的不足**：
  - 传统多目标优化（如 NSGA-II、贝叶斯优化）缺乏架构领域知识，采用概率采样进行盲目搜索，容易陷入局部最优。
  - 现有 LLM 驱动的 DSE 方法（如 LEMOE）虽能生成高质量初始样本，但未能有效利用迭代反馈，搜索后期易停滞，无法持续提升帕累托质量。
  - 基于代理模型的方法存在小样本下预测误差累积的问题。
- **论文意义**：提出 MicroEvo，首次将 LLM 的预训练架构知识与蒙特卡洛树搜索（MCTS）的结构化探索相结合，将“盲目标量采样”转变为“知识引导的进化搜索”，显著提升采样效率和帕累托前沿质量，为高成本微架构 DSE 提供了新范式。

## 2. 方法论

### 2.1 核心思想

- 以 MCTS 作为搜索骨架，LLM 作为进化算子的生成器，通过“选择-扩展-模拟-回传”四阶段迭代搜索。
- 关键创新在于四个组件：
  1. **Pareto-UCT**：多目标感知的树节点选择策略。
  2. **LLM 驱动的进化算子**：知识调优器（Knowledge Tuner）和模式探索器（Pattern Explorer）。
  3. **主动知识积累（AKA）**：从历史探索中提取并复用优化见解。
  4. **状态感知指令（SAD）**：根据搜索进度动态调整 LLM 的行为模式。

### 2.2 关键技术细节

- **MCTS 框架**：
  - 每个节点对应一个微架构设计（参数向量），节点值由仿真得到的 PPA 决定。
  - 四个阶段：选择（按 Pareto-UCT 选择叶子）、扩展（LLM 生成新设计）、仿真（PPA 评估）、回传（更新路径上的值和访问次数）。

- **Pareto-UCT 选择策略**：
  - 公式：  
    `Pareto-UCT(v_i) = Q_HVI(v_i) + e * D(v_i) + λ * sqrt(ln N(v_p)/N(v_i))`
  - 第一项 `Q_HVI`：基于超体积改进（HVI）衡量节点对全局帕累托前沿的边际贡献。
  - 第二项 `D`：拥挤距离，鼓励探索目标空间中采样稀疏的区域，保持前沿多样性。
  - 第三项：带衰减的探索项，随搜索进行逐渐从探索转向利用（`λ = λ0 * sqrt((T-t)/T)`）。
  - 相比标准 UCT，该方法同时考虑了帕累托质量和分布覆盖度。

- **LLM 驱动的初始化与扩展**：
  - **初始化**：LLM 生成面向不同 PPA 偏好的根节点（最大性能、最大能效、平衡、性能优先、功耗/面积优先）。
  - **知识调优器（Knowledge Tuner）**：利用积累的优化见解和父节点 PPA 反馈进行局部改进，遵循微架构参数间的耦合关系（如增加 ROB 时需要匹配 load/store 队列）。
  - **模式探索器（Pattern Explorer）**：分析同父节点的兄弟节点配置，识别高层级设计模式，提出结构性不同的新方案，避免浅层参数扰动。

- **主动知识积累（AKA）**：
  - **帕累托分析**：对已探索设计进行非支配排序，识别当前最优区域和未覆盖的目标空间，生成全局优化方向。
  - **成对分析**：比较父子节点的参数变化和 PPA 差异，提取细粒度的调参规则（如“降低 L2 缓存关联性可显著省功耗且性能损失小”）。
  - **知识记忆**：使用带效用分数 `U(k) = normalized_HVI - ω*log(N(k)+1)` 的记忆模块，兼顾帕累托奖励和访问惩罚，筛选高价值且未被过度使用的见解。
  - 仅当子节点带来显著 HVI 改进或单目标提升>20%时触发知识提取，避免冗余。

- **状态感知指令（SAD）**：
  - 有限状态控制器，包含三种模式：`exploit`（局部精调）、`balance`（平衡）、`explore`（大规模结构变化）。
  - 根据连续停滞次数（无显著 HVI 改进）和算子近期效果自动切换模式。
  - 通过自然语言指令注入 LLM 提示词，使扩展行为适应搜索状态，避免陷入局部最优。

## 6. 主要结论与发现

- **帕累托质量显著提升**：在 45 次预算下，MicroEvo（Gemini）相比 NSGA-II 提升 HV 23.9%，相比 Boom-Explorer 提升 17.0%，相比 RL-DSE 提升 16.6%，相比 LEMOE 提升 21.4%；在 20 次预算下提升更明显（最高 36.2%）。
- **搜索效率大幅提高**：达到 HV=0.74 所需评估次数比 NSGA-II 少 10.6 倍，运行时间仅占 Boom-Explorer 的 8.3%。

- **可扩展到复杂架构**：在 XiangShan Kunminghu 上仍保持最佳 HV 轨迹和更凹的帕累托前沿，验证了跨架构通用性。
- **超越专家设计**：在能效（IPC/Power 和 IPC/Area）的几何均值上，MicroEvo 探索出的最佳设计比手工专家设计高出 8.6%。
- **知识引导是决定性因素**：消融实验表明，移除任何关键组件都会显著降低性能，尤其是成对分析（Pairwise）和 SAD 对长期搜索质量至关重要。

## 7. 优点

- **方法创新性**：
  - 将 LLM 从“黑盒数值优化器”提升为“知识引导的进化算子”，充分利用预训练架构知识。
  - Pareto-UCT 在 MCTS 中引入多目标和拥挤度感知，弥补标准 UCT 与多目标 DSE 之间的鸿沟。
  - AKA 将迭代搜索过程转化为可复用的结构知识和参数规则，知识记忆具有效用感知的增删和检索机制。
  - SAD 动态调整搜索模式，有效平衡局部精调与全局探索。
- **实用性强**：
  - LLM 推理开销低（占 <8%），API 成本极低（约 $0.02–1.32），适合实际工程。
  - 对 LLM 幻觉有处理（参数映射到有效值），并规避了模拟器绝对误差的影响（避免具体量化映射）。
- **实验设计全面**：对比基线覆盖多种方法族，消融详尽，可扩展性和专家对比增强了说服力。

## 8. 不足与局限

- **算力细节缺失**：未报告 GPU 型号、数量等硬件资源信息，仅提及 Intel Xeon 服务器，复现者难以精确对齐环境。
- **LLM 依赖与随机性**：结果依赖具体 LLM（DeepSeek、Gemini）的 API 行为，可能存在版本更新导致性能波动；虽然做了 5 次重复，但未说明随机种子，统计显著性检验不足。
- **评估工具误差**：GEM5/McPAT 的模拟精度与实际芯片仍有差距，文中虽通过指令避免 LLM 依赖绝对数值，但未能完全消除该影响。
- **基准集单一**：实验仅基于 RISC-V 基准套件，未包含真实工作负载（如 SPEC）或更多元化的应用场景。
- **设计空间覆盖有限**：主场景仅 22 个参数，虽已很大，但现代处理器还有更多微架构细节（如预取策略、电源门控等）未纳入。
- **无流片验证**：所有结果基于模拟器，未经过真实硅片验证，实际 PPA 可能偏离。
- **消融实验仅展示了整体性能下降，未分析组件之间的交互效应**（例如 AKA 与 SAD 是否部分重叠）。
- **RL-DSE 的比较公平性**：RL-DSE 需要训练过程，其预算分配可能与 MicroEvo 不对等，可能对 RL-DSE 不利。
