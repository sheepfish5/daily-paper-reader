## 摘要
现代硅前设计空间探索（DSE）遵循从粗到细的工作流程：低成本评估器筛选候选空间，而详细评估则保留给入围名单。晶圆级系统对这两个阶段都构成压力。架构选择会引发对掩模版合规性、晶圆拼接、芯片面积、D2D能力、边界访问和布局的耦合物理影响，因此设计空间不能被视为无约束的笛卡尔积。同时，详细评估成本过高，无法覆盖由此产生的空间，而解析到参考的排名反转使得固定入围名单不可靠。我们提出Fovea，一种可复用的方法论，用于针对特定工作负载的晶圆架构选择，而非固定晶圆模板。Fovea首先进行物理影响感知的设计空间制定，构建一个独特的建模可行空间，同时保留跨维度权衡，并仅应用保留评估器的局部缩减。然后执行决策域引导的跨保真度细化。配对域内校准估计工作负载和空间特定的解析到参考的不一致性，该不一致性参数化参考一致的性能区间，并诱导出一个决策域，用于选择性指定参考评估。在有效的全域不一致性界限下，该域包含指定参考最优解；基于采样的实现在穷举参考设计空间上进行了经验评估。在十个参考可验证的设计空间和七个LLM训练工作负载中，Fovea以10%的配对校准在所有70个评估对中恢复了穷举指定参考最优解，同时实现了4.13倍平均和7.80倍最大的端到端加速。

## Abstract
Modern pre-silicon design-space exploration (DSE) follows a coarse-to-fine workflow: low-cost evaluators screen candidate spaces, while detailed evaluation is reserved for a shortlist. Wafer-scale systems strain both stages. Architecture choices induce coupled physical implications for reticle compliance, wafer tiling, die area, D2D capability, boundary access, and placement, so the design space cannot be treated as an unconstrained Cartesian product. Meanwhile, detailed evaluation is too expensive to cover the resulting space, whereas analytical-to-reference ranking inversions make a fixed shortlist unreliable. We present Fovea, a reusable methodology for workload-specific wafer architecture selection rather than a fixed wafer template. Fovea first performs physical-implication-aware design-space formulation to construct a distinct modeled-feasible space while preserving cross-dimensional trade-offs and applying only evaluator-preserving local reductions. It then performs Decision-Domain-guided cross-fidelity refinement. Paired in-domain calibration estimates workload- and space-specific analytical-to-reference disagreement, which parameterizes reference-consistent performance intervals and induces a Decision Domain for selective designated-reference evaluation. Under a valid domain-wide disagreement bound, this domain contains the designated-reference optimum; the sampling-based implementation is evaluated empirically on exhaustive-reference design spaces. Across ten reference-verifiable design spaces and seven LLM-training workloads, Fovea with 10% paired calibration recovers the exhaustive designated-reference optimum in all 70 evaluated pairs while achieving 4.13x average and 7.80x maximum end-to-end speedup.

# 2. 方法论

Fovea 由两个阶段组成，输入为：工作负载与优化目标、架构组件库、实现约束、评估器对（低成本和指定参考）。

## 2.1 阶段一：物理影响感知的设计空间构建

- **架构参数化**：面向均匀重复投片阵列（homogeneous repeated-die），每个候选包括 die 尺寸、兼容行-列拼接、功能分区以及从组件库中选择的计算/存储/D2D 配置。
- **晶圆级可行性检查**：
  - 掩模合规性（reticle compliance）；
  - 几何包含检查：对每个整数行-列对 (Nrow, Ncol) 实例化 die 阵列，确保每个 die 都完整位于排除边缘后的可用晶圆区域内，而非仅用聚合面积判断。
- **die 级面积预算模型**：
  - \( A_{die} = A_{np} + A_{impl} + A_{alloc} \)，其中 \(A_{np}\) 为不可放置区域，\(A_{impl}\) 为固定实现开销，\(A_{alloc}\) 为可用分配区域；
  - \( A_{alloc} = A_{comp} + A_{mem} + A_{intf} \)。
- **功能分配与配置匹配**：
  - **D2D 能力检查**：请求带宽 \(BW_{D2D}\) 必须不超过 die 轮廓所支持的 \(BW_{max}(L_{die}, W_{die}; \tau)\)；
  - **边界访问与放置检查**：接口块必须满足有效 die 边约束 \(E_{req} \le E_{max}(L_{die}, W_{die}; \tau)\)，通过显式枚举合法边分配与方向进行可放置性检验。
- **精确局部结构缩减**：
  - **等价类约简**：合并镜像或重排但评估可见属性完全相同的配置；
  - **同足迹局部严格支配约简**：若两个配置模型足迹相同且一个在所有比较维度上不劣且至少一个维度严格更优，则移除被支配配置。
- 保留的 die 配置与所有兼容晶圆拼接组合，最终得到“独特建模可行设计空间” \(D\)。

## 2.2 阶段二：决策域引导的跨保真度细化

- **交叉保真度不一致模型**：
  - 定义每个候选的性能分数 \(P_L(d)\) 和 \(P_R(d)\)（执行时间倒数，越大越好）；
  - 相对性能误差 \(e(d) = P_L(d)/P_R(d) - 1\)，全域不一致界 \(\epsilon = \max_{d \in D} e(d)\)；
  - 若 \(0 \le \epsilon < 1\)，则参考一致区间为：
    \[
    \frac{P_L(d)}{1+\epsilon} \le P_R(d) \le \frac{P_L(d)}{1-\epsilon}.
    \]
- **决策域形成**：
  - 令 \(d^*_L\) 为低成本最优，保守保留截止值：
    \[
    R(\epsilon) = \frac{1-\epsilon}{1+\epsilon} P_L(d^*_L),
    \]
  - 决策域 \(C(\epsilon) = \{d \in D \mid P_L(d) \ge R(\epsilon)\}\)，即所有在乐观参考区间内仍可能超过 \(d^*_L\) 悲观参考性能的候选。
  - **条件包含性质**：若 \(\epsilon\) 为有效全域不一致界，则指定参考最优 \(d^*_R\) 必然保留在决策域中。
- **实际校准**：在完整空间上用低成本评估后，按 10% 比例均匀配对采样（20 次独立随机，留一设计空间法经验选择采样率），用样本最大误差 \(\hat{\epsilon}\) 近似 \(\epsilon\)；校准结果被缓存，并参与最终选择。
- **决策域诊断（DDC）**：离线绘制决策域大小随 \(\epsilon\) 变化的曲线，分析不一致界的改变对保留候选规模的影响。

# 6. 结果

- **主结果**：Fovea 在所有 70 个 workload/design-space 对上均恢复了穷举参考最优设计，端到端时间平均为穷举参考的 24.21%（约 4.1 倍加速），其中参考评估占大部分时间，低成本评估与校准开销可忽略。
- **与低成本分析的对比**：Exhaustive Analytical 选择的低成本最优候选在参考评估器下平均仅处于第 10.77 百分位，且平均 20.96% 候选对发生排名反转，说明低成本评估器的排名噪声不可忽略。
- **与多保真度 / 搜索方法的对比**：SA 在所有空间上未能恢复参考最优；Theseus 与 Polaris 在简单空间（设计空间较小、冲突不明显）表现尚可，但在复杂空间（物理约束耦合强、评估器分歧大）上失败，平均恢复率低于 50%。Fovea 在恢复成功率与端到端成本之间取得了明显更优的权衡。
- **校准开销**：10% 配对采样 + 20 次重复所需的参考评估次数仅约为完整参考评估的 10.4%，远低于穷举参考。
- **DDC 诊断结果**：决策域规模随 ε 的增大呈单调递增但非均匀变化；在大多数空间上，ε 从 0 到 0.1 时决策域快速增长，随后增长放缓，说明评估器不一致主要集中在小部分高度冲突的候选上。

# 7. 局限性与未来工作

- **硬件范围限制**：Fovea 目前仅面向同构重复 die 的晶圆级设计，未覆盖异构 die、chiplet 混用、3D 堆叠或更复杂的封装方案。
- **评估器依赖**：可行性检查与面积模型依赖工艺/封装参数（如掩模限制、可用晶圆区域、D2D 物理接口的 τ），若参数与实际 implementation 不匹配，决策域保证可能退化。
- **一致性界估计**：当前用样本最大误差 \(\hat{\epsilon}\) 近似全域不一致界，虽然经验上有效，但缺乏统计置信界；极端分布下可能低估真实 ε，导致条件包含性质失效。
- **目标单一性**：目前优化目标为执行时间（性能）单一标量，未处理多目标（性能-功耗-面积-成本）Pareto 前沿搜索，也未引入能源、热约束或制造成本。
- **工作负载范围**：仅验证了 LLM 训练负载；对于推理、混合工作负载、非规则通信模式或计算受限扩展，结论可能需重新验证。
- **未来方向**：扩展到异构 die 与 3D 晶圆级系统；引入统计校准理论以提供正式置信区间；融合多目标优化与带约束优化；将 Fovea 与编译/映射联合优化；开源方法论与基准以促进可复现研究。

- **最大贡献**：Fovea 的价值在于将“物理可行性”从事后检查提升为设计空间构建的一等公民，同时正视低成本评估器的排名噪声，提出决策域思想——不是去修正评估器，而是缩小需要参考评估的候选集合。条件包含性质在理论上提供了保证性，这是启发式搜索方法不具备的。
- **值得商榷之处**：
  1. 论文对“参考最优”的定义依赖于 ASTRA-sim+ns-3 的准确度，而该模拟器本身是近似模型，并非真实硬件；因此“恢复参考最优”不等于“恢复真实最优”。论文虽用 gem5 Garnet 做了决策级交叉验证，但覆盖范围有限（4 个设置），且 Spearman 相关系数高并不等价于绝对性能误差小。
  2. 10% 配对采样比例的选择依赖“留一设计空间法”的经验结果，缺乏理论保证；若真实 ε 被低估，决策域的包含性质会失效，而论文未提供失败模式的量化风险。
  3. 与 Theseus/Polaris 的比较中，各方法的超参数与预算分配是否公平调优未见深入说明；固定预算为穷举参考 25% 的时间，而 Fovea 平均也约为 24.21%，看似相似但搜索策略本质不同——Fovea 是确定性枚举 + 决策域筛选，而对比方法是随机搜索，这种比较在方法论上合理，但未分析预算分配的敏感性。
  4. 设计空间规模最大仅 5655，相较于真实晶圆级架构设计中组件的组合爆炸（die 尺寸、D2D 参数、分区方式连续变化）仍然较小；Fovea 的可行性检查与决策域枚举在大规模空间上的可扩展性未充分讨论。
- **启发与延伸**：决策域思想不限于晶圆级 DSE，可迁移至其他存在低成本/高成本评估器分歧的架构搜索场景（如 NoC 设计、RTL 综合前/后评估）；物理约束与评估一致性的解耦分析也是体系结构研究常用的通用视角。

总体而言，Fovea 是一篇方法工程完整、实验扎实的论文，其核心贡献是概念性的：指出多保真度 DSE 中低成本评估器的排名噪声与物理约束耦合是主要挑战，并通过决策域筛选提供可证明的恢复保证。尽管存在校准与泛化层面的局限，它在晶圆级 AI 架构逐渐走向实用化的背景下具有较高的参考价值。
