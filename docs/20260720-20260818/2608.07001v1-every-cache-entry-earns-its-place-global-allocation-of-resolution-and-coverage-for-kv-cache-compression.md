## 摘要
随着大型语言模型（LLM）处理越来越长的上下文，KV缓存存储和重复访问已成为主要瓶颈。现有的KV缓存压缩方法依赖预定义的固定压缩规则，并且通常围绕令牌驱逐或合并来开发。因此，缓存资源既不能在层、头和上下文槽位之间自由流动，也不能联合分配以平衡局部分辨率和信息覆盖。为此，我们提出GraceKV，一种在KV缓存压缩中全局分配分辨率和覆盖范围的方法，并将压缩过程形式化为固定缓存预算下的全局资源分配问题。GraceKV将每个层-KV头-槽位组合视为一个原子单元，并构建原型树。叶节点对应令牌级KV条目，而每个内部节点使用单个原型来压缩其子节点覆盖的KV空间。树中一组不重叠的节点构成一个原子单元的表征。添加新树的根扩展信息覆盖范围，而拆分选定节点则提高局部分辨率。所有候选操作在全局竞争共享缓存预算。最终，所有树中保留的节点构成压缩后的KV缓存。该过程自适应地确定缓存资源在原子单元之间的全局分配以及分辨率与覆盖范围之间的平衡。GraceKV无需额外训练，整个压缩和推理过程在GPU上执行。跨多种长上下文任务和压缩比率的系统实验表明，GraceKV在32个设置中的24个中排名第一，并在高达128倍压缩下保持稳健。这些结果验证了全局预算分配在协调信息覆盖和局部分辨率方面的有效性。

## Abstract
As large language models (LLMs) process increasingly long contexts, KV cache storage and repeated access have become a major bottleneck. Existing KV cache compression methods rely on predefined, fixed compression rules and are typically developed around either token eviction or merging. As a result, cache resources can neither flow freely across layers, heads, and context slots, nor be jointly allocated to balance local resolution and information coverage. Therefore, we propose GraceKV, a global approach for the allocation of resolution and coverage in KV cache compression, and formulate the compression process as a global resource allocation problem under a fixed cache budget. GraceKV treats each layer-KV head-slot combination as an atomic unit and builds a prototype tree. Leaf nodes correspond to token-level KV entries, while each internal node uses a single prototype to compress the KV space covered by its children. A set of non-overlapping nodes in the tree forms the representation of an atomic unit. Adding the root of a new tree expands information coverage, whereas splitting a selected node improves local resolution. All candidate actions compete globally for a shared cache budget. Finally, the nodes retained across all trees form the compressed KV cache. This process adaptively determines the allocation of cache resources among atomic units globally and the balance between resolution and coverage. GraceKV requires no additional training, and the entire compression and inference process is performed on the GPU. Systematic experiments across diverse long-context tasks and compression ratios show that GraceKV ranks first in 24 of 32 settings and remains robust up to 128-fold compression. These results validate the effectiveness of global budget allocation in coordinating information coverage and local resolution.

## 1. 核心问题与研究动机

- **背景**：大型语言模型（LLM）在长文档理解、复杂推理等场景中需要处理越来越长的上下文。为了避免自回归生成中的重复计算，LLM 会为每个上下文令牌缓存 Key 和 Value（即 KV cache）。但 KV cache 的存储占用随上下文长度线性增长，并在每一步解码时被反复访问，导致 GPU 内存压力和访存开销持续攀升，成为长上下文推理的主要瓶颈。
- **现有方法的问题**：
  - 现有 KV 压缩方法主要沿两条路线：**令牌驱逐**（token eviction）和**KV 合并**（KV merging），两者各自只侧重于保留子集或聚合表示，无法同时兼顾。
  - 现有方法通常依赖**预定义的固定压缩规则**，即使后续引入了层或头级别的自适应性，仍需事先指定分配粒度或局部配额。
  - 这种"先约束表征形式和局部配额，再做压缩决策"的范式，无法让有限的缓存资源跨层（layers）、跨注意力头（KV heads）、跨上下文区域（context regions）自由流动，也无法在**局部分辨率**（local resolution）与**信息覆盖**（information coverage）之间联合权衡。
- **核心问题**：如何让有限的缓存资源自适应地流向更有价值的位置，从而更有效地组织和保留上下文信息？作者将 KV 压缩形式化为**固定预算下的全局资源分配问题**。

## 2. 方法论（GraceKV）

### 2.1 总体框架

GraceKV 将每个"层–KV头–槽位"组合视为一个**原子单元**（atomic unit），并构建**可逐步精化的原型树**（progressively refinable prototype tree）：

- **叶节点**对应单个令牌的原始 K/V 条目；
- **内部节点**用一个原型（prototype）压缩表示其子节点覆盖的连续区间；
- 一个树中选取的一组**不重叠节点**（frontier）即构成该原子单元在特定分辨率下的缓存表示。

基于该原型树，定义两种基本操作：

- **Add**：为新树添加根节点，扩展信息覆盖范围；
- **Split**：拆分选中节点（替换为其子节点集合），提升局部区域内表示的分辨率。

### 2.2 关键过程：两阶段流程

GraceKV 通过两条互补的"流"完成全局分配：

1. **自底向上的价值流（bottom-up value flow）**：
   - 从令牌级上下文价值出发，沿树向上聚合成节点价值；
   - 结合注意力失真减少量（distortion reduction）与头敏感性（head sensitivity），构成每个候选操作的边际效用。

2. **效用引导的预算流（utility-guided budget flow）**：
   - 将跨所有原子单元的候选操作放入同一个全局优先级队列，按**单位成本的边际效用**竞争共享预算。
   - 预算有限时，高效用操作优先执行；每完成一个操作，将新暴露的子操作入队，直到预算耗尽或无处可执行。

### 2.3 核心技术细节

- **曲率引导的语义槽分割**：将归一化隐藏状态视为沿令牌位置的轨迹，利用多层、多尺度的轨迹曲率（curvature）+ 令牌惊异度（surprisal），通过动态规划产生语义连贯的槽分区（slot partition）。
- **RoPE一致性原型**：先将不同位置 post-RoPE 的 key 逆旋转到统一坐标系，按代表性位置重新施加 RoPE，得到可合并的 key 原型；value 原型按令牌价值加权（含 10% 均匀基底）。
- **有效多重性（effective multiplicity）校正**：根据 key 方向一致性（coherence）校正原型所代表的实际令牌数量，并在解码时以 log 倍数修正注意力 logit。
- **多跳相关性传播**：在采样层经令牌级注意力图进行两跳衰减传播，结合直接相关性与间接依赖关系。
- **层/头敏感性系数**：结合静态输出投影强度与输入相关的动态输出强度，归一化后作为该 KV 头的乘子。
- **单例地板（singleton floor）**：为补偿贪婪分配对非光滑收益的低估，在全局竞争前预算受限地选出一小部分高价值令牌以**精确 K/V 单例**方式保留，其成本计入同一预算。
- **压缩后物理缓存**：所有保留的前沿节点打包为不规整缓存（ragged cache）直接用于 GPU 解码；当压缩比 x=1 时，可精确恢复 FullKV。

### 2.4 数学形式化

分配问题形式化为：

\[
\max_{A'\subseteq A} \sum_{a\in A'} \Delta(a),\quad \text{s.t.} \sum_{a\in A'} c(a) \le B_{\text{alloc}},\quad \text{Pred}(a) \subseteq A', \forall a \in A'
\]

其中 \(\Delta(a)\) 为边际效用，\(c(a)\) 为新增物理 KV 条目数，\(B_{\text{alloc}}\) 为可用预算，Pred(a) 为前提操作集合。

- Add 的效用 = 敏感性 × 根节点价值 ×（完全丢弃代价 − 根原型失真）；
- Split 的效用 = 敏感性 × 节点价值 ×（父原型失真 − 子原型失真之和）；
- 操作按效用/成本之比（utility per unit cost）降序全局竞争。

（注：实际求解采用**全局贪婪分配**，因为精确组合优化空间随树结构指数膨胀。）

## 6. 主要结论与发现

1. **全局分配优于固定规则**：GraceKV 在相同缓存条目预算下，比令牌驱逐、KV 合并和局部自适应方法更有效地组织和保留上下文信息。
2. **跨任务与压缩比稳健**：从 4× 到 128× 压缩，GraceKV 均位居前列或保持竞争力，性能平滑下降；而某些基线在特定任务或紧预算下严重退化。
3. **固定策略存在明显的任务偏向**：合并类方法擅长 Aggregation 但检索能力差；驱逐类方法擅长 Retrieval 但 Aggregation 不佳；GraceKV 通过统一空间中的全局竞争自动平衡两者。
4. **多分辨率表示与全局分配是关键设计**：消融显示 Multi-Resolution 与 Global Allocation 的移除影响最大。
5. **效率收益显著**：30K 上下文中 KV cache 内存较 FullKV 减少 74%（4×）至 92%（16×），解码延迟最高降低约 1.7×；压缩构建的一次性开销可在长生成或缓存复用场景下快速摊销。

## 7. 方法优点

- **统一的概念框架**：将驱逐、合并、无损保留统一为同一棵原型树的不同前沿状态，概念优雅且表达力强。
- **真正的全局预算竞争**：不预设层/头/槽位配额，资源分配结果由输入相关的边际效用自然涌现，突破了"先定配额、再做压缩"的旧范式。
- **覆盖与分辨率联合权衡**：Add 与 Split 使用同一预算、同一效用度量，可直接比较"扩展覆盖"与"提升分辨率"的收益。
- **无需训练，全 GPU 运行**：单次 prefill 后完成压缩，不依赖 CPU 存储或额外模型前向，实用性强。
- **可恢复性**：压缩比 x=1 时精确恢复 FullKV，说明方法是 FullKV 的真实推广而非有损特例。
- **工程细节扎实**：RoPE 一致性 key 原型、有效多重性校正、注意力质量加权的失真度量、单例地板补偿非光滑收益等设计，说明作者对实际推理问题有深入考量。
- **实验广泛**：5 个骨干模型、3 个模型家族、3B–14B 参数规模、6 类任务、4×–128× 压缩比，以及完整的消融和超参数分析，支撑力较强。

## 8. 不足与局限

- **全局最优性不能保证**：作者承认采用全局贪婪分配只是近似求解；精确组合优化空间呈指数级增长，无法在线完成。单例地板只能部分缓解对非光滑收益的低估，不能保证最优。
- **一次性构建开销**：原型树构建引入约 2 秒延迟和约 8% 峰值显存开销。虽然可摊销，但对严格的在线低延迟场景仍构成负担；当前实现未做底层/硬件级优化（如并行建树、算子融合、专用 ragged-attention kernel）。
- **缓存复用受限**：压缩缓存是问题相关的（question-conditioned），换一个新问题需要重新做相关性与全局分配；虽然可复用结构部分，但论文未完整实现该扩展。
- **缺乏代码与复现细节**：作为预印本，未提供开源代码，影响可复现性和后续验证。
- **系统效率对比不够全面**：效率实验仅对比了 FullKV 与 GraceKV 单方法，跨方法同预算的系统开销对比只在表格 12 中展示了少数方法（StreamingLLM、SnapKV），未覆盖全部基线。
- **真实场景验证有限**：任务以标准 benchmark 为主，未涉及真实的超长文档（100K+）或动态多轮对话场景；RULER 上下文仅为 4K/2K/1K/512 量级，与论文标题中的超长上下文目标存在一定差距。
- **无多语言/多模态验证**：LongBench 虽为双语基准，但主实验主要聚焦英文任务；方法对中文等语言的泛化未单独讨论。
