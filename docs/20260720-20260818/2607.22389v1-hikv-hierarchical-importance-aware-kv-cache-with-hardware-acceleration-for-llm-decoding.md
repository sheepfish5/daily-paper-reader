## 摘要
随着长上下文大语言模型（LLMs）的快速普及，解码过程中持续增长的KV缓存已成为关键的内存瓶颈。为应对这一挑战，我们提出了HiKV，一种新颖的算法-硬件协同设计，通过层级重要性感知来利用KV缓存冗余。在算法层面，HiKV在两个粒度上压缩KV缓存：第一阶段在固定预算内驱逐不重要的令牌，第二阶段仅加载每个保留令牌中的重要元素，达到单一粒度无法实现的压缩比。在架构层面，我们开发了一个专用加速器，核心是可重构的重要性排序器，可在不同阶段所需的排序数据路径之间切换，以最小开销在一个电路中统一两阶段加速。在代表性LLMs上评估，HiKV在注意力计算中相比原始KV缓存基线实现了高达7.95倍的加速和90%的能耗降低，精度损失仅为1%。在等精度约束下，HiKV通过比最先进的基于重要性的方法额外减少1.82~4.87倍的外部内存访问，从而优于这些方法。这些优势由专用硬件组件实现，仅增加8%的系统面积。

## Abstract
With the rapid adoption of long-context large language models (LLMs), the continuously growing KV cache during decoding has become the critical memory bottleneck. To tackle this challenge, we propose HiKV, a novel algorithm-hardware co-design that exploits KV cache redundancy through hierarchical importance awareness. Algorithmically, HiKV compresses the KV cache at two granularities: Stage I evicts unimportant tokens within a fixed budget, and Stage II further loads only the significant elements of each retained token, reaching compression ratios unattainable at a single granularity. Architecturally, we develop a dedicated accelerator centered on a reconfigurable importance sorter that switches between the distinct sorting datapaths each stage requires, unifying the two-stage acceleration in one circuit with minimal overhead. Evaluated on representative LLMs, HiKV achieves up to 7.95x speedup and 90% energy reduction in the attention computation over the vanilla KV cache baseline within negligible 1% accuracy loss. Under iso-accuracy constraints, HiKV outperforms state-of-the-art importance-based methods by achieving an additional 1.82~4.87x reduction in external memory accesses. These benefits are enabled by specialized hardware components that add only 8% to the system area.

# HiKV论文总结

## 一、核心问题与整体含义

- **研究背景**：长上下文大语言模型（LLM）在自回归解码阶段需要维护不断增长的KV缓存。随着序列长度增加和批处理（batch）规模扩大，KV缓存成为外部内存访问的主要来源，导致严重的带宽瓶颈和能耗开销。
- **核心问题**：如何在尽量不损失模型精度的前提下，显著减小KV缓存的存储与访问开销，从而提升LLM解码的吞吐和能效。
- **整体含义**：本文提出一种算法-硬件协同设计（algorithm-hardware co-design），通过层级重要性感知在“令牌级”和“元素级”两个粒度同时压缩KV缓存，并以此为基础设计专用加速器，为长上下文LLM高效解码提供新思路。

## 二、方法论

### 核心思想
- 基于注意力分数分析发现：KV缓存冗余同时存在于**令牌之间**与**令牌内部元素之间**，且这两种冗余可以正交组合。
- 因此采用两级压缩：**Stage I**（粗粒度令牌级）驱逐不重要的令牌；**Stage II**（细粒度元素级）仅加载保留令牌中的重要元素。

### 关键技术细节
- **Stage I（令牌级管理）**：
  - 将固定缓存预算 `B_I` 分为“近期令牌库（Recent bank）”和“重要令牌库（Important bank）”两部分。
  - 仅对近期令牌的注意力分数进行局部累积得到重要性分数（IS），降低维护开销。
  - 重要令牌库采用冻结IS + 最小堆（min-heap）结构，使驱逐复杂度从 `O(B_I)` 降至 `O(log B_I)`。
- **Stage II（元素级选择）**：
  - 对Q向量进行全局 top-`B_II` 排序，选出重要维度，指导对应K缓存的选择性加载。
  - 对P向量采用分块（chunk）排序：将P分成与注意力头维度 `d_h` 大小相同的块，每块独立选择 top-`B_II` 元素，避免全局排序的过高开销。
  - 分块排序与全局排序在实验中达到95%以上的召回率。
- **硬件设计**：
  - 核心是可重构重要性排序器（RIS），基于统一的2输入Bitonic排序器构建，支持四种模式：`HEAPIFY_UP`、`HEAPIFY_DOWN`（用于Stage I）和 `GLOBAL_SORT`、`CHUNK_SORT`（用于Stage II）。
  - 配套模块包括令牌重要性分数生成器（TISG）、Scoreboard缓冲区、解码计算引擎（DCE）等。
  - K缓存采用“元素优先”存储布局，V缓存采用“分块索引”布局，以匹配两级选择模式。

### 算法流程
- 每个解码步骤执行：Stage II对Q排序 → 选择性加载K并计算 `QK^T` → softmax得到P → Stage I更新IS并维护堆 → Stage II对P分块排序 → 选择性加载V并计算 `P·V` → 新令牌加入近期库。

## 六、主要结论与发现

- 层级重要性感知的两阶段压缩方法显著优于单一粒度方法：在`<1%`精度损失下，总压缩比可达到单粒度方法的2倍以上。
