## 摘要
长上下文推理是现代大语言模型（LLM）应用（如检索增强生成和多文档推理）的核心。为缓解日益增长的推理成本，近期工作探索了键值（KV）缓存重用以减少冗余的预填充计算。然而，现有的重用方法主要关注计算节省，忽视了长上下文LLM服务中的一个关键瓶颈：存储和访问大型KV缓存的成本。虽然KV压缩似乎是自然的补充，但将压缩与非前缀KV重用简单结合往往会导致严重的精度下降。在这项工作中，我们提出了C$^2$KV，一个用于非前缀KV重用的统一框架，联合优化KV提取和推理时拼接。C$^2$KV学习一个可组合且压缩的KV缓存流形，该流形被明确设计为位置无关。我们的方法引入了一个轻量级辅助提取器，带有可学习的压缩令牌和结构化注意力流，使得模块化KV表示能够在不修改冻结基座模型的情况下灵活重用和拼接。我们进一步采用压缩-拼接协同训练策略，使提取时的表示与其下游重用行为对齐。跨多个长上下文基准和模型家族的广泛实验表明，C$^2$KV显著降低了KV缓存存储和传输成本，在长上下文中实现了高达17倍的推理加速，同时保持了生成质量。

## Abstract
Long-context inference is central to modern large language model (LLM) applications such as retrieval-augmented generation and multi-document reasoning. To mitigate the growing inference cost, recent work has explored key-value (KV) cache reuse to reduce redundant prefill computation. However, existing reuse methods primarily focus on computation savings and overlook a critical bottleneck in long-context LLM serving: the cost of storing and accessing large KV caches. While KV compression appears to be a natural complement, naively combining compression with non-prefix KV reuse often leads to severe accuracy degradation. In this work, we propose C$^2$KV, a unified framework for non-prefix KV reuse that jointly optimizes KV extraction and inference-time concatenation. C$^2$KV learns a composable and compressed KV cache manifold that is explicitly designed to be position-agnostic. Our approach introduces a lightweight sidecar Extractor with learnable compression tokens and a structured attention flow, enabling modular KV representations that can be flexibly reused and concatenated without modifying the frozen base model. We further employ a compression-concatenation co-training strategy to align extraction-time representations with their downstream reuse behavior. Extensive experiments across multiple long-context benchmarks and model families demonstrate that C$^2$KV significantly reduces KV cache storage and transfer costs, achieving up to 17$\times$ inference speedup under long contexts, while preserving generation quality.

### 1. 核心问题与整体含义（研究动机和背景）

- **背景**：长上下文推理已成为现代 LLM 应用（如 RAG、多文档推理、智能体系统）的中心任务。随着输入上下文不断增长，LLM 推理面临三重压力：预填充计算量大（O(n²)）、KV 缓存存储成本高（O(L) 线性增长）、内存带宽受限。
- **现有工作的不足**：现有 KV 缓存重用工作主要分为三类：
  - **前缀重用**（如 vLLM、RadixAttention）：仅能处理完全相同的请求前缀，在 ICL 场景下适用性有限；
  - **训练无关的非前缀重用**（如 CacheBlend、EPIC）：通过选择性重计算来缓解上下文失配，但忽略了 KV 缓存存储与访问这一核心瓶颈；
  - **基于训练的方法**（如 Block-Attention、KVLink）：需修改基座模型或引入信息瓶颈，存在能力损失（catastrophic forgetting）和灵活性差的问题。
- **核心问题**：现有的 KV 重用方法大多只着眼于减少重计算，而忽视了长上下文场景下真正的主导瓶颈——**KV 缓存的存储开销和内存带宽成本**。此外，将通用的 KV 压缩方法与 KV 重用简单叠加会导致严重的精度下降，因为标准压缩表示不是为跨上下文重用而设计的（即“不可组合”）。
- **整体含义**：论文主张 KV 缓存压缩与重用必须**联合设计**，构建一个既能压缩又可自由拼接组合的 KV 表示流形，从而同时缓解计算、存储和带宽三重瓶颈。

### 2. 论文提出的方法论

**核心思想**：构建一个**可组合且压缩的 KV 缓存流形（manifold）**，该流形是**位置无关（position-agnostic）**的，使各文档的 KV 段可以像“即插即用”模块一样在任意位置被灵活重用和拼接。整个框架保持基座 LLM 完全冻结，仅训练一个轻量级附加模块。

**关键技术细节**：

- **C²Extractor（提取器）**：一个轻量级旁路（sidecar）模块，附加在冻结的基座模型之上。文档输入时，它独立地编码文档，输出压缩后的每层键值对（C²KV）。
- **C²Tokens（压缩令牌）**：在文档令牌流中插入一组辅助令牌，压缩比为 k:1，即每个 C²Token 对应 k 个文档令牌。C²Tokens 共享同一个可学习嵌入向量，不承载词法内容，作为“记忆槽位”。
- **新 QKV 投影头**：基座模型的原始 QKV 投影保持冻结，仅用于文档令牌；C²Tokens 使用独立的、可训练的新投影矩阵（公式 6），投影维度与基座模型完全匹配，保证与下游注意力运算兼容。额外参数约占基座模型参数的 10%。
- **残差均值池化变体（C²KV-Residual）**：在第一层将 C²Token 对应的 k 个文档令牌的隐藏状态均值加到 C²Token 的隐藏状态上（公式 7），提供显式的局部语义聚合通路，增强鲁棒性。
- **结构化信息流（Structured Information Flow, SIF）**：通过精心设计的注意力掩码实现三种约束：
  1. **原始令牌不变性**：原始令牌只能看到其他原始令牌（标准因果掩码），不能看到 C²Tokens，确保基座模型行为完全不变，原始 KV 与冻结模型输出一致；
  2. **块局部语义提取**：每个 C²Token 只能看到其对应块内的原始令牌（以及一个 sink 块），实现 k:1 的局部聚合，防止全局信息泄漏；
  3. **跨块因果累积**：C²Tokens 之间可因果地相互关注，使后续压缩块能积累文档级上下文信息。
- **与 Anchor Token 方法的区别**：Anchor token 方法（如 Gist token）依赖双向注意力，使原始令牌表示被修改、KV 与上下文纠缠，本质上不可组合；C²KV 的注意力流是单向的（原始令牌→C²Tokens），C²Tokens 本质上是“潜在的 KV 载体”而非语义瓶颈，从而保证提取的 KV 表示上下文独立、可直接重用。
- **压缩-拼接协同训练（Compression-Concatenation Co-training）**：训练时文档独立编码提取 KV，但监督信号只在多文档 KV 拼接后的生成任务上施加（公式 10）。没有额外的重构损失或对齐损失。由于文档顺序和数量在训练样本间变化，提取器被迫学习一种在多种拼接方式下都有效的 KV 表示——即一个“拼接可用”的 KV 流形。
- **推理时复用**：只需加载压缩的 C²KV，按照拼接段累计位置偏移重新分配位置嵌入（RoPE 再旋转），直接拼接即可解码，无需重计算或混合（blending）操作。

### 6. 论文的主要结论与发现

- **存储与带宽是核心瓶颈**：现有方法只削减了重计算开销，KV 缓存存储与传输才是长上下文服务中更关键的瓶颈。
- **通用压缩与重用不兼容**：将 SnapKV 等通用压缩方法直接叠加到 KV 重用方法上会大幅降低精度（如 MuSiQue 上 CacheBlend+SnapKV 从 0.2720 降到 0.1311），证明二者必须联合设计。
- **C²KV 实现优越的 TTFT-精度平衡**：在几乎全部模型 × 任务组合下，C²KV 同时实现了最低的 TTFT 和接近全量重计算的精度，占据帕累托前沿最优区域。
- **解码效率显著提升**：压缩 KV 足迹使 per-token 延迟不再随上下文长度线性增长（从 16k 到 128k 仅有微小增加），优于 FR、CacheBlend 和 EPIC。
- **大幅压缩仍保持高精度**：4× 压缩下 C²KV 逼近全量基线；8×-16× 压缩下仍优于现有重用方法；动态压缩比训练可提升跨压缩设置的鲁棒性（包括未见过的 10×）。
- **长上下文检索稳定**：RULER 上 4× 压压缩下，4k 到 64k 上下文范围内性能稳定，仅比原模型略有下降。
- **扩展到更大模型有效**：Qwen3-14B 上仍保持与全量基线相当或更优的精度。
- **最高 17× 推理加速**：在长上下文中对比现有方法。

### 7. 优点

- **问题定义敏锐**：准确指出 KV 缓存存储/带宽才是长上下文服务的真正瓶颈，纠偏了领域内研究对计算优化的单边关注。
- **设计优雅而克制**：通过结构化注意力流实现“原始令牌不变性”——基座模型完全冻结意味着不损失任何原始能力，也避免了训练方法导致的灾难性遗忘；以约 10% 的参数增加换取模块化、可组合的 KV 表示。
- **机制与目标深度对齐**：SIF 的设计（块局部提取 + 单向信息流 + 因果累积）不是随意的，而是每个约束都服务于“可拼接性/位置无关”这一目标；压缩-拼接联合训练更是直接优化端到端的重用行为。
- **推理路径极简**：C²KV 将 KV 准备降为“纯加载”操作，省去了混合/重计算/结构调整等所有额外步骤，原理上保证了最低的 TTFT。
- **实验完整性较好**：从 LLM 系统角度覆盖了 TTFT 和解码两个阶段，在多个模型族上验证了泛化性，消融实验验证了每个设计选择的必要性。

### 8. 不足与局限

- **离线假设较强**：C²KV 假定可重用内容可被离线识别和提取；对在线或增量式 KV 提取场景不适用。对动态变化的文档库或流式更新场景缺乏支持。
- **均匀压缩策略**：所有文档和层使用相同的压缩比，未考虑内容重要性和层间差异；自适应/内容感知的压缩预算是明确的未来方向。
- **额外训练开销**：虽然是轻量提取器（参数约 10%），但仍需针对每个基座模型做 SFT 训练，对快速迭代的开源模型生态仍有一定适配成本。
- **精度评估的局限性**：主要使用 F1 和 ROUGE-L；量化指标无法完全反映长上下文推理中的语义连贯性和深层推理能力。7 个 LongBench 子集主要集中在 QA 和摘要两类任务上，对更多任务多样性（如代码、数学、长文档对话）覆盖有限。
- **TTFT 对比中压缩比的公平性**：TTFT 对比中 C²KV 使用 4× 压缩而其他方法不压缩，虽然这是设计本身的目标差异，但严格来说不同方法在所承担信息量上并不对等。
- **系统级实现细节缺失**：论文侧重模型层面设计，对实际的 KV 存储系统架构、检索策略、多请求并发及内存层级间的实际工程开销讨论较少。
- **训练数据本身的多跳推理覆盖面**：虽然使用了多文档 QA 数据集，但实际 ICL 场景中检索文档的噪声和无关信息比例可能更高，对提取器的鲁棒性提出了额外要求。
