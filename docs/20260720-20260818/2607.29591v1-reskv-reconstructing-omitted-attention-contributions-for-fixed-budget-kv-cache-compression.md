## 摘要
KV缓存压缩对于高效的长上下文推理至关重要。现有的驱逐方法会永久丢弃未选中的令牌，从而移除它们对注意力的整体贡献。基于合并的替代方案保留了更多信息，但可能会扰动本应保持精确的保留键和值。我们观察到，缓存驱逐所省略的信息可以表述为softmax注意力分子和分母中的残差统计量。基于这一观察，我们提出了ResKV，它将固定的KV预算划分为一个精确的主缓存和一个紧凑的残差缓存，用于重构被省略令牌的贡献。ResKV让主缓存令牌和残差条目参与相同的softmax归一化，因此残差条目同时恢复注意力的分子和分母质量，而非作为事后修正。构建时的验证代理确定每个层和KV头的残差分配，而解码时的动态门控则调整单个查询的残差贡献。在LongBench和RULER上的全面评估，涵盖了查询感知和查询无关设置、多种骨干网络、缓存预算以及代表性的压缩基线，表明在相同的保留KV预算下实现了广泛的改进，同时保持了压缩解码的实际效率，包括峰值内存使用和长上下文解码吞吐量。

## Abstract
KV cache compression is essential for efficient long-context inference. Existing eviction methods permanently discard unselected tokens and consequently remove their aggregate contribution to attention. Merging-based alternatives preserve more information but can perturb retained keys and values that should remain exact. We observe that the information omitted by cache eviction can be formulated as residual statistics in both the numerator and denominator of softmax attention. Based on this observation, we propose ResKV, which divides a fixed KV budget into an exact main cache and a compact residual cache that reconstructs the contribution of omitted tokens. ResKV lets main-cache tokens and residual entries participate in the same softmax normalization, so residual entries restore both attention numerator and denominator mass rather than acting as a post-hoc correction. A construction-time validation proxy determines residual allocation for each layer and KV head, while a decode-time dynamic gate adjusts residual contributions for individual queries. Comprehensive evaluations on LongBench and RULER, covering query-aware and query-agnostic settings, multiple backbones, cache budgets, and representative compression baselines, demonstrate broad improvements under the same retained KV budget while preserving the practical efficiency of compressed decoding, including peak memory usage and long-context decode throughput.

## 1. 论文的核心问题与整体含义

- **研究动机**：在长上下文 LLM 推理中，KV 缓存随上下文长度线性增长，成为内存和带宽的主要瓶颈。现有压缩方法主要分两类：
  - **驱逐方法**（如 H2O、SnapKV、TOVA、AdaKV）：直接丢弃未选中 token，导致这些 token 在注意力中的聚合贡献（分子与分母质量）被永久移除；
  - **合并方法**（如 CaM、KVMerger）：将驱逐 token 的信息折入保留条目，能保留部分信息，但会扰动本应精确保留的键和值，损害精确检索。
- **核心洞察**：被驱逐 token 对 softmax 注意力的影响可以形式化为分子和分母中的残差统计量（即未归一化的 softmax 统计量）。因此，与其二选一（删除或污染精确条目），不如在固定 KV 预算下用紧凑的残差缓存显式重建这种残差贡献。
- **整体含义**：ResKV 提出了一种“主缓存 + 残差缓存”的新型 KV 缓存表示，在相同总槽位预算下，既保留关键 token 的精确记忆，又以近似方式恢复被省略 token 的聚合贡献，从而兼顾压缩质量与解码效率。

## 2. 方法论

- **总体框架**：将固定 KV 预算 b 拆分为 main cache M（m 个精确 token 槽）和 residual cache R（r 个残差条目槽），即 b = m + r。主缓存和残差缓存共享同一个 softmax 归一化，而不是作为后置校正。
- **主缓存选择**：使用现有基线（如 SnapKV、AdaKV）的 token 重要性分数，再加上最近窗口保护，选出 m 个主缓存 token；其余 token 为被省略侧 E。
- **残差缓存构造**：
  - 将 E 划分为 r 个簇（通过 Lloyd 迭代最小化簇内键均值平方误差，初始化来自 E 中高分 token）；
  - 每个残差条目存储：均值键 k̄、均值值 v̄、群组计数 c；
  - 近似公式：对每个簇 Cj，若成员 logit 相近，则 Z ≈ c·exp(⟨q,k̄⟩/√d)，N ≈ c·exp(⟨q,k̄⟩/√d)·v̄；
  - 当 c=1 时退化为精确 token。
- **共享 softmax 解码**：
  - 主缓存 logits：a_p = ⟨q,k_p⟩/√d；
  - 残差条目 logits：ã_j = ⟨q,k̄_j⟩/√d + log c_j + log g(q)，其中 g(q) 为动态门控；
  - 最终输出：ô = (Σ_{p∈M} e^{a_p} v_p + Σ_{j∈R} e^{ã_j} v̄_j) / (Σ_{p∈M} e^{a_p} + Σ_{j∈R} e^{ã_j})；
  - 残差条目同时贡献分子和分母，保证同一归一化。
- **自适应残差控制**：
  - **构建期验证代理**：将观测窗口分为 fit 部分和 validation 部分；对候选 r 值（如 0.05–0.20），用验证查询计算重建误差 L_val，只有当残差缓存带来的相对改进超过阈值 δ（0.01）时才启用残差；每层、每个 KV 头独立决定 r；
  - **解码期动态门控**：根据主缓存注意力最大权重 p_max 调整残差 logits：当主缓存注意力集中（尖锐）时降低残差权重，保护检索峰值；当主缓存注意力分散时增加残差权重，恢复聚合贡献。门控形式为 sigmoid((τ - p_max)/T_g)，并设置下限 g_min。
- **GQA 处理**：残差条目按 KV 头构造，在同一查询头组内共享；FlashAttention-2 下主分支保持融合路径，残差分支通过 log-sum-exp 统计合并，得到同一共享 softmax。

## 3. 实验设计

- **Benchmark 数据集**：
  - **LongBench**：16 个真实长上下文任务，覆盖单文档 QA、多文档 QA、摘要、Few-shot、合成检索、代码补全；
  - **RULER**：13 个受控长上下文任务，评估 4K 和 32K 两种长度。
- **场景设置**：
  - 查询感知（query-aware）和查询无关（query-agnostic）两种构建方式；
  - 压缩率 ρ ∈ {0.6, 0.7, 0.8, 0.9}，对应保留 40%、30%、20%、10% KV 槽位；
  - 压缩在 prefill 后执行一次。
- **对比基线**：
  - H2O、SnapKV、TOVA、AdaKV（驱逐类）；
  - CaM（合并类）；
  - Full Cache（全缓存参考）。
- **骨干模型**：LLaMA-3.1-8B-Instruct 和 Qwen-2.5-7B-Instruct，均为 GQA 架构。
- **主要结果**：
  - LongBench：ResKV 在显示的 32 个配置中全部提升；平均提升约 1.02 分；tight budget 下提升更大；

## 6. 主要结论与发现

- 被驱逐 token 的聚合注意力贡献确实可以被紧凑残差条目近似重建，而不需要修改主缓存中的精确 token。
- 将主缓存和残差条目纳入**同一个 softmax 归一化**比单独的后置校正更有效，能同时恢复分子和分母的质量。
- **自适应残差控制**有效：构建期验证代理避免在无益处时浪费预算；解码期动态门控保护尖锐检索峰，同时允许在分散注意力下恢复聚合信息。
- 在相同 KV 预算下，ResKV 能显著提升 LongBench 和 RULER 上的任务分数，尤其在高压缩率和查询无关场景，且峰值内存与压缩基线基本一致，解码吞吐在长上下文下保持稳定。

## 7. 优点

- **问题建模清晰**：将缓存驱逐损失形式化为 softmax 分子/分母残差，理论动机明确，数学推导简洁（附录给出误差界）。
- **兼顾精确与紧凑**：主缓存保持原样，残差条目以均值键/值+计数表示，不污染精确记忆，较合并类方法更具可解释性。
- **与现有方法正交可集成**：ResKV 可以叠加在多种基线（SnapKV、AdaKV、TOVA、H2O）之上，复用其分数规则，保持总预算不变，实用性高。
- **自适应机制完备**：层/KV 头级别的残差分配和查询级动态门控，让方法在不同注意模式下都能自适应调整。

- **模型范围有限**：仅评测 7B/8B 指令微调模型（LLaMA-3.1-8B、Qwen-2.5-7B），未涉及更大模型（如 70B 级）、非 GQA 架构或 MoE 模型，泛化性仍需验证。
