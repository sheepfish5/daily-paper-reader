## 摘要
基于Transformer的大型语言模型（LLM）在许多任务上表现出色，但其键值（KV）缓存随序列长度线性增长，给长上下文推理带来了严重的内存瓶颈。现有的启发式驱逐方法（如H$_2$O和SnapKV）依赖静态注意力或位置信号，往往无法捕捉token未来的预测影响。我们提出DistillCache，一个强化学习框架，将KV缓存驱逐建模为序列决策问题。DistillCache利用丰富的内部模型信号（注意力统计、值范数、熵和位置）学习一个轻量级策略网络，并通过REINFORCE算法和基于逐步KL散度的奖励进行训练，以保持完整缓存的输出分布。在7B参数指令微调Transformer（Mistral-7B-Instruct-v0.3）上，DistillCache在25%缓存预算下保留了LongBench上94.2%的完整缓存准确率，比强启发式基线（H$_2$O、SnapKV）高出最多2.7个绝对百分点，并且在我们重新实现的对比中，在长上下文任务上比并行的基于RL的方法（ForesightKV、RLKV）高出最多1.4个百分点。在推理基准上，DistillCache与最佳并行方法相当，并在激进压缩下超越它。它还提供了高达2.1倍的完整缓存吞吐量，同时保持有竞争力的实际效率。这些结果突显了学习型、分布感知策略在内存高效的长上下文LLM推理中的有效性。

## Abstract
Transformer-based large language models (LLMs) achieve strong performance across many tasks, but their Key-Value (KV) cache grows linearly with sequence length, creating a severe memory bottleneck for long-context inference. Existing heuristic eviction methods (e.g., H$_2$O and SnapKV) rely on static attention or positional signals that often fail to capture a token's future predictive influence. We propose DistillCache, a reinforcement learning framework that formulates KV-cache eviction as a sequential decision problem. DistillCache learns a lightweight policy network using rich internal model signals (attention statistics, value norms, entropy, and position) and trains it with REINFORCE via a per-step KL-divergence reward to preserve the full-cache output distribution. On a 7B-parameter instruction-tuned Transformer (Mistral-7B-Instruct-v0.3), DistillCache retains 94.2% of full-cache accuracy on LongBench at a 25% cache budget, outperforming both strong heuristic baselines (H$_2$O, SnapKV) by up to 2.7 absolute points and, under our re-implementations, concurrent RL-based methods (ForesightKV, RLKV) by up to 1.4 points on long-context tasks. On reasoning benchmarks, DistillCache is competitive with the best concurrent method and surpasses it under aggressive compression. It also delivers up to 2.1x full-cache throughput while maintaining competitive practical efficiency. These results highlight the effectiveness of learned, distribution-aware policies for memory-efficient long-context LLM inference.

### 一、核心问题与整体含义

**研究背景与动机：**
- Transformer 架构的 LLM 在自回归解码中依赖 KV 缓存来避免重复计算前文 token 的表示，但 KV 缓存大小随序列长度线性增长。
- 在上下文窗口不断扩展的背景下，KV 缓存已成为 LLM 推理中**主要的内存与吞吐量瓶颈**——尤其对长上下文推理场景影响严重。
- 现有的启发式驱逐方法（如 H₂O、SnapKV）通过注意力统计和位置信号选择保留 token，但这些静态评分规则**无法捕捉 token 对未来预测的影响力**，在长程依赖和结构化推理场景中容易失效。

**核心问题的本质：**
论文将问题提炼为：在固定内存预算下，如何选择保留哪些 KV 缓存 token，使得被剪枝模型的输出分布尽可能接近全缓存模型的输出分布——这是对 **"token 未来预测效用"** 这一关键变量的直接优化。

**整体研究意义：**
DistillCache 证明了**学习式、分布感知的驱逐策略**在内存受限的长上下文 LLM 推理中是可行且有显著增益的方向，而非依赖人工设计的启发式重要性信号。

### 二、方法论

**核心思想：**
将 KV 缓存驱逐建模为**序列决策问题（sequential decision process）**，利用强化学习（REINFORCE）训练一个轻量级策略网络，其奖励信号为**逐步骤 KL 散度**——即保持学生（剪枝缓存）与教师（全量缓存）模型每一步的下一 token 输出分布尽可能接近。

**关键技术细节：**

1. **状态空间（特征设计）**
   每个缓存 token i 构建五维特征向量：
   - **αᵢ**：token i 作为 key 在所有头与层中接收的平均注意力质量。
   - **‖vᵢ‖₂**：token i 值向量的 ℓ2 范数。
   - **σᵢ**：跨注意力头的注意力质量方差。
   - **Hᵢ**：与 token i 相关的近期查询侧注意力熵（注意力加权平均熵），用于区分集中关注与分散关注。
   - **posᵢ**：token 在缓存中的归一化位置。

2. **动作空间**：策略网络为每个 token 输出重要性分数，训练时通过 Gumbel 噪声扰动获得 Plackett–Luce 分布采样的 Top-B 子集；推理时确定性选取 Top-B token。

3. **训练架构（教师/学生双缓存）**
   - 教师缓存永远不剪枝，用于计算全缓存分布 Pₜ。
   - 学生缓存根据策略逐步剪枝，用于计算剪枝后分布 P̂ₜ。
   - 每一步的 KL 散度负值作为奖励。

4. **奖励理论依据**
   论文给出了剪枝后注意力输出误差的上界：被驱逐注意力质量的平方与 KL 散度之间存在理论上界关系（∝ εₜ²），为 KL 奖励提供了原则性基础；同时 KL 奖励通过完整 softmax 端到端地捕获 token 间的非线性交互。

5. **策略优化**
   - 使用 REINFORCE + 熵正则化 + RLOO（留一）基线降低方差，γ=0.99，β=0.01。
   - Gumbel-top-B 的 log 概率通过动态规划精确计算归一化常数（O(L·B) 复杂度），避免蒙特卡洛近似方差。
   - LLM 本身保持冻结，仅训练约 20 万参数的两层 MLP 策略网络。

6. **推理流程**
   - 单一前向传播产生 logits 并更新缓存，随后策略对缓存评分并剪枝，剪枝影响下一步而非当前 token；当前 token 从未剪枝的前向传播 logits 中选择。

### 六、主要结论与发现

1. **核心结果**：在 25% 缓存预算下，DistillCache 在 LongBench 上保留全缓存的 **94.2%** 准确率（绝对准确率 39.1），在 12.5% 预算下仍保留 88.2%。
2. **对比优势**：
   - 在 LongBench 上优于 H₂O 和 SnapKV 最多 +2.7 个绝对百分点（25% 预算）。
   - 在我们的重实现下，优于 ForesightKV 和 RLKV 最多 +1.4 个百分点（长上下文任务）。
   - 12.5% 激进压缩下，推理任务上超越 RLKV（39.9 vs 38.9），但在 50% 和 25% 预算下推理任务略逊于 RLKV。
3. **上下文长度表现**：8K 上下文时优势最明显（38.1 vs 最好并发方法 37.0），2K 时所有方法差异小（预算充裕时策略优势不显著）。
4. **吞吐量**：25% 预算下相比全缓存提供约 **2.1× 加速**；额外开销约 +1.4 ms/token（特征提取 0.9 ms + 策略 0.5 ms），吞吐量（38.0 tokens/s）与并发 RL 方法相当、略低于启发式方法（H₂O 42.8）。
5. **跨模型迁移**：Mistral 训练的 policy 零样本迁移到 Llama-3-8B，在 LongBench（38.4 vs 37.9）和推理（46.2 vs 45.6）上均超过 Llama 原生运行的启发式基线，而并发 RL 方法需要逐模型重新训练。
6. **RL 的必要性**：监督蒸馏排序器（同特征无 RL）为 37.8，低于 DistillCache 的 39.1，证明 RL 的直接长期优化提供了超越静态排序的增量。
7. **与 RLKV 的互补性**：将 RLKV 风格的头级门控（前 20% 重要头全缓存）与 DistillCache token 级策略结合，LongBench 从 39.1 提升至 **39.8**（5/5 种子一致），表明头级与 token 级选择正交、可以自然组合。

### 七、优点

1. **方法设计层面**
   - **以 KL 散度作为直接优化目标**而非启发式代理分数，将"token 保留决策"与"分布保真度"端到端对齐，在方法论上有清晰的理论基础（推导了剪枝误差的上下界）。
   - 奖励设计中 KL 散度自然对**低熵（高确定性）预测**更敏感——这类 token 受驱逐影响最大，即自动惩罚最重要的错误源，无需显式的熵过滤机制。
   - 特征设计丰富（5 维特征：注意力、值范数、方差、熵、位置），充分利用了模型内部信号。
   - 轻量级策略网络（约 20 万参数，~1.4 ms/token 开销）使得**实用部署可行性较高**。
   - 提供了精确的 Gumbel-top-B 子集对数概率计算，避免了 MC 采样近似引入的方差。

2. **实验层面**
   - 实验覆盖全面：预算扫描、上下文长度变化、跨模型迁移、奖励消融、特征消融、混合策略、错误模式、定性分析等。
   - 5 种随机种子报告误差条，统计严谨。
   - 对自身局限坦诚披露：训练成本、推理开销、与并发方法对比的重实现局限、RLKV 在推理任务上的优势。
   - 消融设计清晰——将"特征丰富度"与"RL 优化"各自贡献分离（表 10）。

3. **系统层面**
   - 与系统级优化（offloading、PagedAttention、FlashDecoding++ 等）**正交且可组合**。
   - 零样本跨模型迁移使训练成本可摊销（无需逐模型重新训练），具有较好的实用价值。

### 八、不足与局限

1. **训练成本与稳定性**
   - 训练约需 **130 GPU 小时**（2× RTX 4090），明显高于零训练启发式方法。
   - 训练时双缓存架构使**内存占用翻倍**（训练仅离线进行，实际部署不受影响）。
   - REINFORCE 引入方差，虽用熵正则化 + RLOO 基线 + 多种子缓解，但更先进的估计器（PPO、GRPO）可能更稳定（代价是复杂度更高）。

2. **推理性能对比的有限优势**
   - RLKV 在推理基准（GSM8K+BBH）的 50% 和 25% 预算下仍保持优势（48.9 vs 48.6；45.7 vs 45.0），仅 12.5% 时被 DistillCache 反超。
   - 这暗示**不同任务类型可能需要不同的奖励设计**：推理任务对最终正确性敏感，而 DistillCache 的泛化分布保持目标在激进压缩下才占优势。

3. **模型与方法局限**
   - 策略独立地对每个 token 打分，**未显式建模 token 间交互**。
   - 特征设计与 Transformer 注意力模式耦合，**跨架构迁移可能需要重新设计**。
   - 实验结果仅覆盖 7B 和 8B 模型、最长 8K 上下文——32K-128K 超长上下文和 13B+ 更大模型的验证缺失。

4. **实验对比的公平性风险**
   - 与 ForesightKV 和 RLKV 的对比基于**论文作者的重实现**（非官方代码），原始训练设置或超参差异可能影响精确差距；论文对此有明确但有限的披露。
   - 没有与更多最新的启发式方法（如 Keyformer、CAKE、KeyDiff）在同等条件下对比。
