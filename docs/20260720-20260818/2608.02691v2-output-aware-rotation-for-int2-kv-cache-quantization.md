## 摘要
在长上下文大语言模型推理中，键值（KV）缓存已成为主要的内存和带宽瓶颈，使得超低位量化日益重要。然而，现有的基于旋转的INT2方法在完整注意力读出之前优化缓存统计或代理误差，尽管模型最终受到通过注意力和输出投影$W_O$传播的误差影响。为解决这一不匹配问题，我们提出\textit{OptR}，一种面向输出的旋转方法，最小化$W_O$之后的注意力输出误差。OptR将$W_O$之后的注意力输出误差分解为键诱导和值诱导项，并通过完整的INT2量化和注意力路径学习每头的正交校正。OptR进一步应用注意力等价的键重参数化，在不改变softmax分布的情况下减少大的通道偏移。在三个模型和五个推理与编码基准上，OptR持续改进QuaRot和OSCAR，并增强长上下文检索，同时保持分页KV缓存格式且推理开销可忽略不计。

## Abstract
The key-value (KV) cache has become a major memory and bandwidth bottleneck in long-context large language model inference, making ultra-low-bit quantization increasingly important. However, existing rotation-based INT2 methods optimize cache statistics or proxy errors before the complete attention readout, even though the model is ultimately affected by the error propagated through attention and the output projection $W_O$. To address this mismatch, we propose \textit{OptR}, an output-aware rotation method that minimizes post-$W_O$ attention-output error. OptR decomposes the post-$W_O$ attention-output error into key- and value-induced terms and learns per-head orthogonal corrections through the full INT2 quantization and attention path. OptR further applies an attention-equivalent key reparameterization to reduce large channel-wise offsets without changing the softmax distribution. Across three models and five reasoning and coding benchmarks, OptR consistently improves both QuaRot and OSCAR and strengthens long-context retrieval, while preserving the paged KV-cache format with negligible inference overhead.

# 论文总结：Output-Aware Rotation for INT2 KV-Cache Quantization

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：随着大语言模型（LLM）的规模与上下文长度不断增长，键值缓存（KV Cache）成为长上下文推理中最主要的内存与带宽瓶颈。KV缓存量化通过降低缓存精度来缓解这一压力，其中 **INT2 量化** 尤为关键——仅需 BF16 缓存的 1/8 存储、INT4 的 1/2，可在相同内存预算下支持更长上下文或更大批次。
- **核心问题**：现有基于旋转的 INT2 量化方法（如 QuaRot、OSCAR）在选择旋转矩阵时，要么使用固定的变换（如 Hadamard），要么优化缓存统计量或**注意力读出之前的代理误差**。然而，KV 量化误差需要经过注意力加权聚合和输出投影 $W_O$ 才能真正影响模型后续层。这种**目标不匹配**意味着“最能重建缓存”的旋转未必是“最能保持最终注意力输出”的旋转。
- **整体含义**：论文提出，应将旋转优化的目标直接定义为 **$W_O$ 之后（输出空间）的注意力输出误差**，并据此设计一种可与任意已有旋转初始化配合的通用校正方法——**OptR**。

## 2. 方法论（核心思想、关键技术细节）

### 2.1 核心思想

OptR 是一种 **输出感知旋转（Output-Aware Rotation）** 方法，主要由两部分组成：

1. **注意力等价的 Key 重参数化**（减少量化范围）
2. **逐头正交旋转校正**（在输出空间最小化误差）

### 2.2 关键技术细节

1. **误差分解**：将 $W_O$ 后的注意力输出误差分解为
   - **key 诱导项**：量化后的 key 改变注意力分布（$\Delta p$），进而影响输出；
   - **value 诱导项**：量化后的 value 经注意力加权和 $W_O$ 投影后的误差。
2. **Key 重参数化**：从每个 key 中减去校准集通道均值 $\mu$，因对同一查询下所有位置加相同常数，**不影响 softmax 分布**；同时缩小 INT2 量化范围，减少离群值影响。
3. **正交校正参数化**：对每个 KV 头学习无约束矩阵 $A$，构造偏对称矩阵 $S = A - A^\top$，再通过矩阵指数 $\exp(S)$ 得到正交校正，乘在基础旋转 $R_0$ 上：
   $$R(A) = R_0 \exp(A - A^\top)$$
4. **分阶段校准**：先优化 key 旋转（在 value 保持 BF16 的条件下，目标为 KL 散度 + post-$W_O$ 输出误差），再在选定 key 旋转下优化 value 旋转（目标仅 post-$W_O$ 输出误差）。
5. **STE 直通估计**：INT2 取整不可微，使用 straight-through estimator 估计梯度。
6. **兼容性**：旋转保持在正交群内，缓存形状与内存布局不变，兼容分页 KV Cache 与融合解码内核；value 侧旋转可吸收进投影权重，无额外推理内核。
