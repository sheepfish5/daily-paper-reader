## 摘要
键值（KV）缓存存储过去标记的信息，是长上下文推理中的主要内存瓶颈。现有的量化方法通过以较低精度的数据类型统一表示KV缓存，并设计量化方案以最小化缓存本身的重建误差来解决这一瓶颈，但未考虑该误差如何通过注意力机制传播。我们证明，在白噪声量化模型下，预期的注意力感知失真可分解为键和值的加性贡献，这些贡献在标记和通道之间可分解。基于变换编码和反向注水（信号处理和率失真理论中的经典工具），我们引入了注意力感知变换编码（AATC），它通过在标定集上分配比特来最小化注意力感知失真。在Llama-3.1-8B-Instruct和Qwen-2.5-7B-Instruct上，在LongBench、RULER、GSM8K、MMLU-Pro和MATH-500上的评估显示，我们的方法在约5.8倍压缩下实现了近乎无损的精度，而每个基线至少在某些设置中性能下降。

## Abstract
The key-value (KV) cache stores information from past tokens and is a major memory bottleneck in long-context inference. Existing quantization methods address this bottleneck by representing the KV cache uniformly with lower-precision data types and designing quantization schemes to minimize reconstruction error in the cache itself, without accounting for how that error propagates through attention mechanisms. We prove that, under a white-noise quantization model, the expected attention-aware distortion decomposes into additive key and value contributions that factor across tokens and channels. Building on transform coding and reverse water-filling, which are classical tools from signal processing and rate-distortion theory, we introduce Attention-Aware Transform Coding (AATC), which allocates bits over a calibration set to minimize attention-aware distortion. On Llama-3.1-8B-Instruct and Qwen-2.5-7B-Instruct, evaluated across LongBench, RULER, GSM8K, MMLU-Pro, and MATH-500, our method achieves near-lossless accuracy at approximately $5.8\times$ compression, whereas each baseline degrades in at least some settings.

## 2. 论文提出的方法论

### 2.1 核心思想

论文的核心洞察在于：KV量化误差对注意力输出的影响不是均匀的，而是可以分解为键项和值项两个独立的加性贡献，且每个贡献又进一步在标记（token）维度和通道（channel）维度上可分解。这一分解统一了此前多个孤立的研究视角（如标记驱逐、低秩投影、混合精度分配等），将它们归结为同一个失真目标的不同方面。

### 2.2 理论框架

在**白噪声量化模型**（Assumption 1）和**有界键量化误差**（Assumption 2）之下，论文证明（**Theorem 1**）注意力输出失真可表示为：

- **键失真 Dᴋ** = Σᵢ,꜀ aᵢ²·‖vᵢWᴼ − o‖²·q꜀²·E[(δkᵢ꜀)²]
- **值失真 Dᴠ** = Σᵢ,꜀ aᵢ²·E[(δvᵢ꜀)²]·‖Wᴼ꜀‖²

其中关键权重包括：
- aᵢ²：注意力权重，反映标记对输出的参与程度
- ‖vᵢWᴼ − o‖²：标记值经输出投影后与注意力输出的偏差
- q꜀²：当前查询在各键通道上的分量
- Wᴼ꜀：输出投影矩阵各通道的范数

该方法统一了此前孤立研究的多类因子，包括标记注意力、查询感知精度、输出投影感知精度和逐通道灵敏度。

### 2.3 算法流程（AATC）

**步骤一：白化特征去相关（离线标定）**
- 基于小波变换推导白化变换：给定标定激活 X 和投影矩阵 W，通过 Cholesky 分解得到输入协方差 Σₓ = LLᵀ，进而得到白化权重矩阵 W̃ = LᵀW，最后进行 SVD 分解 W̃ = USPᵀ
- 将原始投影 W 分解为 W = L⁻ᵀUSPᵀ = A·B
- 推理时缓存的是变换后的表示 Hᴋ = X·Aᴋ，原始键可通过 K = Hᴋ·Bᴋ 恢复

**步骤二：基于反向注水的注意力感知比特分配**

通过解决带约束的优化问题：
- 键的分配：min Σ w^(K)ℓ,꜀·(σ^(K)ℓ,꜀)²·2^(−2b) 约束为总预算 Bᴋ
- 值的分配：同理，权重为 w^(V)ℓ,꜀ = ‖(BᵛWᴼ)ᵀℓ,꜀‖²

其连续松弛问题具有经典的闭式反向注水解——高方差、高权重的通道获得更多比特，低于水位线的通道则被置零（等效于自适应秩截断），并通过动态规划处理离散比特约束。

**步骤三：在线量化与推理**
- 按头组计算令牌级缩放因子
- 使用均匀标量量化
- 键和值分别设置独立的比特预算

## 6. 论文的主要结论与发现

1. **理论上**：在白噪声量化假设下，注意力输出失真可精确分解为键、值两个独立项，两者在标记和通道维度上均因子化。交叉项要么精确消失，要么被严格受控的高阶余项所界定。

2. **方法上**：AATC在约5.8倍压缩时，在两个模型上对所有基准均处于FP16的统计不可区分范围内（即准确性与未压缩FP16模型差异不超出2σ）。

3. **Qwen比Llama更难压缩**：Qwen上KIVI甚至在LongBench上降至0.351、RULER低于0.28，而AATC仍保持接近无损；AATC全方法的注意力感知分配在Qwen上有明显增益，尤其在高压缩率和长上下文场景。

4. **PALU的局限**：PALU在短上下文（RULER-4k）有竞争力，但在LongBench代码补全等精确匹配任务上显著退化，其低秩截断损失了细粒度的标记级信息。

5. **注意力感知分配的价值随压缩增强而放大**：在2.5-bit时AATC与AATC var-only差异较小，但在2-bit时后者随上下文长度急剧退化，表明注意力感知权重在高压缩时不可或缺。

6. **统一的视角**：论文提出的失真分解为量化、低秩投影和标记驱逐等已有方法提供了统一的理论框架，将它们映射到同一目标的不同方面。

## 8. 不足与局限

### 理论假设的局限
- **白噪声独立性假设**（Assumption 1）在低比特率下仅是近似成立。论文在正文中表示，虽然独立性在邻近标记间不严格成立，但实验证明该度量在2~4比特下仍然预测性好——但理论上这个假设在极端压缩（1-bit）下的边界没有被刻画
- **交叉标记相关性**被忽略，作者将刻画这种依赖性或建立更弱假设下的保证留作未来工作
- **令牌级分配超出范围**：论文只做通道级分配，没有与标记驱逐方法结合——这既是局限，也是未来方向

### 实验层面的局限
- **覆盖范围有限**：仅两个模型家族（Llama、Qwen），未在更多不同规模/架构的模型上验证；LongBench仅取英文子集
- **无系统级部署测评**：缺乏专用的CUDA实现，没有测延迟、吞吐量、端到端推理加速等实际部署指标
- **基线的重实现可能存在偏差**：KIVI和KVQuant是作者重实现的，尽管做了公平性对齐（FP16窗口一致等），但与原始工作有细节差异的风险

### 应用层面的制约
- 离线标定依赖**标定集与目标分布的匹配**，表中显示只用FineWeb标定时性能下降比只用OpenR1-Math更明显，说明标定集选择会影响效果

- 前3层需要"保护"（给予平均或平均+1比特）是一种启发式设计，缺乏理论支撑，可能在不同模型上需要重新调整
