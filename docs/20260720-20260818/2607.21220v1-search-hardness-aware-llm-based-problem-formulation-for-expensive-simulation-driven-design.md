## 摘要
昂贵仿真驱动设计在工程中被广泛使用，旨在以尽可能少的高保真仿真来识别满足需求的设计。现有的大多数工作通过改进固定问题表述下的优化算法来应对这一挑战，然而问题表述本身通过定义求解器优化的目标和约束，塑造了搜索空间。近期基于大语言模型（LLM）的自动问题表述方法从自然语言需求中生成问题表述，但它们主要关注设计意图对齐，而忽视了问题表述是否能带来高效的搜索过程。为解决这一局限，我们提出了SHA-PF，一种搜索硬度感知的基于LLM的问题表述框架。我们发现，当问题表述优先考虑具有更大进展潜力的稀有样本时，它更有可能引导高效搜索。基于这一发现，SHA-PF定义了一个由搜索硬度引导的问题表述搜索目标，根据该优先级对每个候选问题表述进行评分。随后，SHA-PF通过基于LLM的生成、修复和进化细化，在该目标下搜索问题表述空间。在真实世界多目标基准和五个昂贵天线设计基准上的实验表明，与其他基线相比，SHA-PF发现的问题表述达到设计需求所需的评估次数显著更少。

## Abstract
Expensive simulation-driven design is widely used in engineering to identify requirement-satisfying designs with as few high-fidelity simulations as possible. Most existing efforts address this challenge by improving optimization algorithms under fixed formulations, yet the formulation itself shapes the search landscape by defining the objectives and constraints optimized by the solver. Recent LLM-based automatic problem formulation methods generate formulations from natural-language requirements, but they mainly focus on design-intent alignment and overlook whether the formulation induces an efficient search process. To address this limitation, we propose SHA-PF, a search hardness-aware LLM-based problem formulation framework. We find that a formulation is more likely to guide efficient search when it prioritizes rare samples with greater progress potential. Based on this finding, SHA-PF defines a formulation search objective guided by search hardness, scoring each candidate formulation according to the priority. SHA-PF then searches the formulation space under this objective through LLM-based generation, repair, and evolutionary refinement. Experiments on the real-world multi-objective benchmark and five expensive antenna design benchmarks show that the formulations discovered by SHA-PF require significantly fewer evaluations to reach the design requirements than other baselines.

- **现有 LLM 自动问题表述的不足**：已有 LLM 方法（如 OptiMUS、ORLM、LLMOPT、APF）主要关注将自然语言需求转换为数学上正确、可执行的公式，即“设计意图对齐”，但**没有考虑公式是否会导致高效搜索**。在昂贵仿真场景下，即使多个公式都正确定义了目标区域，不同公式可能让优化器走不同路径，仿真成本差异巨大。
- **整体含义**：本文提出**搜索硬度感知（Search Hardness-Aware）**的 LLM 问题表述框架 SHA-PF，旨在自动发现能诱导高效搜索路径的问题表述，从而显著减少昂贵仿真评估次数。

## 2. 论文提出的方法论

### 核心思想
- **关键发现**：初始采样数据中，**罕见但具有更强支配进步潜力的满意度状态**（即搜索路径片段）对后续搜索更有价值。频繁出现的状态容易被优化器自然到达，无需额外引导；而稀有状态对应“难达但可能通向目标”的方向，若公式能优先排序这些状态，优化器就更容易沿高效路径前进。
- **搜索硬度度量**：对每个满意度状态 z，定义硬度分数 h(z) = 该状态出现次数 / 被该状态支配的状态数 + ε。分子越小越稀有，分母越大越有进步潜力；分数越低表示越“难但值得优先”。
- **锚点状态选择**：从非支配满意度状态集合中，选择 h(z) 最小的作为锚点状态 z_anc。
- **公式搜索目标**：构造锚点状态样本与其它状态样本的配对，优化目标是最大化公式对锚点样本的排序优先级，即锚点样本在公式目标/约束下比其他样本更优的比例。
- **问题表述空间 Φ**：每个候选公式 F 是一个可执行 Python 函数，输入仿真响应 y，输出一个标量目标（最小化）和零或多个约束（g≤0 为满足）。

### 技术流程
1. **状态判定**：用 LLM 作为评判器，将初始样本响应映射为二进制满意度向量。
2. **生成与修复**：生成 LLM 从自然语言需求起草公式；修复 LLM 检查并最小限度修改逻辑错误、符号方向、需求不对齐等问题，使公式保持可执行且与设计意图一致。
3. **进化式公式搜索**：采用种群进化框架，每代评估所有候选，选择最优者为父代，利用四种 LLM 算子生成子代：
   - 组件重组（合并两个父代的有效部件）
   - 约束结构重构（改变约束数量/分组/组合方式）
   - 优化信号重参数化（改变目标或约束违反度的度量/聚合方式）
   - 语义探索（更大范围的公式族探索）
4. **迭代优化**：父代与子代合并后按目标值排序，保留前 P 个进入下一代；到达最大代数或预算后，返回目标值最高的公式用于实际优化。
