## 摘要
分离式LLM服务将KV缓存扫描置于内存优化的硬件上，将投影和前馈网络置于计算优化的硬件上，然后从解码器块中继承了一个两个设备都不想要的依赖：注意力先运行，前馈网络消耗其输出，因此在单个序列内，每一方在另一方工作时都会空闲。通常的修复方案是每个额外的在飞序列占用一个常驻KV缓存，这正是起初分离设备的动机。我们转而移除这个依赖。扫描只需要查询，而交换两个子层使得查询在计算侧仍有工作要做时即可用，因此两者可以并发运行；当前的键和值随后作为缓存写入，没有任何东西等待它。我们将解码描述为一个协议，展示它能在现成内核上运行，并在训练好的检查点上端到端验证，相对误差为3.2x10^-3——没有新算子，没有改变形状，也没有新硬件。然后我们用两个种子对块进行8种方式的训练，仅改变注意力读取的位置并保持其他一切固定。在计算最优的3%处，每字节比特数的领先衡量的是变化对训练的干扰程度，而非其达到的效果，因此我们读取的是幅度而非排名。在5个前馈网络不消耗自身注意力的块中，没有一个读取点与不移动任何内容的读取点之间的差异超过每字节0.0026比特——小于同一臂在第二个种子下的自身差距0.0066——而相同的运行解析出一个25倍大的子层交换。提前移动查询是一个测量无法发现的变化，这正是协议所需要的。其范围有限：从网络输入投影每一层的查询代价为+0.0974，在两个种子上都反驳了预先登记的阈值，因此查询可以提前一个前馈网络读取，而不能更早。

## Abstract
Disaggregated LLM serving puts the KV-cache sweep on memory-optimised hardware and the projections and feed-forward on compute-optimised hardware, then inherits from the decoder block a dependency neither device wants: attention runs first and the feed-forward consumes its output, so within one sequence each side idles while the other works. The usual repair costs one resident KV cache per extra sequence in flight, which is what motivated separating the devices at all. We remove the dependency instead. The sweep needs only the query, and exchanging the two sub-layers makes that query available while the compute side still has work to do, so the two run concurrently; the current key and value follow as a cache write nothing waits on. We state the decode as a protocol, show that it runs on stock kernels, and verify it end to end on a trained checkpoint to a relative error of 3.2x10^-3 -- with no new operator, no changed shape and no new hardware. We then train the block 8 ways at two seeds each, varying only where the attention reads and holding everything else fixed. At three per cent of compute-optimal a lead in bits per byte measures how much a change disturbed training rather than what it reaches, so we read magnitudes and not rankings. Among the 5 blocks whose feed-forward does not consume their own attention, no read point differs from the one that moves nothing by more than 0.0026 bits per byte -- smaller than the gap between an arm and itself at a second seed, 0.0066 -- while the same runs resolve a sub-layer exchange 25 times as large. Moving the query early is a change the measurement cannot find, which is what the protocol needs. The reach is bounded: projecting every layer's query from the network's input costs +0.0974, refuting a pre-registered threshold at both seeds, so a query may be read one feed-forward early and no further back.

## 1. 论文的核心问题与整体含义

**研究动机与背景：**
- 分离式 LLM 服务（disaggregated serving）将存储器密集型 KV 缓存扫描放在内存优化的硬件上，将算术密集型的投影与前馈网络放在计算优化的硬件上
- 但解码器块本身的计算顺序导致一个依赖：注意力先运行，前馈消耗其输出，因此在单个序列内两个设备交替空闲
- 传统修复方案是增加在飞序列数，但每个额外序列都需一个常驻 KV 缓存——这恰恰违背了分离设备的初衷
- 本文的核心问题是：缓存侧设备真正需要什么才能开始扫描？提前给出该输入需要付出什么代价？

**整体含义：**
发现缓存侧设备只需要查询（query）即可执行对已缓存位置的注意力汇总；通过交换子层顺序使查询提前一个前馈周期存在，就可以让两台设备同时工作，且该移动对训练质量的影响在可测量范围内不可分辨。这是一个**精确的、不改变图结构**的干预，而非近似或架构变更。

## 2. 方法论

**核心思想：**
- 在第 j 个解码位置，j−1 个位置已在缓存中，因此注意力的”分数与合并“只需查询即可完成，不需要当前键和值
- 将前馈放到注意力之前，查询仍从块输入读取，则查询在计算侧忙于前馈时即可用于扫描缓存
- 当前键、值随后作为缓存写入，不阻塞任何人

**协议与关键技术细节：**
- **解码协议**：缓存侧只接收查询 qⱼ，扫描缓存返回合并态 (o<j, lse<j)；计算侧自算当前键 kⱼ，与返回的部分 softmax 态合并
- **合并公式**：
  - sjj = qⱼ·kⱼ/√d
  - out = lerp(vⱼ, o<j, σ(lse<j − sjj))
  - logaddexp 维护运行对数和
- **两加速器安排**：MLP 侧持有静态权重并运行所有投影与前馈；缓存侧持有 KV 缓存只做扫描；拆分方式不是按层而是按权重种类
- **代数等价性**：将块的输入输出写为算子，证明 QL = (I+M)⁻¹ ∘ SL ∘ (I+M)，即移动查询读取点后的堆栈与普通堆栈共轭，只是层边界移动了半个子层——验证为逐位相同
- **可合并且可分片**：设备返回 (O, log Z)，可对任意拆分的缓存分片独立扫描后任意顺序合并
- **无需新算子**：使用现有 FlashAttention 内核返回的 log-sum-exp，验证相对误差 4.2×10⁻³

## 6. 主要结论与发现

- **查询读取点可提前一个前馈周期**：家族 A 的 5 个臂相对控制的最大差异不超过 0.0011 bits/byte，远小于 3 种子可分辨的 0.0117；协议所需的 Early-Q 变化在可测量范围内不可区分
- **可达范围有一个明确边界**：从网络输入投影每层查询代价为 +0.1003，超过预注册拒绝阈值 +0.05 的每个种子——查询可提前一个前馈读取，不能更早
- **转换现役检查点可行**：只微调 Wq（9.5% 权重、3,000 步），Qwen3-0.6B 残差 +0.0142，Qwen3-4B +0.0088；加入 Wo 降至 +0.0114 / +0.0073
- **深度扫描**：更深读取虽在混合模式中打开更多并发窗口，但修复后残差上升（+0.0123 → +0.0556），故半个子层是最保守选择
- **缓存可分片合并**：200 个随机四路分片合并与整体扫描一致到 1.4×10⁻⁷
- **Wq 绑定于键而非值**：Wk 在 Wq 子空间内的能量是随机的 2.22 倍，Wv 仅 1.15 倍（官方发布），说明键和值是不同类型的对象
- 低稳定秩不许可低秩分解：截断 Wq/Wk 至秩 48 代价 +1.92 bits/byte，说明函数位于谱尾部

## 7. 优点

1. **精确且有构造性验证**：查询早读与普通堆栈的共轭关系被逐位验证，而非仅在近似意义下成立
2. **无需新基础设施**：协议运行在现成 FlashAttention 内核上，无新算子、无形状变化、无新硬件
3. **训练实验控制极严**：参数数、前向算术、数据顺序、种子全固定，仅移动读取点；预注册阈值、全部种子公开
4. **读取幅度而非排名**：明确声明此预算下领先是训练扰动而非质量提升，避免误读
5. **边界刻画完整性**：不仅证明“查询可以提前”，还证明了“不能提前过多”，有正反两面证据
6. **大量辅助分析**：附录 H/I 提供查询敏感性界、投影几何、容错分析等，帮助理解机制
7. **高可复现性**：声称所有数字由脚本生成，未测量数字会引发构建错误

## 8. 不足与局限

- **未测量加速**：两设备并发带来多少实际加速没有部署验证；是否划算取决于互连延迟与前馈时长的比
