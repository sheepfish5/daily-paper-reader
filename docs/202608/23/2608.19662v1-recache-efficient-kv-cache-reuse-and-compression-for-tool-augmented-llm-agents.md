## 摘要
智能体语言模型会反复编码在不同请求中以不同组合和顺序出现的工具与技能模式，这阻碍了标准前缀缓存对其键值（KV）状态的复用。我们提出ReCache框架，用于独立缓存资源表示，同时降低其推理时的计算与内存开销。资源级注意力消除了跨资源交互，并分配资源局部位置，从而产生组合不变的KV块。随后，ReCache将资源可见性限制在贡献选择出的层-KV头组路由上，并通过结构与语义剪枝仅保留调用关键字段。我们在由七个公共工具与技能使用数据集（包括资源不相交测试）组成的基准上评估了ReCache。资源级注意力与密集调用性能相当（82.3%对82.4%的Inv-F1），同时提供3.655倍的首词时间加速。完整框架将分配的KV张量内存减少了92.43%，并将注意力加速了1.423倍。这些结果表明，将可复用模式编码与选择性资源访问分离，能以有限的有效性损失大幅降低智能体推理成本。代码可在https://github.com/EIT-NLP/ReCache获取。

## Abstract
Agentic language models repeatedly encode tool and skill schemas that recur across requests in different combinations and orders, preventing standard prefix caching from reusing their key--value (KV) states. We introduce \textbf{ReCache}, a framework for independently caching resource representations while reducing their inference-time computational and memory overhead. Resource-wise attention removes cross-resource interactions and assigns resource-local positions, producing composition-invariant KV blocks. ReCache then restricts resource visibility to contribution-selected layer--KV-head-group routes and retains only invocation-critical fields through structural and semantic pruning. We evaluate ReCache on a benchmark assembled from seven public tool- and skill-use datasets, including resource-disjoint tests. Resource-wise attention matches dense invocation performance (82.3\% versus 82.4\% Inv-F1) while providing a 3.655$\times$ time-to-first-token speedup. The complete framework reduces allocated KV-tensor memory by 92.43\% and accelerates attention by 1.423$\times$. These results show that separating reusable schema encoding from selective resource access substantially reduces agentic inference costs with limited effectiveness loss. The code is available at https://github.com/EIT-NLP/ReCache.

## 论文总结

### 1. 核心问题与整体含义

- **研究背景**：智能体语言模型在推理时需动态调用工具和技能资源。相同资源会在不同请求中以不同顺序、不同组合反复出现。标准前缀缓存要求复用内容形成完全一致的前缀，在动态组合资源场景下难以适用。
- **核心问题**：如何在资源组合和顺序变化的前提下，复用已编码的工具/技能模式，同时降低推理时的计算和内存成本。
- **整体含义**：将可复用编码与选择性访问分离，为工具增强型智能体提供了一种大幅降低推理开销且仅产生极小有效性损失的解决方案。

### 2. 方法论

- **核心思想**：以“资源”（Resource）为缓存单位，通过资源级注意力使资源表示与组合方式解耦，再通过结构剪枝和语义剪枝压缩 KV 缓存。
- **资源级注意力（Resource-wise Attention）**：
  - 移除资源间的交叉注意力，每个资源仅关注公共前缀与其内部 token。
  - 位置索引在资源内重置（`pos(t_{i,j}) = j`），使资源 KV 块与全局顺序无关。
  - 注意力计算量从 \(O(D_R^2)\) 降至 \(O(\sum_i D_i^2)\)。
- **结构剪枝（Structural Pruning）**：
  - 基于给定配置 \(\Omega\) 的调用损失 \(\ell_\Omega(X,Y)\)，在其上定义选择目标 \(J(\Omega)\)。
  - 通过 leave-one-in 分析计算层贡献 \(s_l = J(\emptyset) - J(\Omega_l)\) 和 KV 头组贡献 \(s_g = J(\emptyset) - J(\Omega_g)\)。
  - 将正贡献归一化为权重 \(w_i = \max(s_i, 0)/\sum_j \max(s_j, 0)\)，按权重选取 Top-K 层 \(L^*\) 和 Top-K 头组 \(G^*\)，构造最终路由 \(\Omega^* = L^* \times G^*\)。
  - 路由内使用资源可见掩码 \(M_{\text{resource}}\)，路由外使用 \(M_{\text{context}}\) 屏蔽资源 token。
- **语义剪枝（Semantic Pruning）**：
  - 保留资源名称、参数名称、参数描述和末尾 token，压缩资源可见长度。
  - 末尾 token 作为自然的边界表征，汇总前序字段信息。
- **整体流程**：构建独立 KV 块 → 限制层-头组路由可见性 → 保留关键语义字段 → 推理时仅激活选中的路由。

### 6. 主要结论与发现

- 资源级注意力与密集注意力性能几乎持平（82.3% vs. 82.4% Inv-F1），但带来 3.655 倍 TTFT 加速，表明跨资源交互和全局资源顺序在资源调用场景中的价值有限。
- 完整 ReCache 将 KV 张量内存分配减少 92.43%，注意力加速 1.423 倍，同时在 IND 上保留 97.5% 的密集 Inv-F1，在 OOD 上保留 91.8%。
- 贡献引导的结构剪枝优于注意力引导的剪枝和固定层设置（SPEED），在 OOD 上尤其明显（幻觉率从 13.4% 降至 0.5%）。
- 字段感知的语义剪枝优于通用压缩方法（Gist、Beacon），说明精确接口信息对调用正确性至关重要。
- 结构预算随模型规模不同而变化：Qwen3-4B 用 3 个头组即可，Qwen3-1.7B 需要 7 个头组，且受到训练监督量的影响。

### 7. 优点

- **问题定位准确**：洞察到前缀缓存不适用于动态组合的工具资源，并从注意力分析出发给出了实证依据（跨资源注意力弱、后缀 token 受关注高）。
- **方法设计巧妙**：
  - 资源级注意力使资源表示组合不变，从根源上消除重复编码。
  - 使用 leave-one-in 的贡献分析而非注意力权重来选择结构性路由，选择依据更贴近任务目标。
  - 语义剪枝保留接口关键字段，避免通用压缩方法导致调用失败。
- **评价体系完善**：同时覆盖有效性（Inv-F1、ID、幻觉率）、效率（TTFT、TPOT、注意力延迟、KV 内存）和泛化（IND/OOD）。
- **数据结构科学**：多样性优先采样策略降低了资源频率偏差，使评测更关注真正的资源理解能力。
- **扩展性好**：资源长度从 1K 增长到 ≥10K 时，TTFT、TPOT、注意力延迟保持几乎恒定，KV 内存有界。

### 8. 不足与局限

- **模型覆盖面有限**：端到端实验仅在 Qwen3 系列上进行，主要结果来自 Qwen3-4B，未验证更大规模模型和不同架构的泛化性。
- **需要可训练设置**：由于 ReCache 修改了注意力掩码和位置编码，不直接适用于冻结的预训练模型。
- **环境假设限制**：框架假设系统指令和资源模式相对稳定，无法应对高度动态、检索顺序或跨资源依赖本身携带关键信息的场景。
- **时间信息缺失**：未报告训练耗时、GPU 数量和成本等细节，复现成本不透明。
- **对比方法的公平性**：语义压缩基线按资源分配摘要 token 做了适配，但不同方法在字段粒度、交互设计上的差异仍可能影响公平比较。
