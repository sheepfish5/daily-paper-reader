## 摘要
长上下文推理受到键值（KV）缓存内存占用量的瓶颈制约，尤其是在资源预算紧张的小型模型中。现有的KV缓存驱逐方法要么利用模型的注意力分布对词元进行评分，要么在无注意力变体中依据每个键与全局参考点的距离进行评分。通过一项受控的留一法探针实验，我们发现注意力幅度与词元对答案的因果贡献无关（Spearman ρ=-0.004），这挑战了主流驱逐方法背后的前提。我们提出TwinKV，一种无需训练、无需注意力的冗余信号，用于检测某个词元的键是否在上下文中的其他位置存在近似重复。TwinKV并非取代现有策略，而是作为一个可组合的修复通路：给定一个策略的固定保留集合，它识别出没有存活重复的驱逐词元（孤儿）以及信息在其他位置被重复的保留词元（冗余捐赠者），然后在保持原始预算和评分规则不变的前提下交换两者。我们将TwinKV与四种近期驱逐策略组合，在LongBench、LooGLE、RULER以及短上下文MMLU-Pro无伤害对照上，压缩比分别为0.3、0.5、0.7时进行测试。在Qwen3-4B上，TwinKV对两种策略的大多数配置有提升，对第三种策略性能接近持平，而仅对第四种已接近性能上限的自适应基线的小部分配置有效；对三种非上限策略的增益在最宽松的压缩比下最小。然而，在Llama-3.2-1B上的RULER实验中，第四种策略在每个评估单元上都有改进，因为其Alone得分仍有很大提升空间。更广泛地看，与Qwen3-4B相比，Llama-3.2-1B在LongBench上的平均增益较小，但在LongBench和LooGLE上改进单元格的比例更高，并在RULER上取得了明确的胜利。我们还识别出少样本分类示例这一任务结构，在这些示例上TwinKV对两种模型均无帮助。

## Abstract
Long-context inference is bottlenecked by the memory footprint of the key-value (KV) cache, especially for small models under tight resource budgets. Existing KV cache eviction methods score tokens using the model's attention distribution or, in attention-free variants, each key's distance from a global reference point. Using a controlled leave-one-out probe, we find that attention magnitude is unrelated to a token's causal contribution to the answer (Spearman $ρ=-0.004$), challenging the premise behind dominant eviction methods. We introduce TwinKV, a training-free, attention-free redundancy signal that detects whether a token's key has a near-duplicate elsewhere in context. Rather than replacing existing policies, TwinKV acts as a composable repair pass: given a policy's fixed retained set, it identifies evicted tokens with no surviving duplicate (\emph{orphans}) and retained tokens whose information is duplicated elsewhere (\emph{redundant donors}), then swaps them while preserving the original budget and scoring rule. We compose TwinKV with four recent eviction policies across LongBench, LooGLE, RULER, and a short-context MMLU-Pro no-harm control at compression ratios ${0.3,0.5,0.7}$. On Qwen3-4B, TwinKV improves a majority of configurations for two policies, is near-even for a third, and helps only a minority for a fourth adaptive baseline already near a performance ceiling; gains across the three non-ceiling policies are smallest at the loosest ratio. On RULER with Llama-3.2-1B, however, that fourth policy improves in every evaluated cell because its Alone score leaves substantial room to improve. More broadly, Llama-3.2-1B shows a smaller average LongBench gain but a higher fraction of improved cells on LongBench and LooGLE than Qwen3-4B, plus a clean RULER win. We also identify few-shot classification exemplars as a task structure where TwinKV does not help on either model.

## 1. 核心问题与整体含义

- **研究背景**：长上下文推理面临KV缓存内存瓶颈，缓存随序列长度线性增长，对资源受限的小型模型尤为严峻。
- **核心问题**：现有KV缓存驱逐方法大多依赖注意力分布对token评分，但论文通过受控实验发现**注意力幅度与token的因果贡献无关**（Spearman ρ = -0.004, p = 0.96），质疑了主流驱逐方法的前提假设。
- **整体含义**：需要一个不依赖注意力信号、结构性的重要性判据来指导缓存驱逐，确保被驱逐token的信息在剩余上下文中仍可恢复。TwinKV提供了一种**可组合的修复通路**（repair pass），而非又一个独立策略，可对任意现有策略的保留决策进行审计和修复。

## 2. 方法论

- **核心思想**：一个token的信息在驱逐后是否仍然可恢复，取决于上下文中是否存在其近似重复（“孪生”）。若存在重复副本，驱逐该token无损；若没有重复，驱逐则造成真实信息丢失。
- **冗余评分**：
  - 对每个token的关键向量计算与其他非相邻token的余弦相似度 `sim(i,j) = k̂ᵢᵀk̂ⱼ`
  - 排除局部窗口内的token（默认w=32），避免相邻平滑语义漂移被误判为跨上下文冗余
  - 冗余计数 rᵢ = 统计相似度 > 阈值τ（默认0.85）的孪生数
  - 得分 sᵢ = -rᵢ/n，得分越高（冗余越少）越应保留
  - 保护区域：前4个sink token和后64个最近token始终保留
- **可组合修复机制**：
  - 给定任意策略的保留集S₀，计算每个token的最佳存活孪生相似度 bᵢ(S₀)
  - **孤儿（orphans）**：被驱逐但无存活孪生的token，信息真正丢失
  - **冗余捐赠者（redundant donors）**：被保留但已有重复占据槽位的token，浪费空间
  - 按严重程度排序，交换孤儿和捐赠者，保持|S₁| = |S₀| = K预算精确不变
- **关键区别**：与基于全局锚点（如平均键向量）的“全局独特性”方法不同，TwinKV采用**两两局部的比较**，能捕捉“具体事实未被重复”这类全局参考点无法判定的唯一性。
- **旋转不变扩展**：针对LongRoPE等非均匀旋转调度的架构，推导了旋转不变的冗余信号形式，避免位置相关旋转项污染内容冗余判断。
- **复杂度**：O(n²d)每层每头，与注意力计算同阶；修复专用实现可降至O(nKd)。

## 6. 主要结论与发现

- **注意力前提被证伪**：注意力幅度与真实因果效用基本无关（ρ=-0.004），挑战了主流驱逐方法的理论基础。
- **TwinKV修复通路有效**：在Qwen3-4B上，StreamingLLM在LongBench全比例获胜（最多+5.27），PyramidKV在LooGLE全比例大胜（最大+6.70），多数配置得到改善。
- **效果依赖被包裹策略的“余量”**：ExpectedAttention作为自适应基线已在多个基准接近性能上限，修复空间小，反而多为负作用（Qwen3-4B上RULER 9/9失败）；但在Llama-3.2-1B的RULER上因其基线得分低，修复后9/9全赢（平均+4.66）。
- **跨模型不完全迁移**：Llama-3.2-1B在LongBench平均增益更小（+0.17 vs +0.46），但改进单元格比例更高（54.4% vs 41.7%），LooGLE上两者均领先；非均匀弱化，而是独立的任务依赖模式。
- **明确失败模式**：TREC（少样本意图分类）在Qwen3-4B上大幅退化（如ExpectedAttention 64.50→23.00），归因于模板回响产生的“假孪生”而非真实冗余；窗口加宽+阈值调高可修复，表明是超参数伪影而非原理性缺陷。
- **MMLU-Pro并非完全无伤害**：ExpectedAttention在所有比例上均为损失，表明低冗余短上下文中修复通路也可能干扰有效决策。

## 7. 优点

- **挑战主流假设**：以实证（留一法因果探针）打破“注意力=重要性”的领域默认前提，贡献独立证据链。
- **设计精巧**：不是独立的竞争策略，而是可组合的修复通路，保持原策略预算和评分规则不变，即插即用，绿色兼容。
- **无训练、通用性**：仅依赖上下文内键向量两两比较，无需注意力、无需训练、无需任务级校准，对任意现有策略均可叠加。
- **跨架构意识**：针对非均匀旋转调度的架构（LongRoPE）推导旋转不变形式，表明方法对位置编码设计敏感且有适配方案。
- **诚实报告边界**：明确报告基线数量、失败模式（TREC）、跨模型差异、模型依赖效应和效果边界，不做选择性地只报最优结果。

## 8. 不足与局限

- **计算开销高**：O(n²d)相似度矩阵计算作为额外prefill成本是真实负担，长上下文下尤为显著；作者承认修复专用实现可将复杂度降至O(nKd)但留给未来工作。
- **阈值与窗口敏感**：默认(τ=0.85, w=32)对Qwen3-4B有效，但Llama-3.2-1B需调至τ=0.90；TREC需要更激进的(0.95–0.97, w=64–128)才能转正——跨模型/任务架构存在不统一的校准需求。
- **对自适应策略的干扰风险**：当被包裹策略已接近性能上限时（如ExpectedAttention），修复通路反而容易扰动好的决策，造成退步。
- **短上下文控制不完美**：MMLU-Pro上并非完全无害，部分策略在宽松压缩比下有轻微负面效果，对“短上下文无冗余可修”的预期构成反例。
- **覆盖范围受限**：未在更大规模模型（如7B以上）上验证；开发中排除了ChunkKV（因交互持续为负）和H2O（OOM限制），削弱了对更广泛基线的泛化结论。
- **少样本任务结构性失败**：TREC类（模板化的近重复示例）会系统性产生假孪生，导致负面迁移，需要任务感知的窗口/阈值调节才能恢复。
