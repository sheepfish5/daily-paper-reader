## 摘要
大语言模型（LLM）中的长上下文推理日益受到键值（KV）缓存所需内存的限制。KV缓存压缩通过减少先前令牌的存储成本来解决此问题。在现有方法中，低秩压缩尤其具有吸引力，因为它以降低维度来表示每个令牌。之前的低秩方法通常从模型权重中推导出固定的投影空间，从校准激活中构建固定空间，或在广泛的缓存区域上构建共享基。此类表示可能无法捕获详细但重要的信息。我们将每个头部的KV缓存划分为固定长度的逻辑页，并观察到各个页面内存在显著的低秩结构。基于此观察，我们提出了PuzzleKV，一种无需训练和校准的方法，将每个已完成的页面视为独立的压缩单元。PuzzleKV在每一层和KV头部内对页面进行分解，直接对密集和分解后的页面计算注意力，并在自回归解码过程中增量压缩新符合条件的页面。跨模型、上下文长度和基准的实验证明了PuzzleKV在匹配存储预算下的有效性。在约60%的原始KV缓存存储下，PuzzleKV在两个评估模型及所有基准设置中均实现了Full KV性能的96%以上，在RULER上相较于Global SVD有显著提升，并在LongBench上表现相当。为实现更激进的压缩比，PuzzleKV可进一步与量化结合，在仅使用18.7%原始存储的情况下保持Full KV性能的93%以上。

## Abstract
Long-context inference in large language models (LLMs) is increasingly limited by the memory required for the key-value (KV) cache. KV cache compression addresses this problem by reducing the storage cost of previous tokens. Among existing approaches, low-rank compression is particularly attractive because it represents every token in reduced dimensions. Previous low-rank methods typically derive fixed projection spaces from model weights, construct fixed spaces from calibration activations, or construct a shared basis over a broad cache region. Such representations may not capture detailed but important information. We partition each per-head KV cache into fixed-length logical pages and observe substantial low-rank structure within individual pages. Based on this observation, we propose PuzzleKV, a training- and calibration-free method that treats each completed page as an independent compression unit. PuzzleKV decomposes pages within each layer and KV head, computes attention directly over dense and factorized pages, and incrementally compresses newly eligible pages during autoregressive decoding. Experiments across models, context lengths, and benchmarks demonstrate the effectiveness of PuzzleKV under matched storage budgets. At approximately 60% of the original KV cache storage, PuzzleKV achieves more than 96% of Full KV performance across both evaluated models and all benchmark settings, with substantial gains over Global SVD on RULER and competitive performance on LongBench. To achieve a more aggressive compression ratio, PuzzleKV can be further combined with quantization while retaining more than 93% of Full KV performance using only 18.7% of the original storage.

# PuzzleKV: 面向KV缓存压缩的页级低秩分解——论文总结

## 1. 论文的核心问题与整体含义

- 长上下文推理中，KV缓存的内存占用是主要瓶颈。例如 Qwen3-32B 在 BF16 下处理单条 128K 序列需要约 32 GiB 的 KV 缓存。
- 现有低秩压缩方法存在两类不足：
  - 基于模型权重或校准激活构造固定投影空间，缺乏对输入内容的适应性；
  - 在较宽的缓存区域（如整个序列）上共享单一基，容易优先重建占主导的全局方向，丢失局部但关键的信息（如稀疏的键值对）。
- 论文的观察：将每个 KV head 的缓存划分为固定长度的逻辑页后，**页内存在显著的低秩结构**。
- 因此提出 PuzzleKV：**以“页”为独立压缩单元**进行低秩分解，保留每个 token，不依赖训练或校准，从而在低存储下维持较高推理质量。

## 2. 论文提出的方法论

### 核心思想
- 每个完成的 KV 页是一个独立低秩子空间，各页使用自己的紧凑基表示，从而捕获不同区域的主导方向。
- 保留少量密集区域（开头 sink 页、最近窗口），其余历史页以低秩因子存储，不丢弃任何 token。

### 关键技术细节
- **页划分与分解**：对每个 layer 和 KV head 的键/值序列按固定页大小 P 分页；对每个已完成的页做截断 SVD：
  - $X_p \approx L_p R_p$，其中 $L_p = U_{p,r}$，$R_p = \Sigma_{p,r} W_{p,r}^\top$
  - 存储压缩率：$\rho = \frac{(r_K + r_V)(P + d)}{2 P d}$
- **高效批分解**：由于页是“短宽”矩阵（P < d），利用 Gram 矩阵 $G_p = X_p X_p^\top$ 的特征向量得到左奇异向量，可映射为 GPU 上的批处理操作，避免逐页单独 SVD。
- **混合注意力计算**：不重建历史密集缓存，直接对因子化页计算 attention score 和输出：
  - $s_p = \left( q (R_p^{(K)})^\top \right) (L_p^{(K)})^\top / \sqrt{d}$
  - $o_p = \left( \exp(s_p - m_p) L_p^{(V)} \right) R_p^{(V)}$
  - 通过在线 softmax 合并各页部分结果。
- **增量更新**：解码时新 KV 对追加到最近密集页；当页填满并离开局部窗口时，立即被因子化并移入低秩存储。每个解码步最多分解一次页，新生成的 token 均保持压缩状态。

## 6. 论文的主要结论与发现

- **页级低秩结构普遍存在**：在两个模型、不同层、KV head 和页大小下，页内确实具有可压缩的低秩性。

## 7. 优点

- **免训练、免校准**：可直接应用于任意模型，部署成本低；
- **无 token 丢失**：每个 token 均以低秩因子保留，避免了逐出方法对精确回收任务的不可逆损伤；
- **页级并行与批处理**：统一页形状使 SVD 可在 GPU 上批量执行，适合高性能推理；
- **避免缓存重建**：注意力在低秩因子上直接计算，不会产生临时密集 KV 缓冲，保留了内存节省；
- **与分页管理天然契合**：使用与 PagedAttention 一致的页抽象，较易于集成到 vLLM 等现代服务引擎；
- **可扩展性**：与量化技术正交，可以实现更激进的压缩比。

## 8. 不足与局限

- **模型与上下文覆盖有限**：仅在 8B 模型和 ≤32K 上下文上验证，未展示在更大模型（如 70B+）或更长上下文（如 128K）上的表现；

## 9. 潜在改进方向

- **自适应秩分配**：根据页内能量谱或下游任务敏感度动态调整每页的秩，而非全局固定 rK/rV，可能进一步压缩冗余页、保护信息密集页；
- **跨层/跨头冗余利用**：将 PuzzleKV 的页级低秩结构与其他冗余消除方法（如 xKV 的跨层共享、head 剪枝）结合，形成多维度压缩管线；
- **与稀疏注意力结合**：在低秩因子之外，显式保留少量关键 token 的原始向量，形成“低秩 + 稀疏”的混合缓存，兼顾精确检索与整体压缩；
- **更高效的增量分解**：当前填满一页即做一次 SVD；可探索增量低秩更新（如增量 SVD 或在线子空间跟踪）以避免每次从头分解；
- **面向真实服务引擎的实现**：在 vLLM 等系统中集成页级低秩缓存，验证多请求、连续批处理下的吞吐与延迟表现；
- **扩展到更长上下文认证**：在 128K 或更长输入上评估，结合滑窗、稀疏注意力等策略，验证页级低秩假设在极长序列下是否依然成立。

- **影响**：
  - 提出了一种新的压缩粒度——逻辑页，介于逐 token 逐出与全局低秩投影之间，兼具局部适配性与工程可操作性；

## 11. 总结评价

PuzzleKV 提出了一种简洁且有说服力的思路：**将 KV 缓存以固定大小的页为单位做低秩分解，而非在整个序列上共享单一投影方向**。这一粒度选择在算法上既保留了局部结构适配性，又在工程上统一了页形状从而支持批处理 SVD。实验表明在约 60% 存储预算下性能几乎无损，并可进一步与量化结合达到约 18.7% 存储下仍保持 93% 以上的性能。尽管在模型规模、上下文长度、基线覆盖和系统级验证上仍有不足，但其方向具有较高实用价值，尤其在免训练、即插即用、与现有分页推理引擎兼容等方面具有明显的工程吸引力。后续研究若能在自适应秩分配与真实服务场景中进一步验证，有望将页级低秩压缩推向更广泛的长上下文推理实践。
