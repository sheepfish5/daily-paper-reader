## 摘要
大型语言模型（LLM）服务的效率从根本上受到自回归解码顺序特性的限制。推测解码（SD）通过使用轻量级草稿模型推测未来令牌，并由LLM在单次并行前向传递中验证这些令牌，从而缓解了这一限制。为了进一步提高效率，多候选方案提出多样化的候选集以增加令牌被接受的可能性。然而，我们表明这些方案受到残差漂移的瓶颈影响：即初始候选被拒绝导致残差目标分布偏离草稿模型的预测。这种偏移使得后续候选失效，并迫使系统进行昂贵的重采样。为解决这一问题，我们提出了ResiSpec，一个在验证过程中战略性重塑提议分布以将残差目标质量锚定在草稿模型高置信区域内的框架。通过在不影响输出精确性的情况下数学上重新对齐验证过程，ResiSpec防止了候选过时，并在最先进的多候选方法上实现了高达1.92倍的加速。代码可在https://github.com/Czzzk/Resispec获取。

## Abstract
The efficiency of Large Language Model (LLM) serving is fundamentally limited by the sequential nature of autoregressive decoding. Speculative Decoding (SD) mitigates this by using a lightweight draft model to speculate future tokens, which are then validated by the LLM in a single parallel forward pass. To further boost efficiency, multi-candidate schemes propose diverse candidate sets to increase the likelihood of token acceptance. However, we show that these schemes are bottlenecked by Residual Drift: a phenomenon where the rejection of initial candidates causes the residual target distribution to diverge from the draft model's predictions. This shift renders subsequent candidates ineffective and forces the system into expensive resampling. To resolve this, we propose ResiSpec, a framework that strategically reforms the proposal distribution during verification to anchor the residual target mass within the draft model's high-confidence regions. By mathematically re-aligning the verification process without compromising output exactness, ResiSpec prevents candidate obsolescence and achieves up to 1.92$\times$ speedup over state-of-the-art multi-candidate methods. Code is available at https://github.com/Czzzk/Resispec.

# ResiSpec：通过残差分布整形增强多候选推测采样 —— 论文深度总结

## 1. 核心问题与整体含义（研究动机与背景）

大语言模型（LLM）的自回归解码本质上是逐 token 顺序生成的，这一过程受限于内存带宽而非算力，导致 GPU 计算核心利用率低下，成为 LLM 推理效率的根本瓶颈。推测解码（Speculative Decoding, SD）通过"先推测、后验证"的范式缓解这一问题：用轻量级草稿模型（draft model）快速生成候选 token 序列，再由目标大模型在单次并行前向传播中批量验证，从而增加每次内存访问周期内生成的 token 数量。

在 SD 基础上，多候选方案（multi-candidate schemes）进一步通过树状结构（tree-based）或批量采样在相同位置预采样多个候选 token，以扩大搜索空间、提高至少一个候选被接受的概率。然而，本文发现这类方案存在一个关键的**扩展性瓶颈——Residual Drift（残差漂移）**：

- 为保证采样精确性（exactness），当目标模型拒绝某个草稿候选后，其采样分布必须补偿性地偏移到**残差分布**（residual distribution）上；
- 由于残差分布天然集中在草稿模型的"盲区"（即草稿模型低置信度区域），而后续候选 token 又是从原始草稿分布中预采样的，二者之间存在严重的支撑集不匹配（support mismatch）；
- 一旦早期候选被拒绝，剩余的预采样候选在残差分布下几乎失效，导致系统被迫进入昂贵的重采样流程，多候选并行验证的收益被大幅削弱，表现为"候选级联过期"（cascade of obsolescence）。

本文的核心问题是：**能否打破多候选推测解码的残差漂移瓶颈，使拒绝后的残差分布仍然与草稿模型的高密度区域保持对齐，从而让后续候选在更长的验证链中持续有效？**

## 2. 方法论：ResiSpec 框架

### 2.1 核心思想

ResiSpec 的核心洞察是：**通往精确采样的数学路径并非唯一**。传统方法中的残差漂移并非零偏差采样的必然代价，而是次优验证准则的副产品。ResiSpec 在验证阶段引入一个**辅助代理分布**（proxy distribution）k(x) 替代原始草稿分布 q(x)，通过主动整形残差分布，使被拒绝后的目标残差质量保持在草稿模型的高置信区域内，从而保证预采样候选在整条验证链中持续有效，同时不破坏采样的统计无偏性。

### 2.2 关键技术细节

**代理分布机制（Proxy Mechanism）**：给定目标分布 p(x) 和未归一化的残差质量 r(x)，代理分布定义为：

- k(x) = p(x) − r(x) + s(x)，其中 r(x) 是预留给残差分布的质量，s(x) ≥ 0 是松弛函数（slack function），用于补偿归一化；
- 为避免注入质量与预留分布冲突，松弛函数满足**不相交支撑约束**：supp(s) ∩ supp(r) = ∅，即 s(x)·r(x) = 0；
- 代理分布需满足概率约束（总和为 1）、非负性，以及在采样点 x_i 处满足**局部对齐**条件 k(x_i) = q(x_i)，确保与草稿模型的局部概率一致。

**全局质量守恒定律（Proposition 1）**：松弛函数的总质量必须恰好等于预留残差总质量 Z = Σ r(x)，这是代理分布归一化的必要条件。

**理论最优与容量界限**：
- 理想情况下，残差形状 r(x) = Z·q(x) 可使残差分布与草稿分布完全重合（L1 距离为零），但容量约束限制 Z ≤ min_{x:q(x)>0} p(x)/q(x)；
- 由于语言模型存在"长尾"特性，某些 token 上目标分布 p(x) → 0 而草稿分布 q(x) > 0，导致容量上界坍缩到零附近，理论最优解在实践中退化。

**实际算法（Algorithm 1）**：
1. 按序验证候选 token x_i，接受概率为 min(1, R(x_i)/D(x_i))；
2. 若被拒绝，调用 `GetProxy(R, Q, x_i)` 构造代理分布 K：
   - 设定残差预算 Z ← q(x₀) − p(x₀)（即局部质量缺口）；
   - 初始投影：对所有 i ≠ x₀，设置 r_i ← min(Z·q_i, p_i)，"裁剪"进目标模型的可用容量；
   - 容量感知再分配：将由裁剪导致的质量赤字 Δ 分配到仍有剩余容量（p_i > r_i）的 token 上，确保总残差质量严格等于预算 Z 且不超过 p 的上界；
   - 构造代理分布 k = p − r，并在 x₀ 处局部调整使 k(x₀) = q(x₀)；
3. 用代理分布 K 替代原始草稿分布更新残差分布 R ← norm(max(R − K, 0))，然后继续验证下一个候选；
4. 若全部候选被拒绝，从最终残差分布 R 中重采样。

**理论保证（Theorem 1）**：当代理分布 k(x) 在验证点满足局部对齐条件 k(x) = q(x) 时，无论代理分布如何偏离原始草稿分布，只要残差分布与接受准则使用同一个 k(x)，最终的边际输出分布严格等于目标分布 p(x)（逐项推导详见附录 A.1）。

## 6. 主要结论与发现

1. **残差漂移是多候选推测解码的真实瓶颈**：实证研究表明，接受率在第 1 个候选之后急剧衰减（Figure 1），扩大候选数 N 仅带来微弱的 EAL 提升且效率 η 显著下降（Table 5），说明标准验证协议下宽树扩展存在严重的收益递减。
2. **ResiSpec 有效缓解残差漂移**：通过代理分布整形，保证拒绝后的残差质量与草稿模型高密度区域保持对齐，后续候选在接受率和效用上显著提升。
3. **显著的性能提升**：相比 SpecInfer，ResiSpec 在保持数学精确性的前提下，接受长度最高提升 1.86 倍、吞吐量最高提升 1.68 倍（主实验）；在更深的树上最高实现 **1.92 × 吞吐量加速**。
4. **即插即用兼容性**：ResiSpec 作为验证阶段的 add-on，可与 EAGLE（草稿侧优化）和 Sequoia（树构建优化）正交叠加，均带来进一步增益。
5. **零偏差保证**：理论证明（Theorem 1）和 KL 散度实证（~10⁻¹⁰，接近浮点精度）共同确认 ResiSpec 不改变目标模型的输出分布。

1. **问题洞察深刻**：将多候选推测解码的扩展性瓶颈形式化为"残差漂移"这一概念，清晰地揭示了候选级联失效的数学根源，为后续研究提供了新视角；

## 8. 不足与局限

1. **理论最优解在实践中不可达**：论文自身承认，理想残差匹配（r(x) = Z·q(x)）在语言模型长尾分布下退化，Z 的选取只能依赖启发式（Z_applied = max(Z*, |q(x₀) − p(x₀)|)），缺乏对最优 Z 的严格刻画——虽然 Theorem 2 给出了单调性的指导，但从"最小可行预算"到"全局最优"之间仍存在理论缝隙；
