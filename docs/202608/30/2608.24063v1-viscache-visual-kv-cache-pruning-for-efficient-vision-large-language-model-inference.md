## 摘要
尽管视觉大语言模型（VLLMs）在多模态推理中取得了显著成功，但其长上下文推理由于视觉键值（KV）缓存的巨大计算和内存开销而仍然代价高昂。现有的KV压缩方法通常对视觉token和层进行均匀剪枝，导致大量信息丢失和性能下降。为应对这一挑战，我们提出了VisCache，一种无需训练的即插即用框架，用于从粗到细的视觉KV缓存剪枝，它包含两个协同阶段。首先，一个轻量级VLM通过选择性转发语义信息丰富的关键帧来过滤时间冗余。其次，我们引入了PruneKV，一种针对VLLMs注意力动态量身定制的外科手术式KV压缩算法。与刚性剪枝策略不同，PruneKV采用抛物线式逐层预算分配以及不对称更新机制，选择性剪枝键同时融合值，从而保留关键上下文信息。大量实验表明，VisCache显著提升了推理效率，实现了高达2.35倍的加速和显著的内存减少，同时仅保留19%–28%的KV缓存即可保持竞争性能。VisCache持续优于现有基线，为长上下文VLLM推理建立了效率与性能之间新的帕累托前沿。代码可在https://github.com/Wlklk/VisCache获取。

## Abstract
While Vision Large Language Models (VLLMs) have achieved remarkable success in multimodal reasoning, their long-context inference remains prohibitively expensive due to the massive computation and memory overhead of visual Key-Value (KV) caches. Existing KV compression methods often apply uniform pruning across visual tokens and layers, leading to substantial information loss and degraded performance.To address this challenge, we propose \textbf{VisCache}, a plug-and-play framework for coarse-to-fine \textbf{Vis}ual KV \textbf{Cache} pruning without training, which consists of two synergistic stages. First, a lightweight VLM filters temporal redundancy by selectively forwarding semantically informative keyframes. Second, we introduce {PruneKV}, a surgical KV compression algorithm tailored to the attention dynamics of VLLMs. Unlike rigid pruning strategies, PruneKV adopts a parabolic layer-wise budget allocation together with an asymmetric update mechanism that selectively prunes keys while fusing values, thereby preserving critical contextual information. Extensive experiments demonstrate that VisCache substantially improves inference efficiency, achieving up to {2.35$\times$ speedup} and significant memory reduction while maintaining competitive performance with only {19--28\%} KV cache retention. VisCache consistently outperforms existing baselines, establishing a new Pareto frontier between efficiency and performance for long-context VLLM inference. Code is available at https://github.com/Wlklk/VisCache

## 2. 方法论：核心思想、关键技术细节与算法流程

### 整体框架：粗到细的两阶段范式

VisCache 由两个互补的阶段组成，分别处理输入层面的时间冗余和模型内部的结构冗余：

### 阶段一：Prompt-Aware Scout 时间冗余过滤

- **核心思想**：在视觉输入进入 VLLM 之前，先用轻量级视觉语言模型（默认使用 CLIP ViT-B/32）过滤掉与任务无关的冗余帧。
- **技术细节**：
  - 文本编码器将提示词 T 映射为嵌入 h_t，视觉编码器将每帧 f 映射为嵌入 h_f；
  - 采用最大边际相关性（MMR）准则来平衡提示相关性与帧间多样性，MMR 得分为：

    MMR(f) = λ·sim(h_f, h_t) − (1−λ)·max_{f'∈Ω} sim(h_f, h_f′)

  - 其中 λ = 0.7 控制相关性与多样性之间的权衡，Ω 为已选帧集合；
  - 迭代选择 MMR 得分最高的帧加入 Ω，直到达到目标保留比例 p。

### 阶段二：PruneKV 层感知视觉 KV 压缩

PruneKV 包含三个关键组件：

**(a) Token 重要性评分与全局排序**

- 在预填充阶段，汇总每个视觉 token 在所有层上接收到的注意力权重：

  s_v = (1/L) Σ_{l=1}^{L} Σ_{i=1}^{N} A^l_{i,v}

- 所有层共享同一个全局 token 排序（消融实验证明共享全局排序优于逐层独立排序）；
- 该设计将“哪些 token 重要”与“每层保留多少 token”两个问题解耦。

**(b) 抛物线式层间预算分配**

- 设截断层 h（默认 h = 3L/4），层 l > h 的视觉 KV 条目被完全丢弃；
- 对于保留的层 l ∈ [1, h]，预算比例为：

  b_l = 1 − (l−1)² / [2(h−1)²]

- 该策略满足 b_1 = 1、b_h = 0.5：在浅层保留更多 token（细粒度空间细节），在深层更激进压缩（抽象语义容忍剪枝）；
- 与算术递减（PyramidKV）和几何递减（PDrop）相比，抛物线式在极端压缩下信息保留更优。

**(c) 不对称键值更新（“剪键融值”策略）**

- 核心洞察：注意力权重仅由 QK⊤ 决定，因此 key 是相关性选择器；而 value 是信息载体，直接丢弃会造成不可逆的信息损失。
- 具体操作：
  - 对丢弃集 C_d 中的 key 向量完全删除（其注意力贡献可忽略）；
  - 对应 value 不丢弃，而是通过相似度加权聚合重新分配给保留 token；
  - 重分配矩阵：

    Φ = Softmax(V_k V_d⊤ / τ) ∈ R^{b_l × (n−b_l)}

  - 融合公式：

    V_new_k = μV_k + (1−μ)(ΦV_d)

  - 默认 μ = 0.7（消融实验表明该值最优），τ = 1.0。

### 算法流程（PruneKV）

1. 计算平均注意力评分，确定全局 token 重要性排序；
2. 按抛物线公式逐层计算保留预算 b_l；
3. 对每层：划分保留集和丢弃集 → 剪除丢弃集的 key → 为丢弃集 value 计算重分配矩阵 Φ → 融合到保留 value 中；
4. 返回压缩后的 KV 缓存用于后续解码。

## 6. 主要结论与发现

1. **显著的效率提升**：仅保留 19%–28% 的视觉 KV 缓存即可实现最高 2.35× 端到端推理加速；FLOPs 降至全量缓存的 6%–15%（取决于模型规模和 RR）。
2. **性能保持甚至超越**：VisCache 在 28% RR 下于 Qwen2.5-VL-3B 取得 45.64% 的平均准确率，超过全量缓存的 44.16%；在 32B 模型上以 28% RR 达到 56.86% 平均准确率（全量缓存为 57.46%）。
3. **抛物线预算优于算术/几何**：在极端压缩下，抛物线式层间分配比 PyramidKV 和 PDrop 等刚性策略更好地保留关键信息。
4. **不对称键值更新有效**：剪键融值（prune-keys, fuse-values）在所有预算策略（除几何）中均带来一致的性能提升。
5. **两阶段协同互补**：仅用 Scout 过滤在某些基准上会损害性能，仅用 PruneKV 性能稳定但次优；两者结合在所有 RR 下均取得最佳结果。
6. **共享全局排序优于逐层排序**：跨层聚合注意力评分提供更稳定综合的重要性估计。
7. **跨模型和跨方法兼容性良好**：VisCache 可泛化到 Qwen3-VL 和 LLaVA-OneVision，且可与 KIVI/FlatQuant 等量化方法正交组合。
8. **最优 RR 因任务而异**：DREAM1K 在较高 RR 下持续改善，EgoSchema 在约 70% RR 处达到峰值——提示适度的剪枝反而能去除注意力噪声。

## 7. 优点

1. **免训练、即插即用**：无需任何训练或微调，可直接应用于现有 VLLM，适配成本极低；
2. **粗到细的双层冗余消除**：在输入层面（帧过滤）和模型内部（token/层压缩）同时处理视觉冗余，设计逻辑清晰且互补；
3. **洞察深刻的方法设计**：
   - 识别出 key 与 value 的功能不对称性并据此设计“剪键融值”机制，是对注意力机制本质的深入理解；
   - 抛物线式预算分配（缓降后陡降）比算术/几何递减更符合视觉信息随层深抽象化的事实；
4. **实验覆盖面广**：跨多基准、多模型、多压缩比、多种消融，验证了方法的通用性和鲁棒性；
5. **效率指标全面**：同时报告 FLOPs、E2E、TTFT、TPOT、GPU 内存、KV 缓存大小和 TPS，而非只报告单一效率指标；
6. **良好的正交兼容性**：与量化方法（KIVI/FlatQuant）可无缝组合，显示其作为通用插件的潜力；
7. **应用价值明确**：在资源受限的边缘设备上部署 VLLM 的场景中具有很强的实际意义。

## 8. 不足与局限

1. **Scout 与主模型的语义对齐问题**：
   - Scout（如 CLIP）的视觉表征可能与主 LLM 骨干不一致，导致选出的关键帧并非下游模型真正需要的信息；
   - 论文在消融（Table 15）中证实 scout 选择对下游 VQA 准确率有非平凡影响（BLIP 明显较差），说明该环节存在脆弱性；
   - 未探索 scout 与主模型的协同适配。

2. **Prefilling 阶段的注意力分数存储开销**：
   - PruneKV 需要存储所有层的注意力分数以计算 token 重要性，这本身引入内存开销，在超长视频场景下可能部分抵消 KV 压缩收益；
   - 论文承认这一点但未给出量化分析。

3. **实验方法上的不足**：
   - 未报告多次运行的统计显著性检验（除融合强度实验外）；
   - 主实验中某些 RR 下 VisCache 不如基线（如 40% RR 时低于 PyramidKV），论文的解释可再深入；
   - MVBench 实验的 RR 与主实验未能完全对齐；
   - 未在更大的模型（如 70B+）上验证扩展性。

4. **应用局限**：
   - 方法依赖注意力分数作为 token 重要性信号，对注意力分布本身不可靠的模型（如训练不充分的模型）可能失效；
   - 帧级过滤在需要时序连贯性的任务（如动作识别、事件推理）上可能丢失关键过渡帧——论文在附录中也承认了这一失败模式；
   - 性能-保留率关系呈任务依赖性，实际部署需要针对具体任务调整 RR，增加调参负担。

5. **潜在偏差风险**：论文自身承认，基于预训练模型注意力模式的剪枝可能传播基础模型中的偏见，但未对此进行实证分析。
