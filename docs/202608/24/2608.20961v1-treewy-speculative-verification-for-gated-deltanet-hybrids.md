## 摘要
现代开放模型是混合模型：大多数层是线性注意力（门控DeltaNet，GDN）层，携带固定大小的循环状态，而不是不断增长的键值（KV）缓存。这使得普通解码内存高效，但损害了投机解码。为了验证一批草稿令牌，然后回滚被拒绝的令牌，当今的系统对GDN层在每个草稿位置快照完整循环状态，并且这些快照无法在草稿树的分支之间共享，因此宽度大、接受率高的树在内存上不可行。我们消除了快照。利用门控delta规则的树结构WY变换，我们通过一次三角求解计算每个草稿节点的输出，并在提交时仅重建被接受的状态，存储一个小型的伪值矩阵而非每节点状态；该推导仅依赖于门控delta规则，不依赖任何其他架构细节。在一个混合模型族的两种规模（Qwen3.5 35B和397B）的推理基准测试中，该方法在相同接受长度下削减了投机循环状态内存和KV缓存压力，在内存受限时将释放的高带宽内存（HBM）转化为更高的吞吐量和更低的首次令牌延迟（TTFT），在不受限时仅消耗几个百分点。对于树宽度，同样的内存换来了可行性：更宽、接受率更高的草稿成为可能，但还不是吞吐量的胜利。

## Abstract
Modern open models are hybrids: most layers are linear-attention (Gated DeltaNet, GDN) layers carrying a small fixed-size recurrent state instead of a growing key-value (KV) cache. This makes ordinary decoding memory-efficient, but hurts speculative decoding. To verify a batch of draft tokens and then roll back the rejected ones, today's systems snapshot the full recurrent state at every draft position for GDN layers, and those snapshots cannot be shared across branches of a draft tree, so a wide, high-acceptance tree becomes memory-infeasible. We remove the snapshots. Using a tree-structured WY transform of the gated delta rule, we compute every draft node's output with a single triangular solve and reconstruct only the one accepted state on commit, storing a small pseudo-value matrix instead of per-node states; the derivation depends only on the gated delta rule, not on any other architectural detail. In serving benchmarks on two scales of one hybrid model family (Qwen3.5 35B and 397B) this cuts speculative recurrent-state memory and KV-cache pressure at identical acceptance length, turning the freed HBM into higher throughput and much lower time-to-first-token (TTFT) wherever memory binds, and costing a few percent where it does not. For tree width the same memory buys affordability: a wider, higher-acceptance draft becomes possible, though not yet a throughput win.

# TreeWY：门控DeltaNet混合模型的投机验证——详细论文总结

## 1. 论文的核心问题与整体含义

**研究动机与背景**

- **混合模型的兴起**：现代开放权重大语言模型（如Qwen3.5）多为混合架构，即大部分层使用线性注意力层（如门控DeltaNet, GDN），少部分层保留传统softmax注意力。GDN层维护一个固定大小的循环状态矩阵 $S_t \in \mathbb{R}^{d_v \times d_k}$，而非随上下文增长的KV缓存，从而在普通解码时实现内存高效。
- **投机解码中的内存瓶颈**：投机解码（speculative decoding）通过一个轻量草稿模型提出候选令牌，再由目标模型并行验证。在验证一批草稿令牌时，系统需要在每个草稿位置快照GDN层的完整循环状态，以便在部分接受后回滚。这些快照无法在草稿树的各分支间共享，导致：
  - 快照内存随草稿长度（或树节点数）线性增长（k个草稿位置需要 $k+1$ 个完整状态块）；
  - 宽树（多个候选分支）因内存开销过大而变得不可行；
  - 显著限制了推理服务器的并发能力。
- **核心矛盾**：GDN的循环状态是**有损前缀摘要**，不能像KV缓存那样通过移动指针自由裁剪或回滚——这构成了投机解码的根本障碍。

## 2. 论文提出的方法论：TreeWY

**核心思想**

将门控delta规则重写为**树结构WY变换**，从而在验证整个草稿（链或树）时无需存储任何中间状态快照；验证过程化简为**一次三角线性系统求解**，提交时仅重建被接受的那个状态。

**关键技术细节**

1. **伪值（pseudo-value）重写**：将GDN更新规则展开，将delta规则表达为带衰减的加性注意力形式：
   - $S_t = \alpha_t S_{t-1} + \tilde{v}_t k_t^\top$，其中 $\tilde{v}_t = \beta_t(v_t - \alpha_t S_{t-1} k_t)$ 是伪值（原始值减去状态已预测的部分）。
   - 给定所有伪值后，状态和输出都是对前面令牌的衰减加权和，故无需逐步递推中间状态。

2. **一次三角求解验证全树**：将草稿树的N个节点按DFS前序排列（祖先索引小于后代），对所有节点的伪值构造一个线性系统：
   - $\left[I + \text{diag}(\beta) G\right] \tilde{V} = R$
   - 其中 $G[t,i] = g_t/g_i \, (k_t^\top k_i) \, [i \prec t]$ 是严格下三角矩阵（祖先掩码），$R[t] = \beta_t v_t - \beta_t g_t(S_0 k_t)$。
   - 由于矩阵严格下三角，整个系统通过**一次前向代入**即可求解，无需递推、无需逐节点状态，树越宽系统规模也不变。

3. **提交时重建状态**：验证接受某个节点 $a$ 后，仅对该节点的祖先求和重建状态：
   - $S_a = g_a S_0 + \sum_{i \preceq a} \frac{g_a}{g_i} \tilde{v}_i k_i^\top$
   - 只存储伪值矩阵 $\tilde{V}$（规模 $O(N d_v)$），而非每节点一个完整状态。在 $d_k=d_v=128$ 时，伪值矩阵比完整状态小约128倍。

4. **与现有工作的关系**：
   - 继承DeltaNet的链式WY变换，推广到树的严格祖先形式；
   - 借用了STree的标量衰减祖先掩码，但扩展覆盖了GDN的非交换矩阵转移（标量衰减×秩1修正）；
   - 与Bole（SGLang中的并发工作）思路最接近，但独立开发于不同的服务栈。

**实验数量**

- **公平性考量**：TreeWY与storeall在相同模型、相同负载下配对比较；与ReplaySSM比较时各自归一化到各自vLLM构建的基线，但论文报告基线之间吞吐差异在1%以内，故可比。

**不足之处**：论文未与最接近的并发工作Bole进行直接对比（Bole未开源代码）；树宽实验仅在35B一个模型上运行。

## 6. 论文的主要结论与发现

1. **内存收益**：TreeWY将每层的状态存储从 $N+1$ 个块降至1个块（链和树均如此），峰值KV缓存使用量在同负载下降低2–3倍，在相同接受长度下成立。

2. **内存受限时的性能收益**（基线KV池已饱和的场景）：
   - 吞吐量最高提升达 **1.49×**（35B）；
   - p99 TTFT最多降低约 **40×**（683ms vs 27489ms，35B gmu=0.6，并发度128）；
   - 准入请求数大幅提升（如35B下1365 vs 2531被抢占请求）。

3. **内存充裕时的成本**：吞吐量仅下降1–3%（0.97–0.99×），KV减少仍保持2.2–2.5×——释放的内存真实但未被利用。

4. **树宽可行性**：TreeWY使宽树在存储上可行（无论树多宽，每层仅1个块），接受长度随宽度增加（如从(1,1,1)的1.883到(3,3,3)的2.786），但**尚不是吞吐量胜利**——树验证的piecewise（非CUDA图捕获）执行和更长的令牌序列抵消了接受率收益。

5. **与ReplaySSM的对比**：两者释放相近的KV余量，但ReplaySSM在链式吞吐上领先（1.12–1.20× vs 0.99–1.08×基线），论文假设差异源于ReplaySSM的延迟状态写入调度而非核心算法，但**明确承认该归因未经亲自验证**。

## 7. 优点

- **数学优雅且通用**：核心推导仅依赖门控delta规则本身，不涉及任何其他架构细节，原则适用于所有GDN混合模型。
- **直击痛点**：精确识别出GDN投机解码的根本瓶颈（快照不可共享），而非绕道解决，且解决得干净彻底。
- **统一链式与树式验证**：一个三角求解同时覆盖链和树，存储开销均为常数级，这是此前方法未达到的。
- **实验设计扎实**：正确的分区分析（内存受限 vs 充裕的控制组对比）清晰展示了收益的适用条件，避免了线性平均的误导性；对ReplaySSM的对比也提供了透明分解（批大小/每令牌成本），而非单纯罗列数字。
- **诚实报告局限**：明确承认树路径尚未成为吞吐量胜利、与ReplaySSM的差距归因未经检验、与Bole未做对比——这种透明度值得肯定。

## 8. 不足与局限

- **树路径性能未达预期**：树验证需要非因果祖先掩码，无法从CUDA图重放，导致整模型降级为piecewise捕获，GDN混音器被移出图捕获范围，成本远超掩码本身——这是工程实现层面的明显短板。
- **与ReplaySSM的差距未闭合**：论文假设ReplaySSM的延迟写入调度是其吞吐优势的来源，但**没有亲自原型验证**这一假设；该差距可能源自其算法本质而非仅调度层面，需要进一步实验确认。
- **未与Bole直接对比**：最接近的并发工作（Bole）因无代码实现而无法head-to-head，这一对比空缺是验证TreeWY相对先进性的关键缺口。
- **模型覆盖单一**：仅在Qwen3.5一个模型家族上验证，尽管扩展到第二个模型家族已列为未来工作。
- **树宽收益有限**：更宽的树虽可行且接受长度增加，但尚不构成吞吐量收益，实际部署价值待定。
- **额外开销未被完全消除**：在内存充裕时，仍有1–3%的吞吐量损失和0.83–0.95×的TPOT代价，虽被归因于实现伪影（admission机制），但尚未完全优化消除。
- **前缀缓存被禁用**：所有实验均禁用前缀缓存，可能无法反映真实生产环境中前缀缓存启用时的相对表现。
