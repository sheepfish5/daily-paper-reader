## 摘要
在移动设备上部署视觉语言模型（VLMs）因其巨大的内存和计算需求而具有挑战性。我们提出了一个量化框架，用于在资源受限的硬件上实现高效推理。我们的方法结合了一个量化流程，该流程利用模型自身生成训练数据，无需访问训练环境，并采用一种新颖的每参数2.7位格式，支持在Arm CPU上高效执行。我们通过将Llama 3.2 11B Vision Instruct模型压缩至3.7 GB（8位激活），在标准视觉问答任务集上保持强劲性能，从而验证了我们的方法。

## Abstract
Deploying vision-language models (VLMs) on mobile devices is challenging due to their significant memory and compute requirements. We present a framework for quantizing VLMs for efficient inference on resource-constrained hardware. Our approach combines a quantization pipeline that uses the model itself to generate training data and does not require access to the training setup, with a novel 2.7-bit-per-parameter format supporting efficient execution on Arm CPUs. We validate our approach by compressing the Llama 3.2 11B Vision Instruct model to 3.7 GB with 8-bit activations, preserving strong performance on a set of standard visual question answering tasks.

### 1. 核心问题与研究动机

- **背景**：视觉语言模型（VLM）如 Llama 3.2 Vision、Gemma 3、Qwen3-VL 在复杂语言理解和多模态推理上表现优异，但其巨大的内存占用与计算需求使其难以部署到移动设备。
- **核心问题**：如何在**无原始训练数据访问权限**的前提下，对 VLM 实现**亚 3-bit（sub-3-bit）权重压缩**，并保证在 **Arm CPU** 上的高效执行与可接受的性能损失。
- **挑战**：
  - 低比特量化（尤其多模态场景）易导致严重性能退化；
  - 量化感知训练（QAT）效果依赖训练数据分布，而多模态场景缺乏类似纯文本的通用语料；
  - 数值格式需兼顾压缩率与硬件（Arm SIMD）解码效率。

### 2. 方法论

论文提出一个三阶段量化框架：

**① 合成数据生成（Synthetic Data Generation）**
- 使用 ImageNet 训练集的 1,281,167 张自然图像作为图像来源（与下游任务无关，避免过拟合）。
- 以原始 bfloat16 模型（教师）自身生成响应文本：采样温度 0.6、top_p=0.9、最大 512 tokens。
- **随机提示采样策略**（关键创新）：
  - 以概率 p_temp=0.75 应用指令微调模板，保留非指令模板能力；

  - 以概率 p_inst=0.7 前置指令块（含长度约束、格式要求、遵循度探针等）；

- 与固定提示（"Describe the image:"）相比，随机采样显著提升下游性能（图 3b）。

**② 量化感知训练（QAT）**
- 教师-学生知识蒸馏框架：学生模型前向使用量化参数 θ̂_S = Q(θ_S)，通过直通估计器（STE）反向传播梯度。
- 训练损失为生成响应 token 上的 KL 散度：
  - ℒ_KD(I, x, y) = (1/|y|) Σ_t D_KL(p_T^(t) ‖ p_S^(t))
- 训练细节：batch size 128，最大序列长度 512，训练 2048 步（消融 sweep 除外），AdamW（β₁=0.9, β₂=0.95），cosine 学习率调度，学习率 η = 2^(−(b+14))（b 为每参数平均比特数），主权重保持 float32。

**③ S3D8 数值格式（核心贡献）**
- **格式定义**：每个字节存储 3 个权重——共享 5-bit 质心索引 + 3 个符号位（每权重 1 位），平均 2.7 bit/参数（(8/3 + 16/k) bits/element，含 bfloat16 通道尺度）。
- **重构公式**：W̃_ij = α_i · s_ij · C_{q_⌊i/3⌋, j, i mod 3}（α 为每输出通道尺度，s 为符号，C 为 32×3 质心表）。
- **质心构造**：两阶段——先用 Lloyd-Max 算法 + k-means++ 初始化构造质心（冻结），再在 QAT 阶段更新通道尺度、量化索引和符号。
- **硬件协同设计**（针对 Arm CPU）：
  - 每个字节打包 3 个不同输出通道（而非连续输入维度），简化 fused kernel 的 padding/对齐逻辑；
  - 利用 Arm 64-entry TBL 表查找指令直接查找带符号值；
  - 独特的位布局 [S2⊕S0, S1, Q4..0, S0] 仅需 5 条 SIMD 逻辑指令生成 3 个查找索引（解码 48 个元素），汇编验证见 Listing 2。

### 6. 主要结论与发现

1. **S3D8 格式优势显著**：在 2.68 bit/参数下平均任务退化仅 0.083（0.744→0.661），远超同尺寸 INT（0.347）、student-t（0.565）、lloyd-max（0.436）；相比 INT 在相同性能下额外节省约 22% 压缩率。
2. **QAT > GPTQ > direct cast**：在低比特率下 QAT 优势最大；S3D8+GPTQ 在 2.7 bit 时达到 0.340，而 INT+GPTQ 仅为 0.018。
3. **随机提示采样是关键**：固定提示导致 QAT 数据多样性不足，下游性能显著下降。
4. **训练损失与下游性能强相关**（ρ=−0.91），验证了合成数据蒸馏目标的有效性。
5. **运行时效率**：S3D8 在带宽受限的自回归生成（m=1）场景下显著加速（Graviton4 上 1031 GMAC/s vs INT8 461 GMAC/s）；端到端 Pixel 8a 达 3.8 tokens/s（12.5 GB/s），Graviton4 达 36.8 tokens/s，优于 INT8（26.4 tokens/s）。
6. 保留部分层为 INT8 不改善精度-压缩权衡（额外 +944 MB 仅提升 0.006）。

### 7. 优点

- **无需原始训练数据**：利用模型自身生成合成数据，实用性强，可直接迁移到其他 VLM。
- **格式与硬件协同设计**：S3D8 不是单纯追求压缩率，而是围绕 Arm SIMD TBL 指令、位布局、输出通道打包等做了系统性的硬件适配，兼顾率失真性能与解码速度。
- **符号分解式向量量化**：利用权重分布近似对称性，将 256 质心分解为 32 绝对值质心 × 8 符号反射，在降低查找表大小的同时保持良好率失真性能。
- **实验设计严谨**：隔离了格式效应与量化流程效应；对 GPTQ 实现了完整多模态量化（超越开源库仅量化文本解码器的做法）；消融实验覆盖数据生成、格式、层精度分配等关键因素。
- **端到端验证**：提供完整 C++ 推理实现（Linux/Android）、自定义 safetensors 文件格式及开源代码，实用价值高。

### 8. 不足与局限

- **模型覆盖单一**：仅实验了 Llama 3.2 11B Vision Instruct，结论对其他 VLM 架构（如 Gemma 3、Qwen3-VL）的泛化性未验证。
- **评测范围有限**：仅 4 个 VQA 类基准且为固定 1024 样本子集，缺乏对长文生成、多图、视频理解等能力的评估；绝对分数无法直接对标官方模型卡数字（作为相对基准使用）。
- **平台限制**：S3D8 解码依赖 Arm 64-entry TBL 查找指令，其他架构（x86、GPU、NPU）需专门定制 kernel。
- **仅 CPU 推理**：未涉及移动 GPU/NPU 加速场景。
- **计算资源未披露**：未报告 QAT 训练所需的 GPU 数量与时长，影响可复现性与成本评估。
