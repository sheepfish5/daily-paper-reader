## 摘要
长时程智能体的广泛采用，使模型工作负载日益以输入为主。尽管先前工作已大幅降低长上下文计算成本，预填充仍然计算昂贵，而大型 KV 缓存也持续对 HBM 和 SSD 容量及数据传输带宽造成压力。这些计算、存储与带宽需求共同构成了进一步降低部署成本的主要瓶颈。为应对这一挑战，我们提出 DeepSeek-V4.1-Flash，这是一个多模态混合专家（MoE）模型，拥有 552B 骨干参数，并支持长达一百万个 token 的上下文。凭借其因果编码器-解码器（CED）架构，该模型在解码时每个 token 激活 16B 参数，但在预填充时仅激活 8B 参数，从而显著提升智能体工作负载的成本效率。为突破 KV 缓存压缩的极限，DeepSeek-V4.1-Flash 将 Compressed Sparse Attention 2（CSA2）中的跨层 KV 缓存复用与 FP4 KV 缓存相结合。这些设计将其全局 KV 缓存占用（始终位于 HBM）降至每 token 890 字节，约为 DeepSeek-V4-Flash 对应占用的 1/4。此外，通过名为 SWA Bounded Replay 的专用部署优化，DeepSeek-V4.1-Flash 将其持久化 KV 缓存占用（始终位于 SSD 或主机内存中）降至约为 DeepSeek-V4-Flash 的 1/8。尽管 KV 缓存占用大幅缩小，该模型仍显著优于基线性能。另外，我们精简了 DeepSeek-V4 架构，并引入若干高效架构扩展。我们在一个包含 45T token 的多模态语料库上预训练 DeepSeek-V4.1-Flash，并进行了全面后训练，使其在多样化的文本与多模态智能体场景中取得强劲性能。模型检查点可在 https://huggingface.co/deepseek-ai/DeepSeek-V4.1-Flash 获取。

## Abstract
The widespread adoption of long-horizon agents has made model workloads increasingly input-heavy. Although prior work has substantially reduced the cost of long-context computation, prefill remains computationally expensive, and large KV caches continue to strain HBM and SSD capacity and data-transfer bandwidth. Together, these compute, storage, and bandwidth demands constitute the primary bottleneck to further lowering deployment costs. To address this challenge, we introduce DeepSeek-V4.1-Flash, a multimodal Mixture-of-Experts (MoE) model with 552B backbone parameters and support for contexts of up to one million tokens. With its Causal Encoder-Decoder (CED) architecture, the model activates 16B parameters per token during decode but only 8B parameters during prefill, substantially improving cost efficiency for agentic workloads. To push the limits of KV cache compression, DeepSeek-V4.1-Flash combines cross-layer KV cache reuse in Compressed Sparse Attention 2 (CSA2) with FP4 KV caching. These designs reduce its global KV cache footprint (always in HBM) to 890 bytes per token, roughly 1/4 of the corresponding footprint of DeepSeek-V4-Flash. Further, through a dedicated deployment optimization known as SWA Bounded Replay, DeepSeek-V4.1-Flash reduces its persistent KV cache footprint (always on SSD or in host memory) to roughly 1/8 of that of DeepSeek-V4-Flash. Despite its much smaller KV cache footprint, the model delivers substantially better performance than the baseline. In addition, we streamline the DeepSeek-V4 architecture and introduce several efficient architectural extensions. We pretrain DeepSeek-V4.1-Flash on a multimodal corpus comprising 45T tokens and conduct comprehensive post-training, yielding strong performance across diverse text-based and multimodal agentic scenarios. Model checkpoints are available at https://huggingface.co/deepseek-ai/DeepSeek-V4.1-Flash.

## 2. 方法论

### 2.1 整体架构
- **模型类型**：多模态 MoE Transformer，**552B 骨干参数** + 196B Engram 参数，原生支持多模态输入，上下文上限 **100 万 token**。
- **层结构**：40 层因果 Transformer，划分为 **20 层因果编码器 + 20 层解码器**。
- **激活策略**：预填充每 token 激活 **8B**，解码每 token 激活 **16B**，专为输入密集型智能体场景优化成本效率。

### 2.2 因果编码器-解码器（CED）
- 核心思想（受 YOCO 启发）：解码器（上层 L/2 层）的全局 KV **不从自身隐状态推导**，而是用**逐层投影权重**从编码器最后一层隐状态 $H^{L/2}$ 投影得到：
  - $C_l = H^{L/2} W^{KV}_l,\quad Z_l = H^{L/2} W^Z_l,\quad l > L/2$
- 预填充时只需计算前一半层，即可获得上层全局 KV，复杂度由 $O(NL)$ 降至约 $O(NL/2)$，**近乎减半预填充计算**。
- SWA 仍逐层从各层自身隐状态计算，但配合 **Decoder SWA Bounded Replay**，只回放最后 $n_{win}$ 个 token，避免 $L/2 \times n_{win}$ 的昂贵重算。

### 2.3 Compressed Sparse Attention 2（CSA2）
- 沿三个乘法维度联合压缩：**条目大小**（GQA/MLA）、**序列维度**（每 m 个 token 压为一个条目）、**层维度**（跨层复用）。
- **三种静态模式**：
  - **Full Mode**：自行计算主 KV 与 indexer Q，从主 KV 投影 indexer K，运行索引器产生全新 Top-K 索引（完整路径）。
  - **Reindex Mode**：复用前置层的主 KV 与 indexer K，但用自己的 indexer Q 重新打分，产生新的 Top-K 索引（允许跨层选择变化）。
  - **Reuse Mode**：复用前置层的主 KV **和** Top-K 索引，直接做稀疏注意力，不计算 indexer Q。
- 所有模式中，每层仍保留自己的主 Q 与 SWA KV；共享的是主 KV、indexer K 与 Top-K 索引。
- **相对 CSA 的简化**：去除压缩时相邻条目的重叠与绝对位置编码；indexer K 改为从主 KV 投影而非独立压缩路径。
- **Hierarchical Sparse Indexer**（仅用于 CED 解码器）：首个 Full 层构建**共享候选池**（如 2048 块 × 8 位置 = 16384 候选），后续 Reindex 层只在该池内打分，使深层索引器每查询打分成本**从与上下文长度线性相关变为常数**。

### 2.4 其他架构扩展
- **Single-Pass mHC**：将输入混合系数移位一个 block（用 $A_{l-1}$ 代替 $A_l$），消除对当前 block 全量归约的依赖；配套 **Mega-mHC** 融合核将激活访存从 $(4n+4)d$ 降至 $(2n+2)d$，**减半激活内存流量**。
- **Engram**：条件记忆模块，196B 参数均分两模块（置于第 1、14 层），N-gram 阶数 {2,3,4}，8 哈希头，FP8 精度；推理时确定性寻址可从主机内存后台 RDMA 预取。
- **DSpark**：投机解码模块，3 层 Transformer + 滑动窗口 128，单次前向并行生成 5 个草稿位置，Markov 头建模草稿依赖，置信头预测接受概率，调度器结合吞吐曲线动态选择验证长度。
- **FP4 主 KV 缓存**：采用 MXFP4（E2M1 + 每 16 通道一个 E4M3 scale，省略二级全局 scale），经 QAT 在 post-training 引入，量化在 RoPE 之后进行；SWA KV 因敏感仍保留 FP8。
- **优化器**：head-wise Muon（按 head 拆分 Q 权重）、Engram/embedding/预测头采用**动量 + Sinkhorn 平衡**更新（替代 Adam，降低优化器状态内存），其余用 AdamW。

### 2.5 部署优化
- **Persistent KV Cache 管理**：SWA KV 不再持久化到 SSD，改存于每机 10% 主机 DRAM 的分布式内存池（短 TTL、可快速回收）；全局 KV 仍持久化（≥72 小时）。
- **SWA Bounded Replay**（编码器与解码器两条路径）：仅回放最近 $n_{win}$ 个 token 近似重建 SWA 状态，把“灾难性 miss”变成“廉价优雅降级”。

## 6. 主要结论与发现

- **KV 缓存压缩**：
  - 全局 KV 缓存（HBM 常驻）降至 **890 字节/token**，约为 DeepSeek-V4-Flash 的 **1/4**，相对 DeepSeek-V1 减少约 **437 倍**；
  - 持久化 KV 缓存（SSD/主机内存）降至约 **1/8**（其中 SWA KV 不再持久化贡献约一半，全局 KV 压缩贡献 1/4）。
- **计算效率**：上下文从 4K 扩展到 1M（256 倍），单 token 解码 FLOPs 仅增加约 1/4，**近乎恒定**；预填充计算近乎减半。
- **性能不降反升**：尽管 KV 占用大幅缩小，DeepSeek-V4.1-Flash 在推理与智能体 benchmark 上**显著优于 DeepSeek-V4-Flash**，并匹配或超越多个顶级开源/闭源模型：
  - Codeforces 3471（超过 V4-Pro 的 3348 与 V4-Flash 的 3289）；
  - DeepSWE v1.1 74.2%（超过 Opus-5 74.0%、GPT-5.6 Sol 73.0%）；
  - Terminal-Bench 2.1 90.6%（超过 Opus-5 89.1%）；
  - AutomationBench 54.8%、Agents' Last Exam 31.8% 均为领先成绩；
  - 网络安全任务在开源模型中达到 SOTA。
- **参数效率**：基座模型以 1/3 总参数、1/4 激活参数，达到与 DeepSeek-V4-Pro-Base 相当的世界知识/推理/编码能力，并在 held-out 评测上提升 5%–10%，BPB 在所有任务上最低。
- **推理努力可控性**：effort 从 25 提升到 100，8 项推理 benchmark 平均 Pass@1 从 67.1% → 76.3%，DeepSWE v1.1 从 66.0% → 74.2%，Terminal-Bench 2.1 从 82.4% → 90.6%，代价约为 2.5× 输出 token；收益前置于 60–80 区间。
- **脚手架鲁棒性**：智能体能力跨 6 个脚手架家族良好迁移，不依赖特定 harness 约定。
- **多智能体**：在每个截止时间点均优于单智能体配置（ProgramBench Almost@1 峰值 30.04% vs 20.39%；FrontierSWE v2 Mean@5 20h 时 32.90% vs 28.20%）。
- **后训练经验性结论**：在固定且无特殊之处的优化流程下，**数据与环境流水线的工程化边际收益显著超过算法创新**。

## 7. 优点

- **压缩维度协同设计**：CSA2 同时沿“条目大小 / 序列 / 层”三个乘法维度压缩，并解耦“缓存共享”与“索引复用”，比仅做索引复用（IndexCache/YOIO）或仅做 KV 共享（HySparse）的方法更彻底。
- **架构与部署联合优化**：CED（降预填充）+ CSA2（降缓存）+ FP4（降精度开销）+ SWA Bounded Replay（降持久化）形成完整的成本链条，且每项都给出量化收益。
- **近似策略有训练侧对齐**：SWA Bounded Replay 在 post-training 中模拟同样回放，使推理近似与训练
