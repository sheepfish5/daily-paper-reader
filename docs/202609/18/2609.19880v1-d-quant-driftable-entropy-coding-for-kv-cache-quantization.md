## 摘要
KV缓存已成为部署LLM的主要瓶颈，因为其内存占用随序列长度和批大小线性增长，给内存容量和带宽都带来巨大压力。在各种KV缓存压缩技术中，量化因其有效性和易于部署而尤其具有吸引力。然而，大多数现有方法依赖固定位宽量化，其中$b$比特表示本质上仅限于$2^b$个量化级别。随着位宽降低，可用级别数量呈指数级减少，导致严重的信息损失和性能迅速下降。我们进一步观察到，固定位宽量化未能利用KV缓存高度非均匀的分布。经过旋转和归一化后，KV值近似服从正态分布，大多数值集中在中心附近，只有一小部分出现在尾部。然而，固定位宽编码为频繁出现的符号和稀有符号分配相同数量的比特。熵编码通过为频繁符号分配较短码字、为稀有符号分配较长码字，自然地利用这种非均匀性，从而显著减少表示所需的平均比特数。然而，其变长输出不适合高度并行的注意力核，因为高效的反量化和计算依赖于规整的内存布局和固定步长访问。为弥合这一差距，我们提出D-Quant，一种灵活的KV缓存量化框架，它引入漂移机制，将每个token的熵编码表示转换为固定大小的比特流，从而在注意力核内实现规整的内存访问和并行反量化。

## Abstract
The KV cache has become a major bottleneck in deploying LLMs, as its memory footprint grows linearly with sequence length and batch size, imposing substantial pressure on both memory capacity and bandwidth. Among various KV cache compression techniques, quantization is particularly attractive due to its effectiveness and ease of deployment. However, most existing methods rely on fixed-width quantization, where a $b$ bit representation is inherently limited to $2^b$ quantization levels. As the bit width decreases, the number of available levels shrinks exponentially, leading to severe information loss and rapid performance degradation. We further observe that fixed-width quantization fails to exploit the highly non-uniform distribution of KV cache. After rotation and normalization, KV values approximately follow a normal distribution, with most values concentrated near the center and only a small fraction appearing in the tails. Nevertheless, fixed-width coding allocates the same number of bits to frequent and rare symbols. Entropy coding naturally exploits such non-uniformity by assigning shorter codewords to frequent symbols and longer ones to rare symbols, substantially reducing the average number of bits required for representation. However, its variable-length output is not suited to highly parallel attention kernels, where efficient dequantization and computation rely on regular memory layouts and fixed-stride accesses. To bridge this gap, we propose \textbf{D-Quant}, a flexible KV cache quantization framework that introduces a \textbf{drift} mechanism to convert entropy-coded representations of each token into fixed-size bitstreams, enabling regular memory access and parallel dequantization within attention kernels.

# D-Quant: Driftable Entropy Coding for KV Cache Quantization 论文总结

## 1. 核心问题与研究动机

- **背景瓶颈**：LLM 自回归推理中，KV cache 随序列长度与批大小线性增长，成为长上下文与大批量部署的内存容量与带宽核心瓶颈。模型权重尺寸固定，而 KV cache 持续膨胀，量化因此成为极具吸引力的压缩手段。
- **固定位宽量化的根本缺陷**：
  - 一个 $b$ 比特表示本质上只能提供 $2^b$ 个重建级别，位宽下降时可用级别呈指数级萎缩，信息损失严重、性能迅速退化。
  - 无法利用 KV cache 的非均匀分布：经旋转与归一化后，KV 值近似服从正态分布（中心密集、尾部稀疏），但固定位宽编码对高频与稀有符号分配相同的比特数。
- **熵编码的两难**：熵编码可为高频符号分配短码字、稀有符号分配长码字，显著降低平均比特数；但其变长输出破坏了注意力核所需的规整内存布局与固定步长访问，难以在高度并行的内核中直接反量化。
- **整体含义**：论文试图在"压缩效率"与"部署可行性"之间架桥——既保留熵编码对非均匀分布的压缩收益，又恢复固定步长内存布局，使低位宽 KV cache 量化真正可部署。

## 2. 方法论

### 2.1 核心思想
- 为每个 token 的 Key 或 Value 流分配一个**固定字节长度的容器（container）**，流内符号用熵编码（rANS）编码。
- 引入 **drift（漂移）机制**：当编码后的变长比特流超出容器预算时，不整体降低精度，而是让少量"高代价"符号漂移到邻近的"低代价"符号，直到满足长度约束。
- 由此实现：量化级别数不再被位宽绑定（可自由取 $M$ 个级别而非 $2^b$），比特预算可灵活在 K/V 间分配，且内存布局保持规整。

### 2.2 关键技术细节
- **预处理流水线**（图 1）：
  - 对每个注意力头做 Hadamard 旋转（Value 可离线折入投影权重；Key 因与 RoPE 不可交换需在线旋转）；
  - Key 额外去除窗口化的通道均值（token 级标量 offset 无法捕捉通道均值）；
  - token 级仿射量化：$\hat{x}_i = o + s\,m_i$，$m_i \in \{0,\dots,M-1\}$，$s=(\max(x)-\min(x))/(M-1)$，$o=\min(x)$。
- **免校准概率模型**：旋转+去均值后 KV 分布接近标准正态，熵模型直接由高斯次序统计量解析导出，无需校准数据；由于归一化位置的仿射不变性，同一概率表可跨 token 与层共享。
- **长度约束下的符号分配（drift）**：
  - 优化目标：$\min \sum_i (x_i-(o+sm_i))^2$，约束 $\sum_i r(m_i) \le B$，其中 $B = 8C - \sigma$（$\sigma$ 为熵编码器最终状态开销）。
  - 用拉格朗日形式转化为可分离目标 $\min \sum_i [D_i(m_i)+\lambda r(m_i)]$，对固定 $\lambda$ 每个符号独立最优；用二分法搜索满足长度约束的 $\lambda$。
  - 实现上二分的是 $\lambda$ 的指数（$\log_2\lambda$）以保证收敛稳定，迭代 $T=12$ 次；scale/offset 先舍入到 FP16 后再做最终分配，保证编码器优化目标与解码器重建网格一致。
- **实用改进**：
  - **K/V 分离配置**：Key 误差直接扰动注意力 logits 并经 softmax 指数放大，更敏感，故分配更大容器预算，量化级别也可独立配置。
  - **分布锐化**：drift 会把符号推向更集中、更可能的高频符号，故在构建熵表前对解析概率做 $p'_m \propto p_m^\alpha$（$\alpha=1.4$）。
- **rANS 编解码**：精度 $p=8$，仅需 256 项查找表；表中同时存储重建值与状态更新信息，使熵解码与反量化共享一次查表；流反向编码以支持正向解码。
- **内核设计**：
  - 编码：每 warp 负责一条流，数值全程 on-chip，避免物化 $n\times M$ 失真矩阵；最终仿射重拟合与 rANS 编码在同一 warp 内完成。
  - 解码：以 token 为中心组织（每个线程块负责一批 token，每条流只解码一次），warp 按通道而非按 query head 切分输出累加器；仿射变换折入注意力收缩（Key 侧对通道收缩，Value 侧把 per-token scale 折入注意力权重），无需显式逐元素反量化。

## 3. 实验设计

- **模型**：Qwen3-8B（原生 40K 上下文，64K/128K 用静态 YaRN）、Llama-3.1-8B-Instruct。
- **Benchmark**：
  - **RULER**：4K、8K、16K、32K、64K、128K 六个上下文长度，每任务每长度平均 100 个样本；
  - **LongBench-E** 英文子集（SQA、MQA、Sum、FS、Syn、Code），全部使用贪心解码。
- **对比基线**（均 group size 128）：

  - QuaRot（2.25 bit，保留最近 128 token BF16）
  - TurboQuant（2.19 bit，Key 用 Lloyd–Max、Value 用仿射，保留最近 128 token BF16）
  - OScaR（2.26 bit，推荐 256-token 残差窗口）
  - BF16 FlashAttention-2 作为全精度参考
- **效率实验**（Qwen3-8B，单卡 H20 96GB）：

- **消融/分析实验**（RULER 128K，Qwen3-8B）：量化级别数（4–14）、存储预算（约 2.0–2.4 BPV）、K/V 预算分配。
- **附录实验**：与等存储固定位宽编码的配对 KL 对比（27 份 LongBench-E 文档、9 个子集各 3 篇、2,048 token 上下文、20,000 次 bootstrap 重采样）、编码机制的经验分析（最大可行字母表、解析模型 vs 实测分布、drift 稀疏性）。

## 6. 主要结论与发现

- **精度**：在 2.26 BPV 下，D-Quant 在 RULER 上取得 Qwen3-8B 86.50、Llama-3.1-8B 88.94，接近 BF16 的 87.31/89.69，显著优于所有低位基线；LongBench-E 上与 BF16 相当。
- **长上下文鲁棒性**：随上下文增长优势扩大。128K 时 D-Quant 达 70.92/74.65，最强基线仅 57.14/66.15。
- **更低预算仍有效**：1.96 BPV 下 RULER 平均仍达 85.21/87.26，超过所有基线（尽管用更少存储）。
- **效率**：KV cache 显存最高减少约 **7×**（64K 时）；8K prompt 下 BF16 在 batch 64 即 OOM，D-Quant 可扩展到 batch 128 且峰值显存仅 49.4 GiB；各自最大可行批大小下吞吐 563.6 vs 159.5 tokens/s，最高 **3.5×** 提升。代价是小批量时因熵解码额外计算而慢于 BF16。
- **机制发现**：
  - 预处理（旋转+去均值）使 Normal Gap 降至 $5\times10^{-4}$ bits/value，支持免校准解析模型；同时保留 0.72/0.86 bits/value 的编码增益。
  - 等存储下 D-Quant 的 KL 散度约为固定位宽的一半（2.26×/2.00×），固定位宽需多花 0.234/0.267 bits/value 才能追平。
  - drift 只改动 **0.75% 的 Key 符号、5.00% 的 Value 符号**，且没有任何符号漂移超过一个重建级别。

## 7. 优点

- **问题切中要害**：准确识别固定位宽量化"级别数与位宽耦合"这一被忽视的编码格式限制，并给出解耦方案。
- **方法设计巧妙**：用"固定容器 + 长度约束下的漂移"这一最小改动，同时拿到熵编码的压缩收益与固定步长内存布局，思路干净、工程可落地。
- **免校准**：概率模型由标准正态解析导出，无需任何校准数据，跨 token/层/模型共享，部署友好。
- **灵活性**：比特预算与量化级别数不再受整数位宽或组大小约束，K/V 预算可按敏感度独立分配。
- **内核协同设计**：编码端 warp 内 on-chip 求解避免物化大矩阵，解码端以 token 为中心、查表同时完成解码与重建、仿射折入注意力收缩，避免显式反量化和 BF16 KV 物化。
- **实验严谨**：等存储配对对比 + bootstrap 置信区间 + 逐文档计数，有效排除预处理与额外存储的混淆因素；消融覆盖主要设计维度。

## 8. 不足与局限

- **计算开销**：熵解码引入额外计算，小批量时吞吐低于 BF16；优势主要体现在内存受限的高批量/长上下文场景。
- **模型覆盖有限**：仅评测 8B 级模型（Qwen3-8B、Llama-3.1-8B），未验证更大规模模型、MoE 架构或不同注意力变体。
- **超参与配置依赖**：容器大小、级别数（8/6）、锐化因子 $\alpha=1.4$、保留最近 128 token 的 BF16 窗口等均为经验设定，论文称"全模型/层/长度/benchmark 统一配置"，但未系统给出跨模型自适应选择的方法。
- **基线公平性存疑点**：TurboQuant 采用 MSE-only 配置，可能未发挥其最优性能；部分基线（如 KIVI）未使用其偏好的非对称 per-channel/per-token 设置细节在正文中未完全展开。
- **评测范围**：仅英文 LongBench-E 子集，未涉及多语言、多模态或生成质量/困惑度类指标；RULER 依赖 YaRN 外推，绝对分数受外推质量影响。
- **分布假设依赖**：方法有效性建立在"旋转+去均值后近似标准正态"的前提上，对未做此类预处理或分布偏离较大的场景（如极端 outlier、非 Transformer 架构）适用性未验证。
