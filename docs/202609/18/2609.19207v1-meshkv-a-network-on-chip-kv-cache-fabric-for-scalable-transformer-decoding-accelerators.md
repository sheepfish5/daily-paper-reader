## 摘要
自回归 Transformer 解码受限于分块加速器上不规则的键值（KV）缓存移动。先前的压缩与 DRAM 放置系统仍将流量集中在集中式内存路径上，从而成为长上下文服务的瓶颈。我们提出 MeshKV，一种 KV 缓存互连架构，它以分组化流的形式在轻量级片上网络（NoC）上移动数据块。它协同设计：(i) TaKV 仿射条带化，以分散 home 节点并降低热点负载；(ii) Mare 多播，并带有经过验证的重复抑制；(iii) Pad，它通过信用对齐的 FIFO 将预取、tile 乘法和流式 softmax 重叠执行。它们共同将二分带宽背压转化为有用的 KV 传输。在我们采用 LLaMA-2-7B 与 Mistral-7B、在 8K–32K 下的 8×8 FPGA 实现上，MeshKV 将互连流量最多降低 58%，将 KV 带宽利用率提升 2.1 倍，并提供最高 1.9 倍的多流吞吐量。

## Abstract
Autoregressive transformer decoding is constrained by irregular key-value (KV) cache movement on tiled accelerators. Prior compression and DRAM-placement systems still concentrate traffic on centralized memory paths that bottleneck long-context serving. We present MeshKV, a KV cache fabric that moves blocks as packetized flows over a lightweight NoC. It co-designs (i) TaKV affine striping to spread homes and cut hotspot load, (ii) Mare multicast with verified duplicate suppression, and (iii) Pad, which overlaps prefetch, tile multiply, and streaming softmax behind credit-aligned FIFOs. Together they convert bisection back-pressure into useful KV transfer. On our 8x8 FPGA implementation with LLaMA-2-7B and Mistral-7B at 8K-32K, MeshKV reduces interconnect traffic by up to 58%, improves KV bandwidth utilization by 2.1x, and delivers up to 1.9x multi-stream throughput.

## 1. 核心问题与研究动机

- **背景**：自回归 Transformer 解码是"内存受限"的，但在分块（tiled）加速器上，**片上数据搬运**同样造成停顿。注意力计算需要"一对多/全对少"地从不断增长的 KV 前缀中聚集数据，而现有 2D PE 阵列（如 Simba、chiplet mesh）是为稠密 GEMM 设计的，并非为此类 gather 优化。
- **核心矛盾**：
  - Prefill 阶段可摊薄 tile 跳数开销，**Decode 阶段不行**——每个 token 都要把整份 KV cache 完整读一遍。
  - KV 规模公式：`Γ(T) = 2·L·H·d_h·T·bpe` 字节；FP16 下 LLaMA-2-7B 在 T=32768 时约 **16 GiB**，且每步解码全量读取。
  - FlashAttention 只在 batched prefill 中通过 tiled SRAM 复用降低常数项，**B=1 decode 时每个字节都暴露、无复用**。
- **"辐条-轮毂"病态（spoke–hub pathology）**：当 KV 集中在单一逻辑内存控制器/注入点时，所有 tile 的读请求汇聚到同一注入点，mesh 退化为 spoke–hub，**40–60% 的链路周期消耗在背压上**（图 1 中 CENT 在 T=32K 时仅 19% 链路周期用于有效 KV 传输）。
- **整体含义**：论文主张把 **KV cache 视为一种通信基板（communication substrate）**，而非单纯的存储对象，用 NoC 分组化流替代集中式点对点总线，从而把二分带宽背压"转化"为有效 KV 传输。

### 支撑动机的两条观测

## 2. 方法论

### 2.1 核心思想
将 KV 块打包为 **512-bit flit 的分组流**，在轻量 NoC 上以多播方式从 home tile 分发；三个机制协同：**TaKV 放置 → Mare 路由 → Pad 数据流**，分别对应"放哪里 / 怎么传 / 怎么算"。

### 2.2 系统架构
- **4×4 mesh（可扩展至 8×8）**，每 tile 含：MAC 阵列、**四 bank KV SRAM**、partial-sum scratchpad、**双虚网络（VN0/VN1）router**。
- 每列控制器广播描述符 `(ℓ, h)`；tile 自行解算 `π(ℓ,s)` 并在 VN1 注入 `KV_FETCH`。控制器**不在关键路径上**（TaKV 为 4 条组合逻辑指令）。
- 四 bank KV SRAM 使 tile 能在 MAC 消费当前 flit 的同时流式加载下一窗口。
- 三个平面：**TaKV（内存平面）/ Mare（路由平面）/ Pad（计算平面）**。多播树根位于 home tile `π(ℓ,s)`，而非共享内存端口。

### 2.3 TaKV（拓扑感知 KV 条带化）
- **宏块定义**：`B(ℓ,s)` 覆盖 layer ℓ 的 P 个连续 token（含所有 head 与 K/V），`|B(ℓ,s)| = 2·H·d_h·P·bpe` 字节，`s = ⌊j/P⌋`。取 P=64, H=32, d_h=128, bpe=2 时 **|B|=1 MB**，即放置与多播单元。
- **仿射放置**：`π(ℓ,s) = (ℓ mod W, (a·ℓ + s) mod H)`，其中 a 为奇数且 `gcd(a,H)=1`（如 a=W+1）。
- **关键洞察（作者明确说明）**：仿射 π 并**不会缩短到固定 home 的期望跳数**（对称 mesh 上均匀请求者到任一目的地的平均跳数相同）。收益来自**分散 home**，使注入与二分的最大负载 `max Σq̄e` 下降，把图 1 的背压停顿转为有效传输。互质步长 a=W+1 使相邻层落在不同列、同层相邻 segment 走不同行，注入自然分散。
- **占用率交换（occupancy swap）**：每 K=128 步（一次 SRAM 驱逐周期），router 从既有 credit 计数器采样占用率 q̄e，若交换两 home **严格降低 `Σq̄e²`** 且不破坏每 tile 容量 Nmax 才执行；代价仅 4 次比较、2 次寄存器写、1 个控制周期。`Nmax = ⌈L·⌈T/P⌉/(W·H)⌉`。
- **存储层级现实**：U280 有 HBM2（8 GB, 460 GB/s）与 DDR4（32 GB），16 GiB slab 无法全放 HBM；512 个 URAM 分摊到每 tile 仅 8 个（288 KB），只是"四 bank 流式窗口"而非 1 MB 块，因此 home 需按 tile-local 预取描述符把 HBM/DDR 数据提升进 URAM。

### 2.4 Mare（多播路由引擎）
- **三类 flit**（表 I）：
  - `KV_FETCH`（requester→home，VN1）：seg id、layer、32-bit head mask、requester 坐标；
  - `KV_DATA`（home→requester，VN1）：512-bit KV 载荷 + 在途 segment tag；
  - `PART`（tile→reduce root，VN0）：512-bit partial logit 累加器 + softmax 运行统计。
  - 该分类将 **fetch 合并**与**数据扇出**解耦。
- **合并与多播**：home tile 在合并窗口 `Wcoal=12` 周期内将到达请求的 head mask 按位或：`M(ℓ,s) = OR_{r∈Wcoal} mask_r`；随后在目的集合 D(M) 上构建 **XYM 生成树**，每条分支只多播一次（构建 O(H log H)，H=32，出发前 +4 控制周期）。**复制只发生在树分支处**，任一链路最多承载一次载荷。
- **经验证的重复抑制**：每 router 维护 **16 项精确 tag 表**（在途 (seg, ℓ)）+ **256-bit bloom 预过滤**（刷新间隔 Wb=96 周期）。**
