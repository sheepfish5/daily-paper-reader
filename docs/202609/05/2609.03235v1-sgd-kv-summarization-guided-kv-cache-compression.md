## 摘要
大型语言模型（LLMs）在长上下文推理中面临严重的内存瓶颈，原因是键值（KV）缓存的大小线性增长。现有的KV缓存压缩技术通常依赖简单的启发式方法，忽视了不同注意力头的不同功能角色。我们提出了SGD-KV（基于摘要引导的KV缓存压缩），一种头部感知框架，利用新颖的块摘要诊断任务来系统地识别并优先处理专门用于分层信息聚合的注意力头。在Qwen2.5-7B-1M和Qwen3-32B上跨多个长上下文基准的实验表明，SGD-KV在长达100万token的上下文下实现了最先进的性能，同时将KV缓存内存使用量减少高达75%。我们的研究结果表明，基于注意力头的摘要分数分布来战略性地分配KV缓存预算，可以为长上下文推理带来更优的效率-准确性权衡。

## Abstract
Large language models (LLMs) face severe memory bottlenecks in long-context inference due to the linearly growing size of key-value (KV) caches. Existing KV cache compression techniques typically rely on simple heuristics, overlooking the distinct functional roles of different attention heads. We present SGD-KV (Summarization-Guided KV Cache Compression), a head-aware framework that leverages a novel chunk-summarization diagnostic task to systematically identify and prioritize attention heads specialized in hierarchical information aggregation. Experiments on Qwen2.5-7B-1M and Qwen3-32B across diverse long-context benchmarks demonstrate that SGD-KV achieves state-of-the-art performance with contexts up to 1M tokens, while reducing KV cache memory usage by up to 75%. Our findings show that strategically allocating the KV cache budget based on the summarization score distribution of attention heads yields a superior efficiency-accuracy trade-off for long-context inference.

### 一、核心问题与整体含义（研究动机与背景）

- **研究背景**：随着LLM（如Qwen2.5-1M、Gemini 2.5）向百万级token上下文窗口推进，KV缓存随上下文长度线性增长，成为推理时严重的内存瓶颈，制约了超长上下文应用的落地。
- **现有方法缺陷**：已有KV缓存压缩方法（如早期token驱逐策略、近期头级方法）大多依赖基于注意力分数或检索导向的简单启发式（如StreamingLLM、H2O、PyramidKV、AdaKV等），忽视了不同注意力头承担的不同**功能角色**。尤其面对**多文档分析**或**长程对话**等任务时，模型需要进行*层级信息聚合*而非简单模式匹配，现有启发式方法难以胜任。
- **论文核心洞察**：注意力头中存在一种专门负责更高阶认知功能（如层级信息合成）的子集，作者将其命名为“**summarization heads（摘要头）**”。现有研究仅识别过“检索头”“归纳头”“R2头”等基于检索的诊断角色，未覆盖此类做复杂语义聚合的头。
- **解决的问题与整体含义**：SGD-KV通过一种新颖的**分块摘要诊断任务**，系统识别并优先保留这些摘要头，据此指导KV缓存的感知头部预算分配，在百万token上下文上实现高压缩率与高精度的统一。

### 二、方法论

1. **核心思想**：将注意力头按其*摘要能力*（即层级信息聚合能力）评分，以连续分数指导KV缓存预算的**细粒度头级分配**——而不仅仅做二分类（如DuoAttention），也不依赖纯检索导向的评分（如HeadKV、AdaKV）。
2. **分块摘要诊断任务设计**：
   - 将多个短文摘要数据集（如CNN/Dailymail、DialogSum等）中的文档拼接为长上下文样本，并记录各原始文档边界。
   - 提示模型完成两项子任务：
     - **块识别（Chunk Identification）**：识别拼接文档中语义块的数量；
     - **关键词抽取（Keyword Extraction）**：为每个块生成能概括其核心含义的关键词列表。
   - 该设计强制模型先进行高层的文档结构解析，再对每个片段做语义提炼，从而有效探测头在层级聚合中的参与程度。
3. **摘要分数计算**：
   - 对于每个有效样本，按以下公式为每个头 h 计算重要性分数 Ih：
     - Ih = (1/c) Σ_{m=1}^{c} (1/|K_m|) Σ_{j∈K_m} max_n A_h(p_o_j, p_i_j,n)
     - 其中 K_m 为块 m 的关键词集合，p_o_j 为输出关键词 token 位置，p_i_j,n 为输入中相同关键词的第 n 次出现的位置；取最大值来定位从生成关键词到其原文中最显著源token的最强注意力连接。
   - 将头在所有有效样本上的平均重要性分数作为最终"摘要分数"。
4. **KV缓存预算分配**：
   - 先对全头分数做归一化（总和为1）。
   - 保留固定预算给**sink tokens（前部锚点）** 和**滑动窗口（尾部近期token）**。
   - 中间可压缩部分的剩余预算（M = C - b_sink - b_window）按归一化摘要分数 S_h 和各头比例分配：
     - b_h = (S_h · L · H · R) · M + b_sink + b_window
     - 其中 L 为层数，H 为KV头数，R 为总KV缓存预算率。
   - 头内token选取：采用类似SnapKV的基于累计注意力分数的机制选取重要KV项。
5. **水填充（Water-filling）再分配算法**：
   - 当高重要性头的按比例预算超过中间序列长度M时，算法将这些头超出M的部分预算收集（E），将超高分配的头截断至M，再按分数高低将超额预算E分配给仍有余量的高评分头，确保关键头获得足够上下文保留。

### 三、实验设计

- **基准模型**：
  - **Qwen2.5-7B-Instruct-1M**（非推理型小型LM代表，作者发现原始HF checkpoint在多轮对话任务上表现不佳，因此额外进行了监督微调——微调数据为10K合成MRCR、20K合成GraphWalks、25K BABILong样本，并加入10K Gutenberg与10K Llama-Nemotron样本防过拟合；采用全参数微调，cosine学习率1e-5，batch size 128，2个epoch，使用FlashAttention、DeepSpeed stage 0和Liger kernel）。
  - **Qwen3-32B**（可推理的大型LM代表）。
- **基准/数据集与场景**：
  - **MRCR（OpenAI Multi-Round Co-Reference Resolution）**：长程多轮对话指代消解测试；Qwen3-32B上测8k/16k/32k/64k，微调Qwen2.5-7B-1M上测64k–1M。
  - **ETHIC**：包含AT（Attributing）、OG（Organizing）、RC（Recalling）三个高信息覆盖子任务。
  - **BABILong**：检索与推理能力测试（附录），QA1–QA5平均准确率，覆盖32k–1M序列长度。
  - 消融和测试头稳定性的摘要数据：DialogSum、SAMSum、CNN/Dailymail、XSum、Dolly、WikiLingua等。
- **对比基线方法**：
  - **FullKV**（无压缩）；**Minference**（动态稀疏注意力）；**AdaKV**（头级自适预算）；**DuoAttention**（检索头/流式头二分法，作者未微调门控函数而是用R2分数按KV预算做二划分）；**HeadKV**（基于R2头的头级预算分配）；另有部分实验使用DAC+Minference。
- **关键配置**：基线方法均保留前1024 token为attention sink、最近1024 token为上下文窗口（Qwen2.5-7B-1M）；Qwen3-32B下sink和window均降为128 token；压缩发生在GQA的KV复制前。

### 六、主要结论与发现

- **SGD-KV实现新的SOTA**：在两个模型上、多个长上下文benchmark（MRCR、ETHIC、BABILong）中一致领先或追平现有方法，在支持最长1M上下文的同时减少KV缓存内存最高75%。
- **细粒度头级分配更优**：相比DuoAttention式的检索/流式头二分法，基于连续摘要分数的细粒度预算分配在需要复杂推理的长上下文任务中优势更大。特别是在超长上下文（如128K以上）中SGD-KV超过DuoAttention，1M时表现最稳。
- **摘要头功能与检索头有区分度**：虽然检索头与摘要头在top 20%有重叠（检索可能是摘要的基础能力），但20%–60%区间出现明显差异，证明摘要头捕获了超越简单检索的独特功能模式，SGD-KV也倾向于给更早期层更多预算以用于复杂推理。
- **摘要任务可作为有效代理查询**：消融显示，在最终问题不可预先获得时，使用固定的通用摘要提示（“将前文分段并抽取关键词以利后续检索”）作为Proxy-Query，能显著缓解Query-Unaware状态下的性能损失，表明摘要任务诱导模型聚焦语义显著信息。
- **质量分数可解释地引导预算**：反向分配预算（Reverse）或压低低分头（thr）都会在超长上下文造成显著退化，验证了分数排序的信息量与因果作用。

### 七、优点

1. **问题选择具有开创性**：首次将“层级信息合成”这一高阶认知功能引入KV缓存压缩的自动诊断框架，突破了传统以检索/简单模式匹配为中心的功能头分类视角。
2. **方法设计精巧、有解释性**：基于分块摘要诊断任务生成连续分数，用公式与可视化清晰展示分数如何指导预算分配，并提供水填充风格的约束下再分配策略，既直观又可计算。
3. **兼顾头部与token两级压缩**：头部级分配与token级选取解耦，并在设计的消融中区分了各自的贡献与相互影响。
4. **适应性广、稳定性强**：跨多种摘要数据集验证了识别结果的一致性（IoU较高），多个长上下文基准和多种上下文长度（8k–1M）上效果稳定；在GQA结构上还提供了分数导入注意力的优化方案（Ipt., Max）。
5. **附有丰富消融与变体分析**：Reverse、Proxy-Query、阈值裁剪、GQA聚合方式等角度较全面，帮助理解分数与分配的因果作用，而不是只报最佳结果。

### 八、不足与局限

1. **计算资源缺乏披露**：未报告GPU型号、数量、训练时长，无法从资源角度全面评估可行性，也给复现带来不便。
2. **部分评测数据点缺失**：如DuoAttention/AdaKV在部分低KV预算设置下、个别变体在1M长度下缺少结果，虽影响有限，但会让结论曲线的完整性打折扣。
3. **数据集覆盖相对狭窄**：主要聚焦MRCR、ETHIC、BABILong，均为英文检索/推理任务；缺少如代码理解、多语言、真实长文档问答等场景，也未与更多近期长上下文评测（如RULER、LongBench等）做对比。
4. **方法存在附加开销**：分块摘要诊断任务需要额外推理并人工/启发式地筛选有效样本，识别流程本身需要处理来自多个数据集、多种文档类型的数据；分数计算和头排序也是离线步骤，引入额外的pipeline复杂度。
5. **Qwen2.5-7B-1M需要额外SFT才能胜任部分任务**：说明该方法在多轮对话场景下对基础模型能力有一定依赖；且SGD-KV在短上下文（如Qwen3-32B的8k/16k）及DuoAttention变体（DAC）下并非全程最佳，说明短上下文下其优势尚不稳定。作者也指出在ETHIC上各方法差距小、性能可能被基础模型本身的能力上限所限制。
6. **“摘要头”的泛化与理论解释还有待深化**：虽然论文给出了IoU验证，但未进一步从机制层面说明为何这些头具备层级聚合能力、这类能力在预训练中如何形成、以及在多语言/多任务下是否依然成立。
