## 摘要
作为大语言模型中最关键的挑战之一，上下文忠实性直接决定了其在知识密集型应用中的可靠性。这项任务尤其具有挑战性，因为它需要在事实一致性与生成效率之间取得平衡。对比解码方法需要双重前向传递（有上下文和无上下文）来比较模型输出，使推理计算开销加倍，而训练后对齐则需要大量的强化学习，带来巨大的计算开销。为了应对这一挑战，我们提出了SFAD，一种推测解码框架，在不降低推理性能的情况下增强上下文忠实性。我们首先构建了ConFide，一个包含细粒度原子扰动的偏好数据集，通过直接偏好优化训练一个上下文忠实的草稿模型。在推理过程中，Epistemic Friction通过量化由专家确定性加权的分布张力来检测潜在的幻觉。当摩擦超过阈值时，Asymmetric Logit Steering通过基于残差的Logit注入来优化目标分布；否则，执行标准推测过程。大量实验表明，SFAD在实现2.48倍加速的同时显著提高了忠实性，为高效的大语言模型提供了一种实用解决方案。

## Abstract
As one of the most critical challenges in large language models, contextual faithfulness directly determines their reliability in knowledge-intensive applications. This task is particularly challenging as it requires balancing factual consistency with generation efficiency. Contrastive decoding methods require dual forward passes (with and without context) to compare model outputs, doubling inference computational overhead, while post-training alignment demands extensive reinforcement learning with substantial computational overhead. To address this challenge, we present SFAD, a speculative decoding framework that enhances contextual faithfulness without inference degradation. We first construct ConFide, a preference dataset with fine-grained atomic perturbations, to train a context-faithful draft model via Direct Preference Optimization. During inference, Epistemic Friction detects potential hallucinations by quantifying distributional tension weighted by specialist certainty. When friction exceeds the threshold, Asymmetric Logit Steering refines the target distribution through residual-based logit injection; otherwise, standard speculation proceeds. Extensive experiments demonstrate that SFAD substantially improves faithfulness while achieving $2.48\times$ speedup, offering a practical solution for efficient LLMs.

## 1. 核心问题与研究动机

大型语言模型（LLMs）在知识密集型应用中普遍面临**幻觉问题**，其根源在于模型内部参数化知识（记忆）与外部提供的上下文证据之间存在**知识冲突**——模型往往偏好先验记忆而非提供的上下文，导致生成内容缺乏**上下文忠实性（contextual faithfulness）**。

现有解决方案各有明显不足：

- **对比解码类方法**（如 CAD、AdaCAD）：需要双次前向传播（有无上下文各一次），推理开销接近翻倍；
- **后训练对齐类方法**：依赖大规模强化学习（RL），需要巨大的计算资源和高质量偏好数据；
- 因此，在不牺牲推理效率的前提下增强上下文忠实性，是一个尚未解决的关键挑战（效率—忠实性两难）。

论文的核心目标即是：**设计一种无需推理降速、低训练成本的解码框架**，同时提升模型的上下文忠实性与生成速度。

## 2. 方法论：SFAD 框架

### 2.1 整体思想

SFAD（Speculative Factuality-Aware Decoding）的核心洞察是：**将上下文忠实的草稿模型（draft model）作为"事实哨兵"**——利用小型模型检测并纠正大型目标模型（target model）在推测解码过程中产生的幻觉。

### 2.2 阶段一：ConFide 偏好数据集构建（训练阶段）

使用**LLM-AggreFact**与**CG2C**作为源数据，构建细粒度偏好数据集，流程如下：

1. **原子事实分解**：将响应 y 分解为可验证的原子事实集合 A = {a1, ..., am}（形如 subject-relation-object 三元组）；
2. **可控扰动机制（生成负样本 yₗ）**：对原子事实施加三种扰动操作——实体交换（entity swap）、数值扭曲（numerical distortion）、关系反转（relation inversion），再重构成语言流畅的幻觉样本；
3. **正样本精炼（生成正样本 y_w）**：忠实样本经释义增强多样性；不忠实样本由教师模型（GPT-4o）依据上下文修正为严格忠实版本；
4. 配对后形成偏好数据集 P = {(x, y_w, yₗ)}，用于 DPO 训练。

用该数据集（结合 ConFiQA 数据，共约 36K 样本）通过 **直接偏好优化（DPO）** 对草稿模型（Qwen3-1.7B）进行微调，使其对上下文证据保持高度忠诚。

### 2.3 阶段二：推理时动态干预

SFAD 推理流程由五个关键机制组成：

**① 专业者确定性（Specialist Certainty）κₜ（公式3）**

归一化置信度指标，基于草稿模型分布的熵计算：

κₜ = [1 − H(P_m(·|x<t)) / log|V|]^γ

κₜ → 1 表示草稿模型对自身预测高度确信，满足干预的"先决条件"。

**② 认知摩擦系数（Epistemic Friction）Fₜ（公式4）**

Fₜ = D_JS(P_M ∥ P_m) · κₜ

即草稿模型与目标模型分布之间的 Jensen-Shannon 散度，用专业者确定性加权。**高摩擦 = 模型间显著分歧 + 草稿模型高度确信**，这意味着可能发生了"自信幻觉"。

**③ 自适应门控机制 λₜ（公式5）**

λₜ = σ(β·(Fₜ − τ))，由偏移 sigmoid 函数实现平滑切换：Fₜ 远低于 τ 时 λₜ→0（快速路径）；远高于 τ 时 λₜ→1（转向路径）。

**④ 上下文合理性掩码 + 非对称 Logit 转向（公式6-7）**

定义合理候选集 V_CPC = {v ∈ V : P_m(v) ≥ η · p_max}（即只允许草稿模型中语言上合理的 token 被介入）。修正后的 logits 为：

z*ₜ = z_{M,t} + λₜ · ReLU(z_{m,t} − z_{M,t}) · I(x ∈ V_CPC)

- ReLU 保证**单向知识注入**：只放大草稿模型比目标模型更有信心的 token，不惩罚目标模型的语言表达能力；
- 掩码项 I(·) 作为安全护栏，阻止破坏语言流利性的低概率 token 被放大。

**⑤ 混合解码策略（公式8）**

- Fₜ ≥ τ → **转向路径（Steering Path）**：从修正后的分布 Softmax(z*ₜ) 采样；
- Fₜ < τ → **快速路径（Fast Path）**：执行标准推测解码（目标模型验证草稿 token）。

## 6. 主要结论与发现

1. **SFAD 在忠实性与速度上同时大幅领先**：在 Foundation QA、摘要和长文本 QA 三类任务中，SFAD 均显著超越所有解码级基线，将 Qwen3-14B 的忠实性提升到接近甚至超过 Llama-3.1-70B 的水平，同时保持约 0.78×–0.85× 的相对延迟（即快于无推测的基模型，相较目标模型有显著加速，文中宣称 2.48× 的端到端速度提升——注意此处为相对传统对比解码的加速效益）；
2. **推测解码与事实性纠错可以统一**：SFAD 将推测解码从单纯的加速工具升级为"安全监测 + 定向修偏"的推理框架；
3. **验证优于纠错**：标准推测解码无法修正分布偏差（忠实 token 概率仅从 18.73% 提升到 18.91%），而 SFAD 的 logit 级转向将其提升到 62.45%（3.33× 相对提升）；
4. **选择性干预是保效率的前提**：τ = 0.5 时仅 22.4% 的 token 触发转向路径，即用"外科手术式"的精准确认保证了效率；
5. **不损害通用能力**：GSM8K 性能仅从 91.35% 微降至 91.27%，Just-Eval 各维度无实质退化。
