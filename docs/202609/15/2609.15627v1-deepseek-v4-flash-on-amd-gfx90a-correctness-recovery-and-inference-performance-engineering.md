## 摘要
我们展示了在采用 gfx90a/CDNA2 架构的 AMD Instinct MI250 GPU 上，对 DeepSeek-V4-Flash 推理进行启用、正确性恢复与性能工程的工作。该系统集成了原生 safetensors 加载、张量与专家并行、FP4 路由专家混合计算、FP8 稠密投影、稀疏注意力、HIP 图执行，以及 SGLang 内兼容 OpenAI 的服务。最初一条快速执行路径被发现存在数值错误，原因是路由专家的 W2 布局不匹配。我们识别了输出置换，在加载时修复权重布局，并在进一步优化之前建立了固定 token 与基于哈希的正确性检查。在修正后的路径上，通过打包 FP4 权重、INT8 激活量化、CDNA2 点积指令、peer-read all-reduce 以及拓扑感知内核几何，提升了解码性能。预填充通过 CDNA2 MFMA 内核、改进的打包权重复用、降低的稀疏注意力开销、更大的分块以及重新调优的专家排序得到加速。在四个 MI250 GCD 上，TP4/EP1 原生自回归解码达到约 74.5 tok/s，而 4,604 token 的提示达到 2.061–2.062 s 的 TTFT，即约 2,234 输入 tok/s。结果表明，CDNA2 上高效的 DeepSeek-V4-Flash 推理不仅受内存带宽限制，还受 FP4 执行格式不匹配、低 M 利用率以及逐层同步开销的限制。

## Abstract
We present the enablement, correctness recovery, and performance engineering of DeepSeek-V4-Flash inference on AMD Instinct MI250 GPUs using the gfx90a/CDNA2 architecture. The system integrates native safetensors loading, tensor and expert parallelism, FP4 routed mixture-of-experts computation, FP8 dense projections, sparse attention, HIP graph execution, and OpenAI-compatible serving within SGLang. An initially fast execution path was found to be numerically incorrect because of a routed-expert W2 layout mismatch. We identify the output permutation, repair the weight layout at load time, and establish fixed-token and hash-based correctness checks before further optimization. On the corrected path, decode performance is improved through packed FP4 weights, INT8 activation quantization, CDNA2 dot-product instructions, peer-read all-reduce, and topology-aware kernel geometry. Prefill is accelerated using CDNA2 MFMA kernels, improved packed-weight reuse, reduced sparse-attention overhead, larger chunks, and retuned expert sorting. On four MI250 GCDs, TP4/EP1 native autoregressive decode reaches approximately 74.5 tok/s, while a 4,604-token prompt reaches 2.061-2.062 s TTFT, or approximately 2,234 input tok/s. The results show that efficient DeepSeek-V4-Flash inference on CDNA2 is limited not only by memory bandwidth, but also by FP4 execution-format mismatch, low-M utilization, and per-layer synchronization costs.

- **研究动机**：在 AMD Instinct MI250（gfx90a/CDNA2）上高效部署 DeepSeek-V4-Flash 推理。该模型为 284B 总参数、约 13B 激活参数的 MoE 模型，路由专家使用 FP4，非专家权重多为 FP8。
- **关键矛盾**：CDNA2 没有原生 FP4 矩阵核心，FP4 权重需要在线解包、scale 处理、激活量化和专家排序；同时 decode 阶段 M 很小，导致低 M 利用率、逐层同步开销突出。
- **正确性问题**：早期看似快速的 AIter FP4 路径数值错误，不能作为有效性能结果。核心问题是路由专家 W2 输出布局与 gfx90a 执行路径不匹配。
- **整体含义**：在 CDNA2 上，DeepSeek-V4-Flash 推理瓶颈不只是 HBM 带宽，还包括 FP4 执行格式不匹配、低 M 利用率、在线 FP4 解包、scale 布局、专家排序和层同步。必须先恢复正确性，再做性能工程。

## 2. 方法论：核心思想、关键技术细节与流程

- **总体路线**：保留原始混合 FP4/FP8 checkpoint 权重，基于 SGLang 服务框架，在 gfx90a 上使用 shape-specific HIP、AIter、Composable Kernel、Triton 路径执行。最终拓扑为单实例 TP8/EP1，无 routed-expert A2A，但保留 TP collective。
- **正确性恢复核心**：
  - 发现 legacy CK FP4-by-FP4 stage-1 在 gfx90a 上输出零；改用 CKTile BF16-by-FP4 后 stage-1 接近 oracle，但 stage-2 W2 仍错误。
  - 通过输出列 fingerprinting 定位 128 宽 N tile 内 16 行块的映射：fast → reference = `[0, 2, 4, 6, 1, 3, 5, 7]`。
  - 在加载时对 raw W2 权重和 scale 应用逆置换 `[0, 4, 1, 5, 2, 6, 3, 7]`，恢复逻辑输出顺序。该修复是一次性加载变换，不增加 decode 热路径成本。
  - 使用固定 France oracle 输入 ID 和输出哈希作为 sanity check，例如期望完成含 “The capital of France is Paris” 及 token IDs/hash。
- **其他数值修复**：
  - 修复大 prefill BF16-CK 执行中的 E8M0 scale-layout 问题：raw packed weights 不等于 raw logical scales，需反转或匹配 AIter scale shuffling 地址映射。
  - 确定性 index selection：用逻辑 ID 固定 Top-K 成员 tie，并在 rank-local 物理映射前固定顺序。
  - 修复 C4 lifecycle callbacks 与统一 V4 pool 的 compression-ratio discovery，恢复 1M 逻辑 KV pool 和 native graph 构建。
- **解码优化**：
  - 使用 packed 4-bit FP4 权重，不做离线展开。
  - 在线 BF16 激活量化到 INT8，每 32 元素一组。
  - E2M1 nibble 映射到 `0, ±1, ±2, ±3, ±4, ±6, ±8, ±12`。
  - 使用 CDNA2 `v_dot4_i32_i8` / mixed-dot 累加，再做激活和 E8M0 scaling。
  - down projection 中使用四个 16-lane subgroup 处理 top-6 slots。
  - 用 AIter peer-read custom all-reduce 替代高固定延迟 RCCL；TP-only mHC launch geometry 不再为 Mori progress 预留 CU。
- **预填充优化**：
  - packed-FP4 unpack 跨行复用，先 group8 后 group32。
  - 用 `v_perm_b32` 查找表替代分支式 nibble 解码。
  - MI250 block-FP8 调优配置、CDNA2 INT8 MFMA routed gate/down kernel。
  - sparse paged-prefill attention 从 8 wave 降到 1 wave。
  - chunked-prefill 从 512/1024 增至 2048，后续使用 chunk 2304 等。
  - M2048 专用 MFMA grid、native HIP INT8 量化、scale/metadata broadcast。
  - expert sorter 从 32 行增至 64 行，使约 48 assignments 的专家只需扫描 packed weights 一次。
- **最新优化**：
  - **空 indexer tile guard**：当 1M pool 中实际 active prefix 很短时，跳过无有效 key 的 tile，同时保留零存储、有效计算、序列长度、Top-K 语义和物理 index 映射。
  - **恢复 C1 wo_a GEMV 特化**：wave64 路径，组件测试从 30.75 µs 降至 6.88 µs；100 个 mutation 中仅 70 个 bit-equal，最大相对 L2 误差约 0.00179。
