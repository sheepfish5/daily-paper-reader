## 摘要
前沿语言模型正更积极地采用次二次注意力，以降低推理过程中的内存占用和计算需求，同时仍能提供前沿水平的准确率。尽管现有系统围绕稠密注意力做出以注意力为中心的解聚式服务决策，但我们表明，围绕次二次注意力大语言模型独特的算术强度和内存占用进行推理解聚，可在新兴的基于DRAM和仅SRAM的异构系统上显著提升吞吐量和能效。我们提出 SQD（SubQuadratic Disaggregation，次二次解聚），一种细粒度异构解聚方案，它按二次注意力和次二次注意力而非按算子类型来拆分解码，并适用于各种次二次注意力变体。对于稀疏注意力LLM，我们将解码解聚为 top-k 选择（必须遍历完整 KV 进行索引）以及 top-k 注意力加 FFN（具有静态内存占用）。对于线性注意力和滑动窗口注意力LLM，我们将解码解聚为稠密注意力层，以及次二次注意力层加 FFN。在调整后的 8xB200 异构系统代理中，我们观察到，相较于最强的纯 GPU 基线，GLM 5.2 上平均 tokens/J 提升 53%，Nemotron 3 Ultra 上提升 31%，Gemma 4 31B 上提升 56%。在固定功耗预算的 Rubin 加 LPX 系统分析模型中，相较于注意力-FFN 解聚的最佳基线，我们观察到可实现延迟收紧 1.2 倍至 1.5 倍，吞吐量最高提升 3.6 倍。我们的实验还揭示了关于面向次二次注意力的下一代异构系统在芯片与互连资源配置方面的架构洞见。

## Abstract
Frontier language models are more aggressively using subquadratic attention to reduce the memory footprint and compute requirements during inference while still delivering frontier accuracy. While existing systems make dense attention-centric disaggregated serving decisions, we show that disaggregating inference around the unique arithmetic intensity and memory footprint of subquadratic attention LLMs can achieve significant throughput and energy efficiency gains on emerging DRAM-based and SRAM-only heterogeneous systems.   We introduce SQD (SubQuadratic Disaggregation), a fine-grained heterogeneous disaggregation scheme that splits decode by quadratic and subquadratic attention rather than by operator type, and that applies across subquadratic attention variants. For sparse attention LLMs, we disaggregate decode into top-k selection, which must index through the full KV, and top-k attention plus FFN, which have static memory footprints. For linear and sliding-window attention LLMs, we disaggregate decode into dense attention layers and subquadratic attention layers plus FFN. In an adjusted 8xB200 heterogeneous system proxy, we observe average tokens/J improvements of 53% on GLM 5.2, 31% on Nemotron 3 Ultra, and 56% on Gemma 4 31B over the strongest GPU-only baselines. In an analytical model of a Rubin plus LPX system with fixed power budgets, we observe 1.2x to 1.5x tighter achievable latencies and up to 3.6x higher throughput over the best baseline of attention-FFN disaggregation. Our experiments also reveal architectural insights on chip and interconnect provisioning for next-generation heterogeneous systems serving subquadratic attention.

# 论文结构化总结：面向次二次注意力的异构系统解聚（SQD）

## 1. 核心问题与整体含义

- **背景**：随着推理成本逐渐超过训练成本，解码阶段的高内存带宽、低吞吐需求导致系统利用率低、单位 token 成本高，尤其在需要高交互性（低 TPOT）的场景下更为突出。
- **核心矛盾**：现有解聚式服务（prefill/decode 解聚、attention-FFN 解聚）均以**稠密（二次）注意力**为中心做决策，未考虑前沿 LLM 已大量采用**次二次注意力**（稀疏、线性/循环、滑动窗口）这一事实。
- **硬件趋势**：新兴异构系统将 DRAM 型 GPU 与仅 SRAM 的 ASIC 配对，后者带宽与能效高一个数量级但容量小，只适合存放静态工作集。
- **研究问题**：如何围绕次二次注意力 LLM 独特的**算术强度**与**内存占用**特性，重新设计解码阶段的异构解聚方案，以同时提升吞吐与能效。
- **整体含义**：论文主张按**注意力类型（二次 vs. 次二次）**而非算子类型切分解码，为下一代 DRAM+SRAM 异构系统的芯片与互连配置提供架构启示。

## 2. 方法论

- **核心思想（SQD）**：将解码解聚为四个阶段——prefill、二次注意力（footprint 随上下文增长）、次二次注意力（footprint 静态）、FFN/MoE（静态）。二次注意力与 prefill 共置于 DRAM GPU（共享 KV cache），次二次注意力与 FFN 移至 SRAM-only ASIC。

- **按模型族的切分方式**：
  - **稀疏注意力（GLM-5.2）**：在注意力算子**内部**切分。索引器扫描（读取完整 MLA latent KV）留在 GPU；top-k 注意力（固定 k=2048 条目）与 FFN 移至 ASIC。
  - **线性/循环（Nemotron 3 Ultra）**：按**层**切分，108 层中 12 层稠密注意力留 GPU，其余 Mamba-2 循环层 + FFN 移至 ASIC。
  - **滑动窗口（Gemma4-31B）**：60 层中 10 层稠密留 GPU，50 层滑窗 + FFN 移至 ASIC。

- **关键机制一：IndexShare 跨组预取 + 经验秩频（ERF）淘汰**：
  - 利用 GLM-5.2 每 4 层共享一次索引选择的特性，组头计算选择后即预取后续层所需 KV，将层间复用转化为跨步复用。
  - 组头无 slack，其注意力保留在 ASIC 上并配置近满驻留缓存，少量缺失随选择器往返顺带返回。
  - 对五种策略（Belady 上界、ARC、Scissorhands、H2O、页粒度）在同一记录选择流上回放，本方案命中率最优。

- **关键机制二：延迟感知的通信隐藏**：
  - 对 IndexShare 组内偏移 *j*：预算 `budget_j = (j-1)·t_layer`，可用窗口 `slack_j = budget_j - L0`（L0=7μs，含 2μs 线跳 + 5μs dispatch），要求命中率 `h_j ≥ 1 - slack_j·W/(B·k·e)`（W=141 GB/s，e=1152 字节/条目）。
  - 三个实现选择：异步 post/wait 对包裹本地计算、单边 put + doorbell 替代双边 send（消除 rendezvous 偏斜）、按固定契约做图捕获。

- **形式化基础（Table 1）**：给出各阶段 FLOPs、Bytes、算术强度与 footprint 的解析式，仅稠密注意力和 top-k 选择携带随上下文 C 增长的 footprint；仅 FFN 的强度随 batch 增长。

- **硬件落点依据**：Rubin GPU ridge point 为 758 FLOP/byte，LPX 类 ASIC 为 8.2 FLOP/byte，解码各阶段均远低于 GPU ridge、接近 SRAM ridge。

## 6. 主要结论与发现

- **能效（真实 B200）**：SQD 功耗 4.11 kW vs. 基线 7.26 kW（57%），保留 63–97% 解码吞吐；tokens/J 相比最强纯 GPU 基线平均提升 **53%（GLM-5.2）、31%（Nemotron 3 Ultra）、56%（Gemma4-31B）**；相比 Attn-FFN 解聚提升 16–38%。上下文越长优势越明显（32K 时 12–51%，1M 时 53–71%）。
- **吞吐（Rubin+LPX 模型）**：固定功耗预算下，SQD 达到 **1.2×–1.5×** 更高可达用户 TPS；GLM-5.2 上为 Attn-FFN 的 **2.9×–3.6×**；在交互式低延迟区间提供 **2.7×–3.4×** 最快 GPU-only 系统的吞吐。
- **机制归因**：colocation（step 取 max 而非 sum）与 top-k 预取是主要增益来源；SQD 每 4 层（GLM）或 6 层（Gemma）才穿越一次，而 Attn-FFN 每层都需暴露通信。
- **互连洞见**：**延迟比带宽更关键**——Spectrum-X 级延迟（vs. NVLink 6）会使吞吐下降 25–37%，而带宽已远在参考线以下即饱和；建议未来 fabric 优先低延迟、避免为闲置带宽付费。
- **SRAM 洞见**：增加片上 SRAM 显著提升吞吐，因解码在 LPX 上处于容量瓶颈而非带宽/算力瓶颈；收益在静态足迹驻留后饱和，且各模型饱和点相差一个数量级（Gemma4 早饱和，GLM-5.2 在 256GB 仍在增益）。
- **功耗扩展**：系统功耗与吞吐呈亚线性（每设备开销增加），且呈台阶式增长（容量按整芯片/整机架粒度到达）。

## 7. 优点

- **问题切入新颖**：首次将解聚粒度从"算子类型"推进到"注意力类型（二次 vs. 次二次）"，直接契合前沿模型架构演进趋势。
- **软硬协同深度**：同时给出算术强度/footprint 的解析表征（Table 1）、真实系统实现（SGLang 修改、单边通信 kernel、图捕获）与架构建议。
- **工程细节扎实**：识别并解决 rendezvous 偏斜问题（0.8ms → 64.6–130.7μs），量化了通信隐藏的 deadline 公式与所需命中率。
- **缓存机制有据**：在真实轨迹上回放 5 种策略，含 Belady oracle 上界，证明所提 IndexShare+ERF 的优越性。
- **验证严谨**：解析模型 9/9 点在 ±15% 内，且所有优势从测量下界锚定而非凭空预测；对基线（Attn-FFN）的劣势给足甚至偏保守。
- **诚实报告成本**：明确披露 4058 GPU-hours 及其中九成用于测试/验证，学术透明度高。

## 8. 不足与局限

- **代理系统的近似风险**：解码设备是节流后的 B200（16/148 SM），并非真正 SRAM-only ASIC；其数据通路、无缓存特性、编译器调度行为与 LPX 不同，能效绝对值可能被高估或低估。
- **关键结果未经真实异构硬件验证**：Rubin + LPX 的吞吐/延迟优势完全来自解析模型（基于公开规格 + B200 锚点），作者亦声明"这是投影检验，而非未发布芯片的验证"。
- **上下文外推**：Nemotron 3 Ultra 与 Gemma4 的 1M 点超出其服务/训练窗口（262144 / 256K），属训练限制而非系统限制，可能影响局部性统计的代表性。
- **权重为 dummy**：性能测量使用 dummy weights，虽不影响系统时序结论，但未验证真实权重下 MoE 路由/稀疏模式的完整影响。
- **模型覆盖有限**：仅三个 LLM（每族一个代表），未能覆盖其他稀疏注意力实现（如 Quest/InfLLM 类）或不同 k 值、不同 IndexShare 间隔的敏感性。
- **硬件可用性限制**：方案强依赖次二次注意力层占多数且稀疏模型使用 IndexShare 共享——若某 LLM 每层重算选择，则每层都承受组头级别的暴露穿越，收益将大幅缩水。
- **功耗核算假设**：排除了 258W HBM refresh/uncore 功率以近似 ASIC，但真实 ASIC 仍可能有其他功耗项（如 SRAM 泄漏、互连 SerDes），绝对功耗可能偏低。
- **成本模型为约定而非报价**：互连成本/token 采用"美元与延迟成反比"的自定义约定，仅固定权衡形状而非最优点位置。
