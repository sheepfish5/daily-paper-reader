## 摘要
尽管多模态大语言模型（MLLMs）在各种任务中表现出色，但其可扩展性仍受限于KV缓存存储的内存和计算开销。现有的KV缓存驱逐方法结合基于余弦相似度的多样性度量与重要性度量，选择性地保留关键键值对。然而，余弦相似度涉及归一化，丢弃了幅度信息，而且由于隐藏表示的各向异性特性，余弦相似度通常在各层中产生均匀的高相似度值。在我们的研究ECOKV中，我们严格解构了现有多样性度量的能力。超越简单测量，我们提出了一种几何感知复合度量，联合利用欧氏距离和余弦相似度，从互补视角捕捉标记多样性。此外，我们使用这两种度量来估计每个注意力头的冗余程度，从而在标记选择过程中对多样性分数和重要性分数进行自适应加权。最后，我们证明通常用于保留最近标记的观察窗口可以大幅缩减，从而将更多缓存容量分配给信息量丰富的标记，并带来持续的改进。大量实验表明，ECOKV在各种压缩比下均实现了最先进的性能，并能与现有的KV缓存驱逐方法无缝集成。我们还分析了重要性度量与多样性度量之间的关系，并考察了各层和注意力头的冗余模式。

## Abstract
Although multimodal Large Language Models (MLLMs) excel in diverse tasks, their scalability remains limited by the memory and computational overhead of KV cache storage. Recent KV cache eviction approaches incorporate a cosine similarity-based diversity metric with importance metrics to selectively retain critical key-value pairs. However, cosine similarity involves normalization that discards magnitude information, and it often yields uniformly high similarity values across layers due to the anisotropy property of hidden representations. In our study ECOKV, we rigorously deconstruct the capabilities of existing diversity metrics. Moving beyond simple measurement, we propose a geometry-aware composite metric that jointly leverages Euclidean distance and cosine similarity to capture token diversity from complementary perspectives. Furthermore, we use these two metrics to estimate the redundancy level of each attention head, allowing adaptive weighting between diversity and importance scores during token selection. Finally, we demonstrate that the observation window commonly employed to preserve recent tokens can be substantially reduced, thereby allocating more cache capacity to informative tokens and yielding consistent improvements. Extensive experiments demonstrate that ECOKV achieves state-of-the-art performance under various compression ratios and can be seamlessly integrated with existing KV cache eviction methods. We further analyze the relationship between importance and diversity, and examine redundancy patterns across layers and attention heads.

### 一、核心问题与整体含义（研究动机与背景）

多模态大语言模型（MLLMs）在视觉问答、图文理解等任务上表现优异，但其推理过程高度依赖 KV cache（键值缓存）以存储历史token的key和value表示。随着输入上下文长度增加，KV cache 的内存和计算开销迅速增长，严重制约模型的可扩展性。

当前典型的解决方案之一是 **KV cache 驱逐（eviction）**：在给定缓存预算下保留最关键的键值对而移除冗余的键值对。已有方法大多采用“重要性 + 多样性”的混合打分策略，其中多样性评估尤为关键，因为它决定残留token的语义覆盖度。

**论文指出现有多样性度量的深层缺陷：**

- 主流方法（如 MixKV）依赖**余弦相似度**来评估token间多样性，但余弦相似度存在两个根本局限：
  1. 归一化操作**丢弃了向量幅度（magnitude）信息**；
  2. 由于 transformer 隐表征的**各向异性（anisotropy）**，不同层中的余弦相似度往往一致地偏高，导致对冗余度的系统性高估。
- 欧氏距离虽能保留幅度信息、作为潜在互补度量，却在既有LLM研究中表现不如余弦相似度，原因在于缺乏方向信息且度量尺度无界。

**总体意义：** 论文主张单一几何度量无法完整刻画token多样性，提出将余弦相似度与欧氏距离融合，从而更准确地识别KV对中的冗余与关键信息，最终提升有限缓存预算下的模型性能。

### 二、方法论

#### 2.1 核心思想

ECOKV 构建了一个 **几何感知（geometry-aware）的复合多样性度量**，核心流程是：

1. 对每个注意力头计算每个 key 的多样性分数，融合方向信息（余弦）与幅度信息（欧氏）；
2. 估计每个注意力头的冗余度，据此**自适应地调整多样性分数与重要性分数之间的权重**；
3. 大幅缩减观察窗口（observation window），将更多缓存预算让渡给信息量更高的非窗口token。

#### 2.2 关键技术细节

**(a) 基于欧氏距离的多样性度量**

- 计算所有 key 的质心 $\\bar{k}$，然后计算每个 key 到质心的欧氏距离：

  $$\\bar{k} = \\frac{1}{T}\\sum_{i=1}^{T} k_i, \\quad d_E(i) = \\|k_i - \\bar{k}\\|_2$$

- 距离越大，说明该 key 偏离主流分布越远，携带更多独特/非冗余信息；
- 使用**min-max归一化**将距离转换为 $[0,1]$ 区的多样性分数 $s_E(i)$，消除层间尺度差异。

**(b) 复合多样性分数**

将欧氏距离得到的分数 $s_E(i)$ 与既有余弦相似度分数 $s_C(i)$ 线性融合：

$$S_{div}(i) = \\alpha \\cdot s_E(i) + (1 - \\alpha) \\cdot s_C(i)$$

其中 $\\alpha$ 控制两个几何度量的相对贡献。

**(c) 头自适应冗余估计器（Head-adaptive Redundancy Estimation）**

- 对每个注意力头计算 key 集合的平均欧氏距离（相对于质心） $D_E^h$，作为该头“离散程度”的代理指标；
- 通过带温度参数的缩放的 sigmoid 函数得到归一化的幅度感知冗余分数 $r_E$：

  $$r_E = 2 - 2 \\cdot \\sigma\\left(\\frac{D_E^h}{\\tau}\\right),\\quad \\tau = \\sqrt{d_k}$$

- 结合基于余弦相似度的冗余分数 $r_C$，得到综合冗余度 $\\lambda$：

  $$\\lambda = \\beta \\cdot r_E + (1 - \\beta) \\cdot r_C$$

- $\\lambda$ 越大表示该头越冗余，从而给予多样性更高的权重；$\\lambda$ 越小则更依赖重要性排序。

**(d) 最终打分与选择**

- 将多样性分数先缩放到与重要性分数相近的量级：
  $$\\bar{S}_{div} = \\frac{S_{div} - \\min}{\\max - \\min}, \\quad \\tilde{S}_{div} = \\bar{S}_{div} \\cdot \\frac{\\mathrm{mean}(S_{imp})}{\\mathrm{mean}(\\bar{s}_C)}$$
- 最终分数为：
  $$S(i) = \\lambda \\cdot \\tilde{S}_{div}(i) + (1 - \\lambda) \\cdot S_{imp}(i)$$
- 每个注意力头按照该分数取 top-k 键值对保留。

**(e) 极小化观察窗口**

- 传统方法（如 SnapKV）默认保留最后32个token作为观察窗口；
- ECOKV 通过实验证明，**将观察窗口缩减至 1~4 个token**可以释放更多预算用于真正动态的信息选择，在紧预算下普遍提升性能；
- 模型即使不用大窗口，其自然的选择机制也会保留重要近期token，因此窗口的边际作用有限。

### 六、主要结论与发现

1. **互补多样性度量有效**：欧氏距离与余弦相似度的融合优于单独使用任一度量，证实两者各自捕捉了词语之间不同维度的几何信息；
2. **头自适应冗余加权提升压缩性能**：利用平均欧氏距离估计冗余度并结合余弦指标，可在高冗余头中加大多样性权重，在低冗余头中保持重要性优先，更符合层间和头间的异质性；
3. **极小观察窗口在紧预算下具有显著收益**：窗口从32缩减到4甚至1时，各模型和基准下均有稳定增益，说明大规模无条件保留最近token并非必要；
4. **ECOKV可插件化适配多种基础逐出框架**，在几乎所有预算设置下都刷新SOTA；
5. **重要性与多样性相关性整体偏低**，尤其在中间层，说明二者确实是互补信号而非冗余重复；
6. 冗余度呈**早期层高→中间层低→后期层又升高的倒U形变化**，符合不同层对多样性的差异化需求。

### 七、优点（亮点）

1. **问题洞察深入**：清晰揭示了余弦相似度的两点结构性缺陷（幅度丢失和各向异性），并用层间相似度分布与PCA可视化辅助论证，说服力强；
2. **方法具有优雅的理论分解**：欧氏距离 $\|a-b\\|^2 = \\|a\\|^2+\\|b\\|^2 - 2\\|a\\|\\|b\\|\\cos\\theta$ 的展开从几何本质上说明欧氏距离天然综合了幅值与方向信息，为该方法的合理性提供了理论根基；
3. **头自适应机制精细**：不同于全局统一设置权重，按注意力头的实际冗余度动态调整，符合不同头功能分化的已知结论；
4. **实验设计严谨**：对比MixKV时置于完全相同的框架中，变量控制清晰；消融实验覆盖超参数的每个维度；
5. **显著性收益集中在小预算区域**：在64预算下相对MixKV可提升10-15个点，说明该方法在紧约束场景下的实践价值突出；
6. **多处提供反直觉的实践洞见**（如极小观测窗口、固定超参即可接近最优），对工程落地友好；
7. **效率开销极低**：ECOKV的运行时间和内存与基线持平，几乎没有额外推理延迟。

### 八、不足与局限

1. **超参数选择一致性不足**：
   - 最优 $\\alpha$ 在不同基础和不同数据集间存在明显波动（Figure 3），论文虽称固定 $\\alpha=0.8,\\beta=0.6$ 接近最优，其中 $\\beta$ 稳定但 $\\alpha$ 波动，存在一定的调参不确定性；
   - 这种需要调参的复合度量削弱了“即插即用”的纯粹性。
2. **验证的模型规模有限**：
   - 仅在7B级模型（LLaVA-NeXT-Mistral-7B、Qwen2-VL-7B）上评测，未覆盖更大参数量或非解码器架构等场景；
   - 对通用性结论（如层间冗余模式）的外推性存疑。
3. **关键洞察的实验闭环不够完整**：
   - Figure 1/2 所示“余弦相似度偏高且丧失区分度”的问题，论文并未直接验证 EVOKV 在**层0**（最严重的一层）的选点是否相比 MixKV 更加准确；
   - “每层保留的 token 与理想选择之间的分布差距”这类直接证据有所缺失。
4. **小窗口策略泛化作用机制未充分解释**：
   - 论文将“小窗口总是更好”解读为预算释放的收益，但未深入分析为什么此前方法普遍设置的窗口=32一直没有被质疑，底层注意力分布的证据支持略显薄弱。
5. **长上下文评测覆盖有限**：只有MP-DocVQA一个长问答数据集，实际长视频、长图文交错等更复杂的长上下文场景不在实验范围内。
6. **相关统计量偏简单**：如“冗余度”用平均欧氏距离度量，并未考虑到key分布可能呈现多簇结构的情况，质心距离可能受到分布形态的误导。
7. **缺少 LLM 纯文本长上下文基准验证**：论文目标指向MLLM，且说明非直接迁移至LLM场景，未在如 LongBench 等纯文本任务上验证，拓展面较窄。

---

综上，ECOKV以严谨的几何分析为出发点，设计出同时利用欧氏距离与余弦相似度的复合度量，配合头自适应加权和小窗口策略，在KV缓存压缩方向作出了一项完成度高、实验扎实的研究工作，其小预算场景下的显著性能优势尤其值得关注。
