## 摘要
块扩散投机解码通过并行提出一整块未来token，并通过对目标模型进行单次前向传播来验证它们，从而提升大语言模型推理效率。然而，现有方法仅保留被接受的prefix并丢弃被拒绝的后缀，这使得在这些位置上花费的计算无法惠及后续的草稿生成轮次，并迫使草稿模型反复从头为未来token重建表示。我们观察到，拒绝仅决定了一个提议的token是否可以被提交，而被拒绝位置上的验证器表示仍然可以为后续预测提供有用信息。基于这一观察，我们提出了DFlow，一个简单而有效的框架，使得验证器信息能够在草稿生成轮次之间流动。DFlow重用目标验证器为被拒绝后缀产生的隐藏状态来指导后续草稿生成，而无需额外的目标计算。为了有效地学习这种跨草稿轮次的信息流动，我们引入了一种自条件训练策略，将先前预测中的验证器表示反馈到后续预测中。在多种基准测试上针对Qwen3模型的实验表明，DFlow在草稿质量和接受长度上持续优于DFlash。

## Abstract
Block diffusion speculative decoding improves LLM inference efficiency by proposing a block of future tokens in parallel and verifying them with a single forward pass through the target model. However, existing methods retain only the accepted prefix and discard the rejected suffix, preventing the computation spent on these positions from benefiting subsequent drafting rounds and forcing the drafter to repeatedly reconstruct representations for future tokens from scratch. We observe that rejection only determines whether a proposed token can be committed, while the verifier representations at rejected positions can still provide useful information for subsequent predictions. Based on this observation, we propose DFlow, a simple yet effective framework that enables verifier information to flow across drafting rounds. DFlow reuses the hidden states produced by the target verifier for the rejected suffix to guide subsequent drafting without additional target computation. To effectively learn this information flow across drafting rounds, we introduce a self-condition train strategy that feeds verifier representations from earlier predictions back into subsequent predictions. Experiments on Qwen3 models across diverse benchmarks demonstrate that DFlow consistently improves draft quality and acceptance length over DFlash.

## 1. 论文的核心问题与整体含义

提出 DFlow 的这篇论文针对的是**块扩散投机解码（Block Diffusion Speculative Decoding）中的信息不连续（information discontinuity）问题**。

在**研究动机与背景**方面：

- 大语言模型自回归解码天然顺序化，成为推理性能的主要瓶颈。
- 投机解码通过轻量级草稿模型并行提出多个未来 token，再由目标模型一次性验证，以此加速解码。
- 块扩散投机解码（如 DFlash）将整块候选 token 通过一次前向传播提出，显著降低了顺序草稿开销。
- 然而，现有方法在验证后**仅保留被接受的 prefix**，而被拒绝的 suffix 被完全丢弃，导致这些位置已产生的计算和表征未得到利用，下一轮草稿必须从头重建重叠位置的表示。
- 论文的核心观察是：**拒绝（rejection）只决定某个草稿 token 能否被提交，不能说明验证器在该位置产生的隐藏表示没有信息量**。这些表示参与了后续 token 的因果预测，即使所在 token 被拒绝，依然可能包含有利于后续草稿的上下文信息。

核心问题：能否将被拒绝位置的验证器表示跨草稿轮次传递，以提升下一轮的草稿质量，且**不引入任何额外的目标模型前向计算**？

从整体含义上看，论文希望揭示一个更广的原则：**投机提案不仅仅是候选输出，也是揭示推理过程有用信息的“探针”**——DFlow 将该思想延伸到了目标验证阶段。

## 2. 方法论

### 2.1 核心思想

DFlow 采用“**验证器信息中继（Verifier Information Relay）**”方式，将上一轮验证中产生的被拒后缀位置的隐藏状态变换并注入到下一轮草稿输入中，让这些位置继承先前验证获得的信息，而非完全从 mask embedding 重新开始。

### 2.2 关键技术细节

**（1）验证器表示对齐（Verifier Representation Alignment）**：
- 复用 DFlash 已有的特征投影——将选定的目标层 ℓ₁,…,ℓₘ 上的隐藏状态拼接，经共享投影矩阵 W_c 与 RMSNorm 得到与草稿模型兼容的表示，这**不增加目标模型前向计算**。
- 因果目标模型在位置 i 的隐藏状态预测 token i+1，而草稿模型在掩码位置 i 预测 token i，二者存在一位错位，因此中继前需要**移位对齐**，使两者对应同一预测目标。

**（2）拒绝条件草稿初始化（Reject Conditioned Draft Initialization）**：
- 验证时被拒 suffix 的上下文基于首次拒绝提案 ŷ(r)_{a+1}，而下一轮的实际起点是 bonus token b(r)，二者语义差异需要修正。
- 引入轻量级 MLP——输入目标修正 token 的嵌入、首次拒绝 token 的嵌入和验证器表示，输出逐通道缩放与修正向量：
  \[ [β(r)_i; γ(r)_i] = MLP_\phi([E(b(r)); E(ŷ(r)_{a+1}); h(r)_i]) \]
- 将验证器表示归一化后按通道调制，叠加到标准 mask 嵌入形成下一轮输入：
  \[ x(r+1)_i = E_{mask} + β(r)_i ⊙ LN(h(r)_i) + γ(r)_i \]

### 2.3 训练策略：多轮自条件训练（Multi-Round Self-Conditioned Training）

- **标准 DFlash 训练**将每轮视为独立、始终从 mask 开始预测；而 DFlow 推理中后续轮次的草稿依赖上一轮验证器表示。为了弥合此 gap，DFlow 的训练策略也做了展开。
- 分为两个部分：
  - **多轮展开（Multi-Round Rollout）**：把原来的单轮训练扩展到若干连续草稿-验证轮次——起始轮按标准 mask 预测；后续 k 轮接收前一轮中继的拒绝位置验证器表示，进行“拒绝条件预测”（reject conditioned prediction）训练。实验中默认 k=2。
  - **轨迹引导的轮间过渡（Trajectory-Guided Transition）**：在训练中，通过把草稿提议与预先计算的目标轨迹做精确匹配来确定接受前缀与 bonus token（而非直接依赖一次验证结果），从而保持轮次与目标轨迹对齐。
- 总训练损失：多轮损失之和，L_DFlow = L^(0) + Σ_{q=1}^{k} L^(q)，所有轮次共享同一套草稿模型参数并联合反向传播；目标模型冻结。目标验证和轮间转换在计算图上被切断（stop-gradient），防止梯度跨目标模型传播。损失函数延续 DFlash 的指数衰减交叉熵，距离锚点更近的位置获得更高权重。

## 6. 主要结论与发现

- **DFlow 在各类任务和规模上都明显提升接受长度**：
  - 在 T=0 时，平均接受长度较 DFlash 在 Qwen3-1.7B 上从 3.56 涨至 3.93（约 **+10.4%**）；在 Qwen3-4B 上从 3.71 涨至 4.20（约 **+13.2%**）；在 Qwen3-8B 上从 3.66 涨至 4.15（约 **+13.4%**）。
  - 在 T=1 的采样解码下，也保持一致的改善趋势。
- **高并发吞吐量的优势**：DFlow 在 1～32 并发范围内持续领先 DFlash，在某些高并发场景下加速比进一步提高；其额外计算开销很小。
- **消融结论**：“验证器信息中继”是收益的主要来源：
  - 单纯引入多轮 mask 预测只做小幅改进（3.56 → 3.67）；
  - 经 DFlow 训练但禁用中继后性能（3.66）接近上述多轮训练水平（3.67）；
  - 启用中继后在同一模型下显著上升至 3.93。
- **运行时开销只是很小的部分**：验证与草稿执行仍占主导，中继模块每次只有约 0.51 ms（相对 DFlash 约 1.2% 的开销）。
- **兼容性强**：与 Domino 结合后，接受长度进一步提升至 4.50（在 Qwen3-1.7B T=0 下，对应 3.56 是 DFlash、4.02 是 Domino），表明跨轮验证器信息复用与更强的因果依赖建模方法可以互补增益。
- **解决该问题的在线 rollout 练习方法很重要**：若缺少设计训练 rollout 的兼容性手段，教师强制式训练造成的分布偏移将导致性能大幅降低（降至 2.22），提示在跨轮信息流动训练中务必对齐推理时的轨迹与上下文。

## 7. 优点

- **新颖的观察角度**：指出现有方法中被拒后缀信息被“框住”的不可逆丢失，并将“拒绝边界”视为有助于下游草稿的关键信号，在概念上是直观且有效的插入。
- **成本低**：完全复用验证过程已有的隐藏表示、相同特征投影模块、轻量 MLP，显著降低引入额外目标计算的顾虑。
- **训练设计**：多轮自条件训练与轨迹引导转换匹配性强，在训练阶段让模型对验证器信息与拒绝边界信息形成期望性的使用模式，并利用停止梯度避免对抗性梯度传递带来的额外问题；其中 Domino 部分中针对分布对齐的在线 rollout 方式更为精细。
- **泛化能力较强**：覆盖三种模型规模、多类任务、贪婪+采样解码，高低负载等大量场景；相对 DFlash 的增益显著且稳定。
- **实用价值高**：高并发服务的观察结果表明，指标提升能实际转化为吞吐量增益；几乎为零的延迟开销使该方法适合部署。
- **论证设计较合理**：消融和运行时分解都直观，提供的兼容性验证扩展了该机制适用范围。

## 8. 不足与局限

- **实验范围限制**：
  - 主要围绕以 Qwen3 为代表的一类模型展开，DFlow 在其他主流架构（如 Llama、Mistral）上的适用性有待验证；
  - EAGLE-3 对比阶段倾向于直接采用公开 checkpoint，DFlash 则使用相同的训练配置进行对比，这种训练/测试资源分配差异可能带来一定偏倚（不过这也是该领域内常见的对比方式）。
- **测试数据集域偏窄**：训练数据仅来自 ShareGPT，对于数学或代码领域，这类通用对话数据可能不足以代表领域分布。
- **度量单一性**：核心指标为接受长度和吞吐量，未评估生成质量（词义/语义相似度、代码可编译性、人类偏好等）；DFlow 虽然加速了匹配采样下的生成，仍未对生成的文本质量进行直接评估。
- **可泛化性与局限需更细致讨论**：论文假设“拒绝位置的验证器表征仍有用”，但它对这种启发式的边界没有进行分析——例如，在高度不匹配的任务或低接受率设置下，中继信息是否有害或何时失去价值，尚未量化。
- **对超参数敏感性**：没有对 k（rollout depth 默认取 2）等变量做系统敏感性分析，也没有讨论上下文长度对验证器信息可复用比例的影响。
- **并发和系统层结论相对有限**：端到端高并发实验仅在 GSM8K/HumanEval 两个任务中给出结果，且未深入到具体显存占用、批处理大小、Prefill/Decode 分离等系统配置对其影响的细节。
