## 摘要
键值（KV）缓存驱逐对于扩展大语言模型中的长上下文推理至关重要。然而，现有策略主要依赖经验启发式方法，缺乏对固有非线性softmax注意力机制下令牌效用的严格刻画。在本工作中，我们从局部信息几何的视角重新思考KV缓存驱逐，将注意力过程建模为非线性高斯通信信道。通过对注意力映射进行一阶泰勒展开，我们推导出雅可比信息容量，这是一个新颖的目标，明确捕获了查询相关性、softmax敏感性和结构多样性。在该理论的指导下，我们提出了Jacap，一种容量感知的驱逐方法，利用softmax感知的重要性加权和统计杠杆分数进行子集选择。跨多种架构和基准的大量实验表明，\textsc{Jacap}在大多数场景下表现出优越性能，尤其是在高压缩率情况下。

## Abstract
Key-value (KV) cache eviction is essential for scaling long-context inference in Large Language Models. However, existing policies predominantly rely on empirical heuristics, lacking a rigorous characterization of token utility under the inherently nonlinear softmax attention mechanism. In this work, we rethink KV cache eviction through the lens of local information geometry, modeling the attention process as a nonlinear Gaussian communication channel. By performing a first-order Taylor expansion of the attention mapping, we derive the Jacobian Information Capacity, a novel objective that explicitly captures query relevance, softmax sensitivity, and structural diversity. Guided by this theory, we introduce Jacap, a capacity-aware eviction method that utilizes softmax-aware importance weighting and statistical leverage scores for subset selection. Extensive experiments across diverse architectures and benchmarks demonstrate that \textsc{Jacap} delivers superior performance in most scenarios, particularly in high-compression regimes.

## Jacap：基于雅可比非线性信息容量保留的鲁棒KV缓存驱逐

### 1. 核心问题与研究动机

随着大语言模型（LLM）在长上下文推理场景（如多步推理、工具增强代理、交互式决策）中的广泛应用，KV缓存的内存开销与推理延迟成为关键瓶颈。KV缓存驱逐（KV cache eviction）通过动态裁剪冗余缓存条目来缓解该问题，是目前最具实用前景的方案之一。

然而，现有驱逐策略存在以下核心缺陷：

- **依赖经验启发式指标**：如基于注意力分数（H2O、SnapKV）、Token 最近性、值范数等，缺乏对 token 效用的严格理论刻画。
- **孤立打分，忽略结构关系**：大多数方法对每个 token 独立评分，无法捕捉缓存条目之间的冗余性与互补性。
- **线性近似失真**：最新工作（如 CapKV）虽引入信息瓶颈（IB）理论，但采用线性高斯近似，忽视了 softmax 归一化带来的非线性竞争与饱和效应。

针对上述问题，论文提出了一种**基于雅可比矩阵的非线性信息容量理论**，并据此设计出 KV 缓存驱逐算法 **Jacap**，使驱逐策略在理论上更忠实于真实注意力机制。论文整体含义在于：为 KV 缓存驱逐提供一种**有理论根基、可解释、鲁棒性强**的替代方案，尤其在极高压缩率下显著优于既有启发式方法。

### 2. 方法论

#### 2.1 核心思想

论文将注意力过程重新建模为一种**非线性高斯通信信道**：

\[
Y_C = f_C(q) + \epsilon, \quad \epsilon \sim \mathcal{N}(0,\Sigma_{\text{noise}})
\]

其中 `f_C(q) = U_C · softmax(K_C q / √d_k)` 为保留缓存子集 C 所诱导的受限注意力映射。

假设未来查询服从局部高斯扰动模型：`q = μ_Q + δq, δq ∼ N(0, Λ_Q)`，对 `f_C` 在 `μ_Q` 处做一阶泰勒展开（Leamma 1），得到局部线性化：

\[
f_C(q) \approx f_C(\mu_Q) + J_C δq
\]

其中雅可比矩阵：

\[
J_C = \frac{1}{\sqrt{d_k}} U_C S_C K_C,\quad S_C = \mathrm{Diag}(\alpha_C^\star) - \alpha_C^\star(\alpha_C^\star)^\top
\]

`S_C` 为 softmax 竞争矩阵，其对角线刻画局部灵敏度、非对角线编码归一化竞争。这构成**雅可比信息容量**目标（Theorem 1）：

\[
L^{\mathrm{Jac}}_C \approx \frac{1}{2}\log\det\left( I + \Sigma^{-1}_{\text{noise}} J_C \Lambda_Q J_C^\top \right)
\]

该容量矩阵可分解为五个可解释组件：**键可访问性（key accessibility）、输出方向（output directions）、softmax 竞争（softmax competition）、查询统计（query statistics）和模型不确定性（model uncertainty）**。

#### 2.2 Jacap 算法关键步骤

为降低计算复杂度，Jacap 对完整目标做三步近似：

1. **注意力先验近似**：在驱逐前用候选池计算中心注意力权重 `ᾱ_i`，作为子集无关的先验。
2. **矩阵对角化**：
   - softmax 竞争矩阵近似为对角灵敏度：`ρ_i = ᾱ_i(1 − ᾱ_i)`；
   - 查询响应协方差 `KΛ_QKᵀ` 近似为对角项：`κ_i = k_iᵀΛ_Qk_i`。
3. **合并出非线性重要性权重**：

\[
w_i = \frac{1}{d_k} \alphā_i^2 (1-\alphā_i)^2 (k_i^\top \Lambda_Q k_i)
\]

4. 定义能力矩阵 `A = I + Σ w_j u_j u_jᵀ`，利用矩阵行列式引理计算最终边际贡献分数：

\[
\mathrm{score}_i = w_i \cdot u_i^\top A^{-1} u_i
\]

最后取分数最高的 B 个 token 作为保留子集。算法整体流程见 Algorithm 1，时间复杂度为 `O(N·d_h² + d_h³)`。

### 3. 实验设计与 Benchmark

论文从三个维度评估方法，并对比了 **EA、KeyDiff、KNorm、SnapKV**（前四类见文中标注 ">" 对应 `> KEYDIFF` 等）以及最相关的工作 **CapKV** 基线。具体如下：

### 6. 主要结论与发现

1. **高压缩率优势突出**：在压缩率为 0.9 时，Jacap 比次优基线（CapKV）在 LongBench 平均分上领先约 5 分；在 0.75 时与 CapKV 基本持平，但显著优于所有启发式方法。
2. **极端长上下文检索更可靠**：NIAH 热力图显示，Jacap 在长上下文和深层 needle 设置下保持稳定检索能力，而启发式基线严重退化。
3. **解码阶段仍具竞争力**：AIME25 上，2048 token 极紧预算下 Jacap 得分最高（0.30），4096 时与 CapKV 并列第一（0.50），16384 大预算下再次领先（0.73）。
4. **理论预测得到验证**：实验间接支持了理论中"饱和 token 信息价值低、中等注意力 token 更值得保留"的判断。
5. **温度 τ ≈ 10 为最优**：适度锐度的注意力先验在查询相关性与缓存多样性之间取得最佳平衡。

### 7. 方法亮点与贡献

- **理论创新**：首次将 **softmax 竞争矩阵 S_C** 显式纳入信息容量目标，揭示了注意力饱和与竞争对信息流动的影响；线性容量（CapKV）被证明是该框架的特例。
- **统一的解释框架**：将查询对齐、softmax 灵敏度、输出方向多样性、查询统计和模型噪声整合成一个局部可计算的容量目标。
- **理论与实践的结合**：从完整雅可比容量到可在线计算的杠杆分数，有一套自洽的推导链（见 Appendix B），而非纯经验设计。
- **无需修改模型或注意力代码**，可直接迁移到现有推理管线，与量化（如 KVQuant）、系统级内存优化（如 PagedAttention）等方法互补。
- **压缩率越高，优势越显著**，对显存受限场景有较强实用价值。

### 8. 不足与局限

1. **一阶泰勒近似的局限**：论文本身承认只保留了一阶项，在查询分布方差较大或解码过程中查询动态剧变时，近似误差可能增大。
2. **softmax 竞争的过度简化**：完整 `S_C` 被对角化为 `ᾱ(1−ᾱ)`，丢失了负的成对竞争项 `−ᾱ_iᾱ_j`。尽管降低了复杂度，却在理论上削弱了对冗余抑制的刻画。
3. **查询统计估计依赖历史**：μ_Q 与 Λ_Q 从历史查询估计，存在延迟性与估计偏差，在主题漂移剧烈的场景中可能失效。
4. **压缩率低时优势不明显**：从表 1 看，C.R.=0.25 时 Jacap 有时甚至略低于 CapKV 或 EA，说明非极紧约束下理论复杂度未必换取等比例收益。
5. **基准覆盖不够全面**：虽然任务多，但缺乏代码库级长上下文（如 RepoBench）、多轮对话/代理场景、以及更大吞吐量的服务场景；NIAH 检索深度也需要更细粒度的压力测试。
6. **运行时间代码并未附上分析具体开销**：尽管声称与现有方法可比，但理论上多出 `O(N·d_h² + d_h³)` 的额外矩阵运算，且未报告端到端真实吞吐量（tokens/s），在超大上下文服务中该开销可能更突出。
7. **架构泛化有限**：仅在 Qwen、Llama 类标准 decoder-only 架构上测试，未验证 MoE、跨注意力（encoder-decoder）等架构。
