## 摘要
大语言模型（LLM）推理常同时受计算与内存制约，尤其是在基于卸载的部署中，模型权重会在自回归解码过程中跨内存层级传输。在此情形下，减少执行的层数可以降低每 token 延迟，同时避免代价高昂的权重移动。受此观察启发，我们提出 FlexEE，一种面向资源受限且基于卸载的 LLM 推理的提前退出框架。FlexEE 通过逐层退出监督以实现可靠的中间层预测、基于 Top-K 局部词表的自推测解码以实现低成本的退出决策，以及动态隐藏状态管理以实现 KV 缓存正确且内存感知的执行，使提前退出在 LLM 解码中切实可行。在生成式与下游任务中，FlexEE 能够在精度下降极小的前提下实现高效提前退出，在 0%/50% 权重卸载下，于 Llama2-7B 和 Llama3-8B 上分别带来最高 1.27×/3.16× 和 1.25×/2.83× 的端到端加速。

## Abstract
Large language model (LLM) inference is often constrained by both computation and memory, especially in offloading-based deployments where model weights are transferred across memory hierarchies during autoregressive decoding. In this setting, reducing the number of executed layers can lower per-token latency while also avoiding costly weight movement. Motivated by this observation, we present FlexEE, an early exiting framework for resource-constrained and offloading-based LLM inference. FlexEE makes early exiting practical for LLM decoding through layer-wise exit supervision for reliable intermediate-layer prediction, self-speculative decoding over a Top-K local vocabulary for low-cost exit decisions, and dynamic hidden state management for KV-cache-correct and memory-aware execution. Across generative and downstream tasks, FlexEE enables efficient early exit with minimal accuracy degradation, delivering up to 1.27$\times$/3.16$\times$ and 1.25$\times$/2.83$\times$ end-to-end speedups on Llama2-7B and Llama3-8B under 0\%/50\% weight offloading, respectively.

# FlexEE 论文中文总结

## 1. 核心问题与研究动机

- **背景**：Transformer 大语言模型（LLM）参数量持续增长，部署时常超出片上内存容量，需将部分层参数卸载（offload）到片外内存按需加载。此时推理瓶颈从计算转向**片外访存**，降低参数加载量与频率成为加速关键。
- **核心洞察**：提前退出（early exiting）通过在中层动态终止计算，减少执行的层数，在卸载式推理中可**同时减少计算与权重搬运**，是缓解数据移动瓶颈的互补范式。
- **三大挑战**（论文图 1a）：
  - **挑战 1（算法层）**：LLM 中间隐状态语义可解码性弱，直接早退会严重损害生成质量。
  - **挑战 2（算法层）**：早退判断需将中间状态投影到全词表空间（如 Llama2 的 32K），矩阵乘开销大、搜索困难，抵消加速收益。
  - **挑战 3（系统层）**：早退破坏自回归解码所需的 KV 缓存构建，后续层缺少 key-value 对；已有状态复制/KV 复制/KV 驱逐方案要么引入额外计算，要么损害语义一致性，且在卸载场景下仍需加载全部剩余层权重。

## 2. 方法论

### 2.1 核心思想
FlexEE 采用**系统–算法协同设计**，把退出行为与内存/执行特征对齐，包含三大组件：逐层退出监督、自推测轻量预测器、动态隐状态管理。

### 2.2 关键技术细节

**(1) 逐层退出监督（Layer-wise Early-Exit Supervision）**
- 训练时把共享 LM head 连接到多个 Transformer 层，用统一语言建模目标对齐中间表示与最终层解码能力，且不引入推理额外开销。
- 目标函数：对第 l 层隐表示 $x_l$ 与共享头 $g(\cdot)$，加权求和各层交叉熵损失
  $$J(X,Y,t)=\sum_{l=0}^{L-1}\tilde{e}(t,l)\,J_{CE}(g(x_{l+1}),Y)$$
  其中 $\tilde e(t,l)$ 为归一化层权重，训练计划逐步把监督从深层移向浅层。
- 效果：显著降低中间层熵与 WikiText PPL，且最终层性能几乎不变（图 3）。

**(2) 退出特征选择**
- 比较 4 类特征：Top Prob、Gap、Top Logit、Prob Shift。
- 用 300K WikiText token 离线推导各层阈值 $\lambda_l^*$（保证满足退出条件的 token 中至少 $\tau$ 比例与最终层预测一致），并计算覆盖率 $r_{\lambda_l}$。
- 结论：**Top Prob 与 Gap** 阈值平滑、覆盖率高、跨模型一致；Top Logit 不稳定，Prob Shift 覆盖率低。

**(3) 自推测轻量预测器**
- 观察到经逐层监督后，最终层 top-1 token 常出现在浅层 Top-N 候选集中；用 $H_l(N)$ 衡量覆盖概率、$E_l(N)$ 衡量局部与全局 top-1 概率偏差。
- 设计：选取某一中间层作为**自推测层**，保留其 Top-K token 构成局部词表（Llama2 取 K=30，Llama3 取 K=80），后续早退层仅在压缩候选集上投影，避免反复全词表矩阵乘。
- 退出判据：局部 top-1 概率与局部 gap 同时超过离线搜索的逐层阈值时退出；阈值在标定集上保证早退准确率 > 0.99。

**(4) 动态隐状态管理（KV 兼容）**
- 当 token 在中间层退出时，**保留该层隐状态**；生成下一 token 时，前向传播到达退出层之后的第一层时，将保留的隐状态与当前 token 表示共同参与计算；该层 KV 缓存更新完成后清除缓存的隐状态以回收内存。
- 优势：无需强制跨层复制 KV 缓存即可保持跨 token 语义连续性；仅在必要时引入额外隐状态参与，避免对所有剩余层做冗余 KV 重建；系统层面**避免加载后续层权重**，契合卸载场景。

**(5) 执行流程（算法 1）**
逐层加载隐状态与 KV → 计算当前层并评估退出判据（同时异步预取下一层权重）→ 存储更新后的隐状态与 KV → 若满足退出则缓存退出隐状态并终止当前 token 解码。

## 6. 主要结论与发现

- FlexEE 在精度几乎无损的前提下实现高效早退，性能与密集解码接近（部分任务甚至更优）。
- **端到端加速**（Alpaca，随卸载比例升高）：

  - Llama2-13B：**1.25×/2.25×/2.67×/2.68×**
  - Llama3-8B：**1.25×/2.18×/2.83×/3.10×**
- 与 HuggingFace 基线相比最高 **1.18×** 吞吐提升，优于 AdaInfer 与 SpecEE。
- 自推测 Top-K 局部词表相较全词表退出，能在更早的层退出且精度相当，预测开销显著更低（FlexEE 额外 FLOPs 仅为 AdaInfer 的约 1/30.74、SpecEE 的约 1/2.52）。
- 动态隐状态管理在长序列生成中 PPL 更低、延迟更小，优于 KV 驱逐/KV 复制/状态复制。
- 退出分布自适应：简单 token 在 8–15 层即退出，困难 token 延后至更深层或最终层。
- 批量推理收益随 batch 增大而减弱，但在小批量（B=1，主流的端侧交互场景）与卸载场景下增益最大。

## 7. 优点

- **系统–算法协同设计**：将早退与权重卸载瓶颈对齐，直接针对数据移动而非仅计算量优化。
- **轻量预测器**：用自推测 Top-K 局部词表替代反复全词表投影，理论计算分析清晰（额外 FLOPs 对比表）。
- **KV 兼容机制创新**：动态隐状态管理避免状态复制/KV 复制的额外层加载，兼顾语义一致性与内存效率。
- **免训练/低侵入**：复用 LayerSkip 监督 checkpoint，阈值离线标定且跨数据集泛化（余弦相似度 0.997–0.999）。
- **评估多维**：兼顾困惑度、下游准确率、开放式生成质量与系统吞吐，跨模型、跨卸载比例验证。
- **工程可落地**：基于 FlexGen/HuggingFace 实现，权重加载与计算异步重叠，隐藏状态开销仅约 0.02 ms/层。

## 8. 不足与局限

- **依赖底层模型质量**：基于带逐层早退监督的预训练模型，效果受基础模型能力制约。
- **适用场景受限**：主要受益于小批量或内存受限的服务场景；批量增大后退出收益明显衰减（异构退出深度降低有效跳层）。
- **卸载比例边际递减**：50%→75% 卸载时增益趋缓，因早退多发生在深层，无法充分利用额外卸载层。
- **训练成本未报告**：未说明监督训练所需算力/时长，复现门槛信息不完整。
- **评测局限**：开放式生成仅 GPT-4 级裁判、规模有限；部分基线在卸载场景下的公平对比可能受影响；未涉及多模态或超长上下文任务。
- **风险继承**：早退可能改变输出分布，继承底层模型的幻觉、偏见、隐私与滥用风险，高风险领域需额外安全措施与任务特定评估。
