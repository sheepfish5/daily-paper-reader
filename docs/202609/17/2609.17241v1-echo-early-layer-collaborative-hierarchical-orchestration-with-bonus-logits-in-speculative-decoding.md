## 摘要
尽管无草稿模型的推测解码为高效 LLM 推理提供了一条有前景的路径，但它常受限于过时的草稿候选以及验证的高计算成本。为解决这些挑战，我们提出 ECHO，一种利用 LLM 各层功能不对称性的分层双循环框架。借助早期层的高判别效率与最终层的权威分布，ECHO 将推理分为高频内循环和低频外循环。在内循环中，早期层的奖励 logits 以极小成本驱动快速的多步草稿树探索。同时，外循环通过状态复用机制执行权威的全模型验证。关键的是，外循环还利用最终层的奖励 logits 来修正现有路径，并为后续循环向树中补充高置信度候选。在多种基准上的实验结果表明，ECHO 显著提升了平均接受 token 数，并实现了 2.4 倍至 2.9 倍的加速，在工程开销可忽略且无需额外部署参数的情况下优于现有最先进基线，尽管为达到最优加速依赖于一次性微调。代码见 https://github.com/whucs21Mzy/ECHO。

## Abstract
While draft-model-free speculative decoding offers a promising path to efficient LLM inference, it is frequently constrained by stale draft candidates and the high computational cost of the verification. To address these challenges, we propose ECHO, a hierarchical dual-loop framework that exploits the functional asymmetry between LLM layers. Leveraging the high discriminative efficiency of early layers and the authoritative distribution of final layers, ECHO bifurcates inference into a high-frequency inner loop and a low-frequency outer loop. Within the inner loop, early-layer bonus logits drive rapid, multi-step draft-tree exploration at a minimal cost. Simultaneously, the outer loop performs authoritative full-model verification through a state-reuse mechanism. Crucially, the outer loop also utilizes final-layer bonus logits to correct existing paths and supplement the tree with high-confidence candidates for subsequent cycles. Experimental results across diverse benchmarks demonstrate that ECHO significantly boosts mean accepted tokens and achieves a 2.4$\times$ to 2.9$\times$ speedup, outperforming existing state-of-the-art baselines with negligible engineering overhead and no extra deployment parameters, albeit with a one-shot fine-tuning dependency for optimal acceleration. The code is available at https://github.com/whucs21Mzy/ECHO.

## 一、核心问题与研究动机

- **背景瓶颈**：大模型自回归解码受限于顺序生成的内存带宽瓶颈，推理延迟高。推测解码（Speculative Decoding）通过"先草稿、后并行验证"实现无损加速，但存在两条路线各自的困境。
- **基于草稿模型的路线**：需引入辅助 drafter 模型，带来额外计算与显存开销，并存在分布不对齐问题；Medusa、Eagle3 等直接改动目标架构，进一步增加部署参数。
- **无草稿模型路线（draft-model-free）**：
  - 检索式（PLD、REST、后缀数组/树/自动机）依赖表层 n-gram 精确匹配，无法泛化到新语义语境。
  - Logits 式（TokenRecycling、LogitSpec）复用输出分布，但存在**时效性悖论**：草稿信息来自最后一层，必须完成一次完整前向才能刷新，导致草稿信息密度低、候选陈旧，平均接受长度受限。
- **验证墙（Verification Wall）**：标准验证中每个草稿树/序列都必须完整穿越整个目标模型；草稿质量波动时加速比在不同任务间剧烈震荡。
- **自推测解码（Self-SD、LayerSkip、Kangaroo）**：虽用早期层做草稿，但需多次穿越 Transformer 块，草稿开销大，实际加速比不佳。
- **关键观察（Figure 1 信息衰减分析）**：现有无草稿方法在超过前几个 token 后草稿接受率急剧下滑；"上下文+末层 logits"初期精度高但深层迅速退化；早退方法虽质量稳定却开销大。
- **整体含义**：ECHO 主张利用 LLM 各层的**功能不对称性**（早期层判别效率高、末层分布权威），将推理解耦为高频内循环与低频外循环，在不增加部署参数的前提下同时缓解"草稿陈旧"与"验证墙"两大问题。

## 二、方法论

### 1. 核心思想
- 将目标模型 M 在层 $L_e$ 处切分为**敏捷早期层验证器 $V_e$（1~$L_e$）**与**权威后续层验证器 $V_s$（$L_e{+}1$~$L$）**。
- 双循环结构：内循环用早期层做高频草稿树构建与验证；外循环用完整模型做低频权威验证，并通过**状态复用**跳过前 $L_e$ 层。
- 通过算子复合恒等式 $M(X) \equiv V_s(V_e(X))$ 保证分层不改变数学输出。

### 2. 分层验证（Hierarchical Verification）
- **Phase 1 早期层树验证**：将候选组织为分支树 $T$，用 tree attention 并行验证。
  - 退出层隐状态：$H^{(L_e)} = V_e(X_T, M_{tree}, P_{tree})$
  - 位置编码：$P_{tree} = L_{curr} + \text{depth}(T)$
  - 树掩码：$M_{tree}(i,j)=0$ 当 $j \in \text{ancestors}(i)\cup\{i\}$，否则 $-\infty$，确保子节点只关注自身祖先路径，隔离不同语义分支。
  - 迭代 T 次至阈值，得到累积序列 $S_{acc}$ 与隐状态 $H^{(L_e)}_{acc}$。
- **Phase 2 后续层因果验证**：$Y^{(L)} = V_s(H^{(L_e)}_{acc}, M_{causal}, P_{linear})$，直接复用中间隐状态与 KV 缓存，跳过前 $L_e$ 层，减少显存带宽与 FLOPs。
- **无损性**：最终 logits $p_i$ 与标准前向完全一致，配合拒绝采样可保证输出严格服从目标分布 $P(x_i|x_{<i})$。
- **增量自动机更新**：基于 trie 的参考自动机 $R$ 在每次验证后被更新，插入已验证的 n-gram 转移。
- 附录给出**树注意力不变性证明**（TreeAttn ≡ CausalAttn on path）与**分布对齐证明**（$P_{total}(x)=\min(P,q)+\max(0,P-q)\equiv P(x)$）。

### 3. 非对称奖励 Logits（Asymmetric Bonus Logits）
- 定义：验证器在最后一个被接受/纠正 token 处产生的预测分布 $p_j$，无需额外推理成本即可回收为下一轮草稿的锚点。
- **早期层奖励 Logits $\hat{p}^{(L_e)}$**：深度低、成本低、频率高，提供适配局部语境的语义引导。
- **末层奖励 Logits $p^{(L)}$**：全参数精度，作为高保真锚点，尤其在验证失败后修正路径、补充高置信候选。
- 两者的 top-1 token 均作为下一轮草稿树的根节点，保证推测始终从已验证或高置信分布出发。

### 4. 混合草稿树构建
- $T = \text{MATCH}(R, q) \cup \text{Top-}k(p_t)$：融合检索式历史经验（自动机）与 logits 式语义直觉。
- 内循环中早期层同时充当草稿源与验证器，反复强化 LRU 自动机的高概率轨迹，生成高质量多分支草稿树。

### 5. 推理流水线（Algorithm 1）
- **Phase I 上下文初始化**：对 prompt 做一次完整前向，填充全局 KV 缓存，生成首个 Oracle Bonus logits $p^{(L)}$，初始化自动机 $R$。
- **Phase II 敏捷探索（内循环）**：以最新 bonus logits 为根构建混合草稿树，$V_e$ 用 tree attention 验证；被接受的 token 立即写入 $R$；循环直到缓冲区达到阈值 $N_{thr}$。
- **Phase III 权威对齐（外循环）**：同步 KV 缓存与隐状态后，$V_s$ 对累积序列做因果验证，输出最终 Oracle bonus logits 并高保真更新自动机；若出现"认知分歧"（最终接受序列短于缓冲），则回滚 KV 缓存到 Oracle 决策位置重新对齐。
- **状态复用桥（State-reuse Bridge）**：仅传输单层 $L_e$ 的中间隐状态，配合简单的序列级 KV 回滚机制，同步开销极低。
