## 摘要
块量化（BQ）是大语言模型（LLM）高效部署的一种有前景的方法，能够在控制精度损失的同时实现低精度计算。与标量权重仅量化（WoQ）相比，BQ同时对权重和激活进行量化，在统一数据通路上提供更高的硬件效率和端到端推理，但其设计空间（涵盖位宽、块大小、缩放和数值格式）仍未得到充分探索。我们通过设计空间探索（DSE）提供了硬件/基准测试结果。我们发现，增大块大小可通过分摊反量化和累加成本来提高硬件效率，但会降低精度。这一权衡限制了传统BQ方法。基于这一洞察，我们提出了层次化块量化（HBQ）。与先前使用小块和传统2的幂（PoT）或基于整数的缩放方法[1]、[2]不同，HBQ使用大块以最大化效率，并引入低开销的有效数（SIG）缩放用于第二级量化。通过有效分配量化级别并考虑激活与权重的不同分布，SIG缩放比先前的PoT和INT方案更有效地补偿了大块误差。HBQ-A（精确型）在使用W4A5的情况下达到W4A16级别的精度，同时所需硅面积小于NVFP4。HBQ-E（高效型）进一步将硬件成本降低17%，同时保持比所有现有BQ方法更高的精度。我们实现了一款28nm ASIC加速器，将HBQ应用于权重、激活和KV缓存，并集成了一种新的部分和BQ方案以进一步降低EMA能耗。与最先进的WoQ相比，HBQ在相同精度水平下实现了2.3倍/4.6倍的面积/能效提升；与先前BQ方法相比，实现了1.6–3.3倍的系统能耗降低和1.5–3.0倍的加速，同时提供了最佳精度。

## Abstract
Block Quantization (BQ) is a promising approach for efficient deployment of large language models (LLMs), enabling low-precision computation with controlled accuracy degradation. Compared to scalar weight-only quantization (WoQ), BQ quantizes both weight and activation, offering higher hardware efficiency and end-to-end inference on a unified datapath, but its design space, spanning bit-width, block size, scaling, and numeric formats, remains underexplored.   We provide hardware/benchmark results through design space exploration (DSE). We find that increasing block size improves hardware efficiency by amortizing dequantization and accumulation costs, but degrades accuracy. This trade-off limits conventional BQ methods.   Motivated by this insight, we propose Hierarchical Block Quantization (HBQ). Unlike prior methods [1], [2], which use small blocks and conventional Power-of-Two (PoT) or integer-based scaling, HBQ uses large blocks to maximize efficiency and introduces low-overhead significand (SIG) scaling for second-level quantization. By allocating quantization levels effectively and accounting for distinct activation and weight distributions, SIG scaling compensates for large-block errors more effectively than prior PoT and INT schemes. HBQ-A (accurate) achieves W4A16-level accuracy using only W4A5 while requiring less silicon area than NVFP4. HBQ-E (efficient) further reduces hardware cost by 17% while maintaining higher accuracy than all existing BQ methods.   We implemented a 28nm ASIC accelerator applying HBQ to weights, activations, and KV cache, and integrated a novel partial-sum BQ scheme to further reduce EMA energy.   Compared to state-of-the-art WoQ, HBQ delivers $2.3\times$/$4.6\times$ higher area/energy efficiency at the same accuracy level; $1.6$--$3.3\times$ system energy reduction and $1.5$--$3.0\times$ speedup over prior BQ methods while providing best accuracy.

## 1. 核心问题与整体含义

- **背景与动机**：大语言模型（LLM）部署需要兼顾精度与效率。当前主流量化路线分为两类：
  - **权重仅量化（WoQ）**（如 AWQ、AxCore）：精度高，但注意力部分仍需全精度数据通路，难以实现统一的低精度端到端推理。
  - **块量化（BQ）**（如 NVFP4、MXFP4）：同时量化权重与激活，可在统一硬件上完成端到端推理，硬件效率高，但精度有损。
- **核心问题**：BQ 的设计空间（位宽、块大小、缩放格式、数值格式）此前未被系统探索，其精度-效率 Pareto 前沿不清楚；同时 BQ 存在一个内在矛盾：**增大块大小可显著提升硬件效率（分摊反量化与累加成本），但会明显降低精度**。
- **论文含义**：作者通过设计空间探索（DSE）找到更优的 BQ 配置，并提出 **HBQ（Hierarchical Block Quantization）**，首次以 W4A5 精度达到 WoQ（W4A16）级别准确率，同时保持 BQ 的高硬件效率，实现"WoQ 的精度 + BQ 的效率"。

## 2. 方法论

- **Design Space Exploration (DSE)**：在统一 PE 硬件基线上评估不同方案（TSMC 28nm 综合）。
  - **缩放方案**：FP8-scale 相比 PoT（Power-of-Two）scale 精度显著更好，且块增大后硬件开销可摊销，故采用 FP8-scale（格式 `ue5m3`）。
  - **元素格式**：块内数据动态范围窄，高指数位浪费。综合精度与硬件成本，**2 位指数 FP（E2Mx）最优**，优于 INT8 与 E4M3/E5M2。
  - **位宽**：A4→A5 精度提升大，A5→A8 提升有限，**W4A5 是最优工作点**。
  - **块大小**：块越大硬件效率越高（B≥32 增益明显），但精度下降——NVFP4、MXFP4 采用小块的根源即在此。
- **HBQ 的核心思想**：用大块（L1 块 B=128）保证硬件效率，再用**第二级量化（micro-block）**恢复大块造成的精度损失。
- **误差分布分析**（关键动机）：
  - 块从 B16 扩大到 B128 时，**权重的误差集中在高幅值区**（需要更密集的量化级别）；
  - **激活与 KV cache 的误差主要来自小幅度元素**（需要更宽的动态范围覆盖）。
- **Significand Scaling (SIG)**：提出有效数缩放，二级缩放因子为：
  - `α(c) = 1 + c/2^x`，c 为 2-bit 编码，x 为粒度控制参数；
  - 权重选用 **SIG2/SIG3 按块离线混合（1-bit 选择器，无需校准）**，激活选 **SIG1**；
  - 相比 PoT/INT scale，SIG 不引入重叠量化区间，在 B=128 下把 MSE 恢复到 B16 甚至更低水平。
- **HBQ 配置**：
  - **HBQ-A（accurate）**：B=128/μB=8，W4A5，PPL 与 AWQ (W4A16) 持平；
  - **HBQ-E（efficient）**：B=128/μB=32，面积更小，仍优于现有 BQ。

## 9. 潜在争议点与需谨慎解读之处

- **“无需校准”的范围表述易被过度解读**：HBQ 的权重侧 SIG`混合由离线统计决策（按误差或分布特性）完成，确实不需要前向校准数据；但这种元决策本身仍可能依赖一定启发式规则。训练集上的泛化性和不同领域的适用性，论文没有给出压力测试。
- **W4A5 的“5-bit 激活”实际硬件价值**：A5 在真实 PE 中通常需要补齐到 8-bit 对齐或做非标准位宽乘法，尾数 5-bit 的 MAC 未必能直接取得理论宣称的完全面积/能耗优势。作者在硬件上提到使用 E2M3（尾数 3-bit）作为 A5 载体，缓解了一部分对齐问题，但 bit-serial / bit-parallel 混合实现的实际收益仍存在工程化折扣。
- **精度指标选择与极端值掩盖**：部分表格中零样本任务平均分差较小（0.1–0.5），在统计显著性未被报告的情况下，宣称“持平 W4A16”可能过度依赖 PPL 单一指标；代码与数学任务上差距虽然大致稳定，但样本量少（如 HumanEval 仅 164 题）时，可靠区间较宽。
- **“B=128 + SIG”的价值主张对算子的依赖**：线性层（GEMM）上大块收益明显，但对 vector 类算子（RMSNorm、激活、RoPE），大块量化的精度损伤修复更多依赖激活侧 SIG1。论文对这类算子单独讨论较少，整体推理流程中这些部分仍按小 block 或逐元素处理，需要在最终系统对比中进一步透明化。

## 10. 可复现性、实现复杂度与部署适配

- **公式与细节披露度**：SIG 的编码规律（`1 + c/2^x`）、`x` 的取值与选择策略、L1/L2 块数据结构（缩放因子存储位置、与 FP8-scale 的结合方式）在正文与附录中有相应描述，具备中等可复现性；但部分消融（如 c 为 2-bit 时候选缩放值数量对结果的影响曲线）未披露完整。
- **端到端系统重构难度**：HBQ 的精度增益依赖第二级缩放与主缩放联合的反量化顺序。如果目标硬件为现有 GPU 上的 kernel 级实现（而非 ASIC），其 L1=128 块 + 微块二级缩放的访存模式可能带来额外的寄存器/共享内存开销；论文未提供 GPU 部署实验（如 Triton/CUDA kernel 实测），对软件侧读者而言，落地可行性验证尚浅。
- **与主流推理框架的对接**：未讨论与 vLLM、TensorRT-LLM、llama.cpp 等框架的算子映射或 kernel 融合路径，也未讨论 MXFP4 所依托的 OCP 标准生态兼容性——这会影响社区采用速度。

## 11. 对该领域的影响与定位评价

- **方法定位清晰**：HBQ 并非对 LLM 数值格式做一次小修小补，而是把“块大小选择”从一个纯精度问题，重构为一个 **两级精度—硬件协作设计问题**，给出了一条与 NVFP4/MXFP4 差异化的新型量化结构。这对后继工作有启示：**逐 block 统一缩放并不必然是最优结构**。
- **明确把“KV cache 量化”和“部分和量化”纳入统一 BQ 框架**：相比仅关注权重的 WoQ 或仅关注 GEMM 的 BQ，HBQ 提供了一个更完整的端到端低精度数据通路方案，这符合服务端推理、长上下文与大批次生成的现实瓶颈。
- **被引与延伸的潜在方向**：① 将 SIG 的“主+辅双块缩放”推广到专家模型（如 MoE）的动态块选择；② 学习式二级缩放因子分配（将基于误差的离线启发式改为端到端可微优化）；③ 在更大的基座模型（≥100B）和视觉-语言模型上扩展验证；④ 与投机解码/推测量化等推理优化做组合。

## 12. 总结评价（一句话）

HBQ 以系统化的硬件-算法协同探索为基础，通过在“大块”之上引入低开销的二级 SIG 量化，同时优化了块量化在精度与效率上不可兼得的瓶颈，并以扎实的 28nm ASIC 评估与多模型多任务验证支撑“WoQ 级精度、BQ 级效率”的核心主张，是该领域一篇方法完整、证据链清晰的高质量工作；但在基线公平性、更大模型与 GPU 端到端可行性上仍留有验证空间。
