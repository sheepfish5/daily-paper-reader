## 摘要
基于Transformer的大型语言模型（LLM）推理通常受限于内存受限的KV缓存和二次方注意力成本。状态空间模型（SSM）通过线性注意力和固定大小的循环状态缓解了这一问题，但其大规模密集线性投影即使在量化后仍计算开销巨大。我们提出了一种方法，在重度量化的线性注意力模型中诱导稀疏神经活动，同时将性能损失降至最低。低于每投影可训练阈值（$\pm Δ$）的激活被置零，同时保留关键离群值，实现了与密集模型相当的性能，而有效算术运算最多减少4倍。针对多核、多芯片神经形态平台，其中事件驱动执行将非结构化稀疏性在计算和通信层面转化为吞吐量（这是GPU架构根本缺乏的能力），我们预测与可比Transformer模型在边缘GPU上的推理相比，吞吐量最高提升37倍，功耗降低16倍，且相比非稀疏化基线最高提升5.4倍。这些结果将稀疏、量化线性注意力模型定位为在事件驱动多核平台上部署LLM的自然选择。

## Abstract
Inference with transformer-based large language models (LLMs) is often limited by the memory-bound KV cache and quadratic attention cost. State-space models (SSMs) mitigate this through linear attention and fixed-size recurrent states, but their large dense linear projections remain computationally expensive even after quantization. We introduce a method that induces sparse neural activity in heavily quantized linear-attention models with minimal performance loss. Activations below a per-projection trainable threshold ($\pm Δ$) are nullified while preserving crucial outliers, achieving comparable performance to dense models with up to 4$\times$ fewer effective arithmetic operations. Targeting a multi-core, multi-chip neuromorphic platform, where event-driven execution converts unstructured sparsity into throughput at both the compute and communication levels, a capability GPU architectures fundamentally lack, we project up to 37$\times$ higher throughput and 16$\times$ lower power versus edge GPU inference of a comparable transformer-based model, and up to 5.4$\times$ improvements over the non-sparsified baseline. These results position sparse, quantized linear-attention models as a natural fit for deploying LLMs on event-driven multi-core platforms.

## 1. 论文的核心问题与整体含义（研究动机与背景）

- **核心矛盾**：Transformer 架构的 LLM 推理受限于 **KV cache 的内存瓶颈** 和 **注意力机制的二次方计算复杂度**。即使状态空间模型（SSM）和线性注意力模型通过固定尺寸循环状态解决了注意力复杂度问题，其**大量密集线性投影层**在边缘设备上的计算与访存开销依然过高。
- **激活稀疏性的潜力与障碍**：从神经科学和硬件角度，激活稀疏性允许跳过激活值为 0 时对应的权重行访问，从而同时减少乘加运算和内存读取。然而，早期方法存在三类问题：
  1. 传统 Transformer 中自注意力本身是主要瓶颈，掩盖了线性层稀疏化的收益；
  2. 现有稀疏化方法往往只实现局部（如 FFN 某一部分）而非模型级的高稀疏度；
  3. GPU 的 HBM 和锁步执行架构不擅长利用非结构化稀疏性，不规则内存访问会吞噬收益。
- **作者的核心主张**：将**极端量化（三值权重 + 8-bit 激活）的线性注意力模型 MMFreeLM（MatMul-Free LM）** 与**可学习的激活稀疏化方法**结合，部署到 **事件驱动的多核/多芯片神经形态芯片（Loihi 2）** 上。事件驱动硬件既能在片内跳过零激活运算，又能在片间只传输非零事件包，从而把模型中的非结构化动态稀疏性转化为实际吞吐与能效收益。
- **整体意义**：该工作首次在「事件驱动神经形态多芯片平台 + 亿级参数 LLM」这一组合上系统论证了稀疏化线性注意力模型的适配性，为边缘端 LLM 推理提供了一条 GPU 之外的高能效路径。

## 2. 论文提出的方法论

### 2.1 模型基础与目标
- 以 **MMFreeLM（370M 和 2.7B 参数）** 为研究对象，其使用三值权重（−1, 0, +1）和 8-bit 定点激活，并用 MLGRU（无乘法线性门控循环单元）替代 Transformer 自注意力。
- 目标是：在保持量化模型任务性能基本不变的前提下，尽可能提高各线性投影层输入的激活稀疏率，从而降低有效 MAC 数。

### 2.2 敏感性分析（动机驱动研究）
- 对预训练 MMFreeLM 按「逐投影类型」和「逐层」强制施加 top-k 激活稀疏，测量损失上升。
- 主要发现：
  - **LM Head** 和负责隐藏状态转移的投影（I、F）对稀疏性高度敏感；
  - FFN 中较大的 **Down 投影** 对稀疏性容忍度最高；
  - 层级别上，首层、末层和某些中间层具有峰值敏感性，中间层冗余度较高，这与部分 Transformer 研究一致。
- 该分析用于指导稀疏化设计（哪些投影可以更激进地稀疏化，哪些必须保守）。

### 2.3 核心方法：可学习稀疏预激活（learnable sparsifying pre-activation）
- **前向函数（公式 1）**：

  \[
  x_{\text{sparse}} = \operatorname{sign}(x)\cdot \operatorname{ReLU}(|x|-\Delta)
  \]

  即在每个线性投影的输入前，将绝对值小于 ±Δ 的激活**整体置零**，仅保留绝对值大于 Δ 的正负“离群值”。Δ 作为**每个投影独立的可学习参数**，在训练中更新。
- **反向替代梯度（公式 2）**：

  \[
  \frac{dx_{\text{sparse}}}{dx_{\text{smooth}}} = \sigma\big(C(|x|-\Delta)\big)
  \]

  由于硬阈值函数的梯度几乎处处为 0 或非连续，作者使用一个以 Δ 为中心的平滑 Sigmoid 作为替代梯度，保持近零激活区域也能获得梯度。斜率参数 C 设为 20。文中说明，这种平滑替代类似于 SiLU 的平滑特性，比硬阈值在较高稀疏度下收敛更好。
- **损失函数（公式 3）**：

  \[
  L = L_{\text{task}} + \lambda(1-\hat{s}),\quad
  \hat{s} = \frac{1}{N}\sum_{i=1}^{N}\exp(-k|x_{q\text{-sparse},i}|)
  \]

  其中 \(\hat{s}\) 是可微的“稀疏度代理”（用指数函数连续近似零激活占比），k = 10；λ 控制稀疏化强度，按层加权（稀疏化某层带来的 MAC 减少越大，其惩罚权重相应越大）。
- **训练策略**：对已预训练的 MMFreeLM 继续训练。λ 从 0 开始**线性 warm-up**（占总训练步数的 5%），防止在模型还没学到关键特征时过度稀疏化。采用余弦学习率，初始学习率调低以保留原有预训练表示。
- **与现有方法的对比**：
  - ReLU-fication / dReLU 仅在 FFN 的特定位置（如 Down 投影输入）产生高稀疏度，模型整体活动参数占比仍然较低；
  - Q-Sparse 需逐 token 排序找 top-K，引入同步开销，不适合多核分布式部署；
  - 本文方法**逐投影独立**、无需跨层同步、纯局部阈值判断，可自然映射到事件驱动硬件的逐核执行。
- **硬件性能建模（用于估算加速）**：
  - 有效 MAC 密度 \(r = \text{MAC}_{\text{sparse}} / \text{MAC}_{\text{dense}}\)；
  - 片间通信惩罚因子 \(S_{\text{comm}}(\rho_{\text{com}}) = 1/(0.8+0.2\rho_{\text{com}})\)，基于 Loihi 2 多芯片通信开销约削减 20% 的实测结论推导出与激活密度线性相关的抑制模型；
  - 片内 MAC 密度加速因子 \(S_{\text{MAC}}(r)=1/r\)；
  - **Prefill（流水线模式）** 由最慢 block 决定吞吐，使用最大 MAC 密度 \(r_{\max}\) 计算；
  - **Generate（fall-through 模式）** 逐层顺序处理，使用平均 MAC 密度 \(r_{\text{avg}}\) 计算。

## 6. 主要结论与发现

1. **稀疏化效果显著**：在 370M MMFreeLM 上，本文方法（λ=2）实现 **80.1% 的激活稀疏率 / 76.2% 的有效 MAC 数减少**（即 MAC 数降至约 1/4），平均零样本准确率仅比密集基线低约 2.14%（41.88 → 39.74）。λ=1 时稀疏率 69.5%（MAC 减少 64.3%），平均准确率几乎持平（41.24 vs 41.88）。
2. **相比同类方法更优**：在相近或更低 MAC 预算下，本文 λ=1 模型的平均准确率（41.24）高于 dReLU 模型（40.25），且 MAC 数低一半（118M vs 263M）。
3. **优于“只稀疏 FFN”的策略**：ReLU/dReLU 虽然在下投影处达到 87–93% 稀疏率，但模型级 MAC 稀疏率仅约 22–23%，远低于本文方法。
4. **事件驱动硬件能放大稀疏性收益**：
   - 将稀疏 370M MMFreeLM 部署到 Loihi 2（估算）：
     - Prefill：吞吐/能效提升 **3.5×** vs 密集 MMFreeLM；
     - Generate：吞吐/能效提升 **5.4×** vs 密集 MMFreeLM；
     - 与边缘 GPU（Jetson）上同等能力的 Transformer 类模型相比，Generate 阶段吞吐提升最高 **37×**，每 token 能耗降低最高 **16×**。
   - 关键因素：Loihi 2 支持事件驱动、零跳过、片间只发送非零数据包，而 GPU 无法有效利用非结构化稀疏性。
5. **通用性结论**：稀疏化+极端量化+线性循环模型是事件驱动多核神经形态硬件部署 LLM 的天然组合；本文的方法能实现模型级而非局部级稀疏性，且不需要 top-k 排序等同步操作。

## 7. 优点：方法与实验设计中的亮点

- **方法轻量化且硬件友好**：
  - 阈值 Δ 是逐投影的标量可学习参数，前向只需一次绝对值和减法比较，几乎无额外计算开销；
  - 反向使用平滑 Sigmoid 替代梯度，避免了硬阈值导致的梯度消失/死亡神经元问题；
  - 无需跨通道排序与同步（区别于 Q-Sparse 等 top-k 方法），天然适配多核分布式异步执行；
- **保留了正负离群激活**，避免破坏 LLM 中已被证明至关重要的 outlier 信息，这是能维持任务性能的重要原因；
- **敏感性分析完善**：用逐投影/逐层强制稀疏度+损失上升数据来决定哪些层/投影应该被更小心地稀疏化，使方法设计具有可解释性；
- **硬件建模逻辑闭环**：同时考虑片内零跳过和片间通信压缩两个层面，分别公式化，再与已有实测 dense 基线相乘；区分 prefill（流水线瓶颈=最大 MAC 密度）和 generate（顺序延迟=平均 MAC 密度），体现了对神经形态执行模式的准确理解；
- **对比体系有说服力**：包括「相同硬件上的 dense vs sparse」，「相同模型不同稀疏化策略」，「边缘 GPU/服务器 GPU vs 神经形态」多层对照，证伪了“稀疏性只应在 FFN 局部使用”的既有假设。

- **训练 / 算力细节缺失**：未说明 GPU 型号、卡数、训练时间、batch size、学习率具体值（只提“降低初始值”），不利于复现和成本评估。
- **硬件结果属于推算而非实测**：作者明确使用模型公式来“project”稀疏 Loihi 2 性能，严格来说需要真实多芯片部署来验证。估算依赖于：(a) Loihi 2 dense 基线数据来自[26]；(b) 通信惩罚假设与输入激活密度线性相关；(c) 每 block 延迟与 MAC 密度线性相关。这些假设在真实芯片上可能受存储竞争、流水线气泡、事件包开销等影响而偏离。
- **数据集覆盖有限**：只用了英语常识推理任务（约 6 个小数据集），平均准确率本身波动较大（各任务间差异明显，如 HellaSwag 与 OpenBookQA 的分数相差较大），未报告方差或显著性检验；缺乏对长序列、多轮对话、指令遵循、事实验证等更贴近真实 LLM 应用的评估。
- **量化与稀疏化的相互作用未充分分析**：MMFreeLM 本来就是 8-bit 定点激活，基线已存在 10% 左右的“天然稀疏”来自量化导致的零值；稀疏化方法如何与量化误差交互、在更高比特精度（如 16-bit）下效果是否会改变，论文没有讨论。
- **大型模型结果较少**：2.7B 模型只展示了一种 λ 设置，且没有与 ReLU/dReLU 对比；370M 模型仍是 Loihi 2 实际可承载的主要参考。缺少 7B 级别或更大模型的扩展趋势分析。
- **后训练副作用**：论文使用了“继续训练 + 稀疏正则”的方式，但未报告在该 4B tokens 数据上继续训练是否会普遍提高或降低原本模型的能力；缺少“仅继续训练不施加稀疏化”的单独对照，因此在判断“性能损失来自稀疏化还是来自分布漂移”时，因果性不够强（文中提到有 continued-training baseline，但表 III 中没有列出该数据）。
- **多芯片扩展的通用性局限**：性能模型主要基于 Loihi 2 的特定工作模式和通信机制；对其他多核神经形态芯片（如 Intel 之外的 SNN 芯片）的结论不一定成立。GPU 对比中也只考虑了边缘 GPU（Jetson），未与定制稀疏 ASIC（如 SCNN/Eyeriss v2）直接对比。
