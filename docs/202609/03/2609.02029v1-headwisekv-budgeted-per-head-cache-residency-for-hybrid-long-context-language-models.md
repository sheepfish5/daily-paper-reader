## 摘要
长上下文推理在解码过程中会保留不断增长的键值（KV）缓存，这消耗大量GPU内存并可能降低生成吞吐量。这一瓶颈在混合语言模型中依然存在，因为其残留的全局注意力层可能主导与上下文相关的缓存需求。我们研究如何在总KV驻留预算下分配这种状态。我们引入HeadWiseKV，一种无需训练的框架，用于压缩混合语言模型的残留全局KV缓存，同时保留其原生的局部、循环和线性路径。它为每个物理KV头分配一个静态的多级历史窗口，使缓存需求在服务前即可预测。我们将此分配问题表述为一个受限的操作率失真问题，并提出SeqCalib作为HeadWiseKV中的核心策略生成算法。SeqCalib按执行顺序处理层，并根据部署时使用的较低层策略来调节每个决策，从而考虑跨深度的交互。分组缓存运行时将所选策略实现为实际的每头KV驻留，而不是完整缓存上的掩码。我们在四个混合长上下文模型上评估下游质量，并在Qwen3.6-27B上研究物理驻留和服务行为。HeadWiseKV在评估的模型中保持了接近全KV的RULER和LoCoMo质量。在固定模型系统研究中，它在112K上下文长度下将采样峰值设备内存降低了8.59%，并将最大的已验证成功上下文从114K扩展到161K。

## Abstract
Long-context inference retains a growing key--value (KV) cache during decoding, which consumes substantial GPU memory and can reduce generation throughput. This bottleneck remains in hybrid language models because their residual global-attention layers can dominate context-dependent cache demand. We study how to allocate this state under an aggregate KV-residency budget. We introduce HeadWiseKV, a training-free framework that compresses the residual global KV caches of hybrid language models while preserving their native local, recurrent, and linear paths. It assigns each physical KV head a static, multilevel history window, making cache demand predictable before serving. We formulate this allocation as a restricted operational rate--distortion problem and propose SeqCalib as the core policy-generation algorithm in HeadWiseKV. SeqCalib processes layers in execution order and conditions each decision on the lower-layer policy used at deployment, thereby accounting for interactions across depth. A grouped-cache runtime materializes the selected policy as actual per-head KV residency rather than a mask over a full cache. We evaluate downstream quality across four hybrid long-context models and study physical residency and serving behavior on Qwen3.6-27B. HeadWiseKV retains near-Full-KV RULER and LoCoMo quality across the evaluated models. In the fixed-model systems study, it reduces sampled peak device memory by 8.59\% at a 112K context length and extends the largest verified successful context from 114K to 161K.

## 1. 核心问题与整体含义（研究动机）

- **问题背景**：在长上下文自回归推理中，每个全注意力层都会为每个已缓存 token 存储 Key 和 Value 向量，形成随上下文长度及并发度增长的 KV 缓存，从而耗尽设备显存并降低生成吞吐量。
- **混合模型的残余瓶颈**：尽管混合语言模型（如 Gemma 3 的“全局+局部滑动窗口”设计、Qwen3-Next/Qwen3.6 的“全局+循环 Gated-DeltaNet”设计）通过引入局部或循环路径缓解了 KV 缓存压力，但其中残留的全局注意力层仍会保留随输入长度线性增长的历史，因此混合化只是转移了瓶颈位置，而非消除瓶颈——少数全局层即可决定一个长请求能否装入显存。
- **现有方法的局限**：
  - 依赖提示词（prompt-dependent）的方法（如 Ada-KV、HeadKV、KV-Compress 等）能保留对特定查询重要但孤立的远端证据，但它们的系统收益依赖运行时实现：逻辑稀疏掩码未必减少物理显存；在线打分、索引、KV 搬迁会带来请求期开销；先构建完整缓存再压缩的方法无法降低 prefill 阶段的内存峰值。
  - 静态方法（如 StreamingLLM、DuoAttention 等）把分配决策提前到请求之前，内存可预测且免去请求期选择开销，但多为“全历史 vs 压缩/流式”的二元切分，粒度过粗——混合模型中不同残差全局头所需的历史长度差异很大，统一的窗口会在可容忍压缩的头上浪费显存、在敏感头上过早截断。
- **跨层校准问题（depth calibration）**：截断浅层缓存会改变深层所消费的表示；若深层策略基于“所有浅层都是全量历史”的前提来标定，部署后会失效。因此可部署的静态策略必须在低层策略既定的前提条件下进行逐层标定。
- **核心目标**：在给定的总 KV 驻留预算下，为每个物理 KV 头离线选定一个静态的、多级的历史长度窗口，使缓存需求在服务前即可预测，并将策略直接落实为实际物理驻留，从而在不牺牲下游长上下文质量的前提下提高显存效率和可服务上下文长度。

## 2. 方法论

### 2.1 总体结构
HeadWiseKV 采用“离线到在线”三阶段流水线：

1. **结构化驻留模型（Structured Residency Model）**：定义候选窗口的取值与存储成本；
2. **SeqCalib 前缀条件化校准**：离线生成按层条件化的静态分配策略；
3. **分组缓存运行时（Grouped-Cache Runtime）**：将策略矩阵加载一次并落实为真实的物理显存布局。

整个过程无需重训练、无需修改模型架构。

### 2.2 结构化驻留模型

- 决策单元是**物理 KV 头**（而非 query 头）。对于 GQA，同一 KV 头组的所有 query 头共享同一分配。记决策单元集为 \(U = \{(\ell,h)\}\)。
- 每个决策单元分配一个窗口长度 \(a_{\ell h} \in W = \{w_1,\dots,w_K,\text{full}\}\)，如 W = {8K, 16K, 32K, full}。窗口的含义是保留从当前位置往前的最近历史。
- 保留成本模型：
  - 上下文长度为 C 时，\(r_C(w) = \min(w, C)\)，full 保留全部 C 个 token。
  - 结合每头的 key/value 维度及 KV 缓存精度，定义名义存储 \(n_{\ell h,C}(w)\) 与策略总成本 \(N_C(a)\)。
  - 归一化驻留率 \(R_C(a) = N_C(a)/N_C(a_F)\)（相对全满策略的存储比例）。
- 理想目标形式化为受限操作率失真问题：
  \[
  D^*_{C,P_C,p_{KV}}(\beta) = \min_{a: R_C(a)\le\beta} \mathbb{E}_{x\sim P_C}[\delta_{C,p_{KV}}(a,x)]
  \]
  由于搜索空间含 \((K+1)^{|U|}\) 个策略矩阵且需端到端评估，直接优化不可行，因此引入 SeqCalib。

### 2.3 SeqCalib：顺序前缀条件化校准（核心）

- **思想**：逐层（按执行顺序）处理，每层决策都依赖已经冻结的低层策略（即“部署时实际生效的前缀”）。
- **算法流程**（以 layer ℓ 为例）：
  1. 运行冻结的已确定低层前缀策略 \(a_{<\ell}\)；
  2. 以全局注意力层 ℓ 的全量历史模式 trace 一次，得到 post-transform 的 Q/K/V 张量；
  3. 从同一 trace 中重放（replay）每个候选窗口 w，并重新归一化注意力权重、计算 attention 输出；
  4. 对每个候选 w，计算该输出与“条件全满历史参考输出”之间的**平均余弦相似度**（在多个校准样本、采样位置和 GQA 组内 query 头上取平均）；
  5. 选择能通过相似度阈值 \(\tau\) 的最低成本窗口。
- 目标选择的候选满足：
  \[
  \hat a_{\ell h,\tau} \in \arg\min_{w\in W} \{n_{\ell h,C}(w) : \hat S_{\ell h}(w \mid \hat a_{<\ell,\tau}) \ge \tau\}
  \]
  由于 full 始终在 W 中，每一阶段都可行。\(\prec_W\) 用于相等成本时的确定性 tie-break。
- **保证与性质**：给定已确定的低层前缀后，每个层的选择是“stage-wise（逐层）最小成本”的；但论文明确这不是全局联合最优的保证。附录还给出了**扰动传播递归分析**：若块映射是 Lipschitz 的，低层策略偏差会沿深度递归影响高层状态，所以按执行序校准是必要的。
- **预算选择**：在不同阈值 \(\tau_g\) 上独立运行 SeqCalib，得到一组策略记录（策略矩阵、归一化驻留率、地板得分等）。预算选择器在满足预算的记录中按规则确定性选取：先选最大记录地板得分，再选最小驻留率，最后选最小网格序号。

### 2.4 分组缓存运行时（物理实现）

- 部署时只加载一次策略矩阵，**不做任何基于 prompt/注意力/请求历史的动态决策**。
- 每个可配置 KV 头按分配窗口写入和读取对应缓存组；相同窗口的头可共用一个组配置，但 KV 内容各自独立不共享。
- 所有头输出按原模型方式拼接并通过原始投影层——不改变模型的门控和输出投影逻辑。
- 原始的局部和循环/线性注意力路径完全保持不变。
- 与“在全缓存之上做掩码”不同，HeadWiseKV 是直接按策略分配物理存储，因此缓存需求在 prefill 前就可准确预测。

## 3. 实验设计

### 3.1 模型与配置
- 评估 4 个指令微调混合模型：**Qwen3.5-9B、Qwen3.6-27B、Qwen3.6-35B-A3B、Gemma4-31B**。

### 5.3 内部一致性与概念辨析

- **策略可迁移性**：SeqCalib 仅需每模型运行一次，策略以静态矩阵形式保存，可直接迁移到同模型的不同服务部署而无须重新校准；论文将“权重量化版本”对应的 KV 校准与权重精度解耦，体现其面向实用部署的设计取向。
- **与“掩码式”核心区分**：HeadWiseKV 的每条缓存都是物理上真实分配的被保留条目，不存在“保留了但不参与注意力”或“参与了但未驻留”的中间状态。这一点使它区别于 HeadKV 等“在显存中构建全缓存后再做逻辑压缩”的实现，也是其峰值显存可预测、prefill 阶段无额外高峰的直接来源。
- **评价指标定义闭环**：实验统一以“压缩率=（策略成本/全满策略成本）”的归一化驻留率表述预算，所有策略生成都输出对应的归一化驻留率，保证跨方法比较时至少有一个共同口径（总容量）。

## 6. 主要结论

1. **静态多级窗口在质量上不输动态方法**：最强的静态逐头多级历史分配在 RULER、LoCoMo 与 τ²-Bench 上与最强的 prompt-adaptive 基线（AdaKV/HeadKV-R2）打平甚至超过——这说明保留哪些远端 token 的“决策时刻”未必需要推迟到请求期；在混合模型的物理 KV 头上按静态窗口做选择，已足以捕获多数下游任务所需的长程语义。
2. **结构条件是质量保持的关键**：将“无限制窗口”替换为“候选窗口码本 + 一致的层条件化参考”后，大部分缓存用于保存中近期 token（如最近 8K–32K），而非一律退化为仅保留极少量 sink 或流式状态；全局注意力头只有在能够维持与条件全历史输出高度一致（τ>.995）时才被缩短。
3. **物理驻留带来确定性的系统收益**：因为策略事先确定且直接落到缓存组布局上，所有虚拟内存与吞吐收益都转化为可量化的物理显存减少；没有请求级扫描、重新排序或稀疏索引查找开销。
4. **深度校准的必要性得到验证**：浅层截断若被深层忽略，质量会显著下降；采用 SeqCalib 逐层条件化标定使策略对深层实际接收到的前缀保持自适应，保证了离线决策在真实推理部署中依然成立。
5. **压缩质量-系统收益的权衡可以被校准阈值控制**：通过一个阈值 τ 即可在“保留质量”与“压缩率”之间做系统性滑动，不同模型可依据下游容错需求选出合理工作点。

## 7. 局限与未解决问题

- **没有全局最优保证**：SeqCalib 的逐层贪心只在每层做 stage-wise 最优，低层策略一旦冻结就不再回退重调；同一总预算下是否存在更好的全局联合策略（如允许某一层额外多留一点、另一层更激进一点）仍属开放问题。
- **窗口码本粒度受限**：候选窗口是从离散码本（8K/16K/32K/full）中选取，未覆盖不同头上“相同窗口但不同位置偏移”或“非最近式”的保留形态（如同时保留 n 个历史区块）；对需要分散多段历史证据的任务可能仍不够灵活。
- **校准成本与配置选择**：SeqCalib 需要访问模型内部表示并做逐层多候选重放，虽然论文未披露具体总时长，但其依赖校准数据长度（C_cal=131072）与采样位置数（256）的乘积规模；实际使用者需自行承担此一次性成本。
- **评估的统计效力有限**：多数质量结果来自单次基准运行，未提供误差棒或显著性检验；性能差异低于几个样例（如 2 个问题）时不建议作确定性结论。
- **非混合架构的适用性未展开**：实验覆盖的模型全部为混合架构（混合了滑动窗口/Gated-DeltaNet/局部注意力与全局注意力）。对于纯全注意力模型，HeadWiseKV 的原理仍可平移应用（将每一层都视为全局层），但论文并未单独系统验证纯 Transformer 下的收益边界。
- **离线静态定位的适用场景边界**：如果真实线上上下文长度的分布与校准分布差异极大（如请求长度普遍远长于 C_cal，或证据集中出现在非最近但非最老的中段位置），固定的逐头窗口优势可能减弱；此时动态方法理论上更灵活，但会牺牲内存可预测性。论文提供的是一种“内存确定性”与“运行时可塑性”之间的取舍，而非无条件占优的万能方案。

## 8. 简评与启示

HeadWiseKV 的贡献与多数“请求期压缩”工作形成鲜明互补：它把分配决策从“每个请求来了再算”前移到“模型第一次部署前就算好”，用一次性校准换取运行时的零决策、低复杂度与高显存可预测性。其方法论中 SeqCalib 的“按执行顺序条件化”部分不仅仅是工程细节，更是使静态窗口在多残差层叠加后依然成立的关键机制，对后续任何缓存压缩方法都有借鉴意义——未来的动态压缩方法若想保持质量，也必须以“低层实际被截断后”的状态为锚定来标定高层策略，而非假定全量历史的理想输入。

同时，论文的对比实验口径合理、对基线的适用性描述诚实，没有回避“静态 vs 动态”的本质张力，而是以系统可量化收益来正面回应。就实际部署价值而言，HeadWiseKV 很适合那些上下文长度分布较稳定、对服务质量稳定性要求高、希望提前预算显存并支持长时间并发服务的场景；而对高度个性化、证据分布难以先验刻画的任务，它仍然为动态方法留下了明确的发挥空间。
