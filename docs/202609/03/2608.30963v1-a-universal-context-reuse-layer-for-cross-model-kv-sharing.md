## 摘要
现代大语言模型（LLM）服务系统越来越多地处理重复或共享的上下文，然而即使另一个模型已经处理过相同的输入，每个模型通常仍会执行自己的预填充计算。现有的KV缓存复用机制在单个模型内显著减少了冗余计算，但通常假设缓存的产生者和消费者是同一个模型。我们研究了跨模型KV共享，它将源模型产生的KV状态转换为可由不同目标模型（包括在规模、架构、注意力配置、分词器和模型家族方面存在差异的模型）使用的表示。我们在家族内和跨家族设置中评估了该方法。对于Qwen2.5-7B到Qwen2.5-1.5B的转换，转换后的KV状态将LongBench2准确率从27.59%提升到34.48%，比原生1.5B基线提高了6.89个百分点，同时相对于原生目标预填充降低了交接成本。对于跨家族的Qwen2.5-1.5B到Gemma-2-2B设置，KV交接在4K上下文长度下将目标侧预填充成本降低了高达67.05%，同时将解码困惑度保持在接近原生模型基线的水平。在更异构的Llama3.1-70B到Qwen2.5-7B设置中，跨家族交接实现了44.0%的准确率，而原生Qwen2.5-7B推理为45.7%，同时将实测延迟从899毫秒降低到138毫秒。这些结果提供了初步证据，表明KV状态可以作为可迁移的计算表示，而非严格局限于模型的缓存，并促使将“上下文移动性”作为一种系统抽象，用于减少异构LLM和多智能体推理工作流中的冗余预填充。

## Abstract
Modern large language model (LLM) serving systems increasingly operate over repeated or shared context, yet each model typically performs its own prefill computation even when another model has already processed the same input. Existing KV-cache reuse mechanisms substantially reduce redundant computation within a single model, but generally assume that the producer and consumer of a cache are identical. We study \emph{cross-model KV sharing}, which translates the KV state produced by a source model into a representation that can be consumed by a different target model, including models that differ in scale, architecture, attention configuration, tokenizer, and model family. We evaluate the approach in both within-family and cross-family settings. For Qwen2.5-7B $\rightarrow$ Qwen2.5-1.5B, translated KV states improve LongBench2 accuracy from 27.59\% to 34.48\%, a gain of 6.89 percentage points over the native 1.5B baseline, while reducing handoff cost relative to native target prefill. For the cross-family Qwen2.5-1.5B $\rightarrow$ Gemma-2-2B setting, KV handoff reduces target-side prefill cost by up to 67.05\% at 4K context length while maintaining decoding perplexity close to native-model baselines. In a more heterogeneous Llama3.1-70B $\rightarrow$ Qwen2.5-7B setting, cross-family handoff achieves 44.0\% accuracy compared with 45.7\% for native Qwen2.5-7B inference, while reducing measured latency from 899ms to 138ms. These results provide initial evidence that KV states can serve as transferable computational representations rather than strictly model-local caches, and motivate \emph{context mobility} as a systems abstraction for reducing redundant prefill across heterogeneous LLM and multi-agent inference workflows.

## 1. 论文的核心问题与研究动机

随着 LLM 服务从单模型走向**多模型异构协作**（如模型路由、级联、多智能体协同），越来越多的应用场景要求**不同模型反复处理同一份共享上下文**（如多轮对话历史、检索文档、任务状态等）。当前推理系统的关键问题是：即使另一个模型已经对相同输入完成了 prefill（预填充）计算并生成了 KV cache，新调用的模型依然通常会**从原始 token 重新开始做完整的 prefill**。由于每个模型各自维护独立的 KV 表示，现有的 KV 缓存复用机制（如 prefix caching、CacheBlend、DroidSpeak 等）几乎都局限于**同一模型内**（或架构强对齐的模型变体之间）的缓存重用，无法跨模型传递计算状态。

因此，论文的核心研究问题定义为：

> 是否存在一种机制，使源模型（source model）产生的 KV 状态可以被翻译/转换成另一个目标模型（target model）可直接消费的表示，从而避免多模型工作流中**重复的上下文预填充计算**？

论文将这些来源不同的 KV 状态视为**可迁移的计算表示（transferable computational representations）**，并提倡利用“上下文移动性（context mobility）”作为异构 LLM 推理的系统级抽象。这项工作为跨模型、跨家族、跨架构的 KV 复用提供了一种新型的机制路径。

## 2. 方法：通用上下文复用层

### 核心思想

论文提出一种**跨模型 KV 共享/交接（handoff）**机制。核心思想是：不要求目标模型从裸 token 重新做 prefill，而是通过一个**学习得到/构造的翻译层（translation layer）**，将源模型已算好的 KV cache 转换到目标模型的表示空间，让目标模型在“翻译后的 KV 状态”之上进行解码。形式上可写成：

\[
dKV_B(C) = T_{A→B}(KV_A(C))
\]

- \( KV_A(C) \)：源模型 A 对共享上下文 \( C \) 的已有 KV cache；
- \( T_{A→B} \)：从源模型表示空间映射到目标模型消费空间的转换；
- \( dKV_B(C) \)：目标模型解码所需的近似 KV 状态。

### 翻译层的性质要求

论文强调该翻译层具有下列重要特征：

- 它不仅是**张量格式或维度的转换**，更需要在两个**异构表示空间**间迁移语义信息；
- 翻译后的状态 **不要求** 严格等于目标模型原生 KV：

\[
dKV_B(C) \neq KV_B(C)
\]

  只要下游解码质量满足任务需求即可。

- 翻译层的设计空间包括：逐层映射、分组映射、KV 头（head）级映射、压缩表示或低维适配器等，用于在**保真度、开销、内存占用和模型扩展性**之间取得平衡。

### 优化目标

最简单学习目标是最小化翻译结果与目标原生 KV 之间的距离：

\[
L_{KV} = D(T_\theta(KV_A(C)), KV_B(C))
\]

但论文进一步提出：**最小化 KV 距离并非唯一或最重要目标**——因为数值不同但行为相近的状态完全可行，更任务导向的目标（如下游 logits、注意力分布、任务准确率等）是更合理的优化视角。这为不同翻译方法提供了宽松而实际的设计依据。

### 系统级操作逻辑

从推理系统角度来看，跨模型共享的执行流程改变了对异构应用执行模型的要求：新模型被调用时，运行时先检查已有上下文计算是否可用于该模型，寻找可用翻译路径；当翻译成本满足

\[
C_{translation} + C_{overhead} < C_{native\ prefill}
\]

才能带来净收益，否则回退到常规原生 prefill。

## 3. 实验设计

### 场景与模型配对

实验设计了三种**异构程度逐步增加**的转移方向：

1. **同族内规模差异**：Qwen2.5-7B-Instruct → Qwen2.5-1.5B-Instruct
2. **跨家族、同规模级**：Qwen2.5-1.5B-Instruct → Gemma-2-2B-IT

### 交接（Handoff）流程设定

每次实验的运行协议：

- 源模型对 prompt 做 prefill，生成原生 KV；
- 学习得到的传输模块将 cache 映射到目标模型的 KV 表示空间；
- 冻结的目标模型直接从翻译后的状态开始解码，不再对完整输入做独立 prefill。

论文还专门强调：**所有 handoff 的延迟测量**只计算“已有源 cache 可用之后”的增量成本，源模型端 prefill 不计入，因此不能把交接延迟解释为“为了转移而重新生成 cache”的总代价。

## 6. 主要结论与发现

1. **同族内、跨规模 KV 共享有效**：
   - Qwen2.5-7B 原生 KV 翻译到 Qwen2.5-1.5B 后，LongBench2 准确率从原生 1.5B 的 27.59% 提升到 34.48%，提升了 6.89 个百分点；这个准确率差值恢复了 1.5B 与 7B 原生差距的 38.1%。

2. **交接延迟显著低于目标自推理**：
   - 8K–16K：handoff 34.5 ms vs. 1.5B prefill 158.7 ms（约 4.6 倍加速）；
   - 16K–32K：handoff 53.8 ms vs. 1.5B prefill 288.3 ms（约 5.4 倍加速）；
   - 相对 7B 原生 prefill 分别加速约 14.5 倍和 16.7 倍。

3. **跨家族（同规模）传递保持质量、节省开销**：
   - Qwen2.5-1.5B → Gemma-2-2B：预填充成本降低 45.25%（128 tokens）到 67.04%（4K tokens）；
   - 解码困惑度在手递手路径上接近并部分赶上原生 Gemma。例如 H=1 时 handoff 反而获得最低困惑度 14.086。

4. **跨家族 + 大规模差异下依然有较好性能**：
   - Llama3.1-70B → Qwen2.5-7B 手递手准确率 44.0%（相对原生 Qwen 45.7%，占其 96.3%）；
   - 延迟从原生 Qwen2.5-7B 的 899 ms 降至 138 ms（约 6.5×加速），比原生 Llama 70B 快 53.1 倍。

5. **总体核心判断**：KV 状态可以成为一种**跨模型、可转移的语义缓存**，传统“同模型预填充”假设可被打破，为异构多模型与多智能体推理的基础系统提供更通用的上下文运动抽象。

## 7. 论文的主要优点

- **问题定义清晰、实用性高**：抓住多模型工作流中普遍存在的“重复 prefill 却不共享计算”这一真实浪费，定义出跨模型 KV sharing 这一明确任务；
- **对系统级抽象的概念化有一定价值**：提出“KV 是可迁移的计算资产、上下文移动性”的视角，将问题从单模型工程优化提升为异构系统的通用抽象层；
- **异构梯度设计很有层次**：从“同族不同规模”到“跨族同规模”、再到“跨族大规模差”逐级加大难度，有助于读者判断方法的适用范围与边界；

- **比较公平**：在三条推理路径（源原生、目标原生、handoff）上用同样的任务打分和同一批数据，避免评估口径漂移。
