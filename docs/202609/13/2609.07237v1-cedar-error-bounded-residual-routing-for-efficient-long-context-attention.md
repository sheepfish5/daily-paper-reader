## 摘要
事后稀疏注意力通过将每个查询路由到一小组词元级交互来加速长上下文预填充。然而，硬选择会为每个被省略的块分配零概率：路由失误无法恢复，固定的扩展预算会在简单查询和歧义查询上花费相同的工作量。我们提出由粗到细的误差感知动态注意力路由（CEDAR），这是一种在保持语言模型冻结的同时保持全局覆盖的由粗到细方法。每个语义块向一条残差注意力路径贡献低成本的键-值摘要；随后，估计近似误差高的块会被扩展为精确的词元注意力。精确贡献与摘要贡献在单一 softmax 归一化中结合，因此细化会替换而非重复粗粒度证据。我们推导出一个由块内键/值离散度控制的输出误差界，并利用它分配可变的细化预算。一项受控的聚类注意力研究表明，在相同的精确块预算下，残差摘要相较于硬丢弃可将重建误差降低 98% 以上。在长上下文基准上的实验表明，CEDAR 能够恢复硬稀疏路由所损失的大部分质量，同时在 128K 上下文下保持约 3 倍的内核加速。

## Abstract
Post-hoc sparse attention accelerates long-context prefill by routing each query to a small set of token-level interactions. Hard selection, however, assigns zero probability to every omitted chunk: a routing miss cannot be recovered, and a fixed expansion budget spends the same work on easy and ambiguous queries. We introduce Coarse-to-fine Error-aware Dynamic Attention Routing (CEDAR), a coarse-to-fine method that keeps the language model frozen while preserving global coverage. Each semantic chunk contributes a cheap key--value summary to a residual attention path; chunks with high estimated approximation error are then expanded to exact token attention. Exact and summarized contributions are combined in a single softmax normalization, so refinement replaces, rather than duplicates, coarse evidence. We derive an output-error bound governed by within-chunk key/value dispersion and use it to allocate a variable refinement budget. A controlled clustered-attention study shows that residual summaries reduce reconstruction error by more than 98% relative to hard dropping at equal exact-chunk budgets. Experiments on long-context benchmarks demonstrate that CEDAR recovers most of the quality lost by hard sparse routing while maintaining approximately $3\times$ kernel speedup at 128K context.

## 1. 核心问题与整体含义

- **研究背景**：长上下文语言模型在书籍、代码仓库、多文档证据和长对话等场景中越来越常见，但标准 softmax 注意力中每个 query 都要与所有历史 key 交互，预填充阶段代价极高。
- **现有方法的问题**：后验稀疏注意力通过将每个 query 路由到少量 token 级交互来加速，但常用“硬选择”路由存在两个失败模式：
  - **硬遗漏**：未被选中的块被赋予零概率，既不贡献 softmax 分母也不贡献值，一旦路由失误便不可恢复。
  - **统一细化预算**：固定 token 密度对简单查询和歧义查询分配相同精确计算量，简单查询被过度服务，不确定查询可能细化不足。
- **论文整体含义**：CEDAR 提出一种“由粗到细、误差感知”的动态注意力路由方法，在保持语言模型冻结的前提下，让所有语义块通过廉价 KV 摘要保持全局可见，同时仅对高估计误差块展开精确 token 注意力。其目标是兼顾全局覆盖、可变细化预算和后验部署效率。

## 2. 方法论

### 2.1 核心思想

- 在 DHSA 式内容感知语义分块基础上，将每个语义块同时视为：
  - **路由单元**：决定是否展开为精确 token 注意力；
  - **压缩单元**：用长度校正的键值摘要表示未展开块。
- 精确 token 贡献与摘要贡献在**同一个 softmax 归一化**中融合，细化时摘要被替换而非重复计算，避免双重计数。
- 当所有块都被细化时退化为稠密注意力；当没有块被细化时退化为长度校正的块级注意力。

### 2.2 关键技术细节

- **语义块摘要**：
  - 对块 \(C_c\)，计算均值键和均值值：\(\bar{k}_c = \frac{1}{n_c}\sum_{j\in C_c} k_j\)，\(\bar{v}_c = \frac{1}{n_c}\sum_{j\in C_c} v_j\)。
  - 摘要 logit 为 \(\ell^{sum}_{ic} = q_i^\top \bar{k}_c/\tau + \log n_c\)。其中 \(\log n_c\) 是长度校正项，用于恢复被压缩 token 的多重性，避免长块被系统性低估。
- **混合精确–摘要注意力**：
  - 对 query \(i\)，选择精确细化块集合 \(R_i\)，对应精确 token 集合 \(E_i\)；未细化块集合 \(U_i\) 保留摘要。
  - 输出分子为精确 token 的 \(\exp(q_i^\top k_j/\tau)v_j\) 加未细化块的 \(\exp(\ell^{sum}_{ic})\bar{v}_c\)；分母为对应指数权重之和。
  - 细化块只以精确 token 出现，未细化块只以摘要出现，因此既不丢弃也不重复任何块。
- **因果性、GQA 与多头**：
  - 包含当前 token 的块、最近窗口和 sink 区域始终强制精确，避免使用未来 token 的部分摘要。
  - 边界可跨头共享，摘要按 KV head 计算；同一 KV head 的 query head 可共享摘要和离散度统计。GQA 下可共享细化布局，或在优先级分歧大时拆分。
- **误差感知细化**：
  - 用块内键/值离散度衡量近似风险：\(r^c_k = \max_j \|k_j-\bar{k}_c\|_2\)，\(r^c_v = \max_j \|v_j-\bar{v}_c\|_2\)。
  - 定义 logit 半径界 \(\epsilon_{ic} = \|q_i\|_2 r^c_k / \tau\)。
  - 实用细化优先级为 \(\pi_{ic} = e^{\ell^{sum}_{ic}}[(e^{\epsilon_{ic}}-1)(\|\bar{v}_c\|_2+\rho_i)+e^{\epsilon_{ic}}r^c_v]\)，其中 \(\rho_i\) 是当前输出范数的运行估计。
  - 该优先级同时考虑块可能携带的概率质量，以及一个摘要对块内 logits 和 values 的表示误差。
