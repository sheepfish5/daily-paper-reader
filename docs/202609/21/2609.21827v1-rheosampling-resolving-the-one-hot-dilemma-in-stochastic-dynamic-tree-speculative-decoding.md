## 摘要
推测解码通过并行草拟多个 token 来加速 LLM 推理，而基于树的方法进一步借助层次结构提升效率。诸如 EAGLE-3 之类的动态树方法通过确定性的 top-K 扩展和全局剪枝，在贪婪解码下表现良好。然而，在随机解码（T>0）中，该机制会将草拟分布坍缩为独热概率，导致接受率严重下降。这形成了一个两难：动态树方法为保留上下文感知的拓扑而牺牲随机采样，而静态树方法则以上下文无关的结构保留随机采样。问题源于同一个概率分布被用于两个相互冲突的任务：构建树和验证 token。这种耦合使得直接注入随机性因所产生的随机过程而颇具挑战。我们通过解耦这些角色来解决该问题：RheoSampling 为从草拟分布中采样得到的 token 分配一个用于树扩展和剪枝的代理概率，同时保留其用于验证的真实采样概率。具体而言，我们在确定性的 top-K 槽位中注入一个采样 token，并在构建和验证期间以不同概率对待它，使 RheoSampling 成为首个同时具备上下文感知 top-K 构建和随机采样且保持无损性的动态树方法。我们通过等价类分析将随机树空间压缩为可处理的类别，从而建立无损保证。基于 OT 的验证策略和稀疏草拟机制确保理论收益转化为实际效率。跨 LLM 和基准的实验表明，相比最先进的动态树方法，该方法在接受率和加速比上均有提升。该框架或可为分析随机树结构提供一种模板。

## Abstract
Speculative decoding accelerates LLM inference by drafting multiple tokens in parallel, with tree-based methods further improving efficiency through hierarchical structures. Dynamic-tree methods such as EAGLE-3 perform well under greedy decoding via deterministic top-K expansion and global pruning. However, in stochastic decoding (T>0), this mechanism collapses the draft distribution into one-hot probabilities, causing a severe drop in acceptance rate. This creates a dilemma: dynamic-tree methods sacrifice stochastic sampling to preserve context-aware topology, while static-tree methods preserve stochastic sampling with context-agnostic structures. The issue arises because the same probability distribution is used for two conflicting tasks: constructing the tree and verifying tokens. This coupling makes direct injection of randomness challenging due to the resulting stochastic process. We resolve this by decoupling these roles: RheoSampling assigns a token sampled from the draft distribution a proxy probability for tree expansion and pruning alongside its true sampling probability for verification. Specifically, we inject a sampled token among the deterministic top-K slots and treat it with different probabilities during construction and verification, making RheoSampling the first dynamic-tree method with both context-aware top-K construction and stochastic sampling while maintaining losslessness. We establish the lossless guarantee through an equivalence-class analysis that compresses the stochastic tree space into tractable classes. An OT-based verification strategy and a sparse draft mechanism ensure that theoretical gains translate into practical efficiency. Experiments across LLMs and benchmarks demonstrate improvements in acceptance rate and speedup over state-of-the-art dynamic tree methods. This framework may provide a template for analyzing stochastic tree structures.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：自回归解码是 LLM 推理延迟的主要瓶颈。推测解码（speculative decoding）用轻量草稿模型并行预测多个 token，再由目标模型一次前向验证，从而加速推理。基于树的方法（Medusa、SpecInfer、EAGLE-1/2/3、Opt-Tree、Sequoia 等）把多个候选序列组织成树结构，进一步提高单步命中率。
- **核心问题**：当前最强的动态树方法（EAGLE-2/3）采用"先扩展、再重排剪枝"的范式，整条流水线本质上是**确定性**的——token 只通过 top-K 选择，草稿分布被坍缩为一组点质量（one-hot），长尾概率信息被完全丢弃。
  - 在贪婪解码（T=0）下这很有效；
  - 但在随机解码（T>0）下，接受率取决于 p(x)/q(x) 而非 q(x) 本身，确定性 top-K 会造成尾部探索不足、接受率骤降。论文指出官方 EAGLE 实现甚至在验证时把草稿概率直接视为 1.0。
- **暴露的两难（dilemma）**：动态树方法为保留上下文感知拓扑而牺牲随机采样；静态树方法保留随机采样但结构上下文无关。
- **根因诊断**：问题在于**同一个概率分布同时承担两个互相冲突的任务**——构建树（扩展/重排/剪枝）与验证 token。这种耦合使直接注入随机性变成一个难以分析的复杂随机过程。
- **整体含义**：论文主张把这两个角色解耦，使动态树首次同时具备"上下文感知 top-K 构建"与"随机采样"，且严格保持无损性（losslessness）。

## 2. 方法论

### 2.1 核心思想：双身份（Dual-Identity）解耦
- 给单个随机采样 token 赋予**两个独立概率身份**：
  - **代理概率（proxy probability）**：用于树扩展、重排与剪枝；
  - **真实采样概率（true sampling probability）**：用于验证。
- 关键在于让采样 token 的"存活"不依赖其具体取值，从而不扭曲其条件分布，保证无损性。

### 2.2 混合采样机制（Hybrid Sampling）
每个扩展步的候选池有 K 个槽位，分配方式为：
1. **Top-m 确定性 token**（lead tokens，草稿概率最高）；
2. **1 个采样 token** x_s，来自残差分布 q̃（即 top-m 之外尾部质量的重归一化）；
3. **K−m−1 个填充 token**（fill tokens，剩余词表中概率最高者）。

### 2.3 采样 token 的双重处理
- **构建阶段**：代理概率设为
  q_proxy(x_s) = min{ q(x_m), z }，其中 z = 1 − Σ_{i=1}^{m} q(x_i) 为残差质量，q(x_m) 为第 m 个确定性概率。
  - 当 m = 0 时，代理概率设为 q(x_1) + ε（ε>0），把采样 token 锚定在第一槽位。
- **验证阶段**：使用真实采样概率 q̃(x_s)，而非代理概率。
- 该设计保证采样 token 在候选池内固定排在 m+1 位（Lemma 4：q_proxy ≥ q(x_{m+1})），使其存活与自身取值无关。

### 2.4 流变参数（Rheostat Parameter）m
- m 是"流变阻"式调节旋钮：
  - m 越小 → 代理概率越大 → 采样 token 存活率高、随机探索能进入最终树，但确定性骨干变弱；
  - m 越大 → 保留高质量拓扑，但采样节点可能被剪掉。
- 论文认为 m=1 是标准随机解码下的"甜点"（兼顾代理质量与 OT 验证优势）。

### 2.5 稀疏草稿分布（Sparse Draft）
- 在 softmax 前把 logits 截断到 top-128，其余置 −∞，避免在全词表上采样。
- 只要**验证使用同一截断分布**，无损性仍成立；实验显示 top-128 覆盖草稿分布质量约 91%（MT-bench），Alpaca 约 96%、HumanEval 约 95%。

### 2.6 RheoVerification（基于最优传输 OT 的验证算法）
流程（Algorithm 1）：
1. 若采样 token 存活（s ≠ −1），先独立验证：以概率 min(1, p(u_s)/q̃(u_s)) 接受并下降到其子树；
2. 若被拒绝，计算残差分布 r = norm(max(0, p − q̃))，在剩余候选上做递归拒绝采样；
3. 若全部候选被拒，从最终残差分布中采样一次；
4. 若采样 token 不存在（s = −1），退化为标准 top-K 验证，仅依赖目标分布 p。

- **与 RRSw 的关系**：RRSw（无放回递归拒绝采样）按顺序逐个验证，不做全局质量重分配；OT 验证通过归一化草稿分布全局重分配概率质量，从而最大化与目标分布的"结构重叠"，提高采样 token 的接受率。

### 2.7 理论保证
- **Theorem 1（无损性）**：对任意剪枝预算 R 和任意序列 Seq，E_{T_R}[Pr(Rheo(T_R) = Seq)] = p(Seq)。
- **证明工具**：等价类分析（equivalence-class analysis），把随机树空间按"剪枝后结果相同"压缩为可处理类别 [U]_R，再对 R 做归纳。
- **Lemma 4（局部排序保持）**、**Lemma 5（祖先单调性）**、**Lemma 7（槽位确定性）**：分别保证采样节点排在所有 fill token 之上、路径分数随深度递减（剪枝结果祖先封闭）、以及第 k+1 个节点的槽位在等价类内不变、采样槽按 q̃ 比例划分子类。
- **Theorem 3（单层接受率）**：给出 Rheo 的闭式单层接受率表达式，并给出其上界。
- **Appendix D.3（近似比较）**：在温和近似下证明 A_Rheo ≥ A_RRSw，且只要存在尾部 token 满足 (1−A)q̃(v) < p(v) < q̃(v)，差距严格为正——这正是"随机优先"（stochastic-first）策略优于顺序 RRSw 的理论依据。

## 6. 主要结论与发现

- **无损性**：首次为"随机动态树"给出严格的 losslessness 证明（Theorem 1），核心工具是等价类分析。
- **接受率提升**：在全部 3 个模型 × 6 个任务上 τ 均有一致提升，平均增益 +0.14（Vicuna-13B）至 +0.22（DeepSeek-R1-Distill-8B）。
  - Vicuna-13B：5.75 → 5.89，加速 3.37× → 3.43×；
  - Llama-3.1-8B：5.04 → 5.25（+4.2%），加速 2.84× → 2.93×（+3.2%）；
  - DeepSeek-R1-Distill-8B：4.99 → 5.21，加速 2.89× → 2.99×。
- **加速比增益小于 τ 增益**：因为采样与验证采样 token 带来额外开销，但净加速在所有模型上严格为正。
- **m 的最优值**：m = 1 在多数设置下最优或接近最优；m = 0 与 m = 2 仍优于 Top-K；m ≥ 3 因代理概率被压低、采样节点被剪枝而收益递减。
- **退化行为的不对称性**：
  - m = 0 具有"双重退化"——T→0 时采样与结构都退化为 Top-K；
  - m = 1 只有"采样退化"——结构仍因代理概率与真实概率不匹配而保持差异，这解释了低温下 m=1 与 Top-K/m=0 的接受率差距。
- **验证策略贡献可分离**：受控实验显示 Top-K 80.0% → RRSw 83.5%（+3.5%，来自混合采样）→ RheoVerification 85.4%（+1.9%，来自 OT 质量重分配）。
- **稀疏草稿**：支持集 128 时覆盖率已达 91%，τ（4.84）与 Full（4.89）几乎无差，草稿延迟基本不变，说明稀疏截断不带来系统性损失。
