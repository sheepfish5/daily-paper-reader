## 摘要
大型推理模型（LRMs）通过扩展思维链（CoT）生成实现卓越的问题解决能力，但由此产生的键值（KV）缓存随序列长度线性增长，并造成严重的内存瓶颈，对于长推理轨迹往往超出GPU容量。现有的KV缓存压缩方法依赖近期查询来估计未来令牌的重要性，隐含地假设这些查询可作为未来注意力模式的可靠代理。我们证明这一假设在长时推理中失效：某些解码步骤会生成思维回访令牌（TRT），这些令牌重新关注早期形成的远距离先前上下文，如任务求解计划。通过系统分析，我们发现对应于TRT的查询在嵌入空间中聚集为少量相似性组。基于这一洞察，我们提出BeaconKV，一种无需训练的KV缓存压缩方法，它维护信标查询，即每个全局查询簇的紧凑代表，以预测哪些KV对将被重新访问，而无需存储完整查询历史。在四个开源LRM和多种推理基准上，BeaconKV通常优于现有压缩方法，实现了高达5.8倍的内存缩减，同时几乎保持完整缓存准确性，并将吞吐量提升超过4.3倍。

## Abstract
Large Reasoning Models (LRMs) achieve superior problem-solving through extended Chain-of-Thought (CoT) generation, but the resulting key-value (KV) cache grows linearly with sequence length and creates severe memory bottlenecks, often exceeding GPU capacity for long reasoning traces. Existing KV cache compression methods rely on recent queries to estimate future token importance, implicitly assuming these serve as reliable proxies for future attention patterns. We demonstrate that this assumption fails in long-horizon reasoning: certain decoding steps generate Thought Revisiting Tokens (TRT) that re-attend to distant previous context, such as task-solving plans formulated early in the trace. Through systematic analysis, we discover that queries corresponding to the TRT cluster into a small number of similarity groups in the embedding space. Based on this insight, we propose BeaconKV, a training-free KV cache compression method that maintains beacon queries, compact representatives for each global query cluster, to anticipate which KV pairs will be revisited without storing the entire query history. Across four open-source LRMs and diverse reasoning benchmarks, BeaconKV generally outperforms existing compression methods, achieving up to $5.8\times$ memory reduction while nearly preserving full cache accuracy and improving throughput by over $4.3\times$.

- **核心问题**：论文通过实证分析发现，上述假设在长时推理中不成立。LRM 解码过程中存在一类"思维回访令牌"（Thought Revisiting Tokens, TRT）——某些查询会重新关注很早之前形成的任务计划、问题约束等远距离上下文，以维持推理全程的全局连贯性。这类回访行为出现得稀疏且不可预测，导致依赖近期查询的压缩方法会提前驱逐后续证明必需的 KV 对。
- **关键洞察**：论文发现全局回访查询并非随机分布，而是在嵌入空间中聚成少量相似性簇。这为预测"哪些 KV 对将被未来回访"提供了结构性基础。
- **整体含义**：BeaconKV 提出了一种免训练的 KV 缓存压缩框架，通过维持少量"信标查询"（beacon queries）作为全局查询簇的代表，在不存储完整查询历史的前提下预判未来注意力重访，从而缓解 LRM 长推理推理中的显存瓶颈，兼顾压缩率与推理质量。

## 2. 方法论：核心思想与技术细节

### 2.1 核心思想

- 保留**两类观察查询**用于 KV 重要性打分：
  - **近期查询（recent queries）**：维持局部上下文连贯性；
  - **信标查询（beacon queries）**：从历史查询中筛选出的几何上多样且具代表性的查询，用于模拟未来可能出现的 TRT 注意力行为。
- 将两种查询共同用于注意力打分，使距离当前很远的"待回访 KV"也能获得较高重要性分数，从而避免被提前驱逐。

### 2.2 关键技术细节

1. **查询分类与观察**：
   - **局部查询（local queries）**：注意力集中在邻近 key 上。
   - **全局查询（global queries）**：注意力跨越远处位置，对应 TRT。
   - 实验表明全局查询分散出现在多个层和注意力头中，而非集中于某一组件，说明 TRT 是长程推理中的普遍现象。

2. **几何结构分析**：
   - 使用 pre-RoPE 查询状态（排除位置编码干扰）计算余弦相似度，发现 TRT 查询对邻居不相似但彼此高度相似。
   - PCA 投影显示全局查询集聚成少量簇，说明可以用少量簇代表覆盖其分布。

3. **信标查询选取——Continual FPS（连续最远点采样）**：
   - 基础算法为最远点采样（Farthest Point Sampling, FPS）：在余弦相似度空间贪心选取彼此距离最远的查询。
   - Naive FPS 需存储全部历史查询，内存开销大；Continual FPS 为每个注意力头维护一个**有界缓冲区**，当缓冲区达到上限 $B^{max}_Q$ 时触发 FPS 压缩回下限 $B^{min}_Q$，形成"填充—压缩"循环，保证查询历史足迹有界。

4. **注意力打分与聚合**：
   - 在驱逐触发时刻 $t$，观察查询集 $Q_{obs}$ 由信标查询 + 最近查询组成。信标查询通过 RoPE 对齐到当前步 $t$，模拟"此刻发生回访"的效果；近期查询保留其原始生成位置。
   - 对 GQA 多头分组结构，将组内所有 query-head 的注意力权重按位置取 **Max 聚合**（而非均值），避免稀疏但高价值的 TRT 信号被均值稀释。
   - 保留头部前缀 token 和最近 $n_{recent}$ 个 token 保证局部流畅性，其余预算按分数 Top-K 填充。

5. **驱逐流程**：
   - 当 KV 缓存达到上限 $B^{max}_{KV}$ 时触发压缩，每次驱逐掉 $1/8$ 的缓存条目；保留窗口为最近 $n_{recent}$ 个 token（BeaconKV 默认 16，R-KV 为 8，其他方法为 32）。
   - 驱逐后，保留的信标与近期查询合并，再次经 FPS 压缩，使信标集合能持续跟踪推理过程中新出现的全局查询模式。

### 2.3 全文未涉及训练

BeaconKV 完全免训练，不引入可学习参数，也未修改模型架构。

## 6. 主要结论与发现

- **问题证实**：现有基于近期查询的 KV 压缩方法在 LRM 长推理中系统性失效，原因是无法预测稀疏的 TRT 回访行为。
- **结构发现**：TRT 对应的全局查询在 pre-RoPE 嵌入空间中聚成少量簇，该几何规律支撑了用少量信标查询做代表的有效性。
- **方法有效**：BeaconKV 在几乎所有（模型，基准，预算）组合上优于 RPC、R-KV 与 SnapKV；低预算区间的优势最大，最高超过现有方法 **31.7 个百分点**（Qwen3-14B 上 AIME24、1024 预算）。
- **压缩效率**：在 Qwen3-4B 32K 生成场景下单卡 batch=14 时，峰值显存从 77.0GB 降至 13.3GB（**5.8×** 降低），吞吐量从 82.3 提升至 356.4 tokens/s（**4.3×** 以上提升），且精度几乎不损失。
- **同预算对比**：BeaconKV 的系统吞吐与显存占用与 RPC 基本持平，但精度显著更高（2K 预算 +6.3 点、1K 预算 +12.3 点，LiveCodeBench）。
- **消融结论**：近期与信标查询配比存在最优平衡点（本文为 16:16）；Max 聚合优于 Mean；动态更新的信标查询显著优于仅保存初始查询（Initial+Recent）的静态方案。

## 7. 优点

- **洞察新颖且可操作**：首次系统识别并命名了 LRM 推理中的 TRT 现象，并将其与嵌入空间聚类结构关联，为 KV 压缩提供了新的理论视角。
- **免训练、即插即用**：无需任何训练或模型微调，可直接套用于现有开源 LRM 推理管线，具备较强的实用推广性。
- **方法设计简洁有据**：每步设计（pre-RoPE 空间、FPS 几何采样、Max 聚合、RoPE 对齐）均有对应的实证或消融支撑，而非启发式堆砌。
- **内存足迹受控**：提出 Continual FPS 在线缓冲压缩机制，解决了 Naive FPS 需要保留全部历史查询的内存开销问题，兼顾了代表性质量与可用性。
- **实验评估立体**：不仅报告精度，还覆盖了吞吐、延迟、峰值显存等系统级指标；多模型、多任务、多预算的评估矩阵较完整。
- **收益平衡验证**：与 RPC 的系统效率对比表明精度提升并非以明显性能开销为代价。
