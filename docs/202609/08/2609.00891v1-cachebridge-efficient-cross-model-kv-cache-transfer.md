## 摘要
在多模型系统中，模型间共享上下文要求接收模型对共享前缀进行预填充，因为KV缓存是模型特定的。近期提出的闭式跨模型KV迁移（下文称为全头映射）通过拟合从源缓存到目标缓存的免训练仿射映射器，避免了这种重放。然而，其全头设计将每个目标KV头映射到选定层中的每个源KV头，使得迁移质量对架构差异敏感，并导致映射器的存储与应用成本随层支持而增长。为此，我们提出CacheBridge，它在保留用于在线部署的闭式仿射接口的同时，协同设计了架构索引的映射器支持、注意力对齐的校准和有界映射器构造。CacheBridge将每个目标头限制到匹配的源头，通过因果注意力敏感性对重建误差进行加权，并使用融合GPU内核构建加权充分统计量，而无需实化完整的观测张量。在三个迁移方向上，CacheBridge恢复了Ministral 3中全头映射严重损失精度的两个迁移方向，同时在Qwen3上保持了99.83%的平均目标保留率。在Qwen3 14B→32B上，它将映射器存储减少8倍，应用加速最高达3.0倍，仅用全头映射十分之一的校准数据即可与之匹配，并将500序列的构造时间从92.63秒减少到8.63秒（10.7倍）。

## Abstract
Sharing context between LLMs in a multi-model system requires the receiving model to prefill the shared prefix because KV caches are model-specific. Recent closed-form cross-model KV transfer, hereafter Full-Head Mapping, avoids this replay by fitting a training-free affine mapper from source to target caches. However, its full-head design maps each target KV head from every source KV head in the selected layers, making transfer quality sensitive to architectural differences and causing mapper storage and application cost to grow with layer support. To this end, we introduce CacheBridge, which co-designs architecture-indexed mapper support, attention-aligned calibration, and bounded mapper construction while retaining a closed-form affine interface for online deployment. CacheBridge restricts each target head to a matched source head, weights reconstruction errors by causal attention sensitivity, and uses a fused GPU kernel to construct weighted sufficient statistics without materializing full observation tensors. Across three transfer directions, CacheBridge recovers the two Ministral 3 transfer directions where Full-Head Mapping loses substantial accuracy while preserving 99.83\% mean target retention on Qwen3. On Qwen3 $14\mathrm{B}\to32\mathrm{B}$, it reduces mapper storage by $8\times$, accelerates application by up to $3.0\times$, matches \fullhead with one tenth of the calibration data, and reduces 500-sequence construction from 92.63 to 8.63 seconds ($10.7\times$).

**研究背景：** 已有工作在跨模型 KV 传输上提出了首个免训练闭式方法——FULL-HEAD MAPPING（Heo et al., 2026），通过拟合从源模型缓存到目标模型缓存的仿射映射器，避免目标侧重复 Prefill。但其设计缺陷明显：将每个目标 KV 头映射至选定源层中的全部 KV 头，导致：

- **O1 模型敏感性强**：在 Qwen3 14B→32B 上能保持接近原生精度（79.2% 对 80.2%），但在 Ministral 3 的两个迁移方向上准确率严重崩塌（仅 52.2% 和 44.4%）——表明相同的 KV 接口之下隐藏着架构依赖的头对应关系。
- **O2 KV 拟合质量 ≠ 续写质量**：坐标级重建误差（如 R²）无法反映接收模型注意力和下游层对误差的实际放大效应；相同范数的 KV 残差在不同查询下会诱发截然不同的注意力输出漂移。
- **O3 成本随层支持扩张**：应用延迟随选层数 k 近乎线性增长，在 k≥16 时已接近目标重新 Prefill，在 k≥20 时超过后者。
- **O4 Top-k 选层碎片化**：每个目标层选择不同的源层子集，通用拟合流程反复将散布、居中、加权张量实化，内存访问主导构造过程。

## 2. 论文提出的方法论：核心思想、关键技术细节与算法流程

### 2.1 总体设计框架

CACHE BRIDGE 遵循一条统一的设计原则：**协同设计映射器支持、校准目标与构造路径，服务于仿射在线部署**。它为 FULL-HEAD MAPPING 遗留的开放问题提供三个互补回答，且不额外增加推理阶段，修改的是同一套离线标定管线上的不同环节：

- **S1 HEAD-LOCAL**：确定哪些源头可以解释每个目标头 → 修改映射器支持结构
- **S2 ATTN-REPAIR**：确定哪些重建误差对接收方注意力重要 → 修改校准权重
- **S3 FUSED-FIT**：确定如何高效执行固定映射器支持的构造 → 引入新 GPU 内核

虽然由三个组件构成，但核心创新既是局部层面的（不再简单复用全头映射），又通过整体协同保持了部署简单性。这一框架的可行性，源于对线性误差传播和交叉头结构的理论分析，而非纯粹的启发式工程调优。

### 2.2 闭式传输接口（保留基线）

```text
对于目标层 ℓ：
  1) 首先用校准专用选择器对所有源层执行居中单源层 OLS 探针
  2) 计算各层的 held-in R²（跨 KV 头、跨 K/V 平均）
  3) 选择得分最高的前 k 个源层构成 S_ℓ
  4) 映射器在 "内容空间"（去除 RoPE 后）中以闭式岭回归拟合
  5) 在线应用后再施加目标侧 RoPE
```

映射器的形式为式 (8)-(10)：对非负样本权重（均值为 1）进行居中仿射岭回归：

$$Ŵ = \arg\min_W \sum_i w_i \left\| (y_i-\bar{y}_w) - (x_i-\bar{x}_w) W \right\|_2^2 + \lambda \|W\|_F^2$$

$$Ŵ = (X_c^\top D_w X_c + \lambda I)^{-1} X_c^\top D_w Y_c, \quad \hat{b} = \bar{y}_w - \bar{x}_w Ŵ$$

### 2.3 HEAD-LOCAL：头级结构局部性

**核心思想：** 将"全头拼接"改为"按架构索引的单头拼接"。每个目标 KV 头只接收来自每个选定源层中**一个**匹配源头的特征：

$$\mathbf{x}^{local}_{\ell,h,t} = \mathrm{concat}_{j \in S_\ell} \; \mathbf{Z}_{S_{j,t,a(h)}}, \quad p_\ell = k d_s$$

其中 $a(h)$ 是确定性架构索引的映射（源、目标 KV 组对齐时为恒等映射，即 $a(h)=h$）。因此头部 fan-in 从 "k × Hs × ds" 降至 "k × ds"，参数总量减少 **Hs 倍**（此处为 8 倍）。在该模型的实验设置中，参数总量从 4.296 GB 降至 0.538 GB，这也使该类方法与空间映射研究形成对照。

### 2.4 ATTN-REPAIR：注意力对齐的校准

**核心思想：** 在固定 HEAD-LOCAL 的映射支持下，不在统一/坐标系度量下重建全部 KV 坐标，而是通过接收模型自身的因果注意力机制，确定校准边界上的键值权重——用局部一阶代理来近似注意力输出误差。对每个校准序列，固定 32 个对数间隔的因果前缀边界，并对每个目标层、头、分量分别构造非负敏感性 $r_i$，计算方式为利用 Jacobian 块迹：
- V 敏感性 $r_i^V = \sum_{u \in G(h)} a_{ui}^2$
- K 敏感性 $r_i^K = \sum_{u \in G(h)} a_{ui}^2 \cdot (\|v_i-o_u\|_2^2 \, \|q_u\|_2^2 / d)$
- 其中 $a_{ui}$ 为 softmax 注意力权重，$G(h)$ 为共享 KV 头的查询头集合

**有效样本量约束：** 直接采用原权重可能高度集中，因此使用公式 (17)-(19)，按所选 KP（当前层键值对数量上限）对权重系数 α 引入收缩：

$$w_i(\alpha) = 1 + \alpha (r_i - 1), \quad n_{eff}(w) = \frac{n}{1 + \alpha^2 \mathrm{CV}^2(r)}$$

基于按层设置的 $\tau_\ell = \min(n, 2p_\ell)$，通过二分搜索找到可允许的最大 α。这种方法可以防止高权重集中在极少数 token 上，同时保留对接收模型计算敏感位置的关注度。

### 2.5 FUSED-FIT：有界的映射器构造

**核心思想：** Ridge 求解仅需充分统计量（加权均值及 $A_h$、$B_h$），而通用实现反复物化大矩阵。FUSED-FIT 设计了新的融合 GPU kernel，以有界的两遍构造方式完成统计量计算：

- 第一遍通过归约获得加权均值 $\mu_x$、$\mu_y$；
- 第二遍将观测数据按有界块遍历，kernel 内完成：step1: 按照 target 层静态编译的 gather schedule 收集所需的 head-local 源块；step2: 居中和加权；step3: 写出连续每 head 面板；step4: 用 head-batched 矩阵乘累积得充分统计量 $A_h = \sum_i w_{i,h}(x_{i,h}-\mu^h_x)(x_{i,h}-\mu^h_x)^\top$、$B_h = \sum_i w_{i,h}(x_{i,h}-\mu^h_x)(y_{i,h}-\mu^h_y)^\top$

- 附加内存占用仅 $O(H_t b(2p_\ell + d_t))$，b 为块大小。

**线上部署不变量：** 整个流程求解的是相同的岭回归形式（在线推理端点不变化），只改变特征维度和系数，不引入额外的推理层，映射生成阶段不增加 stage 切换开销。

## 6. 论文的主要结论与发现

1. **Head-Local（头部局部性）修复架构敏感失效**：在原本失败的 Ministral 3 3B→14B 和 8B→14B 两个方向上，CacheBridge 将 HellaSwag 精度从 52.2%→72.6%、44.4%→76.0%，平均目标保留率从 65.89%→88.23% 和 59.43%→97.57%。在 Qwen3 14B→32B 上以相同的 Calibration 协议维持平均误差极低，4 任务精度波动仅是 0.2~1.0 分。归因实验进一步证明：即使参数数量和完整度降低到相同水平，Block-PCA 明显降低坐标 R²、循环头映射也导致 15% 的保留率下降。因此支持结构上的“架构索引头级对应”对正确性至关重要。

2. **注意力校准提高续写质量而非 KV 拟合质量**：ATTN-REPAIR 与 Head-Local-only 相比改变 K/V R² 极小（仅 0.006/0.001 波动），但提升了 1.25 分目标保留率（95.26→96.51），并将 NLL@4K 从 2.446 压至 2.350。这验证了坐标拟合度并非足够的续写质量代理指标，接收者敏感度加权才是有效的改进途径。
