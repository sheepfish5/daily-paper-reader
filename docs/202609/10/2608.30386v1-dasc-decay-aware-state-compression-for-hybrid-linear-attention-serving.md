## 摘要
混合线性注意力架构近期已扩展到大型开放权重模型，在质量可与全注意力相竞争的同时，大幅降低了键/值（KV）缓存的增长。然而，其原地循环状态更新使缓存管理复杂化：前缀复用需要状态检查点与全注意力 KV 并存，而完整存储状态检查点会增加内存压力，导致更多逐出和重复预填充。通过分析门控 DeltaNet（GDN）和 Kimi Delta Attention（KDA）的衰减结构，我们发现不同头和通道在显著不同的时间尺度上保留前缀信息，我们将其称为保留时域（retention horizons）。这种差异表明持久状态检查点具有可观的压缩潜力。基于此观察，我们提出衰减感知状态压缩（DASC），它从模型权重中推导保留时域，选择长时域状态单元，并将它们打包成不规则状态检查点布局。为了高效集成到张量并行推理引擎中，DASC 进一步在 TP 秩间均衡压缩后的状态检查点。复用时，DASC 要么对省略的单元进行零填充，要么以额外计算代价从有界后缀刷新它们。在 Kimi-Linear 的检索与端到端推理基准上，保守的 DASC 配置在将 KDA 循环状态检查点压缩 2.63 倍的同时，仍接近完整缓存。在固定的状态检查点内存预算下，由此获得的容量增益使平均首 token 时间（TTFT）降低 42.6%，并使输入吞吐量提升 68.4%。在更高压缩比下，后缀刷新可恢复因更激进的省略而损失的大部分精度，代价是额外的重放计算。采用 GDN 的 Qwen 表现出类似的质量—效率趋势，表明 DASC 可从通道级 KDA 扩展到逐头 GDN。

## Abstract
Hybrid linear-attention architectures have recently scaled to large open-weight models, offering quality competitive with full attention while substantially reducing key/value (KV) cache growth. However, their in-place recurrent-state updates complicate cache management: prefix reuse requires state checkpoints alongside full-attention KV, while storing state checkpoints in full increases memory pressure, leading to more evictions and repeated prefill. By analyzing the decay structure of Gated DeltaNet (GDN) and Kimi Delta Attention (KDA), we find that different heads and channels retain prefix information over markedly different timescales, which we term \emph{retention horizons}. This variation suggests substantial compression potential in persistent state checkpoints. Building on this observation, we introduce \emph{Decay-Aware State Compression} (DASC), which derives retention horizons from model weights, selects long-horizon state units, and packs them into a ragged state checkpoint layout. To integrate efficiently with tensor-parallel inference engines, DASC furtherly balances compressed state checkpoints across TP ranks. On reuse, DASC either zero-fills omitted units or refreshes them from a bounded suffix with additional compute cost. Across retrieval and end-to-end reasoning benchmarks on Kimi-Linear, conservative DASC configurations remain close to full caching while compressing KDA recurrent state checkpoints by $2.63\times$. Under fixed state checkpoint memory budgets, the resulting capacity gains reduce mean Time to First Token (TTFT) by 42.6\% and improve input throughput by 68.4\%. At larger compression ratio, suffix refresh recovers much of the accuracy lost to more aggressive omission, at the cost of additional replay computation. Qwen with GDN exhibits a similar quality--efficiency trend, showing that DASC extends from channel-wise KDA to head-wise GDN.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：混合线性注意力架构（如 Qwen3-Next、Kimi-Linear，乃至万亿参数的 Qwen3.8-2.4T-A95B、Kimi K3）通过在全注意力层之间插入线性注意力层，用固定大小的循环状态汇总前缀，从而显著抑制 KV 缓存随上下文长度的增长。
- **核心矛盾**：线性注意力层是**原地更新**的——新 token 到来时会覆盖旧状态，不像全注意力 KV 那样保留历史前缀边界。因此前缀复用（prefix caching）必须在固定 token 间隔处物化完整的**状态检查点（state checkpoint）**，并与全注意力 KV 块一同存放。
- **痛点**：
  - 状态检查点包含所有线性层的巨大状态矩阵，频繁检查点会迅速耗尽 HBM；
  - 检查点稀疏则会增加重放/重复预填充（repeated prefill）开销。
- **关键观察**：GDN 与 KDA 的衰减结构显示，不同头/通道保留前缀信息的时间尺度差异巨大（称为 **retention horizons / 保留时域**）。许多单元很快遗忘远期 token，只有少数子集长期持久。这说明持久状态检查点存在可观的压缩空间。
- **整体含义**：论文把"哪些状态单元必须在每个检查点被保留"这一表示层面的问题，转化为一个**输入无关、仅由权重推导**的静态选择策略，从而在保持质量的同时大幅提升缓存驻留容量、降低 TTFT。

## 2. 方法论

### 2.1 核心思想
- 利用模型权重中固有的衰减参数，为每个状态单元估计"静态保留时域" `Hs`，据此筛选长时域单元并压缩存储，短时域单元在复用时可零填充或从有界后缀刷新。

### 2.2 关键技术细节

- **状态与衰减结构**：KDA 状态更新为 `St = S_{t-1} Diag(α_t)(I − β_t k_t k_t^T) + β_t v_t k_t^T`，其中 `α_t ∈ (0,1)^{d_k}` 为逐通道衰减；GDN 则参数化到逐头粒度。
- **权重推导的静态保留时域**：
  - GDN 的 log-decay 为 `g = −exp(A_log) · softplus(a + dt_bias)`，其中 `A_log`、`dt_bias` 为学习到的衰减参数，`a` 为输入相关门控 logit。
  - 为获得输入无关的静态度量，固定 `a = −0.3`（相比 `a = 0` 会减缓衰减、偏向保留更多单元，属于有意保守偏置）。
  - 定义静态保留时域 `Hs = ln(ε) / g`，实验统一取 `ε = 10^{-3}`。
- **选择与存储（SELECT & PACK）**：
  - 设定阈值 `Wmax`：若 `Hs(u) > Wmax` 则单元为全局（保留），否则为局部（省略）。
  - 选择粒度跟随架构的衰减粒度：**GDN 保留整头**，**KDA 保留 `(head, k)` 键通道** `S^{(l)}_{h,:,k}`。
  - 掩码仅依赖权重，**离线构建一次**，无需校准 prompt 或在线 profiling。
  - **Ragged（不规则）布局**：各层只存自己的 `r_l` 个保留单元并记录偏移，避免 padded 布局中被最宽层"钉死"分配。时间状态压缩比 `C^rag_temp = Σn_l / Σr_l`，完整检查点压缩比还须计入 BF16 卷积状态；相对 padded 的布局增益为 `Rmax / r̄`。
- **TP 均衡放置（TP-Balance）**：
  - 由于各层保留比例不均，压缩后各 TP rank 的负载可能严重倾斜，而驻留检查点数受最重 rank 限制。
  - 两阶段均衡：① 模型加载时的**头束重排置换**（对所有耦合张量施加同一置换，属精确重索引、无额外逐 token 通信）；② STORE 时把整个 TP 组视为共享存储池，以目标槽宽 `C = ⌈ΣU_r / T⌉` 通过 variable-split all-to-all 仅发送远端拥有的单元，LOAD 时做逆变换。通信仅发生在检查点存取路径，prefill 与 decode 保持计算本地化。
- **加载策略（LOAD）**：
  - **DASC-NR（默认）**：省略的局部单元置零，不增加任何模型计算。
  - **DASC-WR**：从零初始化的临时状态重放一个有界后缀，仅把刷新出的局部单元拷回活动状态；存储的全局检查点与全注意力 KV 不变。每个单元的窗口按 `W_u = clamp(next_pow2(Hs(u)), 4, Wmax)` 取上界，`W_replay = max_u W_u`。WR 仍是近似的，因为无法恢复重放窗口之前的局部状态历史。
- **与量化互补**：量化减少每个保留值的比特数，DASC 减少保留单元的数量，两者可叠加。

## 6. 主要结论与发现

- **冗余证据（表 1a）**：在 RULER NIAH-S1 上，把全注意力 KV 置零使精度降为 0；而把循环状态检查点置零，精度变化 ≤1 个百分点（GDN 0.990、KDA 1.000），说明循环状态检查点存在压缩空间。
- **静态时域有效（表 1b）**：权重推导的 `Hs` 与观测经验时域 `He` 的 Spearman 中位相关为 **0.801（GDN）/ 0.856（KDA）**；与状态幅值相关 0.632/0.533，与读出幅值相关 0.537/0.402。说明 `Hs` 能较好保持时域排序，但与"重要性"只是中等关联，因此选择必须保守。
- **衰减异质性**：KDA 通道衰减分布宽（中位 α=0.471，IQR [0.170, 0.774]），GDN 头部衰减普遍偏慢（0.969，[0.894, 0.997]）；在 16-token 截断下，90.6% 的 KDA 头同时包含两侧通道，因此按头聚合会掩盖差异——这正是 KDA 采用通道级、GDN 采用头级选择的原因。
- **质量**：`Wmax=16` 时 Kimi-KDA 在 4k/8k/16k 上为 0.95/0.95/0.95（dense 为 0.95/0.96/0.95），Qwen-GDN 为 0.84/0.83/0.81（dense 0.84/0.83/0.80），所有聚合值均在 dense 的 0.01 以内。`Wmax=1024` 时 Kimi-KDA 下降 0.04/0.06/0.07，主要损失集中在 16k 的 MK1、MV、CWE、QA-S。
- **端到端**：`Wmax=16` 时 DASC 每行均在 dense 的 1.3 个百分点内；Kimi-KDA 在全部 15 项推理比较中优于 5 掩码随机均值，其中 7 项经 Holm 校正后仍显著。
- **服务性能**：TP 均衡后，通道级 KDA 实现 **2.63–28.04×** 检查点压缩（`Wmax=16–512`），头级 GDN 为 **1.10–2.48×**。KDA 上 TTFT 降低 **25.4–42.6%**、输入吞吐提升 **39.3–68.4%**；`Wmax=16` 时 TTFT 从 567.6 ms 降至 326.0 ms，吞吐从 33.25 升至 55.98 k tokens/s。GDN 在 `Wmax=512` 时 TTFT 从 614.4 降至 374.5 ms，吞吐从 30.56 升至 50.96 k tokens/s。
- **后缀刷新的权衡**：`Wmax=128` 时 DASC-WR 相对 NR 在五个端任务上提升 0.8–7.4 个百分点；MMLU-Pro 上 NR 从 66.94% 降至 60.17%，而 WR 保持在 66.59–67.19%（dense 67.50%）。最佳折衷点是 `Wmax=16` 的 DASC-NR：TTFT 降 42.6%、精度仅损失 0.56 个百分点。
- **与量化组合**：`Wmax=16` 通道选择 + INT8 状态存储 + DASC-NR 达到 **8.11×** 检查点容量，且五个端任务精度基本无损（如 AIME 0.6073→0.6219）。
- **跨架构泛化**：DASC 可从通道级 KDA 推广到头级 GDN，但 GDN 因粒度更粗而收益更小。

## 7. 优点

- **问题定位精准**：把混合线性注意力前缀缓存中"状态检查点该存多少"这一被忽视的表示维度问题单独拎出，与已有的条目准入/逐出策略（如 Marconi）和重放策略（ReplaySSM）正交、可互补。
- **信号设计优雅**：用权重中的衰减参数推导**输入无关、离线一次计算**的保留时域，避免了请求级动态 profiling 的工程复杂度，且刻意用 `a=−0.3` 偏向保守，降低了误删风险。
- **选择粒度贴合架构**：识别出 KDA 需通道级、GDN 只需头级，并通过 90.6% 混合头的统计证据支撑该设计，而非拍脑袋。
- **系统实现完整**：ragged 打包 + 两阶段精确 TP 均衡 + 存取路径 all-to-all，且明确保证"均衡是精确的、不引入额外近似"，通信仅局限在 STORE/LOAD。
- **NR/WR 分离的双路径设计**：默认路径零成本，激进压缩时

可选择性启用有界后缀刷新，把"零成本默认"与"高保真选项"解耦，工程上易于分阶段落地。

- **实验对照严谨**：计数匹配随机掩码把"压缩比"固定、只比较选择准则，直接隔离了衰减感知排序本身的贡献；配对 bootstrap + Holm 校正也避免了多臂比较的假阳性膨胀。
- **结论颗粒度诚实**：论文没有宣称 DASC 是"无损"的，而是明确指出 WR 仍是近似的（重放窗口之前的局部历史不可恢复）、`Hs` 与重要性仅中等相关（0.4–0.6），并因此把选择偏置向保守方向调，这种自我限定的表述提升了可信度。
- **与量化正交可叠加**：`Wmax=16` + INT8 达到 8.11× 容量且精度基本无损，说明该表示压缩与比特压缩是两条独立的收益曲线，组合空间大。

## 8. 不足与局限

- **算力与硬件信息不透明**：只说明"Hopper GPU、TP8"，未给出 GPU 型号（H100/H200/H800？）、节点数、总 GPU 时。对服务系统论文而言，TTFT/吞吐的绝对值强依赖硬件与实现细节，缺少这些信息会削弱跨环境可比性。
- **部分结论的网格覆盖有限**：`Wmax` 只扫到 {16, 64, 128, 512, 1024}，且 `Wmax=16` 已是压缩率最高档；是否存在比 16 更小、精度仍可接受的工作点并未探索，GDN 的"压缩上限"因此更像区间内的观察而非真正的上界。
- **`ε = 10^{-3}` 与 `a = −0.3` 两个超参缺乏敏感性分析**：前者决定 `Hs` 的绝对尺度（进而决定哪些单元被划为"全局"），后者是人为的保守偏置。论文未报告在这两个量上做扫描的结果，读者难以判断结论对该选择有多敏感。
- **`Hs` 与"重要性"相关性只有中等**：0.4–0.6 的读出/幅值相关意味着衰减感知排序并非最优准则，只是"够用且便宜"。论文用计数匹配随机对照证明了它优于随机，但没有与更强的重要性度量（如激活幅值、梯度、注意力贡献）做同预算对比，因此"最优性"未被确立。
- **匹配 HBM 服务实验是受控回放负载**：基于 MMLU-Pro 构造的固定前缀复用模式，六个阶段的人工容量边界，而非真实生产到达分布。真实场景中前缀复用率、并发波动、检查点命中率的时间局部性都可能不同，2.63–28.04× 的压缩率能否线性转化为端到端收益仍需生产验证。
- **DASC-WR 的近似误差未做理论刻画**：论文承认无法恢复重放窗口前的局部状态，但只给出经验上的精度恢复（MMLU-Pro 66.59–67.19% vs dense 67.50%），没有给出误差上界或随对话轮数增长的衰减行为分析。
- **TP 均衡引入的通信开销未单独量化**：all-to-all 只发生在 STORE/LOAD 路径，论文强调"prefill 与 decode 保持计算本地化"，但未报告该通信在检查点密集命中场景下的绝对时间占比，因此"均衡净收益"的边界条件不清晰。
- **GDN 收益明显弱于 KDA**（1.10–2.48× vs 2.63–28.04×）：论文归因于头级粒度更粗，但未进一步讨论是否可以用更细的 GDN 选择粒度（如对 head 内部做低秩/通道分组近似）来缩小差距。
- **未评估对训练/微调的影响**：DASC 是纯推理侧方法，但如果模型后续微调导致衰减参数漂移，离线掩码需要重算——论文未讨论掩码的鲁棒性或重算触发条件。

## 9. 启示与可拓展方向

- **把"表示维度"的压缩思路推广到其他循环结构**：Mamba-2、RWKV、xLSTM 等同样有逐通道/逐头衰减，`Hs` 式静态时域推导原则上可直接迁移。
- **与条目级缓存管理策略联合优化**：Marconi 式的准入/逐出决定"存哪些前缀"，DASC 决定"每个前缀存多少"，两者可构成二维联合调度问题。
- **动态与静态信号的混合**：既然 `Hs` 与重要性只中等相关，可考虑以 `Hs` 为离线先验、辅以极轻量的在线统计（如状态幅值滑动估计）做二阶修正，在几乎不增加工程复杂度的前提下提升选择质量。
- **更细粒度的 GDN 选择**：若能证明 GDN 头部内部的衰减异质性足够大，可考虑按 `(head, 通道组)` 而非整头选择，把 KDA 的通道级收益部分迁移到 GDN。
- **面向真实 trace 的服务评估**：用生产级前缀复用分布（含命中率波动、突发并发）验证压缩率到端到端 TTFT/吞吐的转化效率。
- **误差可控的 WR 变体**：为后缀刷新引入可证明的误差界，或按 `Hs` 分层决定重放窗口预算，使"精度-算力"权衡更可预测。

## 10. 一句话总结

DASC 抓住了混合线性注意力前缀缓存中被忽视的"状态检查点表示冗余"问题，用**权重派生的输入无关保留时域**做离线选择、以**架构对齐的粒度**（KDA 通道级 / GDN 头级）压缩、再以**精确 TP 均衡**消除负载倾斜，在质量基本无损的前提下把检查点容量提升至 2.63–28.04×（KDA）/ 1.10–2.48×（GDN），TTFT 最多降 42.6%，并与 INT8 量化叠加达 8.11×——是一项动机清晰、系统完整、对照严谨的推理侧工程贡献，其主要短板在于硬件细节缺失、超参敏感性未探、以及服务评估仍停留在受控回放负载。
