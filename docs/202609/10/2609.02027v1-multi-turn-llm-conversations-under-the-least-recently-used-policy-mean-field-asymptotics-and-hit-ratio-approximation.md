## 摘要
现代大型语言模型（LLM）服务系统的主要工作负载已从单次LLM调用转向多轮对话，其中新的回复基于此前所有轮次的完整对话历史生成。因此，命中率，即直接从存储于高带宽内存（HBM）中的现有缓存访问的KV缓存平均比例，是决定系统性能的关键指标。由于系统动力学复杂，估计命中率是一项非常困难的任务：KV缓存前缀随轮次增长，且受限于有限内存容量，部分缓存必须被逐出。我们将该系统建模为最近最少使用（LRU）策略下的多轮对话模型。通过平均场渐近框架，我们证明：当对话到达率和内存容量按比例趋于无穷大时，命中率收敛到一个闭式极限。基于该极限的刻画，我们进一步提出了一种实用的命中率估计器，并通过在Ascend NPU上实现的Qwen3-8B模型上进行的真实LLM服务实验验证了其准确性。我们的结果为多轮LLM服务系统的分析提供了理论基础，并为内存容量配置提供了实用指南。

## Abstract
The major workloads in modern large language model (LLM) serving systems have shifted from single-shot LLM calls to multi-turn conversations, where new responses are generated based on the whole conversation history across all previous turns. The hit ratio, i.e., the average fraction of KV caches accessed directly from existing caches stored in high-bandwidth memory (HBM), is hence a crucial metric that governs system performance. Estimating the hit ratio is a highly nontrivial task due to the complex system dynamics, where the KV cache prefixes grow with turns and some must be evicted due to finite memory capacity. We formulate the system as a multi-turn conversation model under the least-recently-used (LRU) policy. Through a mean-field asymptotic framework, we prove that as the conversation arrival rate and the memory capacity grow proportionally to infinity, the hit ratio converges to a closed-form limit. Based on the characterization of the limit, we further propose a practical hit ratio estimator, and validate its accuracy by real LLM serving experiments on the Qwen3-8B model implemented on Ascend NPUs. Our results provide a theoretical foundation for the analysis of multi-turn LLM serving systems and a practical guideline for memory capacity provisioning.

- **上下文缓存（context caching）是关键对策**：将已生成的 KV cache 存入 HBM 复用，可避免重复 prefill，大幅降低 TTFT 与推理成本（DeepSeek 报告 128K 重复输入的 TTFT 从 13s 降至 500ms，命中部分按 1/10 计价）。

## 2. 方法论

### 2.1 建模框架：多轮对话模型（MCM）

- 采用 **Prefill-Decode 分离架构**（1 个 prefiller + decoder 池），HBM 容量为 N 个 KV block。
- 对话按 **Poisson 过程**到达（速率 λ₀）；轮数 M 独立同分布；轮内间隔 W 独立同分布、CDF 为 F。
- 关键记号：
  - 第 1 轮增量 Z₁ = X₁；第 j 轮增量 **Z_j = X_j + Y_{j−1}**（新 prompt 块 + 上一轮回复块）；
  - 第 j 轮后历史规模 **R_j = Σ_{ℓ≤j} Z_ℓ**；
  - 生命周期总块数 **B := R_M**。
- **假设**：{Z_j} 与 M 独立；B 的矩母函数在 0 附近有限（E[e^{θ₀B}] < ∞，轻尾）；W 的 CDF 满足 Lipschitz 连续。
- **命中率定义**：h = E[Σ_{j=2}^{M} R_{j−1} H_j] / E[Σ_{j=1}^{M} R_j]，其中 H_j 为"第 j 轮到达时 R_{j−1} 历史块仍驻留 HBM"的指示变量。
- **内在上界**：h ≤ h_max = A_H / A_R，其中 A_R = E[Σ R_j]、A_H = E[Σ_{j=1}^{M−1} R_j]；该上界只依赖负载统计结构，与缓存策略、到达动态无关（在 SCM 特例下 h_max = p，即续谈概率）。

### 2.2 驱逐策略：整内容 LRU（whole-content LRU）

- 系统维护从 MRU 到 LRU 的有序驻留列表；命中则把对话移至 MRU 并替换为扩大后的内容；未命中则插入 MRU。
- 超出容量时**从 LRU 端整体逐出完整对话内容**，直至满足容量约束（Algorithm 1）。命中即全部 R_{j−1} 块复用，未命中则全部不命中。

### 2.3 平均场渐近框架（核心技术）

- **缩放制度**：令 λ₀^(N) = N λ₀，即对话到达率与 HBM 容量同比趋于无穷；其余原语（F、M、增量分布）保持不变。等价解释：固定 λ₀ 而把轮内间隔分布按 F(·/N) 缩放（更贴近实验做法）。
- **标记对话位移过程**：标记某对话在其第 j 轮访问后置于 MRU，研究此后其他对话"越过"它而累积的块质量 D_{N,j}(t)，归一化为 D_{N,j}(t)/N；用 Palm 构造 + Slivnyak 定理，得到标记 Poisson 随机测度表示（Lemma D.1），并证明其分布与标记轮次 j 无关。

## 6. 主要结论与发现

- **理论**：在到达率与容量同比趋于无穷的平均场缩放下，LRU 下多轮对话的命中率收敛到**闭式极限** h^(∞) = (A_H/A_R)·F(T_C)（实用版为 (A_H^hash/A_R)·F(T_C^prac)），并给出非渐近误差界与 O_P(N^{−1/2}) / O_P(N^{−1/3}) 收敛速率。
- **命中率由三要素决定**：内在复用潜力 A_H/A_R（负载结构）、特征时间 T

C（缓存被"位移质量"填满的时间尺度）、以及 F(T_C)（下一轮 prompt 赶在驱逐前到达的概率）。三者相乘即为极限命中率，缺一不可。
- **反直觉的方向性结论**：**到达率越高，命中率反而越低**。因为 λ₀ 增大同时放大 d(t) 的两项（新块生成 + 历史前缀推进），使 T_C = d⁻¹(1) 缩短，从而压低 F(T_C)。这与"流量越大缓存越有效"的朴素直觉相反，根源在于 KV 前缀随轮次单调增长、且对话终止后其块失去复用价值。
- **上界的可达性**：h^(∞) ≤ h_max = A_H/A_R，且当 F(T_C) → 1（即轮内间隔远小于缓存冲刷时间）时上界可达。因此 h_max 给出了**任何缓存策略在该负载下都无法突破的天花板**，可作为策略评估的绝对标尺。
- **实验验证**：两组实验的估计命中率与在线实测命中率在同一量级且趋势一致；posterior 估计器（用实测 μ̂_F）普遍优于 prior 估计器（用目标指数分布），说明误差主要来自分布假设失配而非模型结构本身；Exp 2 中命中率随 λ₀ 增大而下降，与理论预测方向吻合。
- **工程可用性**：估计器只需聚合统计量（Â_R、Â_H^hash、Ê[B]、F̂）即可闭式求解，**无需逐条对话轨迹、无需在线试跑**，可用于容量规划（给定目标命中率反解所需 HBM block 数 N）、SLA 设计与缓存定价。

## 7. 局限与未来工作

- **模型假设较强**：Poisson 到达、轮内间隔独立同分布、轮数 M 与增量 Z_j 独立、B 轻尾（矩母函数在 0 附近有限）。真实 agent 负载中，间隔常与任务复杂度相关、轮数分布可能重尾，这些都会削弱收敛速率甚至改变极限形式。
- **策略覆盖单一**：仅分析 **whole-content LRU**（整对话为驱逐单元）。真实系统多采用 **block 级前缀树 + LRU/partial-content** 驱逐，同一对话的不同前缀块可被不同对话共享，本文模型未刻画跨对话的**前缀共享**。
- **未建模存储层级**：只区分"HBM 驻留 / 不驻留"，忽略 CPU DRAM、SSD 等下层缓存的搬运带宽与延迟，也未纳入 KV 传输（Mooncake）开销对时序反馈的影响。
- **哈希尾部块处理是启发式**：以"每轮扣除 1 个不可哈希块"近似未填满 block 的影响，未给出该近似与真实 tokenizer/分块器行为的误差界。
- **实验外推性有限**：单一数据集（ShareGPT）、单一模型（Qwen3-8B）、单一硬件（Ascend 910B2）、固定 N = 2,275，缺乏对 N、模型规模、数据集、并发模式的敏感性分析，也缺少与经典 LRU 命中率近似方法（Che 近似、TTL、working-set）的横向对比。
- **平均场制度的现实性**：理论要求 λ₀ 与 N 同比趋于无穷，而真实部署中二者均为有限值；论文未量化"有限 N 下估计器偏差随 N 衰减"的经验速度。

## 8. 总体评价

- **理论贡献扎实**：首次为"多轮 LLM 对话 + 单调增长前缀 + 有限复用寿命 + 整内容 LRU"这一组合给出了命中率的**闭式平均场极限**，推导链条完整（Palm 构造 → Slivnyak → 位移过程 → 特征时间 → 命中率），并附非渐近误差界与 O_P(N^{−1/2})/O_P(N^{−1/3}) 收敛速率，方法论上较有新意。
- **与经典工作的区分点清晰**：经典 LRU 命中率近似（Che、Fagin、Dan–Towsley）多针对**固定大小对象**，本文处理的是**大小随轮次单调增长、生命周期有限**的对象，这是 LLM 场景特有的结构。
- **实用价值明确**：把"命中率"从"只能实测"变为"可由少量聚合统计量预先估算"，对 LLM 服务的容量规划与成本建模有直接指导意义；h_max 作为策略无关上界亦具诊断价值。
- **主要短板在实验**：验证规模偏小、无 baseline 对比、无消融与敏感性分析，属于"理论为主、实验为辅"的论文形态。若补充 N 扫描、多数据集/多模型复现、与既有 LRU 近似方法的对比，说服力会显著提升。
- **总体定位**：一篇**理论驱动、工程导向**的系统分析论文，核心增量在于平均场框架与闭式命中率公式，实验部分更接近概念验证（proof-of-concept）而非全面基准评测。
