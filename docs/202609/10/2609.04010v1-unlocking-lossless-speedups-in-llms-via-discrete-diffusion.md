## 摘要
大语言模型（LLM）的成功在很大程度上归功于下一 token 预测（NTP），但其自回归（AR）结构需要缓慢的顺序 token 生成。为克服这一瓶颈，我们引入了扩散增强的 LLM，这是一类在定义自回归模型分布的同时，利用扩散从该分布中并行采样多个 token 的新型模型。我们将这些模型的参数解耦为两组：使用标准 NTP 目标训练的 AR 权重，以及经过训练以同时生成多个 token 的轻量级扩散权重。扩散权重通过一个简单的扩散蒸馏阶段学习，为现有 LLM 训练流程增加的开销可忽略不计。我们还引入了 $Ψ$-Spec，这是一族采样器，能够在固定上下文长度下实现无损加速和推理时扩展。与推测解码不同，我们的方法不需要单独的草稿模型。与扩散 LLM（d-LLM）不同，它在加速生成的同时不会牺牲底层 AR 模型的质量。由此得到的模型称为 Uno，可以从头训练，也可以通过增强现有的开放权重 AR LLM 来构建。在所有评估的批量大小下，Uno 的吞吐量均高于领先的推测解码方法，并且相比基础 AR 模型最高可实现 3 倍加速，包括在设备支持的最大批量大小下。值得注意的是，我们的 8B Uno 模型在智能体工具使用、编码和长上下文推理的所有评估基准上，均优于领先的开放 d-LLM——26B DiffusionGemma，以及专有模型 Mercury 2。我们在以下网址发布代码和检查点：https://s-sahoo.github.io/uno/

## Abstract
Large Language Models (LLMs) owe much of their success to next-token prediction (NTP), but their autoregressive (AR) structure requires slow, sequential token generation. To overcome this bottleneck, we introduce diffusion-augmented LLMs, a new class of models that defines an AR model distribution while using diffusion to draw multiple tokens in parallel from that distribution. We decouple the parameters of these models into two sets: AR weights, trained using the standard NTP objective, and lightweight diffusion weights, trained to generate multiple tokens simultaneously. The diffusion weights are learned through a simple Diffusion Distillation phase that adds negligible overhead to existing LLM training pipelines. We also introduce $Ψ$-Spec, a family of samplers that enables lossless acceleration and inference-time scaling at a fixed context length. Unlike speculative decoding, our method requires no separate draft model. Unlike diffusion LLMs (d-LLMs), it accelerates generation without sacrificing the quality of the underlying AR model. The resulting models, called Uno, can be trained from scratch or built by augmenting existing open-weight AR LLMs. Uno achieves higher throughput than leading speculative-decoding methods at every evaluated batch size and delivers up to $3\times$ speedups over the base AR model, including at the largest batch size supported by the device. Notably, our 8B Uno model outperforms the leading open d-LLM, the 26B DiffusionGemma, and the proprietary Mercury 2 across all evaluated benchmarks in agentic tool use, coding, and long-context reasoning. We release code and checkpoints at: https://s-sahoo.github.io/uno/

# 论文总结：Unlocking Lossless Speedups in LLMs via Discrete Diffusion

## 1. 核心问题与整体含义

- **背景**：LLM 的成功很大程度上依赖下一 token 预测（NTP），但其自回归（AR）结构导致推理必须逐 token 顺序生成，速度慢且随推理链变长而愈发昂贵。
- **瓶颈本质**：
  - 顺序解码与自然语言中大量可预测的固定搭配、公式化片段不匹配；
  - 解码通常是内存受限的（memory bound），权重与 KV 状态的搬运限制了 GPU 利用率。
- **现有方案的两难**：
  - **投机解码**（如 EAGLE-3、DFlash）虽无损，但需额外的草稿模型，收益依赖草稿器质量，且需维护独立模型；
  - **扩散 LLM**（d-LLM，如 DiffusionGemma、Mercury 2）可并行生成，但存在质量-速度权衡，加速往往是**有损**的，且在大批量下加速消失；
  - **多 token 预测（MTP）** 需修改 Transformer 架构。
- **整体含义**：论文提出**扩散增强 LLM**（diffusion-augmented LLM），在定义 AR 模型分布的同时，用扩散并行采样多个 token，实现**无损加速**且**无需独立草稿模型**，兼顾质量与速度。所得模型称为 **Uno**。

## 2. 方法论

### 核心思想
- 在单个架构内**解耦两组权重**：
  - **AR 权重 θ_AR**：用标准 NTP 目标训练，决定响应质量；
  - **扩散权重 θ_∆**：轻量级，专用于并行生成 token。
- 每层均含两套权重，扩散权重以 **LoRA 适配器**（rank-128，LoRA-α=256）形式叠加在 AR 权重上（θ_AR + θ_∆）。
- 生成时两套权重并行起草 token，**仅由 AR 权重验证**，采样器可证明保持 AR 输出分布，实现无损加速。

### 关键技术细节
- **Diffusion Distillation 阶段**：冻结 θ_AR，仅训练 θ_∆。
  - **一步蒸馏（One-step Distillation）**：将整条去噪轨迹蒸馏为单步，直接把完全腐蚀的 z₁ 映射到干净序列 x，无需模拟中间 PF-ODE 状态。
  - **块扩散（Block Diffusion）**：将序列分块（大小 B），块内并行去噪，块间保持因果；使用**门控 LoRA**（gated LoRA）在干净位置关闭适配器、在噪声位置启用，从而单次前向同时得到教师（AR）与学生（扩散）logits。
  - **总变差损失 L_TV**：最小化扩散分布与 AR 分布的块级 TV 距离，提升连续 token 被接受的概率，从而增加接受前缀长度。
  - **总损失**：L(θ_∆) = E[α·L_DCD + β·L_TV]，实践中 α=0.01、β=1 或纯 TV（α=0, β=1）效果最好。
- **Ψ-Spec 采样器**：
  - 用扩散通路并行起草一个块（Linear 采样器采单个候选；Tree 采样器用 top-K + 前缀预算 V 采多个候选）；
  - 用标准投机解码的**拒绝采样**对 AR 分布验证，保留最长被接受前缀；
  - 单步扩散生成下，起草分布退化为 z₁⁰ ∼ x_θAR(·)，z₂:ᵦ⁰ ∼ ∏ x_θAR,θ∆(·)；
  - **TPF（Tokens-Per-Forward-pass）** 满足 1 ≤ TPF ≤ (B+1)/2，因每步需两次前向（起草+验证）。
- **推理时扩展**：允许去噪步数 T 超过起草 token 数 B，在固定上下文长度下增加算力换质量，为未来工作。

### 训练课程（两种场景）
- **仅加速推理**：完成 AR 预训练/后训练（或直接初始化开源权重）后，冻结 θ_AR，蒸馏 θ_∆；
- **同时加速 RL 训练与推理**：在 SFT 后、RL 前进行扩散蒸馏，适配器可加速 RL rollout；RL（PPO/GRPO/DAPO）仅更新 θ_AR，不更新 θ_∆。

## 6. 主要结论与发现

- **Uno 匹配基座 AR 质量**，在所有批量下吞吐更高：batch size 1 约 **2.2×**，最大批量（64）约 **1.5×**，最高可达 **3×** 加速。
- **8B Uno 全面优于 26B DiffusionGemma、Nemotron-Labs-Diffusion 与 Mercury 2**（Agentic 工具使用、编程、长上下文推理），并在系统吞吐上更高（Mercury 2 的 ~4.6×，且 Uno 运行在更慢硬件上）。
- **Uno_Qwen 严格快于 EAGLE-3 和 DFlash**：系统吞吐 >5700 tok/s（1.6× 基座），单请求 2.5× 基座，且参数更少、共享 KV cache、峰值内存更低。
- **RL 训练加速**：SFT 扩散适配器在 RL 后仍保留加速，TPF 仅下降约 6%；端到端 RL 训练加速最高 **40%**（数学与代码专家）。
- **跨数据分布有效**：扩散权重可在与 AR 训练数据不同的分布（OpenThoughts）上训练，仍实现无损加速。
- **扩散权重训练成本极低**：仅需约 7B token，远少于 AR 权重的 23T token。

## 7. 优点

- **无损性**：Ψ-Spec 采样器保留 AR 分布，质量不受加速影响，区别于有损 d-LLM 与自投机方法。
- **无需独立草稿模型**：单架构、共享 KV cache，参数开销小（0.35B），峰值内存低于 EAGLE-3/DFlash。
- **批量鲁棒性**：加速在从小到大所有批量下持续，适合智能体并发工作负载与 RL rollout。
- **可插拔**：可从头训练，也可直接增强现有开源 AR LLM，训练开销可忽略。
- **训练效率**：Diffusion Distillation 仅需少量 token；DFlash 训练上下文为 B·L，本方法恒为 2·L。
- **评测规范**：统一 1K/8K 吞吐测试，避免因推理链长度不同导致的误导；区分系统吞吐与单请求吞吐。

## 8. 不足与局限

- **数据不可复现**：从零训练的 Uno 使用专有内部数据，无法完全复现。
- **部分基线不可控**：Mercury 2 参数量、量化方式未公开；部分结果取自 Artificial Analysis，硬件与精度条件不完全一致。
- **推理时扩展未充分探索**：论文提出 T > B 的去噪步数扩展可超越 AR 质量，但明确留待未来工作，未给出系统实验。
- **应用限制**：
  - 需额外训练扩散适配器（虽开销小，但仍需一定算力）；
  - 依赖 gated LoRA 与特定采样器实现（Nano-vLLM / SGLang）；
  - 工具使用与搜索类任务的加速较小（受工具调用耗时主导）；
  - 与 MTP 架构改动的结合、二次采样（quadratic sampler）等未验证。
- **潜在偏差**：无损方法不报告准确率，难以直接观察质量差异；树采样器超参（B,K,V）需网格搜索，最优配置随任务与批量变化。
